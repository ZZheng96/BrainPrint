# E122 PCA-96 SPD deployment: three-way audit

E121 证明 PCA-96 投影把 Test S1-vs-S2 诊断 AUC 从 0.6854 提到 0.7658。本实验把该分数完整部署，同时报告三项必需指标。

| 原型数 | LOSO 拒识 | LOSO AUC | Test S1 拒识 | Test S2 接受 |
|---|---:|---:|---:|---:|
| k1 | 0.6261 | 0.8579 | 0.7916 | 0.5823 |
| k3 | 0.8301 | 0.9192 | 0.9245 | 0.3799 |

三项同时达标要求：LOSO 拒识高、Test S1 拒识高、Test S2 接受高。

## 结论：本实验是迄今三项综合最优

| 方案 | LOSO 拒识 | Test S1 拒识 | Test S2 接受 | 三项最小值 |
|---|---:|---:|---:|---:|
| E95（旧） | 0.899 | 0.1543 | **0.9414** | 0.1543 |
| E102 SPD ratio（旧） | 0.831 | **0.8427** | 0.2873 | 0.2873 |
| E118 C7（旧） | 0.842 | 0.7362 | 0.3278 | 0.3278 |
| **E122 k1** | 0.6261 | **0.7916** | 0.5823 | **0.5823** |
| E122 k3 | **0.8301** | **0.9245** | 0.3799 | 0.3799 |

**E122 k1 把"三项最小值"从 0.3278 提到 0.5823**，是重大进步：

- Test S1 拒识 0.7916（接近 0.80 目标）
- Test S2 接受 0.5823（比 E102 的 0.2873 高一倍）
- LOSO 拒识 0.6261（比 E95 的 0.899 低，但仍显著高于随机）

**E122 k3 走另一个极端**：LOSO 0.8301 和 S1 0.9245 都很高，但 S2 掉到 0.3799。

## 关键机制

PCA-96 投影是本次突破的来源：

1. **降维过滤掉了跨 Session 不稳定的高频噪声方向**。855 维 logSPD 中大量方向的方差由采集噪声主导，跨 Session 不一致；PCA 保留的前 96 维更稳定。
2. **Test 诊断 AUC 从 0.6854 提到 0.7658**（+12%），这是所有 20+ 个实验中唯一提升了 Test 可分性的操作。
3. **单原型（k=1）优于多原型（k=3）**：在 Test 上，3 个 k-means 中心收窄了每个身份的接受域，导致 S2 接受率腰斩（0.5823 → 0.3799）。多原型只在 LOSO 上有益，因为 LOSO 的分布比 Test 更接近 Train。

## 仍未达标

三项都还没到目标（LOSO ≥0.80、S1 ≥0.80、S2 ≥0.85）。差距分别约 0.17、0.01、0.27。

**S1 已经非常接近**（0.7916 vs 0.80），**S2 是最大缺口**（0.5823 vs 0.85）。
