# E233 跨段偏移 δ 的直接估计与对称移除

> **一句话结论**：`mean_align`（逐 (session,task) 批次均值对齐）按点估计达标——冻结 tau 下 Test S2 **0.3122**（基线 0.3043，+0.0079），S1 拒识 1.0000（基线 0.9637，已饱和），分离 AUC 0.8795，簇纯度守住；但整簇重采样的 ΔS2 95% CI 跨 0，属边际改进。
S1≥0.95 约束下 S2 = **0.7569**（基线同约束 0.3360，`mean_align`）；S1≥0.70 约束下 S2 = **0.8441**（基线 0.6809）。两道门槛的差异与原因见第 2 节。

**两种读法为何差这么多（必须分开看）**

基线的 S1 分数中位数 -35.81、95% 分位 -24.53，S2 分数中位数 -26.52，E228 部署 tau = -24.14。
1. **冻结 tau 读法**（不随候选调整、完全 Train-only）：`S2 acc` 列。它衡量的是"E228 标定的那一个阈值"下的接受率，最保守、也最可比。
2. **S1 门槛读法**（把 tau 调到该候选自身 S1 分布的 95% 分位）：`S2@S1.95` 列。它衡量"在同样拒掉 95% S1"的前提下能接受多少 S2，是官方约束的标准读法，但阈值由 Test S1 分数决定（transductive），且 S1 只有 5 名未注册被试（E232 混叠），所以数字偏乐观。
两者方向一致但幅度差异巨大：对齐把 S1 整体推到更远离原型的位置（S1 分数整体下移、S1/S2 分离度上升），因此同样的 95% S1 拒识对应的 tau 更低、S2 能过得更多。**冻结 tau 的 S2 增益（+0.0079）不应被当作该方案的全部价值，+0.42 的门槛增益也不应被当作纯生物特征增益。**

## 6. 判定

- **达标并冻结**：`mean_align`。LOSO 拒识 0.9000（在 [0.89,0.91]）、Test S1 1.0000 ≥ 0.95、Test S2 0.3122 > 0.3043、簇纯度 k20/k28 = 0.6350/0.6461（均 ≥ 基线 95%）。
- 增益幅度：ΔS2 = +0.0079（行级配对自助 95% CI [+0.0045, +0.0115]），ΔS1 = +0.0363，ΔsepAUC = +0.0877；同 S1 水平下 ΔS2 = +0.4337。
- 官方门槛读法：S1=0.95 时 S2 = 0.7569（基线 0.3360，+0.4209）；S1=0.70 时 S2 = 0.8441（基线 0.6809）。该增益来自 S1/S2 分离度上升（sepAUC 见上），不是"接受更多同分布样本"；但 S1 仅 5 名未注册被试，其拒识率同时承担"未注册"语义，属 E232 混叠，不能当作纯生物特征增益。
- **但增益的稳健性有限**：行级配对自助 CI 不含 0，整簇（k=20，按身份/task 相关性）重采样的 95% CI 为 [-0.0103, +0.0235]，**跨 0**；且增益几乎全部来自样本最多的 Imagery task（见第 5 节）。因此这是「方向一致的边际改进」，不是稳健的大幅提升；判定按 config 的点估计规则成立。
- 这是小幅 S2 增益且 S1 同时变好（S1 已饱和到 1.0），不是 S1/S2 权衡；纯度读数见第 3 节 `#pred`/`max share` 列（预测身份没有被压成少数几个）。

- **`coral` 被判为退化解（不可采纳）**：S2 0.3458 虽然高于基线 0.3043，但 S1 跌到 0.8365（< 0.95）、分离 AUC 从 0.7918 崩到 0.5724、簇纯度 k20/k28 = 0.5561/0.5680（基线的 87.0%/87.1%）。在同一个 S1=0.95 门槛下它的 S2 只有 0.2119（基线 0.3360）——说明它的 S2 提升完全来自把 S1 也一起放进门内，是典型的接受放宽而非身份变准。

- 参考：把基线自身的 tau 下调到恰好 S1=0.95 也能把 S2 抬到 0.3360。因此评价任何候选的 S2 增益时，必须与**同一 S1 门槛**下的基线对照，而不是只与 0.3043 比。

## 7. 限制

- **transductive 灰区**：对齐统计量来自被评分的同一批 Test 输入（无标签），属于转导式使用测试数据，是否允许需用户/赛规确认；本轮的 S1/S2 数字不能直接当作可提交方案的指标。
- **session 与注册状态混叠**（E232）：S1 = 5 名未注册被试（k=5），S2 = 20 名注册用户。因此 S1/S2 不是纯生物特征指标，"只对齐 session2"这类操作会直接泄漏注册信息，已作为退化对照标注，不构成结论。
