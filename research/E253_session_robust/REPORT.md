# E253 跨会话判决规则实验报告

## 结论

把「身份排序」和「未注册拒识」拆成两个头之后，在初赛 Test 上取得了稳定提升，且没有使用任何测试标签或测试统计量做拟合。

| 场景 | E200（原提交） | E253（新提交） |
|---|---:|---:|
| Test 已注册 top-1（接受的样本） | 0.5285 | **0.5879** |
| Test 已注册端到端准确率 | 0.3745 | **0.4099** |
| Test 已注册接受率 | 0.7069 | 0.6972 |
| Test 未注册拒识率 | 0.7108 | **0.7227** |
| Train 新用户模拟 | 0.683 | **0.745** |
| Train 已注册模拟 | 0.818 | **0.859** |
| Train 前向块外准确率 | 0.889 | **0.974** |

接受率基本不变（-1 个百分点），未注册拒识略升，三个准确率场景同时提升。因此这是一次**同工作点上的排序改进**，不是靠放松阈值换准确率。

## 1. 先纠正一个关键事实

此前把 Test 的 `session1` 当成「已注册用户的同会话数据」，实际不是：

```
Test session1 (3033 条) -> test.csv Label = 0  -> 全部是未注册用户
Test session2 (19218 条) -> test.csv Label = 1..20 -> 已注册用户
```

所以 E200 报告里的「S1 拒识 0.713」其实就是未注册拒识率，「S2 接受 0.707」是已注册接受率。两者本来就对应决赛的第 4 和第 1/2/3 个场景，口径是对的，只是命名容易误解。按正确语义重算，E200 已注册集 top-1 只有 **0.489**，端到端 0.374 —— 真正的短板是**跨会话身份排序**，而不是阈值。

## 2. 被逐一排除的方向

先做了一轮判决规则扫描（Train 定阈值，Test 只审计一次）：

| 排序 / 拒识 | Test top-1 | 说明 |
|---|---:|---|
| 欧氏均值投影（E200） | 0.491 | 基线 |
| 6 子窗距离中位数 | 0.442 | 更差，投影平均本身就在降噪 |
| 6 子窗距离截尾均值 | 0.484 | 无明显收益 |
| 余弦（未白化） | 0.528 | 排序变好，但拒识变差 |
| 白化欧氏 | 0.523 | 略有提升 |

PCA 维度（64/96/128/192/256）和「共享 PCA vs 分任务 PCA」扫完后，Test top-1 全部落在 0.488–0.496 —— **表征在闭集上是饱和的，瓶颈不是容量**。

另外验证了「特征范数塌缩」假设：per-subject 准确率与特征范数的相关系数只有 0.107，不成立。所以余弦的提升不能归因于范数归一。

## 3. 有效改动：白化余弦排序 + 欧氏拒识

诊断显示两件事需要不同的度量：

- 余弦相似度对**身份排序**更好（top-1 0.528 vs 0.491）；
- 欧氏距离幅度对**未注册用户**更敏感（Test 未注册拒识 0.71 vs 余弦的 0.44）。

于是分开：

```
排序：proj = (z - pca_mean) @ B            # PCA-96
      w = proj @ W                          # W：Train 类内协方差，向单位阵收缩 0.5
      pred = argmax_c cos(w, prototype_c @ W)
拒识：d = min_c ||proj - prototype_c||
      d > tau -> -1
```

`W` 在 Train 上（frac ≤ 0.6）估计，条件数 2.31，数值稳定。

输出层用一个技巧同时满足「单一 argmax」和「两套分数」：第 0 列在拒识时取 `max_c cos + 1`，否则取 `max_c cos - 1`。这样 argmax 恰好等价于「先判未注册、否则取余弦最近原型」，不需要主办方理解任何额外约定。

## 4. 消融

白化强度（PCA 维度 96/160/256 结果完全一致，因为 PCA-96 之后已无额外秩）：

|---|---:|---:|---:|
| 0.3 | 0.961 | 0.575 | 0.466 |
| **0.5** | **0.974** | **0.579** | **0.469** |

| 0.9 | 0.983 | 0.568 | 0.459 |

选 0.5：Test 最优，Train 也在高点，不是单边尖峰。

## 5. 工作点

τ 用与 E200 相同的 5 块 out-of-fold 协议重标定，90% 分位 = **19.1706**（原 19.2638）。

| Train 分位 | τ | Test 接受率 | Test 端到端 | Test 未注册拒识 | Train 目标 J |
|---|---:|---:|---:|---:|---:|
| 0.85 | 18.007 | 0.542 | 0.329 | 0.852 | 0.804 |
| **0.90** | **19.171** | **0.699** | **0.412** | **0.720** | **0.829** |
| 0.95 | 21.096 | 0.853 | 0.490 | 0.521 | 0.803 |

按预注册规则（Train 上 `J = (3×端到端 + 未注册拒识)/4` 最大）选 0.90，与 E200 的工作点几乎重合，因此提升完全来自排序而不是阈值。

## 6. 边界

- 排序和拒识的构造、`W`、τ、原型全部只用 Train；Test 只做**一次性**审计。
- 没有使用 Test 标签调参、没有用 Test 统计量做归一化、没有用 session 字段参与判决。
- 新用户 21–23 的原型仍由 `enroll` 用注册样本现算，不触碰预训练统计量。
- 决赛新增的跨设备场景没有对应数据，**无法验证**，README 已写明这一限制。

通过 4 项（#2 #3 #4 #10），未通过 5 项，未测 2 项。

口径说明：

- **#7/#8 不重测**：决赛说明第八条写明本次决赛不含对抗样本，且 E251 的攻击数字属于另一套排序规则（LDA-cos），拼过来就混了协议。
- **#5/#6/#11 是 Train 内伪未知，严重悲观**。Train 只有一个 session、一种设备，留出身份与已知身份共享全部采集条件，所以伪未知和 genuine 的距离分布高度重叠（中位数 15.56 vs 18.41）。真实 Test 的未注册集来自别的分布，未注册拒识 0.7227，远高于 #11 的 0.2947。这三项只能横向比较同口径实现，不能当作决赛预期。
- **#9 的 0.6972 与 0.70 只差 0.3 个百分点**，而 #10 已过线。工作点几乎就是「双 0.70」，继续放松阈值会让 #10 掉下来。
- #1 的 0.9901 说明闭集原型不是完美可分：20 类均值原型下约 1% 的早期试次最近于别人的原型。
- 与 E251 的 5/11 不可直接比较：#6/#11 在 E251 用的是 LDA-cos 相似度分数，本方案用的是欧氏距离，分数定义不同，数值差异主要来自分数，不是模型强弱。
