# E157 逐样本距离归一化（不触碰 Test 统计量）

目标：验证只对**单个样本自己的距离向量**做归一化，能否消除会话带来的整体平移/尺度变化，从而真正提升 Test S1-vs-S2 诊断 AUC，而不只是把工作点从 S1 挪到 S2。

严格合规：per-task 标准化 / PCA-96 / 原型全部只由 Train 拟合；LOSO 每折排除被评分身份，原型只用 `frac<=0.6`；五块 Train OOF 校准阈值；Test 只评分；session 仅用于诊断。Test 官方 AUC/F1：**N/A（无真实标签）**。

设备：`cuda`；E65 correlation-logSPD；k 扫描 [1, 3, 6, 12]；接受率网格 0.80–0.96。

## 分数定义（统一为“越大越像注册者”）

- `raw`：`-d1`，最近同 task 原型距离取负（E143 基准）。
- `z_profile`：把该样本的相似度向量 `-d` 用自身中位数/IQR 归一化后取最大，等价于 `(median(d) - d1) / IQR(d)`。
- `softmax_profile`：`max_j softmax(-d_j/tau) = exp(-d1/tau) / sum_j exp(-d_j/tau)`，`tau` 取 Train OOF 每个 task 的最近距离中位数。
- `rank_profile`：`d1` 在该样本自身距离向量中的分位（1 − 1/M）。由于最近距离必为最小值，它是结构性常数，只作为“该类定义不可用”的诊断。
- `ratio_d2_d1`：`d2/d1`；`d2` 是**不同身份**的最近原型距离（同身份的第 2 个原型会使 margin 退化）。越大表示次优身份越远、间隔越干净。
- `gap`：`d2-d1`，越大表示身份间隔越干净。
- `rank_ref_control`：`1 - ECDF_{Train-OOF, 同 task}(d1)`，是 raw 的单调分位重标定对照，只用于区分“排序提升”与“工作点移动”。

## 结论摘要

**最佳 W（含对照）：rank_ref_control / k=12 / 接受率 0.90 → W = 0.7002**（LOSO 0.8147 / S1 拒识 0.7969 / S2 接受 0.5945，诊断 AUC 0.7583，Train OOF AUC/F1 0.9810/0.9895）。

但 `rank_ref_control` 是 raw 的单调重标定对照，二者 AUC 只差 0.0005；真正的逐样本分数里诊断 AUC 最高的是 `softmax_profile` (0.6560)，仍比 raw (0.7578) 低 0.1018。**没有任何逐样本归一化真正提升了排序能力。**

E143 raw 基线复现：k=12、接受率 0.90 时 W=0.6958（LOSO 0.7936 / S1 0.7979 / S2 0.5960，诊断 AUC 0.7578）；参考值 W=0.6958、AUC=0.7578。

## 关键判断

- `rank_ref_control` 是 raw 的单调分位重标定，各 k 的 AUC 最大只差 0.0042（分位离散化造成的并列）；W 的微小变化来自工作点，验证了“标定只能挪工作点、不能改排序”。
- `z_profile`（k=6）把 Test 中位残移从 raw 的 -1.37sd 压到 -0.71sd，S1/S2 中位残移也几乎重合，但诊断 AUC 降到 0.5815：会话平移和身份可分性被同一个 IQR 归一化一起抹掉（与 E138 结论一致）。
- `softmax_profile` / `gap` / `ratio_d2_d1` 的诊断 AUC 分别为 0.6594 / 0.5900 / 0.6213，都低于 raw 的 0.7578。
- `rank_profile` 在自身距离向量上的分位恒等于最小值的位置（1/M），是结构性常数：AUC=0.5、W=0.5，说明“自我秩”定义不可用；W=0.5 本身也说明该目标可被常数分数套利。
- 判定标准：只有诊断 AUC 上升才算真的提升排序能力；AUC 不变而 W 变化只是工作点移动。本实验中没有任何纯逐样本分数通过该标准。
