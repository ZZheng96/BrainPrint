## 4. 证据边界

- Test 无真值，`C_full` 与 `A` 都是假设值，代理分只能用于工作点之间的相对比较，不是官方分。
- RA 代理 1.0000 是**同会话噪声扰动**下的结果；Test 的对抗样本同样来自跨会话记录，真实 RA 会更低。
- 距离型拒识在 Test 上 AUC 0.758，仍不是强判别（理想 >0.9），因此 U 与 C 的换算存在误差。

## 5. 关于「Test S2 是否大多为未注册」的定量检验

用户提出「Test S2 大多是未注册」。这件事可以用第 1 次提交的 69.17 反推检验：

第 1 次提交对**全部** Session1 输出 0、**全部** Session2 输出身份。设未注册样本中有比例 `p` 落在 Session1，
则 U = p。官方公式：

```
69.17 = 100 · C^0.40 · (0.7·RA + 0.3·ASafeR)^0.35 · U^0.25
```

若 Session2 有一半是未注册，则 `p ≤ 3033/(3033+9609) = 0.24`，`U^0.25 ≤ 0.70`，
反推需要 `C^0.40 · A^0.35 ≥ 0.988`。即使取 `C = A`，也要 `C ≥ 0.984` —— 即正常识别与对抗识别
都要接近 100%，这对任何模型都不可能。

反过来，若 `p = 1`（未注册全在 Session1），只需 `C ≈ A ≈ 0.61` 即可得到 69.17，这与真实模型水平相符。

**结论：69.17 这个分数在数学上排除了「Session2 大多数是未注册」的可能。**
前置条件是官方公式与 U 的定义如赛题说明所述；如果这一点有变化，需要重新推算。

另一个直接的分布证据：到最近注册类中心的距离中位数
`Train 29.68 < Test S2 31.26 < Test S1 34.33`。
若 S2 大多是未注册，它应该和 S1 一样远，而不是明显更近。
