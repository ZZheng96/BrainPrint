# 基于 Session 结构先验的下一轮改进与试验方案

日期：2026-11-07

## 1. 核心判断

用户的推测具有较强数据结构支持，可以作为**预赛竞赛先验**使用：

- H1：Test `session1` 很可能主要是 5 名未注册被试，标签为 0。
- H2：Test `session2` 很可能主要是 20 名注册被试的正常样本及其对抗扰动样本，标签为 1–20。

但 H1/H2 仍不是官方逐 Trial 真值。后续应采用双轨：

1. **竞赛轨**：允许使用 Session 先验，目标是提高本次预赛的有效得分。
2. **科研轨**：不使用 Session 拒识，继续报告纯 EEG 开集性能，作为真实方法能力和决赛迁移的约束。

现有正式候选已经使用 `session1 → 0`。因此下一步不是重复该规则，而是解决 **session2 上注册者身份是否分对、正常与对抗样本是否保持一致**。当前主要瓶颈已从“闭集身份不可分”转为“跨 Session 身份识别与对抗鲁棒性”。

## 2. 已知证据与当前基线

### 2.1 测试结构

| Session | EC | EO | Imagery | SSVEP | 合计 |
|---|---:|---:|---:|---:|---:|
| session1 | 292 | 291 | 1,459 | 991 | **3,033** |
| session2 | 1,680 | 2,021 | 9,748 | 5,769 | **19,218** |

支持上述推测的观察：

- 赛题说明明确：20 名多会话被试为注册者，另外 5 名单会话被试为未注册者。
- Train 只有注册者的 Session1；Test 同时出现 Session1 和 Session2。
- Test Session2 的 19,218 条恰好等于 `2 × 9,609`，与正常样本和对抗样本成对加入的设计相容。
- Session2 内已找到大量高相似波形关系；现有图包含 3,492 个多样本组件，覆盖 10,205 条 Session2 Trial。

这些证据支持竞赛假设，但不能推出每条 Session1 都是 0、每条 Session2 都非 0，也不能直接识别哪条是对抗样本。

### 2.2 当前结果

- 纯 EEG `base_target_zscore`：内部嵌套伪未知验证 AUROC **0.9960**、macro-F1 **0.9653**、unknown-F1 **0.9746**，C=0.9424、U=0.9951。
- 上述结果只来自 Train Session1，不是真实跨 Session 或测试成绩。
- 纯 EEG 测试候选出现 81.77% 或 94.26% 的过度拒识，说明源域固定阈值不能直接迁移。
- 当前竞赛候选采用 Session2 z-score、任务特异模型、高相似图融合、部分 Sinkhorn 和 `session1 → 0`；测试真实 C/RA/ASafeR/U 仍未知。
- 硬聚类路线已被训练集前推实验否定，不应恢复为后续主方案。

## 3. Session 先验下，优化目标如何变化

竞赛基线设置为：

- Session1：全部输出 0。
- Session2：不使用全局开集拒识阈值，直接输出 1–20 中的身份。

若 H1/H2 完全成立，则 U=1；若 Session2 又完全不输出 0，则对抗样本只有“预测原身份”或“误分为其他注册身份”两种情况，因此 ASafeR=RA，A=RA，条件性评分简化为：

\[
Score_{conditional}=100\times C^{0.40}\times RA^{0.35}.
\]

这不是测试成绩预测，而是说明：**在该假设下，继续全局压低 Session2 接受率没有依据，应该优先提高 C 和 RA。**

后续仍可试验“仅拒识极可能误分类的对抗样本”，但必须证明它提高 A，且不过度损害 C/RA；不能重新启用导致大面积拒识的源域 5% 分位阈值。

## 4. 总体实验原则

1. 正式提交保持不动，新结果只生成独立实验候选。
2. 每轮只改变一个主要因素，先消融再组合，避免把收益错误归因。
3. 所有有标签选择只在 Train 内层完成；外层标签仅评估。目标侧伪标签适配必须只使用目标特征和无标签预测。
4. 测试侧只报告分布、置信度、类别均衡、配对一致性等诊断，不把它们写成 C/RA/U/AUC/F1。
5. 保留四个已有时间/块留段协议，并增加嵌套伪目标适配；不能只用曾经参与调参的单一前推协议。
6. 计算优先使用 GPU；每个实验分别保存 JSON 和 MD，MD 必须写明当前 AUROC、macro-F1、unknown-F1，以及适用时的 C/RA/ASafeR/U 和本地代理分。

## 5. 实验 E0：先验证结构，而不是直接调答案

### 目的

判断 Session 先验与 EEG 特征是否一致，并识别“Session 与身份混杂”及错误配对风险。

### E0.1 Session 可分性探针

- 按 task 分别用测试特征区分 Session1/Session2，做块保留交叉验证。
- 高相似图组件必须整体进入同一折，避免正常—对抗近重复跨折泄漏。
- 报告 Session 二分类 AUROC/AUPR；同时与打乱 Session 标签的置换基线比较。

解释：高 AUROC 表明 Session 域差异很强，说明直接利用 Session1/Session2 伪标签可能学到域差异，而不一定学到身份；它不用于证明或否定 H1/H2。

### E0.2 Session1 的 EEG 异常审计

- 对比 Train 伪未知、Test Session1、Test Session2 的 margin、energy、最近类距离和特征分布。
- 检查 Session1 是否存在大量稳定、高置信且跨 task 一致的注册者匹配。
- 只做审计，不据此自动翻转 Session1 标签；当前低校准置信度不能单独否证 H1。

### E0.3 配对图质量审计

- 按 task 报告相似度、最近与次近邻相似度间隔、互反边比例、组件大小和覆盖率。
- 检查长链组件是否可能连接不同身份；只有高相似且互反的边进入高风险融合实验。
- 不强行把 19,218 条 Trial 配成严格的 9,609 对。

### E0 产物

`session_audit.json` 与简短 MD。若发现明显跨 task 身份矛盾或图组件异常，先修配对/路由，再进入适配实验。

## 6. 实验 E1：冻结 Session 先验基线并做消融

固定 Session1 全 0，Session2 暂不做全局拒识，比较：

| 配置 | 对齐 | 身份模型 | 图融合 | Sinkhorn |
|---|---|---|---|---|
| E1a | 无 | full/base | 无 | 无 |
| E1b | 当前 z-score | full/base | 无 | 无 |
| E1c | 当前 z-score | 当前任务特异模型 | 无 | 无 |
| E1d | 当前 z-score | 当前任务特异模型 | 当前冻结规则 | 无 |
| E1e | 当前完整竞赛候选 | 当前冻结规则 | 当前冻结规则 | 当前冻结规则 |

目的不是重新选择一套复杂规则，而是量化每一步在多种内部协议上的真实贡献。测试侧只记录相对当前候选的标签变化、各类别数量、Session2 拒识数和配对一致性。

若图融合或 Sinkhorn 只提高测试一致性、却不能在有标签协议上提高 C/RA/代理分，则从后续候选移除。

## 7. 实验 E2：优先比较 SPD/Riemannian 跨域对齐

### 假设

当前 z-score 在 log-cov 特征上逐维对齐，未必能消除协方差空间中的旋转、缩放和相关结构偏移。SPD 域对齐更符合当前特征的几何结构。

### 单因素比较

1. 无对齐。
2. 当前 log-cov target z-score。
3. **Riemannian recentering**：按 task 估计源域与 Session2 目标域的 SPD 参考均值，将目标协方差映射回源域参考系。
4. **Riemannian Procrustes Analysis（RPA）**：在 recentering 后进一步比较旋转/缩放对齐。

所有对齐统计只使用相应目标批次的无标签 EEG，不使用 Session 身份标签或伪身份标签。先固定分类器、图融合和 Sinkhorn，避免同时改变多个环节。

### 内部验证

- 源训练与目标评估按时间/块分离，目标统计不读取目标身份。
- 使用块外推、时间前推、反向留段和中间留段；汇总每折 C、macro-F1 和最弱 task。
- 对严格 EEG 轨继续运行嵌套留被试，报告 AUROC、unknown-F1、U，检查身份对齐是否损害未知可分性。
- 在特征空间攻击上做初筛，报告 RA、ASafeR 和 A；不把特征攻击强度解释为真实采集扰动强度。

### 保留条件

只有在多个外层协议上稳定改善身份指标，且严格轨 AUROC/unknown-F1 没有明显崩溃时才保留。测试类别更均衡或配对更一致只能作为辅助证据。

## 8. 实验 E3：利用正常—对抗一致性，但不把一致性当准确率

在 E2 的最佳对齐上，单独比较：

1. 不融合。
2. 当前组件内分数均值。
3. 相似度加权的温和分数收缩，而非完全覆盖原始分数。
4. 组件中心/最高完整性代表 Trial 辅助投票，但保留源模型分数锚点。

重点观察：

- 正常样本 C 是否下降；既有实验已表明理想配对平均可能提高 RA、却降低 C。
- 对抗样本 RA、ASafeR、A 是否共同改善。
- 是否仅通过大组件传播错误标签。
- 高相似边一致率只作为稳定性诊断，不能作为候选收益证据。

若均值融合只增加一致性而不提高有标签代理指标，优先尝试温和收缩；若仍无稳定收益，则删除图融合，不再增加图规则。

## 9. 实验 E4：受限的 Session2 伪标签适配

仅在 E2/E3 仍有明确身份错误瓶颈时进行，不恢复已失败的硬 KMeans。

### 伪标签选择

候选 Trial 必须同时满足：

- 源模型置信度位于本 task、本预测类别的前列，而不是只使用全局固定 margin；
- 若属于可靠高相似组件，其身份与组件多数意见一致；
- 每个身份的样本数设置上限，并参考 Train 对应 task 的类别先验，防止多数类吞噬少数类；
- 对抗/正常配对不因标签不同而重复扩大权重。

### 适配方式

先实现最小的置信度加权自训练 Ridge：源域训练 Trial 保持权重 1，目标伪标签使用较小权重；目标权重和伪标签比例只在内层伪目标协议选择。与完全冻结的源模型比较，不叠加新的开集阈值。

### 防退化条件

出现以下任一情况即停止该路线：

- 多个时间/块外层协议没有一致收益；
- 预测类别进一步塌缩或少数身份消失；
- 去掉伪标签适配后配对一致性不变，说明收益可能只来自后处理；
- 严格 EEG 开集 AUROC/unknown-F1 明显下降。

## 10. 实验 E5：可选的 Session2 选择性拒识

E1 的 Session2 全接受是基线。只有当模型能较可靠地区分“很可能正确的对抗样本”和“很可能误分类的对抗样本”时，才测试选择性拒识。

对单个对抗 Trial，若校准后的身份正确概率为 p：

- 接受并正确时，对 A 的期望贡献同时进入 RA 和 ASafeR；
- 拒绝时不得 RA，但可计入 ASafeR；
- 在局部期望近似下，拒识只有对低正确概率、且确属对抗的 Trial 才可能有价值。

因此不能对正常 Trial 或所有低 margin Trial 统一拒识。该实验必须使用内部正常/对抗配对验证完整 C/RA/ASafeR/A，并与 Session2 全接受比较。若配对身份或正确概率校准不可靠，直接放弃 E5。

## 11. 严格 EEG 对照轨

所有竞赛候选都同时保留一个不使用 Session 规则的纯 EEG 对照：

- 基线固定为 `full/base × target_zscore` 的嵌套留被试结果。
- 新对齐或适配若在竞赛轨看似有效，必须检查它是否也改善纯 EEG 的 AUROC、unknown-F1、U 和 C。
- 若收益只在 `session1 → 0` 下存在，应明确归类为比赛结构收益，而不是脑纹本质特征或未知拒识能力提升。
- Session 批量对齐和伪标签适配属于 transductive 方法，不能直接声称适用于决赛现场单样本/小批量场景。

## 12. 执行顺序与候选准入

### 推荐顺序

1. **E0 + E1**：结构审计和现有候选消融，先确认哪些组件值得保留。
2. **E2**：SPD/Riemannian 对齐，是下一轮最高优先级的新方法。
3. **E3**：在最佳对齐上检验温和的正常—对抗一致性约束。
4. **E4**：只有身份分类仍有瓶颈时才做受限伪标签适配。
5. **E5**：只有对抗样本定位和正确概率校准可靠时才做选择性拒识。

不建议一次性叠加 RPA、图融合、伪标签和拒识，否则无法判断收益来源，也容易对测试无标签诊断过拟合。

### 新候选必须同时满足

1. 相对冻结基线，在多个有标签外层协议上改善本地代理分，且 C、RA 或严格轨 unknown-F1 没有不可接受的下降。
2. 增益不是只出现在某一个 task、某一个折或测试一致性指标上。
3. 无严重类别塌缩；输出变化规模和受影响 task 可追溯。
4. 22,251 行、Sample 顺序、0–20 整数标签和无缺失检查通过。
5. 与当前正式候选分开保存，报告完整 AUC/F1 与 C/RA/ASafeR/U；未经正式决定不覆盖答案。

官方提交最多 3 次，应每次只提交一个冻结候选并保存反馈。一次官方分数可以用于检验路线，但不应用同一反馈反复进行大量局部搜索。

## 13. 风险与预期边界

- **假设错误风险**：若 Session1 含注册者，硬规则会损失 C/RA；若 Session2 含未知者，全接受会损失 U。
- **域混杂风险**：Session1/Session2 伪标签可能让模型学习采集域，而不是身份；E0 探针和纯 EEG 对照不可省略。
- **伪标签确认偏差**：高置信不等于正确，尤其在跨 Session 和对抗扰动下。
- **误配风险**：高相似波形不保证同身份，大组件可能传播错误。
- **证据边界**：测试一致性、类别均衡和可视化都不是准确率；没有官方反馈时不能声称达到 62 分或已解决未知拒识。
- **决赛迁移**：Session 硬规则仅作为预赛策略，决赛仍需要小样本注册、逐 Trial 开集拒识和独立校准方案。
