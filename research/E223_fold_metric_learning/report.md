# E223 折内度量学习（固定无监督表征 + 小 MLP 度量头）

严格 20 折 subject-LOSO：每折只用 enrolled outer-train 且 trial fraction<=0.6 的行拟合 task-wise 标准化、PCA、度量头、原型/协方差与阈值；评估窗口 (0.6,0.8]；tau 由内层 5 块 known OOF 的 0.1 分位确定；Test 在全部折与追加轮决策冻结后只读取一次。

打分口径沿用 E221：高分=known，score<tau 拒识；unknown 作正类计算 F1 与 AUC(-score)。`e65_baseline_repro` 为 E221/E222 原配方复现。

## 1. 表征与训练设置

- 输入固定为无监督特征：E65 correlation-logSPD(855) + E146 log-band-power(90)，不使用 E162 等全身份监督嵌入。
- 每折 enrolled fit 行内：按 task 做 z-score → 每流 PCA（e65=96，logbp=32）→ 块 RMS 归一化 → 拼接 128 维。
- 度量头：128→128(GELU, dropout 0.1)→32，L2 归一化；损失 = CE（仅 enrolled 身份）+ 0.5 × 监督对比（同 subject 为正，含跨 trial/task 对）。
- 漂移增强（仅训练、仅特征空间）：band gain σ=0.1、channel gain σ=0.1、spectral tilt σ=0.08、加性噪声 σ=0.05、band-block 替换 p=0.3（同身份另一 trial；缓存特征无原始子窗，故为特征空间近似）。
- 早停：只用折内 fit 行按 trial-fraction block 划出的验证块（CE），再用最优 epoch 在全 fit 行重训；Test/held 身份从不参与。

- 20 折 × 2 个头全部触到固定上限：`best_epoch` 均为 [79]，`n_epochs` 均为 [80]（早停 patience=10 从未触发）。

## 5. 判断与结论

**未冻结任何候选。** 没有任何候选同时满足 LOSO 拒识>0.90 与 Test 分离 AUC≥0.80。Test 分离 AUC 最高的是 `e65_baseline_repro`（0.766024），baseline 为 0.766024。 最佳学习候选 `mlp_ce_contrast_maha` 的 LOSO 拒识由 0.5635 升到 0.9995，但 Test 分离能力没有提升（0.5156 vs baseline 0.7660），按预设判断这属于域偏移而非表征问题，不再刷同一配方。

**域偏移证据（对应预设判断分支）**：

- 同会话 LOSO：`mlp_ce_contrast_maha` AUC=0.995766、unknown 拒识=0.999545；baseline 为 0.910173/0.563519。度量头在折内把身份聚得很紧，LOSO 开放集能力大幅提升。
- 跨会话 Test：k1 的 S1 分数 mean±std=0.7742±0.1697，S2=0.7835±0.1538，两者几乎重合；tau=0.9498 把两边都判为偏远，S2-vs-S1 分离 AUC=0.509893（baseline 0.766024）。maha 同样只有 0.515561。
- 即使用 Test 分数做条件最优，S1 拒识≥0.70 时 k1 的 S2 接受上限也只有 0.237121（baseline 0.680144）；k3/maha 分别为 0.241753/0.243209。
- 增强未改变结论：`mlp_no_augment` LOSO 拒识=0.998688、Test 分离 AUC=0.506975，与加增强的 k1（0.998648/0.509893）基本相同。
- 结论：LOSO 提升真实存在（同会话内），但 Test 分离能力反而低于 baseline，说明学到的主要是会话内身份方向，跨会话发生域偏移，而不是阈值、k 或表征维度的问题；按预设规则不再重复同一配方。

## 7. 限制

- 官方 Test AUC/F1 因 Test 无身份标签为 **N/A**；S1/S2 只是会话分层行为指标，不等同官方未知/正常分类指标。
- Test 已被本系列实验反复查看，虽然本轮所有超参与候选预先固定、未按 Test 调参，评估偏倚仍不可消除。
- LOSO 指标为逐折宏平均；unknown:known 约 1:19，拒识 F1 受类别比例影响。
- “跨 trial 同身份为正”的监督对比不使用 held 身份；Test 不参与表征、度量头、早停或阈值。
- 特征空间的 band-block 替换是“随机时间子窗特征替换”的代理，因为缓存特征已是 trial 级汇总。
