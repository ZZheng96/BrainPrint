## 6. 阶段 F：多视图、尺度与度量学习（E137–E142）——含 LOSO 污染

| 实验 | 内容 | 旧报告值 | 修正后 |
|---|---|---|---|
| E137 | 多视图分数融合（14 视图） | Test AUC 0.7895 | LOSO 污染，W 作废 |
| E138 | 尺度无关分数形式 | raw d1 AUC 0.7566 | LOSO 污染 |
| E139 | 特征级拼接 + PCA 维数 + 原型数 | PCA-96 最优 | LOSO 污染 |
| E140 | 监督度量学习（ArcFace / triplet） | **Test AUC 0.49–0.57，失败** | 9 个模型权重已保存 |
| E141 | 加权目标 + 图像化路线 | — | LOSO 污染 |
| E142 | 有界化（全局 CDF）多视图融合 | CDF ≈ raw z | LOSO 污染 |

**严重方法论问题（E144 复盘确认）**：E137–E142 的 LOSO 把被评分 known 块放进了原型集合，导致 known trial 成为自己的原型、距离趋近 0、阈值被抬高、unknown rejection 虚高到 0.95–1.00。

修正方式：

```python
# 错误
p2, k2 = build_prototypes(a, subjects, tasks, pm, enrolled, k)
# 正确
p2, k2 = build_prototypes(a, subjects, tasks, pm & fit_rows, enrolled, k)
```

修正后 E65 k=12 a=0.90 得 LOSO 0.7936 / S1 0.7979，两者几乎一致——这也反过来验证了修正是对的。

**E159 是本阶段的转折点**：把 E143 冻结分数的阈值在 2000 个分位点上扫满，最优 W 只有 0.6971；即使把 LOSO 固定为历史最好 0.7936、Test 工作点任选，上界也只有 **0.7352**。

**E161–E164 构成原始 EEG 端到端的完整证伪链**：
1. SupCon 排序反转（AUC 0.4301）
2. 去掉 L2 归一化 + 双扰动族跨会话不变性 → 纠正到 0.6756
3. 与 E65 融合 → 0.7609，无实质提升
4. 抬高表征秩 → 99% 有效秩从 10 提到 26–47，但 95% 有效秩不动，AUC 反降到 0.35–0.50

副产品：E164 变体 D 与 E162 唯一差别是 `BN → GroupNorm`，AUC 从 0.6756 掉到 0.4081——**BN 在这条管线上对跨会话排序其实有帮助**。

## 9. 阶段 I：TTA、时频图与幅值互补（E165–E171）

| 实验 | 内容 | 最佳 W | 诊断 AUC | 判定 |
|---|---|---:|---:|---|
| E165 | Test-Time Augmentation | 0.6958 | 0.7578 | **数学上不可观测的增强，零收益** |
| E166 | 时频图 + Train 内对比学习 | 0.6534 | 0.7358 | 失败（有效秩 8/256，OOF F1 0.766） |
| **E167** | **E65 × logbp 分数/特征融合** | 0.6997 | **0.7999** | **首次把 AUC 抬过 0.76** |
| E168 | 子窗口协方差 | 0.7156 | 0.7822 | AUC 上升但未转化为 W |
| E169 | 尺度无关谱型特征 | 0.7010 | 0.7919 | 去掉幅值同时丢掉排序力与 LOSO |
| E170 | 三路融合 + 上界分析 | **0.7181** | 0.7943 | **同口径上界 0.7704，仍差 0.03** |
| E171 | N 延展至 12 + 多尺度 + 融合 | 0.6998 | **0.8055** | **AUC 新高，但 S1=0.80 处 S2 仅 0.58** |

### 9.1 E165 的结构性发现

三组预注册 TTA 增强对 E65 是**数学上不可观测**的：

- `channel_gain`、`band_emphasis`：E65 在每个 trial、每个频带内先按通道除以自身标准差，逐通道/逐频带常数增益被完全约掉
- `shift`：循环平移对相关矩阵精确不变（$\sum_t x_i(t+\tau)x_j(t+\tau)=\sum_t x_i x_j$），且频带滤波是 DFT 矩形掩码，与循环平移可交换

11304/11304 行的特征 max|Δ| ≤ 1e-3。**推论：E65 已完全丢弃幅值/尺度信息，只保留跨通道相关结构。**

### 9.2 E167：本轮第一次 AUC 突破

| 配置 | 诊断 AUC | W@0.90 |
|---|---:|---:|
| E143 基准 | 0.7578 | 0.6958 |
| logbp 单独 PCA-16 k=12 | 0.7809 | 0.6249 |
| 分数融合 0.5·E65(64)+0.5·logbp(48) k=12 | 0.7943 | 0.6568 |
| 特征拼接 block_norm 64+32→96 k=6 | **0.7999** | 0.6721 |
| 特征拼接 raw 96+32→96 k=12 | 0.7806 | 0.6997 |

原因：logbp 携带的正是 E65 通过逐通道标准化主动丢弃的幅值信息。

### 9.3 E168：子窗口尺度归一化

E65 对整个 1200 点只算一个相关矩阵。把它切成 N 个不重叠子窗口、各自走 E65 流程（含非线性的 `detrend_zband`）再平均，AUC 随 N 单调上升：

```
N=1  0.7637
N=2  0.7691
N=3  0.7735
N=4  0.7822
N=6  0.7902
N=8  0.7866
N=12 0.7937
```

`subwin_std`（trial 内非平稳性）与 E65 相关性最低（r=0.475–0.623），确实是新信息，但单路 AUC 仅 0.50–0.64、融合无增益——**非平稳性不含可用的身份判别信息**。

### 9.4 E170：优化目标必须修正

扫满 2000 个阈值、三指标严格同阈值联动：

| 冻结分数 | 诊断 AUC | 扫满最优 W | S1=0.80 时 S2 |
|---|---:|---:|---:|
| E143 E65 PCA-96 k=12 | 0.7578 | **0.6972** | **0.5929** |
| E167 E65+logbp（最高 AUC） | 0.7999 | 0.6745 | 0.5847 |
| E170 三路最佳 | 0.7943 | 0.6691 | 0.5659 |
| E65 PCA-64 k=12 | 0.7622 | 0.6984 | 0.5956 |

两个决定性事实：

1. **AUC 0.80 的分数，扫满阈值最优 W 只有 0.6745，比 AUC 0.7578 的 E143（0.6972）还低。**
2. **S2 对 AUC 的斜率是 −0.46**：AUC 从 0.7578 升到 0.7999，S1=0.80 处的 S2 反而从 0.593 掉到 0.585。

原因：E167 的 AUC 增益集中在 ROC 尾部，没有落在 S1=0.80 / S2 这个关键工作点上。

由此得到正确的优化目标：

```
maximize S2 at S1_rej = 0.80
```

当前该值为 0.585–0.596，需要 0.78 才能让 W=0.80（LOSO 取实测最好 0.8412）。

### 9.5 E171：AUC 新高但不改善工作点

| 配置 | 诊断 AUC | W |
|---|---:|---:|
| E65+logbp 对照 | 0.7999 | 0.6721 |
| 0.1×E65 + 0.4×logbp + 0.5×subwin(N=12) | **0.8055** | 0.6691 |
| subwin_mean N=4 PCA-48 k=12 | 0.7764 | 0.6998 |

E171 的 `verdict.w_ceiling_080_met = true` 是**错误标记**：该配置的 E159 同口径上界实为 **0.7489**，单阈值 oracle 仅 0.6704，均未达到 0.80。

## 10. 方法学教训汇总

1. **LOSO 自原型污染**（E119、E137–E142）：原型集合绝不能包含被评分 trial，必须 `pm & fit_rows`。污染会把 LOSO 虚高到 0.95–1.00。
2. **Test 侧统计量违规**（E135）：用 Test 批次 CDF 校准虽然有效（等权口径曾达 0.8738），但不可用于冻结模型，结果作废。
3. **Train 内高 AUC ≠ 跨会话能力**：E154 Train OOF AUC 0.9861 而 Test S2 仅 0.3561；E156 OOF 0.9949 而 LOSO 仅 0.1001。
4. **全局 AUC ≠ W**：E170 用斜率 −0.46 定量证明，AUC 增益可能全部落在无用尾部。
5. **表征坍缩是系统性的**：E161/E162/E164/E166 的 embedding 有效秩都只有 8–10 维（无论 128/256/512 维输出），来源是 Conv+BN+池化结构本身。
6. **"松口径上界"不可采信**：把 LOSO 固定在其网格最高值、同时让 Test 工作点任选，会得到虚高上界（如 E169 的 0.7930、E171 的 0.7489 与 oracle 0.6704 的巨大差距）。唯一诚实的口径是**单阈值 oracle** 或 E159 同口径。

## 13. 未解问题与建议

1. **核心矛盾**：S1 拒识与 S2 接受由同一阈值控制，两者沿固定 ROC 反相关。E170 实测斜率 −0.46，意味着单纯抬全局 AUC 无效。

3. **下一步应该（而非继续调阈值）**：
   - 直接以 `S2 at S1=0.80` 为目标筛选表征，而不是全局 AUC；
   - 探索能改变 ROC **形状**（而不仅是整体抬升）的表征，例如对 S2 中的对抗样本鲁棒的身份匹配；
   - 若两周内仍无法把该局部指标从 0.59 推到 0.78，应正式接受 W≈0.72 的上限。
4. **数据侧事实**：Train 只有 session1，无法真正模拟跨会话。这是所有失败的共同根因，且不可通过算法绕过。

## 17. E194：LOSO 与 Test S1 落差的机理（决定性结论）

### 17.1 问题

用户指出：LOSO 留出的身份与 Test S1 的未注册者**都是 session1**，情况可比，
那为什么 E183 出现 LOSO 0.99 vs S1 0.27 的巨大落差？

### 17.2 三因素分离（两个门控平均）

| 原因 | 贡献 |
|---|---:|
| **域漂移**（Train 与 Test 的采集批次不同） | **75%** |
| A：拟合泄漏（LOSO 未知者的 fit 块参与了标准化/PCA） | 19% |
| B：阈值参考分布不同 | 6% |
| C：样本构成与估计方式 | 0.1% |

E183 单独看，域漂移贡献 **98.8%**。

### 17.3 决定性证据：Test S1 本身就是另一个采集批次

用 E65 PCA-96 特征做域分类（5 折）：

| 对比 | 域可分性 AUC |
|---|---:|
| **Train session1 ↔ Test S1** | **0.9789** |
| Train session1 ↔ Test S2 | 0.8698 |
| Test S1 ↔ Test S2 | 0.9767 |

**5 个未注册者的 session1，比注册者的 session2 还更不像 Train。**
说明赛题的 "session1/session2" 标签不代表同一采集批次——Train 与 Test 是独立采集的。

### 17.4 最强证据：LOSO 对 S1 无预测力

同一批 S1 样本在两个门控上落在 LOSO 分布的两端：

| 门控 | S1 相对 LOSO unknown | S1 相对 LOSO known |
|---|---|---|
| E65 距离 | −19.43（比 unknown 还远） | 远 |
| E183 融合 | 0.324（**紧贴 known 0.390**） | 近 |

两条门控给出完全相反的定位，说明 **LOSO 排序与 S1 的实际难度无关**。

### 17.5 修正一个历史误判

E143 报告的「LOSO 0.7936 ≈ S1 0.7979」是**假重合**：

```
泄漏使 LOSO 虚高  +0.17
域漂移使 S1 偏低  −0.23
两者相抵，看起来一致
```

严格嵌套（排除留出身份的 fit 块）后：

| 门控 | 原 LOSO 拒识 | 严格 LOSO 拒识 |
|---|---:|---:|
| E65 距离 | 0.7936 | **0.6448** |
| E183 融合 | 0.9828 | 0.9848（每折本来就已排除） |

### 17.6 影响

1. **LOSO 不能作为 Test S1 的代理**，也不能用于门控选择——这是 E181/E183/E193 反复失败的真正原因。
2. **E143 的干净基准 LOSO 0.7936 本身被泄漏抬高了 0.165**，严格值是 0.6448。
3. **#5/#6 用 LOSO 度量，与 Test S1 无因果关系**，因此"LOSO 高 ⇒ Test 好"的推理链整体失效。
4. 7/10 的顶线（E191）不受影响——它是在 Test S1/S2 上直接测的。

### 17.7 与 16 节的关系

16.7 说"高 LOSO 门控 Test 必崩"，E194 给出了更准确的机理：
**LOSO 度量的是"同批次内是否像注册者"，Test S1 需要的是"跨批次是否像注册者"，
两者在特征空间中由不同分量主导，因此 LOSO 排序对 S1 无预测力。**

## 18. E195：第 11 项指标（LOSO 拒识 > 0.90）与三条互斥边界

### 18.1 #11 很容易满足

| 门控 | loso_std | loso_strict |
|---|---:|---:|
| WCCN 距离比 | 0.9918 | **0.9877** |
| E183 三视图 | 0.9914 | **0.9848** |
| E65 距离 | 0.7936 | 0.6448 |
| subwin6 | 0.5866 | 0.3982 |

**拟合泄漏并不普遍**：E183（0.007）、E162（−0.010）、WCCN（0.004）几乎无泄漏；
只有 E65（0.149）与 subwin6（0.188）明显。之前"所有 LOSO 都虚高"需收窄到具体方法。

### 18.2 #11 与 #9/#10 互斥

Pareto 前沿（349 个候选 × 权重点）：

```
E183 单门控        strict 0.9848  →  Test min 0.2733
三路融合（窄缝）    strict 0.928–0.964 → Test min 0.702–0.722
subwin6 单门控     strict 0.3982  →  Test min 0.6916
```

strict ≥0.90 时 Test min 最高 0.7221，但只有 **3 个点**满足，且**只能靠 Test 审计找到**。

### 18.3 两套结果必须分开记录

| 选权方式 | strict LOSO | Test S1 | Test S2 | 通过项 |
|---|---:|---:|---:|---:|
| Test 选权（**不合规**） | 0.9640 | 0.7052 | 0.7087 | 8/11 |
| Train 选权（合规） | 0.9848 | 0.2733 | 0.9288 | 7/11 |

8/11 方案：`E183 0.4 + E65 0.3 + subwin6 0.3`
- 通过 #1–#5、#9–#11
- 未过 #6 U@95 0.883、#7 RA 0.947（差 0.003）、#8 ASafeR 0.962（差 0.018）

**合规上限 7/11；经验权重上限 8/11。**

### 18.4 三条互斥边界汇总

| 冲突对 | 机理 |
|---|---|
| #11 vs #9 | strict LOSO 高 ⟺ 同批次内可分；Test S1 在另一批次，由不同分量主导 |
| #7 vs #10 | `RA ≤ 门控接受率`，放开接受率则 Test S1 崩 |
| #6 vs #9 | U@95 需 ROC 在 5% FPR 极陡，与 Test 均衡点不重合 |

### 18.5 待验证

Test S1 是 **5 个身份**，而 LOSO-1 的未知池只有 1 个身份。
若改用 leave-5-out，未知池构成与 Test S1 更接近，可能让 Train 侧指标重新具备预测力
（见 §19）。

## 19. E196：leave-1/2/5/10 对比（未知池规模假设被否定）

### 19.1 动机

Test S1 是 **5 个身份**，而 LOSO-1 的未知池只有 1 个身份。
假设：改成 leave-5-out 后未知池构成与 Test S1 更接近，Train 侧指标可能恢复预测力。

### 19.2 结果（跨 10 个门控的 Spearman）

| k | leave-k vs Test S1 | 固定 Test 列后 |
|---|---:|---:|
| 1 | 0.394 | 0.394 |
| 2 | 0.406 | 0.394 |
| 5 | 0.503 | 0.394 |
| 10 | 0.636 | 0.321 |

### 19.3 关键判定：表观提升是假象

- k=1/2/5 的 **Train 侧门控排序逐位相同**（ρ=1.000），k=10 只多一次相邻交换（0.988）。
- **把 Test 列固定后，ρ 没有任何提升**（k=10 反而降到 0.321）。
- 表观提升来自 **gallery 从 19 缩到 10** 导致的 Test 侧排序漂移
  （k=1 ↔ k=10 的 Test 排序仅 0.867；例如 WCCN 的 S1 拒识从 0.610 涨到 0.790）。

### 19.4 未知池规模贡献为 0

同一 instrument/阈值下，"5 个身份合并评估"与"逐身份平均"的 ρ 都是 **0.503**。
即：**未知池大小对预测力没有影响**。

### 19.5 结论

1. **leave-5 不可作为选门控的代理**：ρ=0.503、平均偏差 −0.164、逐门控最大偏差 0.366。
2. 用户的"未知池规模"假设被否定；**主因仍是域漂移**（E194：域可分性 AUC 0.9789）。
3. 严格拟合已与 E195 逐位复现（0.6448 / 0.3982 / 0.3239 / 0.1887 / 0.5897 / 0.9877）。

### 19.6 全项目最终能力边界

| 口径 | 通过项 | 方案 |
|---|---:|---|
| 合规（Train-only 选一切） | **7 / 11** | E183 一族（strict LOSO 0.9848，Test S1 0.2733） |
| 合规 + Test 侧均衡取向 | 7 / 11 | E191 `subwin6@a=0.90`（S1 0.7135 / S2 0.7069） |
| 经验固定权重（看过 Test） | **8 / 11** | E195 `E183 0.4 + E65 0.3 + subwin6 0.3` |

三条互斥边界（§18.4）在 leave-k 各协议下均不变：
`#11 vs #9`、`#7 vs #10`、`#6 vs #9`。

**根本原因**：Train 与 Test 是两次独立采集（域可分性 AUC 0.9789），
Train 内任何划分（LOSO-1/2/5/10、OOF、交叉验证）都无法模拟该漂移，
因此 Train 侧指标对 Test S1 的预测力上限约 ρ≈0.5。

## 20. E197：三阶段注册流程（用户定义）—— 预测力显著恢复

### 20.1 与 E196 的协议差异

| 阶段 | E196 strict | **E197（用户定义）** |
|---|---|---|
| 训练抽取器（标准化/PCA/WCCN） | 排除留出者（19 人） | **全部 20 人** |
| 注册（模板/原型） | 19 人 | **20−k 人** |
| 评估 | 只算拒识 | 拒识 k 人 **+ 识别 20−k 人** |

用户的框架把"训练"与"注册"分开：抽取器用尽全部数据，注册环节才受限。

### 20.2 核心数值（k=5）

| 指标 | 值 |
|---|---:|
| 已注册 15 人识别准确率 | 0.8998（`e65_pca96` 单族 **0.9812**） |
| macro-F1 | 0.8970 |
| **未注册 5 人拒识率** | **0.6460** |
| AUC | 0.8870 |
| Test S1 实际拒识 | 0.7415 |

### 20.3 拒识率随 k 单调上升

| k | 1 | 2 | 5 | 10 |
|---|---:|---:|---:|---:|
| Train 侧拒识 | 0.6235 | 0.6270 | 0.6460 | 0.6860 |

主因是 **gallery 从 19 缩到 10**（注册库变小，边界更松），不是未知池变大。

### 20.4 预测力：0.503 → 0.85

| 协议 | 与 Test S1 的 Spearman | 平均绝对偏差 | 系统偏差 |
|---|---:|---:|---:|
| E196 strict leave-1 | 0.503 | — | — |
| **E197 三阶段 leave-5** | **0.85** | 0.121 | −0.095（偏保守） |

**这是本项目第一次拿到可用的 Train 侧门控排序代理。**

### 20.5 必须注意的偏差

E197 相对 E196：Train 侧拒识 +0.127、AUC +0.032，但 **Test S1 只 +0.009**。
说明"训练集扩容"的收益基本是**样本内红利**，不能解释为跨批次能力提升。
因此 E197 只能用于**排序选型**，不能用于**绝对值估计**。

另注：`wccn_dr`（有监督类均值）的拒识从 0.9925 崩到 0.3298——它对注册集规模极敏感，
后续不应作为候选。

### 20.6 后续可做的事

既然 leave-5 三阶段协议对 Test S1 的排序相关达到 0.85，
就可以用它**合法地**做门控与融合权重的选择（不再需要看 Test），
见 §21。

## 21. E198：用 leave-5 合法选型的结果（5/11）—— 结构性缺口浮现

### 21.1 选型设置

455 个候选（5 个单门控 + 全部两两/三路 0.1 步长融合），预注册规则：
`acc5 ≥ 0.95` 且 `loso_strict > 0.90` → 最大化 `rej5`。

### 21.2 关键结果

| 阶段 | 结果 |
|---|---|
| `acc5 ≥ 0.95` 的候选 | 128 个 |
| **同时 `loso_strict > 0.90` 的候选** | **0 个** |
| 回退规则选出 | `e65_dist 0.7 + e162_dist 0.3`（rej5 0.9123、acc5 0.9778、loso_strict 0.8270） |
| Test 一次性评分 | **S1 0.8414 / S2 0.5282** |
| 11 项通过 | **5 / 11**（过 #1–#4、#10） |

### 21.3 三个具体原因

1. **候选池里没有 E183/WCCN 级的判别门控** → `#5` 上限 0.9442、`#11` 上限 0.8270。
2. **S2 在 Train 上不可观测** → 最大化 `rej5` 必然抬高阈值，S2 被压到 0.5282。
3. **唯一 Test 双过 0.70 的 subwin6 被 `acc5 ≥ 0.95` 约束排除**（它的 acc5 较低）。

### 21.4 最重要的结构性认识

```
Train 只有 session1：
  未注册者 → 可以观测（leave-k 拒识）
  已注册者的跨会话接受 → 完全不可观测
```

因此**任何纯 Train 侧准则都无法看到"过度拒识"的代价**，
必然向"更严格拒识"漂移，S2 必然下滑。

这解释了为什么：
- E191 的 7/11（S1 0.7135 / S2 0.7069）是靠 **Test 侧 min(S1,S2) 平衡**选出来的
- E195 的 8/11 也是 Test 选权
- 而纯 Train 选型（E198）只能到 **5/11**

### 21.5 最终能力边界（三档并列）

| 选型依据 | 通过项 | 方案 | 备注 |
|---|---:|---|---|
| 纯 Train（leave-5 三阶段） | **5 / 11** | `e65 0.7 + e162 0.3` | 完全合规，S1 0.84 / S2 0.53 |
| Train + Test 平衡取向 | 7 / 11 | E191 `subwin6@0.90` | S1 0.7135 / S2 0.7069 |
| Test 选权 | **8 / 11** | E195 `E183 0.4 + E65 0.3 + subwin6 0.3` | S1 0.7052 / S2 0.7087 |

### 21.6 结论

**在没有"跨会话已注册样本"的情况下，S1/S2 的平衡点必须由 Test 侧信息决定。**
这不是方法缺陷，而是可观测性缺口：Train 里根本不存在能反映"S2 会不会被误拒"的数据。

要真正合规地达到 8/11，唯一途径是引入**第二个采集批次的已注册样本**（哪怕少量），
用它标定"跨批次接受率"，从而把 S2 的代价纳入 Train 侧的可观测范围。
