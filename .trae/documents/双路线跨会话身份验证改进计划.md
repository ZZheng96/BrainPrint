# 双路线跨会话身份验证改进计划

## Context

BrainPrint 两条路线均已具备较强的同 Session 识别能力，但 Test 的 S2 拒识率≤2%、S1 拒识率≥95% 尚未达到。现有证据表明瓶颈不是普通阈值调优，而是缺少可迁移的跨 Session 身份表征；图像化路线还存在 clean/对抗骨干互斥，纯 EEG 路线的 RA/ASafeR 也尚未完全达标。

用户已授权自主迭代、两条路线切换或融合、不限定骨干，并允许外部公开 EEG 数据与预训练。目标是最终通过当前 Train/Test 的 10 项门禁，Test 两项优先；不扩展决赛流程。

## 固定约束

- 逐样本仅凭 EEG 决策；禁止使用 Session、路径、顺序、样本数量、对抗分组或近重复配对。
- Test 不参与训练、调参、阈值或模型选择，只在候选冻结后审计；Test AUC/F1 始终报告 N/A。
- 未知拒识使用留被试 pseudo-unknown、独立内层标定和外层一次评估。
- 新实验从 E72 起，不占用另一会话的 E63/E71，不覆盖历史负结果。
- 优先 GPU；每个阶段输出 config、结果 JSON 和含 AUC/F1 的 report.md，阶段完成后提交并推送 Git。

## 实施方案

### 阶段 1：E72 正确性审计与模板匹配基线

新建 `research/E72_pair_protocol/`，包含 `pair_protocol.py`、`run_e72.py`、`config.json`。

1. 建立共享的数据、配对采样、模板评分和指标接口；复用：
   - `research/E54_outlier_exposure/run_e54.py` 的嵌套被试隔离与评估流程；
   - `research/E65_correlation_spd/run_e65.py` 的 `WCCNPrototype`、`distance_ratio`；
   - `src/metrics.py` 的 AUROC、U@95、官方 Score。
2. 将开放集任务实现为“查询样本—注册身份模板”匹配：内折注册被试建立模板，内折未知被试只用于标定，外层被试只评估；比较余弦、WCCN、top1/top2 margin 和 distance ratio。
3. 先用官方 Train 的时间块/任务构造正负样本对，跑通纯协方差和现有 DINO 特征基线。此阶段没有真实跨 Session 数据，失败不阻止外部预训练，但暂停融合和复杂对抗改造。
4. 正式比较前完成输入正确性审计：图像必须为 float32 `[0,1]`，隔离既往 `uint8` 未除 255 的缓存；核对频带不超出官方 1–40Hz、缓存与 metadata 行对齐、dtype/SHA256 入 manifest。旧缓存只用于流程冒烟，不作为新结论。

阶段出口：数据隔离与缓存校验全部通过；至少一路保持或接近 C≥0.95、AUROC≥0.98、U@95≥0.95。若不满足，记录差距并直接进入真实跨 Session 监督，不在旧特征上继续扫阈值。

### 阶段 2：E73 外部真实跨 Session 预训练

新建 `research/E73_external_multisession/`，包含 `external_data.py`、`pretrain.py`、`verify_external.py`、数据许可与哈希清单。

1. 首选 MOABB `Lee2019_MI`/OpenBMI 的 MI 子集：54 名被试、跨天双 Session、62 个 EEG 通道、1000Hz、4 秒 Trial、CC0；避免下载完整约 209GB 数据集。小型端到端流程可用 BCIC IV-2a（9 人、双 Session）作补充。
2. 统一至竞赛的 18 通道交集、300Hz、1–40Hz、4 秒分段和逐记录稳健缩放；保留 subject/session 仅用于训练划分和损失，绝不作为推理输入。
3. 按被试划分预训练、阈值标定和外层未知；注册与查询必须来自不同 Session，并做 Session1→2、Session2→1 双向评估。
4. 训练跨 Session 对比/度量嵌入及样本—模板 same/different 匹配头；官方 Train 仅用于后续留被试适配和验证，不读取 Test。

阶段出口：外部跨 Session 身份验证 AUROC≥0.95、EER≤0.10，并在外部独立被试上测量“已知接受率≥98% 时未知拒识率”。若同一表征在两个数据集或两轮完整训练中 AUROC<0.90，停止该表征并更换数据/编码器，不继续堆融合权重。

### 阶段 3：E74/E75 两路线独立适配

分别新建 `research/E74_eeg_template/` 和 `research/E75_image_template/`。

- **纯 EEG**：复用 E54 `EEGNetEmbedding.embed`、原型初始化和 ARPL/OE，加载 E73 encoder 权重时剔除旧 `prototypes/radius_raw/task_head`，在官方 Train 内重建注册模板；复用 E65 模板评分。
- **图像化**：复用 `src/eeg_image_dinov2/image_encoders.py`、E20J 的可切换骨干和 E31 WCCN；先冻结骨干验证，再按需微调末端层或更换视觉骨干。DINOv2-clean 与 DINOv3-robust 不强行共用探针。
- 两路线均使用相同 E72 数据隔离、模板匹配和指标口径。只有第 1–6 项 clean 门禁全部通过，才进入融合。

### 阶段 4：E76 融合与 E77 对抗鲁棒

1. E76 仅在内折融合两路模板分数或嵌入；外层 Score 比最佳单路提高≥0.5，且 C/F1/AUROC/U 无门禁回退才保留，否则维持独立路线。
2. E77 仅对 clean 合格候选加入 SNR20/30、定向/非定向攻击和 clean/adv 一致性损失；复用 E54/E69 `raw_attack`、E69 可微协方差链和 E70 `RobustHead`。
3. 在线攻击若启用，必须从 E55 导入 `online_training_attack`，避免 E59 当前错误导入；E59 已证明无增益的配置不重复扩展。
4. 保留 E58 三段式分工，但将跨 Session/拒识分数替换为 E72–E75 的模板匹配分数。目标 RA≥0.95、ASafeR≥0.98，且 C/U 下降不超过 0.005。

### 阶段 5：E78 冻结与 Test 审计

新建 `research/E78_frozen_test_audit/`，复用 E64 的 `freeze_models`、`verify_freeze`、模型/源码哈希和 `offline_session_audit_after_csv`。

- 仅当前八项门禁全部通过，且外部跨 Session 工作点达到预设要求后冻结候选。
- 先生成全部 22,251 条逐样本预测和 CSV，再离线读取 Session 审计 S1/S2；校验顺序、标签范围、行数与哈希。
- Test 失败不得据此调整阈值或比较细微超参。只有新的外部/Train 独立证据达到预注册升级条件，才允许形成并冻结下一代候选。

## 自主迭代与切换规则

- 每个候选均跑相同嵌套外层协议，报告 C、身份 macro-F1、连续块准确率、AUROC、unknown-F1、U、RA、ASafeR、A 和 Score。
- 同一方向连续两轮完整嵌套的 AUROC/U@95 增益均<0.003且 Score 增益<0.3，即停止局部调参：图像停滞则转纯 EEG，两路均停滞则更换外部数据或会话不变预训练。
- 长数据准备和训练交由子 Agent/后台任务；GPU 训练串行，主线程继续做协议审计、报告和下一候选准备。
- 不承诺历史不可达结论必然能被突破；每轮以可验证增量决定继续、切换或停止旧方向。

## 算力与缓存

- RTX 3080 Laptop 16GB，使用 AMP、batch 16–32、梯度累积；按显存实测调整。
- Train 小批量波形尽量驻显存，外部/Test 流式读取；不物化 N² 样本对。
- 特征使用 FP16 memmap、GPU 分块转 FP32，逐折释放模型和缓存。
- 所有缓存记录源码、配置、权重、metadata、dtype、输入值域和 SHA256，禁止跨错误缩放版本复用。

## 验证

1. 单元/冒烟检查：输入形状、18 通道映射、频带、值域、有限值、缓存行对齐、被试/Session 隔离和 Test 零访问。
2. 小样本容量检查：拟合准确率应达到 100%，但不能作为泛化证据。
3. 完整验证：5 外层×2 内层、时间块、外部跨 Session 双向评估、统一攻击套件。
4. 端到端验证：训练→标定→外层评估→冻结→逐样本 Test 推理→CSV 校验→离线 S1/S2 审计。
5. 每阶段更新 `research/README.md` 和报告；阶段验收后创建新 Git commit 并推送远程。
