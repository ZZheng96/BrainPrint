## 2. AS-Norm 候选（固定 config，完整 20 折）

- 基础打分：E65 任务标准化 + PCA96 + k12 原型 top-1 距离（与 E221 baseline 完全一致）。
- 原型级 cohort：每个 task 下所有注册身份的原型（LOSO 19×12；Test 20×12），排除查询 top-1 所声称身份的全部原型后计算 cohort 均值/标准差。排除的是该查询 top-1 声称身份（可部署、无需标签），不是真值身份。
- asnorm_all：cohort 全量；asnorm_topk10/25/50：cohort 中最高 k 个原型分数。z-norm：每个身份模型用 outer-train fit 中其他身份语句估计均值/标准差；z+t-norm：z-norm 后再按 cohort 做 t-norm。
- 每折内 cohort、标准化、PCA、原型、归一化参数只用 fit_fraction<=0.6 且非 held 身份拟合；tau 来自内层 5 块 OOF 的 known 分数，不用 in-sample。

## 3. 关键发现

1. **实现一致性**：`baseline_raw` 完整复现 E221（AUC 0.910173、LOSO 拒识 0.563519、known 接受 0.918387、Test S1 0.826574、Test S2 0.550734），说明 AS-Norm 对比基线可靠。
2. **单阈值硬上限**（表 3，仅诊断）：S1 拒识 ≥0.70 时 S2 接受最高只有 0.6801；S1 ≥0.95 时 S2 最高 0.3419；S2 接受 ≥0.70 时 S1 拒识最高 0.6799；S2 ≥0.98 时 S1 最高仅 0.0795。即阶段性目标 (S1 0.70 / S2 0.70) 即使把阈值调到最优也差一点，官方门槛 (0.95/0.98) 在单一分数上完全不可能。
3. **尺度确实偏移**：baseline 原始分数上 LOSO known 中位数 −12.42，而 Test S2 known 中位数 −16.10，整体下移约 3.7；S1 未知分数再低约 3.3（mean −20.06 vs S2 −16.77）。把 LOSO unknown 90% 拒识的 tau（−14.46）直接搬到 Test，得到 S1 拒识 0.9716、S2 接受 0.2579——LOSO 尺度下的“好阈值”在 Session2 上会大面积误拒注册者。
4. **AS-Norm 在 LOSO 有效、跨会话不可迁移**：AS-Norm 把 LOSO unknown 拒识从 0.5635 提到 0.9101（all）/0.9199（topk50），LOSO AUC 从 0.9102 提到 0.9454/0.9458，但 Test S2 接受反而从 0.5507 掉到 0.2527/0.2255；z-norm 类较温和（LOSO 拒识 0.8360/0.8379，Test S2 0.3850/0.3450），仍远低于 baseline。原因是 cohort 的 mean/std 在 Session2 同向漂移，按查询内部归一化只能重排尺度，无法消除会话间整体偏移，反而把“会话整体偏远”误判为“未知”。
5. **结论**：跨会话差距不是阈值问题，也不是单查询 cohort 归一化能解决；没有任何候选同时满足 LOSO 拒识 >0.90、Test S2 接受 >0.70、Test S1 拒识 ≥0.70（表 5 最后一列全为“否”）。下一步若继续，应做会话级（而非查询级）无监督自适应或多视图一致性约束，但 Test 已经反复查看，任何继续以 Test 为导向的迭代都会过拟合。

## 4. 限制

- 官方 Test AUC/F1 因 Test 无身份标签为 **N/A**；S1/S2 只是会话分层行为指标，不等同官方未知/正常分类指标。表中同时给出阶段性目标（S1 拒识≥0.70、S2 接受≥0.70）与官方门槛（S1 拒识≥0.95、S2 接受≥0.98），两者不可混用。
- Test 已被反复查看，本报告所有候选、top-k、原型数与阈值均预先固定于 `config.json`，未按 Test 选择；但 Test 复用带来的评估偏倚不可消除。
- 表 2/3/4 使用 Test 分数分位点，只能用于判断可行性，不能反过来定义为阈值。
- LOSO 指标为逐折宏平均（micro 为合并计数），unknown:known 样本约 1:19，拒识 F1 受类别比例影响。
- cohort 中的“排除身份”取查询 top-1 声称身份（可部署、无需标签）；该操作在 known 查询上通常等价于排除自身身份，但不使用真值。
