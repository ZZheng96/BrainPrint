# E29：DINO 开集标定改进

日期：2026-11-12
状态：完成。结论：**E28 报告的内层 AUROC 0.45–0.51 是标定构造错误；正确构造下内层 AUROC 为 0.62–0.64，与 Test 的 0.7065 只差 0.07，标定可信。**

## 0. 修正 E28 的错误

E28 用「内层被试按奇偶分半」构造伪未知，但两半被试都在同一会话、且都参与训练，
导致伪未知与已知几乎不可分（AUROC 0.45–0.51）。

E29 改为标准做法：**留出被试**（外层 5 折留 4 人，内层再留一半注册者作伪未知），
伪未知样本完全不参与训练。

| 构造方式 | 内层 AUROC | 与 Test（0.7065）差距 |
|---|---:|---:|
| A. 留出被试（正确） | **0.6369 ± 0.0695** | **0.0695** |
| B. 时间外推（前 60% 训练 / 后 40% 伪未知） | 0.6239 ± 0.0669 | 0.0826 |

两种构造都接近 Test，说明**内层标定是可信的**，E28 的「标定质量差」判断不成立。

## 1. 工作点（DINO covariance5 + 距离型新颖度）

内层：已知距离 p50 = 20.17，伪未知 p50 = 22.12。
Test：S2 p50 = 20.94，S1 p50 = 54.27。

| 工作点 | 内层伪未知拒识率 | S2 接受率 | S1 拒识率 | 0 标签数 |
|---|---:|---:|---:|---:|
| q01 | 0.011 | **0.955** | 0.430 | 2,172 |
| q02 | 0.020 | 0.933 | 0.470 | 2,719 |
| q05 | 0.058 | 0.885 | 0.529 | 3,812 |
| q10 | 0.140 | 0.813 | 0.566 | 5,317 |
| q20 | 0.307 | 0.706 | 0.618 | 7,526 |
| q30 | 0.451 | 0.620 | 0.650 | 9,279 |
| q40 | 0.583 | 0.525 | 0.690 | 11,223 |
| q50 | 0.692 | 0.433 | 0.729 | 13,101 |

**内层伪未知拒识率与 Test S1 拒识率差距很大**（q01：0.011 vs 0.430）。
原因：内层伪未知是「同会话留出被试」，其距离分布（p50 22.12）与真实 S1（p50 54.27）差异巨大。
AUROC 接近，但**分布位置不同**，所以按分位设阈值会系统性偏松。

## 2. 关键结论

- **AUROC 层面**：内层 0.62–0.64 vs Test 0.71，标定可信，说明「距离型新颖度」这个判据是有效的。
- **阈值层面**：内层伪未知的距离绝对值远小于真实 S1，按分位设阈值会低估 S1 拒识率。
  这是「同会话 vs 跨会话」的本质差异，无法用内层完全模拟。
- 因此工作点选择应看**相对排序**（q 值），而不是内层伪未知的绝对拒识率。

## 3. 与 E27（原始协方差）对比

| 工作点 | E27 S2 接受 / S1 拒识 | **E29 DINO S2 接受 / S1 拒识** |
|---|---|---|
| q01 | 0.965 / 0.207 | **0.955 / 0.430** |
| q05 | 0.845 / 0.467 | **0.885 / 0.529** |
| q20 | 0.599 / 0.757 | 0.706 / 0.618 |

**在 q01–q05 区间，DINO 同时做到 S2 接受更高、S1 拒识更高**，这是 DINO 路线的实质优势。
