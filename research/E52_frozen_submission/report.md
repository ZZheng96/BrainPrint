## 系统

| 组件 | 配置 |
|---|---|
| 身份（clean 区） | 全 Train fit 块（trial ≤ 0.8·max，N=8,996）WCCN，20 类 |
| 身份（受扰动区） | 原始波形 CNN + PGD7 对抗训练，width 96，40 epoch，TTA5 |
| 拒识 | WCCN `distance_ratio` |
| 决策 | `dr ≥ tau_high` → logSPD 身份；`tau_low ≤ dr < tau_high` → CNN 身份；`dr < tau_low` → 0 |
| 阈值 | 校准块（trial > 0.8·max，N=2,308，未参与训练）的 q0.02 / q0.05 → 1.0796 / 1.1071 |

## 关键警示（必须读）

1. **Train 校准块只有 2% 落在拒识区，Test 却是 72.5%** —— 这说明 Test 的 `distance_ratio` 整体分布远低于 Train，是典型的跨会话/跨域偏移（与 E21–E35 的发现一致）。阈值在 Train 上校准，迁移到 Test 后几乎把所有样本判为新颖。
2. 因此 **E49 的 91.03 不能外推为 Test 预期**；在 Test 上三段式规则退化为"以拒识为主"，CNN 区只覆盖 5.9% 的样本，身份分支的增益大部分无法兑现。
3. 该 72.5% 的拒识水平与历史 E19 候选（79.2%）同量级，而 E19 官方得分 69.17。这进一步说明 S1/S2 的"未注册/注册"强推断不可靠，Session 拒识率不能当真值指标。
4. 按项目约束，不能用 Test 批次统计或 Session 重新标定阈值，因此该偏移无法在提交侧修正。

## 建议

- 该 CSV 只是候选，**不建议在无法验证的情况下替换历史最佳提交**；若提交，属于"用不同机制做一次尝试"，预期收益不确定。
- 真正要兑现 E49 的增益，需要解决跨会话分数标定（E11–E19 的 session-blind 路线），而不是继续提升同会话 RA。
