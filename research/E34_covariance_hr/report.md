# E34：高分辨率协方差图（covariance_hr）

日期：2026-11-12
状态：完成，**负结果**。分辨率从 74×74 提到 224×224，Test AUROC 反而从 0.7327 降到 0.7223。

## 0. 动机

E20 的 covariance5 把 5 张 18×18 协方差矩阵平铺到 224×224，每个矩阵只占 74×74 的一个格子，
再经插值后实际有效像素更少。DINOv2 的 patch 是 14×14，单个矩阵只覆盖约 5×5 个 patch。
本实验把每个频带的 18×18 矩阵直接双线性放大到 224×224（信息密度提升约 9 倍），
低频(δ+θ)/中频(α+β)/高频(γ) 三组分别作为 R/G/B。

## 1. 实现

- 新增编码器 `covariance_hr_image`（`src/eeg_image_dinov2/image_encoders.py`），
  用真正的双线性插值 `_resize_bilinear`（原 `_resize_to` 实为最近邻，与注释不符）。
- 图像生成：train 11,304 张 29 秒，test 22,251 张 55 秒。
- DINOv2 特征提取：train 111 秒，test 203 秒。

## 2. 结果（任务条件化 WCCN，与 E31 同协议）

| 特征 | 内层 AUROC | Test AUROC | q01 S2 / S1 | q05 S2 / S1 | q20 S2 / S1 |
|---|---:|---:|---|---|---|
| covariance5（E31） | 0.7119 | **0.7327** | 0.917 / **0.509** | 0.840 / 0.558 | 0.471 / 0.754 |
| **covariance_hr** | 0.6400 | 0.7223 | 0.949 / 0.456 | 0.863 / 0.549 | 0.594 / 0.696 |

## 3. 结论

1. **提高分辨率没有帮助**：Test AUROC 0.7223 < 0.7327，内层 AUROC 也从 0.7119 掉到 0.6400。
2. 工作点曲线只是「沿曲线滑动」：q05 时 hr 的 S2 接受高 2.3 个点、S1 拒识低 0.9 个点，本质等价。
3. 说明瓶颈不在图像的信息密度，而在 **DINOv2 特征对跨会话身份变化的敏感性**。
   高分辨率让模型看到更多细节，但这些细节同样会随会话漂移。

## 4. DINO 路线的完整尝试清单

| 方向 | 实验 | Test AUROC |
|---|---|---:|
| 图像表示 | covariance5（74×74 平铺） | 0.7327 |
| 图像表示 | covariance_hr（224×224 单图） | 0.7223 |
| 图像表示 | topomap5 | 0.5892 |
| 图像表示 | correlation | 0.5334 |
| 骨干 | DINOv3 ViT-B/16（E20J） | 0.8694（图像单独 AUC，非同一指标） |
| 身份头 | ArcFace / 普通 CE | 0.6321 / 0.6522 |
| 判据 | dist → WCCN → 任务条件化 → ratio | 0.7063 → 0.7243 → 0.7327 → 0.7403 |

**结论：DINO 路线的最优配置是「covariance5 图像 + 冻结 DINOv2 + 任务内 WCCN 距离」，
Test AUROC ≈ 0.73–0.74。继续在图像或骨干上做文章的预期收益很低。**
