# E209 全量数据注册（分块交叉拟合）报告

## 目的
E200 的注册只用每个身份 `frac≤0.6` 的 trial，这是评估协议的限制，不是部署限制。部署时 20 个注册身份可以使用 session1 的全部 trial。本实验检验“注册数据从 60% 提到 100%”能带来多少跨会话收益。

## 方法
- 校准（诚实的 Train 侧）：把每个身份的 trial 按时间切成 5 个连续块；第 b 块的 query 只与“其余 4 块”构建的原型比较，因此任何 query 都不会匹配到自己。
- LOSO：留出身份不进入任何原型或统计量。
- 部署：20 个身份用全部 Train 行构建原型。
- 阈值：Train only（LOSO 拒识 ≥0.90，最大化 known 接受率）；Test 冻结后审计一次。

## 结果
| 指标 | 数值 |
|---|---:|
| LOSO AUC | 0.8032 |
| Train known 接受率（LOSO UR=0.90 工作点） | 0.5873 |
| LOSO 拒识率 | 0.9000 |
| Test S1 拒识率 | 0.9918 |
| Test S2 接受率 | 0.1625 |
| Test 前沿 max S2 @ S1≥0.70 | 0.7282 |
| Test 前沿 max S1 @ S2≥0.70 | 0.7293 |
| Test 前沿平衡点 | S1 0.7168 / S2 0.7160（该点 LOSO 0.3108） |

可部署工作点（Train known 90% 分位阈值）：
| 阈值来源 | tau | LOSO 拒识 | Test S1 拒识 | Test S2 接受 |
|---|---:|---:|---:|---:|
| known 90% | -19.142 | 0.3295 | 0.7310 | 0.7022 |
| known 92% | -19.720 | 0.2535 | 0.6680 | 0.7586 |
| known 95% | -20.798 | 0.1637 | 0.5493 | 0.8412 |

## 结论
把注册数据从 60% 提到 100%，Test 前沿从 0.7178 提升到 **0.7282**，且存在单阈值工作点同时满足 S1=0.731、S2=0.7022，**两项均超过 0.70**。但该工作点的 LOSO 拒识只有 0.3295，远低于 0.90。

因此“注册用全量数据”是一个免费的正向改进（不依赖 Test、不改变特征），应保留到最终方案；它单独不能解决 LOSO。

AUC/F1：LOSO AUC 0.8032；Test 无标签，F1 记 N/A。
