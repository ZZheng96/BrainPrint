# AS-norm / kNN 平滑 / 自适应阈值：纯 EEG 开集决策实验

日期：2026-11-07　代码：`src/asnorm_openset/run.py`　日志：`research/E05_asnorm_openset/run.log`

## 结论

- **内部伪目标：AUROC 0.9751，macro-F1 0.9262**（冻结配置，留一折选阈值）。
- **测试 Session 代理诊断：AUROC 0.464（低于 0.5）**。即在冻结模型下，Session1 行（推测为未注册者）的置信度反而高于 Session2 行（推测为注册者及其对抗样本）。
- AS-norm、kNN 平滑、GMM 自适应阈值都没有解决真正的问题。测试中跨会话漂移对分数的影响大于身份信息，内部仿真没有复现这种漂移。
- 冻结候选 `submission_asnorm_frozen.csv` 只作诊断保存，**不建议提交**。

## 方法

基础打分器是分频带 log-cov + Ridge，取 base 分支，按 task 分别建模（复用 `open_set_calibration`）。在打分器之上，按 task 对整个目标批次比较以下单因素变量：

| 因素 | 取值 |
|---|---|
| 对齐 | none / target_zscore |
| 分数归一 | raw / AS-norm（冒名者 cohort 取自目标批次中 argmax≠k 的 top-100） |
| kNN 平滑 | 0 / 10（目标批次内特征余弦近邻，置信度 0.5 自身 + 0.5 邻居均值） |
| 置信度 | max / top1−top2 margin |
| 阈值 | 源校准 5% 分位 / 固定阈值（留一折选择） / 按 task 的 2 组件 GMM |

内部伪目标采用 5 折，每折留出 4 名被试作为未知。注册者的每个 (subject, task) 按 trial 顺序切分：前 50% 训练，50–70% 用于源校准，后 30% 作为目标。未知样本比例取 15% 和 45% 两档。合成漂移采用全局偏移加被试特异偏移，γ∈{0, 0.5, 1}，单位为特征标准差。选择指标为 √(C·U)。

## 解读

1. **内部仿真不能代表测试偏移。** 合成漂移把内部 AUROC 从 0.97 压到 0.95，测试代理 AUROC 却低于 0.5。真实的跨会话变化不是"各特征平移"这种形式，会话间变化让注册者的样本更不像自己的注册原型。
2. **未注册者可能和训练数据处于相近的采集条件。** 如果 Session1 行确实来自未注册者，而训练集也是 Session1，那么"接近训练分布"这一信号会让未知者获得更高置信度。凡是基于最近原型置信度的开集方法（raw、AS-norm、energy、margin）都会受这个问题影响。
3. **闭集身份同样受损。** 被接受的 Session2 标签高度集中，说明跨会话后部分注册者的原型已经失效，问题不只出在阈值上。

## 后续建议

以下建议只基于内部协议，不得用测试 Session 结果调参：

- 首要问题是跨会话不变的表征，阈值是次要问题。可以试验：用 Train 内 Run1/Run2、首尾静息段作为最接近"时间漂移"的正对，做 NAP/WCCN 投影，去掉会话内的时间漂移方向；或者做监督对比学习，让同一人在不同 Run/task 下聚在一起。
- 内部验证需要更真实的漂移。可以用 Train 中首尾静息 Run 之间的特征差构造经验漂移库，替换各向同性的随机偏移。
- 用聚类级开集匹配，减少对单 Trial 置信度的依赖。在目标批次内按 EEG 相似度聚类，再把簇与注册原型做带拒识代价的匹配，同时检查是否有原型无人匹配（如身份 8）。
- 对抗维度本轮没有评估。
