# E249 计划：只用 Train 估计漂移，兼顾严格 LOSO 与 S2

## Context

- 目标：在严格 LOSO 下保持未注册拒识约 0.90，同时让 Test S2 的接受率达到 0.60 以上。
- 现状：LDA-cos 的同会话表征已经够强（E247 Late AUC 0.971，已知接受 0.919，拒识 0.918），但 S2 没有合规的改善证据。Test 审计中，LDA-cos 在 0.3295 阈值下 S1 和 S2 的接受率都是 0.515。欧氏@LOSO 下 S1 接受 0.035、S2 接受 0.293。
- 根因判断：S2 的已注册者因跨会话漂移，分数落到了未知者的区间。只调全局阈值无法同时满足两端，必须让打分本身对漂移不敏感。
- 特征现状（[model.py](file:///d:/WORK/BCIC2026/BrainPrint/final/team_hymn/model.py#L62-L96)）：特征已经用相关矩阵，消除了通道增益；对角也做了中心化，逐 band 做了 z-score。所以通道幅值、全局增益这类“简单漂移”已经被消掉。剩下的漂移在相关结构里，需要从数据中估计方向。

## 方法：漂移子空间投影（NAP / WCCN 思路），漂移方向只从 Train 估计

Train 只有一个会话，因此用两种会话内的“状态变化”代理漂移：

1. **时间漂移**：每个身份、每个 task 的 Late 原型减 Early 原型（每折只用该折的拟合身份）。
2. **跨 task 漂移**：同一身份在不同 task 下的原型差，先减去所有身份共有的 task 均值差，只保留“个体内状态变化”的部分。

两类差向量合成漂移散度矩阵 D，并预先固定 3 个候选：

| 候选 | 做法 | 超参 |
|---|---|---|
| C0 基线 | E247 严格 LDA-cos，shrink 0.01 | 无 |
| C1 NAP | 在 PCA96 空间中投影掉 D 的前 k 个方向，然后再做 LDA-cos | k ∈ {4, 8, 16}，用内层折选 |
| C2 WCCN+漂移 | 白化用的协方差 = 类内协方差 + α·D | α ∈ {0.5, 1, 2}，用内层折选 |

阈值沿用 E247 的内层留一、加权 FAR10 流程。超参只用内层折选，外层只报告结果。

## 评估协议（执行前固定，写入脚本常量）

基于 [run_e247.py](file:///d:/WORK/BCIC2026/BrainPrint/research/E247_train_temporal_loso/run_e247.py) 复用 `Space`、`fit_model`、`weighted_far_threshold`、`metrics`，新增两个代理终点：

- **P1 时间代理**：与 E247 相同，Early 注册、Late 评估。
- **P2 跨 task 代理（新增，更接近“状态改变”）**：注册用 task A 的 Early，评估用 task B 的 Late，打分时用 A 的原型。这一项检验原型能否跨条件匹配。
  - 由于漂移方向含跨 task 成分，估计 D 时排除被评估的 task 对（留一 task 对），避免泄漏。
- 主判据（预先固定）：P2 上已知接受率提升，且 P1、P2 的未知拒识都 ≥ 0.88。两者用身份级配对 bootstrap，95% 区间不跨 0 才算有效。
- 尾部诊断：报告最差 3 个身份的拒识，不做按身份特设阈值。
