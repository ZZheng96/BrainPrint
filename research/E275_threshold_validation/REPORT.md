# E275 独立协议复核报告

## 结果概要

固定三折及阈值后，决赛四项等权代理由 final3 的 **0.839664** 上升至候选方案的 **0.852384**，配对差值为 **+0.012719**。新人 clean 准确率提高 0.072435，未知 clean 拒识率下降 0.021557，两个老身份代理指标保持不变。三折等权差值均为正。

四个敏感性场景等权的 AUC 和 F1 分别为 final3 的 **0.967341、0.880800**，候选方案的 **0.962473、0.890495**。这些场景均为 Train-only 代理，stress 模拟扰动不代表真实跨设备评测。

## 数据和协议

- 仅使用 Train 元数据和特征缓存，共 11,304 条记录，未读取 Test 或使用其标签与统计量。
- 固定种子 286、312、346，按非循环随机身份排列，每折划分 14 个老身份、3 个新人和 3 个未知身份。老身份的同身份同任务早段进度 `<= 0.6` 用于拟合，查询使用进度 `> 0.8`。
- 直接复用 E272/E271 排名链使用的 E270 `fit`，拟合任务标准化、PCA、类内白化及旧身份原型。旧身份原型在白化空间求均值。每折新人按排名链选取每身份每任务前 5 条早段记录，共 60 条。该分配属于本实验协议，真实注册数据不保证每任务均有 5 条。
- 适配 compat 的 `enroll` 返回新 artifact 语义，注册样本跨任务汇总后由兼容模板逻辑在各任务标准化空间生成原型。使用缓存特征的本地适配层复用 compat 几何计算，未修改正式包。每折拟合 artifact 保存在 `fits`。
- 固定 `tau_score = 0.40755866169929506`，`beta = 0.5`，老身份使用原阈值，新人旧规则使用偏移 −0.03，新规则使用 −0.06。偏移单位为无量纲门控分数。本次未搜索或调参。
- 本报告在 E275 实验中比较的是候选训练折判定和旧规则判定。正式包验收另运行 `final3_compat/verify.py`，其中“旧包兼容测试”核对权重及既有分数不变，不适用于改变阈值后的最终类别；新增“新旧阈值判定配对测试”则逐行验证，类别仅能在新人胜出且门控分数位于 `[tau_score−0.06, tau_score−0.03)` 时变化，其余行必须与旧规则一致。
- clean 与 stress 使用同一批 Train 查询的两套缓存特征。缺失任务场景剔除对应任务查询、将对应任务原型标记为无效，并删除所有剩余查询的 task 元数据以触发跨任务 fallback。完整任务场景保留任务元数据。

## 局限与复现

三折身份划分及训练内早晚段切分是有限的内部验证，不能推断隐藏身份或真实跨设备表现。模拟缺失任务同时改变可用原型和查询元数据，不能视作真实采集缺失的完整替代。实验注册采用每任务 5 条的排名链规则，真实注册任务分布可能不同。缓存特征适配层保留包的几何与门控语义，实验不包含原始 EEG 特征提取入口的端到端评估。
