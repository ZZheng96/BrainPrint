## 1. 相对 E161 的预注册改动

- 去掉输出的 L2 归一化：256 维 pooled 向量经加宽到 256 维的投影头输出（不接 BN），避免坍缩到低维球面
- 加入 VICReg 式方差 hinge（目标 std≥1）+ 去协方差项，权重扫 {0.0, 0.1, 1.0}
- 温度扫 {0.1, 0.2}，投影头加宽到 256
- 每个 trial 用两组互斥强扰动模拟跨会话正样本（A=通道增益+电极漂移，B=频带幅值重加权+噪声），并施加显式 MSE 不变性约束，把会话风格从身份中剥离

## 2. 表征训练（严格 Train-only）

- 输入：原始 18×1200 @300Hz，per-trial 去通道均值 + 全局 RMS 归一化（固定规则、无 batch 统计）。
- Encoder：4 层 stride-2 Conv1d [32, 64, 96, 128]（kernel [7, 7, 5, 5]）+ BN + ELU + 全局 mean/max 池化 → Linear(256→256)，参数量 176,960（预算 <1M），**无 L2 归一化、无 BN**。
- 损失：SupCon（温度 0.10）+ 1.0·MSE(视图A, 视图B) + 0.0·(方差 hinge(std≥1.0) + 去协方差)。
- 跨会话模拟正样本：同一 trial 的两组互斥强扰动——视图 A 只做通道增益 U(0.5,1.5) + 电极慢漂移（线性斜坡+0.5–3 周期正弦，幅度 U(0.2,1.0)）；视图 B 只做 6 个频带 ±6dB 幅值重加权 + 加性噪声 SNR 10–20dB。两者共享 ±50 点时间平移，增强后重新归一化。
- batch：20 身份 × 2 个不同时间块 trial × 2 视图 = 80 样本，同任务内异身份为 hard negative。
- 划分：每 (subject,task) 内 frac≤0.6 拟合（6695 条），0.6<frac≤0.8 仅用于早停（2301 条），>0.8 不参与训练。
- 早停：验证块留半最近质心身份准确率（余弦度量）；最佳 epoch 34、准确率 0.8782，训练耗时 64s。
- 权重：`model_lam0.0_t0.1.pt`；embedding：`train_emb_lam0.0_t0.1.npy` / `test_emb_lam0.0_t0.1.npy`（另存 best 别名 `train_emb.npy` / `test_emb.npy`）。

## 3. 评估协议（与 E143/E161 完全一致）

task-wise Train 标准化 → PCA(32/64/96，仅 fit_rows 拟合) → k=1/3/6/12 原型（每 task×identity，kmeans 种子与 E143 一致）→ 最近原型负距离为分数 → 五块 Train OOF 分位数阈值 → LOSO 每折排除被评分身份、原型只用 fit_rows、评估块 0.6<frac≤0.8 → Test 只评分。Test 诊断 AUC = roc_auc(S1 为负类, S2 为正类)。
