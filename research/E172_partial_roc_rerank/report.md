# E172 局部 ROC 重排（S1 拒识 = 0.80 处的 S2 接受）

E170 的结论：全局诊断 AUC 不是正确的优化目标——AUC 越高，S1 拒识 0.80 工作点上的 S2 接受反而越低（拟合斜率 −0.46），增益全在 ROC 尾部。本实验把所有已有缓存分数（不训练任何新模型）按**局部 ROC 指标**重新排序：主指标 `S2_at_S1_080`，即 S1 拒识恰为 0.80 时的 S2 接受率，用 Test 分数向量按 session 分组（S1 为负类、S2 为正类）做 ROC 后线性插值得到。

协议（不可改动）：task-wise Train 标准化（该 task 全部 Train 行）→ PCA 用 fit_rows(frac≤0.6) 拟合 → 原型只用 fit_rows → k=1/3/6/12 → score = −最近距离；LOSO 每折排除被评分身份、评估块 0.6<frac≤0.8；Test 只评分。Session 分组只用于诊断性评估，不参与任何特征 / PCA / 原型 / 阈值拟合。

Test 官方 AUC / F1：**N/A**（Test 无真实标签）。下表 AUC 为诊断性 AUC，F1 为 Train OOF 宏平均 F1（可复现的训练侧指标）。

## 结论

- 候选分数共 **166** 个（单路 112 + 融合 54），全部来自已有缓存，未训练任何新模型。
- 局部最优：**subwin_n4 PCA-64 k=12**，`S2_at_S1_080` = **0.6181**，pAUC[.75,.95] 0.5499，诊断 AUC 0.7822，Train OOF AUC/F1 0.9630/0.9893，implied W 0.6940。
- 全场 implied W 最高：**2way 0.4*E65(96) + 0.6*subwin(64) k=12**，W 0.7014（`S2_at_S1_080` 0.6170，LOSO@S1=.80 0.7715）。E143 公布最优 W 0.6982，E170 扫满最优 0.6984。
- 全局 AUC 最优：**3way 0.1*E65(96) + 0.4*logbp(16) + 0.5*subwin(64) k=12**，AUC 0.8034，但其局部指标只有 `S2_at_S1_080` = 0.6015（局部排名第 29/166）。
- Spearman(全局 AUC, `S2_at_S1_080`) = **0.7763**（p = 1.07e-34，n = 166）；只看单路 0.9190（p = 2.76e-46，n = 112）；把范围收窄到 AUC ≥ 0.75 的 107 个竞争性候选后只有 **0.1770**（p = 0.0683）。局部前 10 与 AUC 前 10 只重合 **0/10**。
- **是否存在 `S2_at_S1_080` ≥ 0.70 的候选**：否（0 个）。**≥ 0.78 的候选**：否（0 个）。全场最高 0.6181，离达标还差 0.1619。
- 家族层面（详见「各族最优」）：subwin_mean_N4 与 E65 局部最好（0.596–0.618）；logbp 的全局 AUC 更高（0.781）但局部只有 0.5475，再次说明 AUC 与工作点分离；phase 类（pac / wpli / spectral_entropy）AUC < 0.53、局部 < 0.23，基本无区分力；两个 embedding（E162 / E166）AUC 0.63–0.74、局部 0.37–0.46。

## 说明

- 单路候选的 PCA 维度按任务书给定网格：E65 64/96；logbp 16/32/48（90 维）；spectral_entropy / pac / wpli / hjorth 16/32；relpower 16（18 维，由 logbp 逐通道 logsumexp 减通道均值派生）；subwin 48/64/96；E162 32/64/128；E166 32/64。
- E168 子窗口特征目录经 `feature_manifest.json` 核对后只有 N=2/3/4 三个窗数（N=6/8/12 未落盘），故按实际可用文件取 `subwin_mean_n2/n3/n4`（855 维）。
- 融合用 0.1 步长权重网格，各路子分数先 z 标准化再加权：两路 9 个权重，三路在权重均 ≥0.1 的单纯形上取 36 个组合；融合基准 k 固定为 12，E65 固定 PCA-96，logbp / subwin 取各自单路在 k=12 下 `S2_at_S1_080` 最优的维度。
- 注意：这一步的基准维度用了 Test 诊断指标来挑，因此融合理由带 Test 选点乐观性；特征是 Train-only 的，没有被 Test 拟合，但「哪一路最好」这一选择看过 Test。单路 112 个候选与 LOSO 无关的结论不受此影响（它们全部来自固定网格）。
- `implied_W` = 0.25×LOSO@阈值 + 0.25×0.80 + 0.5×`S2_at_S1_080`，阈值为插值得到的 S1 拒识恰为 0.80 的分数阈值，LOSO 由该阈值对应的 Train-OOF 接受率经每折 known 分位反推，三个指标始终联动。
- 局部 ROC 用 Test 全部观测分数作阈值，取 S1 拒识 vs S2 接受的经验曲线后线性插值；`partial_auc` 为 S1 拒识落在 [0.75, 0.95] 的曲线下面积除以区间宽度 0.2。
