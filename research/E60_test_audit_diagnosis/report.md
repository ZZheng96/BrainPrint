# E60 Test 审计诊断：S1/S2 两项门禁在 logSPD 特征层面不可达

## 目的

E52 实测 E49 系统在 Test 上 S1 拒识 0.5875、S2 拒识 0.7467，两项门禁（S2≤2%、S1≥95%）都失败。
本诊断只做无标签结构分析，量化这两项门禁在特征层面是否可达。

## 结果

| 项目 | 数值 |
|---|---|
| Train 校准块 dr | q02=1.0787、q05=1.1066、中位=1.2397 |
| Test S1（N=3,033）dr | q02=1.0008、q05=1.0021、中位=**1.0371**、q95=4.6035 |
| Test S2（N=19,218）dr | q02=1.0008、q05=1.0021、中位=**1.0329**、q95=2.3096 |
| **AUROC(S2 vs S1)** | **0.4159** |
| 若 S2 拒识=2%（τ=1.0008） | S1 拒识 = **0.0201** |
| 若 S1 拒识=95%（τ=4.6055） | S2 拒识 = **0.9978** |
| 用 Train 阈值（τ=1.0796） | S1 拒识 0.5875 / S2 拒识 0.7467 |

## 结论

1. **S1 与 S2 的 `distance_ratio` 分布几乎完全重合**：中位 1.0371 vs 1.0329，q02/q05 完全相同。
2. **AUROC 0.4159 < 0.5**，方向甚至相反——该分数在 Test 上完全没有区分未注册者与注册者的能力。
3. 两项门禁**互斥且都不可达**：满足 S2≤2% 时 S1 拒识只有 2%；满足 S1≥95% 时 S2 拒识 99.8%。
4. 与 Train 上 AUROC 0.9984 形成极端反差，说明 logSPD 的类条件结构在跨会话后彻底失效，**不是阈值问题，是特征问题**。

## 与 E56 的关系

E56 已证明 Test 的 dr 分布与 Train 不重叠且形状不同（秩映射无法修复）。
E60 进一步证明：即使在 Test 内部，S1 与 S2 之间也不可分。因此任何基于 logSPD `distance_ratio` 的阈值策略都不可能同时满足两项 Test 门禁。

## 含义

- 第 9、10 项门禁（S2 拒识≤2%、S1 拒识≥95%）在当前特征族下**不可达**。
- 要满足它们必须找到在 Test 上 S1/S2 可分的特征，而 E21–E35（DINO）与 E36–E59（logSPD/CNN）两条路线都未找到。
- 这与历史提交一致：E00 第四轮 69.17 分依赖 `Session1 → 0` 规则（不合规），说明合规方案在该数据上难以同时满足两项审计。

## 证据边界

只读取 Test 波形与元数据中的 `session`/`path`/`sample`，Session 仅用于**离线审计**，未参与任何决策、阈值或模型选择。Test 无真实标签，AUC/F1/C/RA/ASafeR/U 全部 N/A。
