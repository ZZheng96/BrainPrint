# E22：跨会话身份可恢复性验证

## 问题

E21 证明「Test 分数只有训练一半」不是尺度漂移，逐样本归一化无法修复；且
AUROC(S2 vs S1)=0.39~0.50，未注册样本的分数反而更高。本实验不再调阈值，只回答一个问题：

**在合法（归纳式、无 Session、无批次统计）的前提下，是否存在一种表征/训练方式，
让跨会话的身份证据真正保留下来？**

## 可判定的验收标准

一个表征 / 训练配置算「跨会话可用」，必须同时满足：

1. Train 严格嵌套闭集准确率 ≥ 0.99（不能靠牺牲闭集能力换取迁移）；
2. Test 审计 AUROC(S2 vs S1) ≥ 0.65（注册者必须比未注册者更像已注册库）；
3. Test S2 分数中位数 / Train 内层分数中位数 ∈ [0.7, 1.3]（分数尺度可迁移）。

三条全部不满足 ⇒ 判定「trial 级跨会话身份证据不可恢复」，停止在该方向继续投入。

## 方法

### E22A 会话偏移模拟（唯一可用标签度量的跨会话代理）

在特征空间构造物理上合理的会话偏移，对**训练集**施加，用标签度量精度损失：

| 偏移 | 物理含义 | 强度 |
|---|---|---|
| 通道增益抖动 `D C D` | 电极阻抗变化 | σ=0.25 / 0.50 |
| 频带功率缩放 | 放大器/滤波差异 | σ=0.20 |
| 两者叠加 | 综合 | σ=0.35 + 0.20 |

对每个表征测量 clean 精度与 shifted 精度，**精度保持率**作为跨会话鲁棒性代理。
全部在 Train 上完成，可用真实标签，不接触 Test。

### E22B 域随机化训练

把上述偏移作为训练增广（clean + 2 份扰动副本），检验：
移位精度是否回升、Test 的三条判据是否改善。增广只用 Train，完全归纳。

### E22C 决策

按三条判据给结论；若不满足，明确写下「不可恢复」的证据与边界。

## 约束

不读 session 参与决策；阈值只用内层伪未知；测试侧只用无标签诊断量（分数比、接受率、AUROC 审计）。
