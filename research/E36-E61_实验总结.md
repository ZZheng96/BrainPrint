## 3. 关键机制发现

1. **RA 可以救，但必须换表示**：固定 logSPD 特征族下 RA≈0.02–0.09 是硬边界（E37/E43 证明）；原始波形 CNN + 对抗训练把 PGD20/SNR20 直接准确率从 0.082 提到 0.55（E45）。
2. **CNN 不能做未知拒识**：softmax 与嵌入距离的伪未知 U 都 ≤0.30（E46），因为 CNN 学到跨被试可迁移的任务特征。
3. **分工是唯一解**：logSPD 的类条件结构负责"是不是注册者"（AUROC 0.998），CNN 负责"被扰动后仍能认出"。
4. **三段式优于双模型**：按 `distance_ratio` 分段让 clean 区域用 logSPD（direct=1.0），C 从 0.9148 提到 0.9719。
5. **迁移攻击不比白盒弱**（E44）：官方预生成攻击不会更弱，E36C 的 RA≈0.06 是合理估计。

## 5. 核心未解问题：跨会话泛化

- **E52 实测**：E49 系统在 Test 上 72.5% 判为拒识（Train 校准块仅 2%），S1 拒识 0.5875、S2 拒识 0.7467。
- **E56 诊断**：Test 的 `distance_ratio` 与 Train 几乎不重叠（中位 1.033 vs 1.240，q95 3.65 vs 1.77），且**秩映射后拒识率仍 0.7231**——不是尺度偏移，是分布形状不同。
- **含义**：任何逐样本单调变换都无法修复；96.74 是 Train 内层代理，**不能外推为官方 Test 得分**。
- 这与 E21–E35（DINO 路线）的跨会话结论一致，是两条路线的共同瓶颈。

## 5.1 E60：Test 两项门禁在 logSPD 特征层面不可达

目的：量化「若 S2 拒识≤2%，S1 拒识是多少」与「若 S1 拒识≥95%，S2 拒识是多少」。

| 项目 | 数值 |
|---|---|
| Train 校准块 dr | q02=1.0787、q05=1.1066、中位=1.2397 |
| Test S1（N=3,033）dr | q02=1.0008、q05=1.0021、中位=**1.0371**、q95=4.6035 |
| Test S2（N=19,218）dr | q02=1.0008、q05=1.0021、中位=**1.0329**、q95=2.3096 |
| **AUROC(S2 vs S1)** | **0.4159** |
| 若 S2 拒识=2%（τ=1.0008） | S1 拒识 = **0.0201** |
| 若 S1 拒识=95%（τ=4.6055） | S2 拒识 = **0.9978** |
| 用 Train 阈值（τ=1.0796） | S1 拒识 0.5875 / S2 拒识 0.7467 |

**结论**：
1. S1 与 S2 的 `distance_ratio` 分布几乎完全重合（中位 1.0371 vs 1.0329，q02/q05 完全相同）。
2. **AUROC 0.4159 < 0.5**，方向甚至相反——该分数在 Test 上完全没有区分未注册者与注册者的能力。
3. 两项门禁**互斥且都不可达**：满足 S2≤2% 时 S1 拒识只有 2%；满足 S1≥95% 时 S2 拒识 99.8%。
4. 与 Train 上 AUROC 0.9984 形成极端反差，说明 logSPD 的类条件结构在跨会话后彻底失效，**不是阈值问题，是特征问题**。

## 5.2 E61：Test 上 10 个逐样本特征的 S1/S2 区分力筛查

目的：系统筛查所有已有逐样本特征，看是否存在能区分 S1（未注册）与 S2（注册）的替代特征。

| 特征 | AUROC | S1 中位 | S2 中位 | 效应量 \|d\| |
|---|---:|---:|---:|---:|
| **raw_high_band_ratio（20–40Hz 能量占比）** | **0.2767**（取方向后 **0.7233**） | 0.1366 | 0.0761 | **1.0090** |
| raw_channel_corr（通道间平均相关） | 0.5970 | 0.3729 | 0.4101 | 0.3098 |
| raw_kurtosis | 0.5402 | 3.6638 | 3.9065 | 0.1383 |
| raw_spectral_flatness | 0.5088 | 0.0041 | 0.0042 | 0.0366 |
| logspd_feature_norm | 0.4987 | 29.2404 | 29.2404 | 0.0000 |
| logspd_feature_std | 0.4982 | 1.0006 | 1.0006 | 0.0000 |
| logspd_distance_ratio | 0.4159 | 1.0371 | 1.0329 | 0.0052 |
| logspd_margin | 0.4121 | 0.0176 | 0.0155 | 0.0142 |
| logspd_max_cosine | 0.3695 | 0.5769 | 0.5459 | 0.2919 |
| raw_signal_norm | 0.3298 | 3187.46 | 2220.12 | 0.2642 |

**结论**：
1. **只有 `raw_high_band_ratio` 有实质区分力**：AUROC 0.7233、效应量 1.01。S1（未注册者）的 20–40Hz 能量占比明显更高（0.137 vs 0.076）。
2. 其余特征全部接近随机（0.50–0.60），logSPD 系列甚至反向（0.37–0.42）。
3. **但 0.72 远不足以满足门禁**：要在 S2 拒识≤2% 时达到 S1 拒识≥95%，需要 AUROC 约 0.99 以上。0.72 对应的最佳工作点大约只能做到 S2 拒识 2% 时 S1 拒识 10–15%。
4. 该特征区分的是"未注册者整体频谱更偏高频"这一群体差异，**不含身份信息**，不能用于身份识别，只能作为拒识的辅助信号。

## 5.3 E60/E61 合并结论

- Test 两项门禁（S2≤2%、S1≥95%）在 logSPD 与 10 个逐样本特征下**均不可达**。
- 最强单特征 AUROC 0.7233，距所需 0.99 差 0.27。
- 这解释了为什么历史 69.17 分依赖 `Session1 → 0` 规则：合规特征在该数据上确实无法达到审计要求。
- 后续 E67/E68 进一步证明：Test 的 S1/S2 可分性（0.9971）来自特定人群组合，不可迁移（详见 `E62-E70_实验总结.md`）。
