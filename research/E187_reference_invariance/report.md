# E187 参考化 / 去共模不变性

E65 的 correlation-logSPD 对逐通道增益、频带增益、循环平移精确不变（E165），但对**共模成分**敏感：若 Train 与 Test 的参考电极不同、或参考电极接触状态不同，18 个通道会叠加同一个共模信号，相关矩阵被整体扭曲。本实验对原始 18×1200 逐 trial 施加纯逐样本的参考化变换，再走**完全相同的 E65 correlation-logSPD** 与 **E143 协议**。

| 变体 | 定义 |
|---|---|
| `raw` | 恒等（复用 E65 冻结特征） |
| `car` | 共平均参考 x − mean(通道) |
| `car_rank` | CAR 后每通道秩→正态分位 |
| `laplacian` | 减去固定 10-20 最近邻通道均值 |
| `bipolar` | 18 组固定双极导联差分 |
| `car_plus_slope` | CAR E65 特征 + E186 1/f 斜率（18 维，块 RMS 归一） |

评估协议逐字沿用 E143：Train-only task z 标准化 → PCA-96 → k∈{1,3,6,12} 原型 → 5 块 Train OOF 阈值 → LOSO 每折排除被评分身份、原型只用 `pm & fit_rows`、评估块 0.6<frac≤0.8 → Test 只评分、Session 只审计。

## 1. 判定（核心）

1. **参考化是否提升 Test 诊断 AUC？** raw **0.7578** → CAR **0.7435**（Δ=-0.0143）；CAR 是否 > 0.78：否。全实验最高诊断 AUC 为 0.7778（bipolar）。
2. **S1+S2 能否突破 1.4479？能否达到 1.50？** 最高 **1.4165**（bipolar k=1 @a=0.90）→ 未突破 1.4479；未达到 1.50。（冻结分数扫满阈值的犯规上界最高 1.4189，raw 上界 1.3970。）
3. **哪个变体最好？共模是不是会话偏移主因？** 最佳变体 **bipolar**（S1+S2 1.4165，诊断 AUC 0.7736）。CAR（精确移除共模）相对 raw 的诊断 ΔAUC=-0.0143（同 k=12 时 -0.0833，S1+S2 -0.1256）；bipolar ΔAUC=+0.0158、Laplacian ΔAUC=+0.0095。**共模是主因：否** —— 彻底移除共模的 CAR 反而降低判别力，说明共模不是跨会话偏移的主要来源。

## 6. 机制解读

1. **raw 对照精确复现**：AUC 0.7578、S1@.90 0.7979、S2@.90 0.5960、S1+S2@.90 1.3938，与 E65/E186 冻结基准逐位一致（True）。
2. **CAR 是负收益**：诊断 AUC 从 0.7578 降到 0.7435（最优 k=1），同 k=12 时 0.6745（-0.0833），S1+S2 从 1.3938 掉到 1.3607。CAR 精确移除了通道间的加性共模，如果共模是会话偏移主因，这里应当显著变好；实际相反，说明**共模不是主因**，而且被减掉的 18 通道均值里含有身份相关的全局成分（如全脑节律幅度），损失大于收益。
3. **Bipolar / Laplacian 是正收益但幅度有限**：bipolar 最优 AUC 0.7736（+0.0158）、S1+S2 1.4165；Laplacian 最优 AUC 0.7673（+0.0095）、S1+S2 1.4104。它们同样消除共模，但保留局部空间梯度（相邻通道差分），说明收益来自「保留局部梯度、压低全局共模」这个组合，而不是单纯去共模。
4. **CAR-rank 基本无效**：最优 AUC 0.7563（k=1），k=12 时只有 0.6973。秩变换抹掉了幅值和重尾信息，而在本数据里身份信息恰恰部分存在于这些统计量中。
5. **CAR + 1/f 斜率不叠加**：AUC 0.7424、S1+S2 1.3519，与 CAR 单用几乎相同。原因是斜率块只有 18 维且与 CAR 的 logSPD 高度相关（E186 已证明它只是同一条跨会话 ROC 上的另一工作点）。
6. **工作点与 LOSO 的此消彼长**：最优 S1+S2 出现在 k=1 的 bipolar，但同一配置的 LOSO 拒识只有 0.5832（raw k=12 为 0.7936）。也就是说，跨会话 S1/S2 的改善部分来自「压低 Train 侧未知拒识、把阈值放松」，这是同一 ROC 上的工作点搬移，不是系统性变强——与 E179 的松弛门禁结论一致。
7. **犯规上界仍不够**：bipolar k=1 把阈值扫满后上界只有 1.4189，依旧低于历史最好 1.4479，说明参考化这一族变换没有改变 S1 拒识与 S2 接受之间的斜率，限制来自排序能力本身（诊断 AUC 0.75–0.78 区间），而不是参考电极。


## 7. 合规

- 所有变换都是逐 trial 的逐样本操作，未使用任何跨样本 / 跨批次 / Test 统计量；PCA、标准化、原型、阈值全部只用 Train（PCA 与 block RMS 只用 frac≤0.6 的 fit_rows）。
- LOSO 一律 `pm & fit_rows`，被评分身份从原型中剔除，评估块从未进入拟合；Test 只评分，Session 只用于描述性审计，未置 0。
- 逐样本不变性（单条 vs 批 vs 置换）已在 GPU 上复核，见 results.json 的 feature_checks。
- 未修改任何已有实验目录，未提交 git。
