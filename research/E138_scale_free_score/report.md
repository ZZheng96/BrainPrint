## 结论

**三项均值 0.7784（d1 + 全量 Train 原型 k=3，接受率 0.85），比 E136 的 0.7163 高 0.062，仍未达 0.85。**

### 1. 主要增益来自"原型用全量 Train"

E136 的原型只用 frac ≤ 0.6 的拟合块；这里改用全量 11304 条。原型更稳，Test 分数整体上移，中位偏移从约 -2.2 个标准差收窄到 **-1.30**，同一个接受率下 S1 拒识从 0.939 降到 0.867、S2 接受从 0.350 抬到 0.482。

### 2. 尺度无关的分数形态没能同时保住可分性与校准

| 形态 | Test AUC | 中位偏移（sd） | 说明 |
|---|---:|---:|---|
| d1 | 0.7566 | -1.30 | 基准，最好 |
| d1_over_sig | 0.7357 | **-0.86** | 偏移最小，但 AUC 掉 0.021 |
| d1_over_rms | 0.7358 | -2.16 | |
| d1_over_mean | 0.7325 | -2.18 | |
| d1_over_both | 0.6336 | -1.35 | |
| margin_d1 | 0.4347 | +0.62 | 失效（LOSO 拒识 0） |

按逐身份原型散布 σ_c 归一化确实把偏移从 -1.30 压到 -0.86，但可分性损失更大，净收益为负。**偏移与可分性在这个结构下是同一个东西的两面：把跨会话的距离差归一化掉，同时也把它们之间的差异归一化掉了。**

### 3. 两种工作点的对称性

| 接受率 | LOSO 拒识 | Test S1 拒识 | Test S2 接受 | 三项均值 |
|---:|---:|---:|---:|---:|
| 0.85 | 0.9867 | 0.8665 | 0.4820 | 0.7784 |
| 0.90 | 0.9451 | 0.7656 | 0.6044 | 0.7717 |
| 0.95 | 0.8244 | 0.6159 | 0.7597 | 0.7333 |

0.85 与 0.90 几乎等价，说明单纯挪阈值已到顶（S1 拒识 + S2 接受 ≈ 1.35–1.37 的结构上限）。

### 4. 还差多少

要在 LOSO≈0.98、S1≈0.87 的工作点达到均值 0.85，S2 需要 **0.70**（当前 0.48），即 Test 诊断 AUC 需要 **≥0.87**（当前 0.7566）。下一步必须提高可分性本身，方向是特征级多视图融合（E139）与更强的度量学习。
