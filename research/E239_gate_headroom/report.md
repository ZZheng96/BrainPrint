# E239 先买余量：min / 软 and / 加权和组合下的 A/B/C 三列读数

> **一句话结论**：名义达标但机制未证实：`wsum_50_50` 的 B 列 S2=0.3145，仅比 0.3122 高 +0.0023（比同规则 EEG 基线 0.3089 高 +0.0056），且其 LOSO AUC 从 0.9088 降到 0.8896、A 列 LOSO 只有 0.7040——所以 S2 的微升不是"先买余量再花"，而是加权和压缩了 unknown 高分尾部的形状效应，不稳健。min 规则已确认无效（B 列 S2=0.2995）。

## 1. 问题与机制

唯一问题：**在 LOSO 保持 0.90 的前提下提升 Test S2**。

结构性事实（本轮的前提，不是结果）：LOSO=0.90 不是一个性能指标，而是把 tau 钉在训练域冒充者分数的 90% 分位。对一个分数做任何单调变换（秩、z-score、sigmoid）都不改变 (LOSO, S2) 的组合。因此唯一可行的机制是：**在不抬高 tau 的前提下先提高 LOSO（买到余量），再把 tau 降下来花在 S2 上**。本轮把两个分支都换成逐 task z-score（同一组 fit 行 mu/sd），再构造 min / 软 and / 加权和三类组合，按 A/B/C 三列读数检验机制是否成立。

## 2. 读数定义

| 列 | tau 来源 | 读什么 | 合规性 |
|---|---|---|---|
| A | E228/E233 原始 tau（换算到 EEG 逐 task z 空间：`tau_z(t) = (tau_eeg - mu_eeg(t)) / sd_eeg(t)`） | 同 tau 下 LOSO 拒识、训练域已知接受率、Test S1/S2 | 训练侧标定，合规 |
| B | 组合分数自身的 LOSO=0.90（train 侧 unknown 的 90% 分位） | S1/S2/sepAUC/簇纯度 | 训练侧标定，合规 |
| C | 在 B 的 tau 上继续下移到 Test S1 的 5% 分位（S1 拒识=0.95） | S2 | **评估选点，不可当作合规结论** |

注：A 列用的是部署 tau = -24.138367（E228 由 deploy 模型 inner-5-block OOF **已知**分数的 19.5% 分位标定，E233 原样沿用）。在 E235 冻结逐折分数上直接读，这个 tau 的 LOSO 拒识是 0.8979；E233 报的 0.90004 是因为它给每折重新取了该折 OOF 已知分位作为折内 tau。两者都记录在案，A 列的所有横向比较都在同一个部署 tau 下进行，因此比较本身不受这个约定差异影响。B 列则统一改为分数自身 pooled unknown 的 90% 分位。

## 8. 机制诊断（这是本轮的实质结论）

**（1）min / 软 and 规则：A 列 LOSO 确实上升，但不是"余量"，是"收紧阈值"。**

- A 列同 tau 下 LOSO 拒识：EEG 0.8979 → `min_rule` 0.9192、`min_rule_3view` 0.9296、`and_rule_soft` 0.9279，看似买到了 0.0213～0.0317。
- 同一 tau 下训练域已知接受率同时从 0.8058 掉到 0.7565 / 0.7097 / 0.7541。取两支较小值必然整体压低分数，所以这是“两个门都要过”的代价，不是排序变好。
- 排序诊断（唯一能支撑余量的量）：LOSO AUC 从 0.9088 变成 0.9003 / 0.8835 / 0.8993，**全部下降**。逐 task 看也一样（EC/EO 掉得最多）。
- 结果：B 列重标定后 S2 = 0.2995 / 0.2825 / 0.3084，全部低于 0.3122，也低于同规则 EEG 基线 0.3089。**min 规则无效，A 列的上升是阈值收紧的假象。**

**（2）加权和：A 列 LOSO 反而下降，B 列微超靠的是联合尾部形状，不是排序。**

- A 列同 tau 下 LOSO 拒识：`wsum_70_30` 0.8205、`wsum_50_50` 0.7040，都远低于 EEG 的 0.8979：在部署 tau 上它们反而少拒。换言之它们**一点余量都没买到**。
- B 列：把 tau 重标定到自身 LOSO=0.90 后 S2 = 0.3132 / 0.3145，比 0.3122 高 +0.0010 / +0.0023，比同规则 EEG 基线高 +0.0056。但同期 LOSO AUC 从 0.9088 掉到 0.9034 / 0.8896。
- 机制解释：AUC 是**全局**排序量，而 B 列只读 unknown 的 90% 分位这一点。加权和压低了 unknown 的整个高分区（训练域冒充者不再有高分尾部），于是同一个 90% 分位对应的 tau 变低，Test S2 因此多进一点；这是**分布形状**的收益，不是“已知被推右”的排序收益，所以它和 LOSO AUC 的方向可以相反。

**（3）稳健性：名义超标的幅度小于归一化约定的敏感度。**

- 同一个 50/50 配方，E237 用**全局** z 读到 B 列 S2=0.2906，本轮用**逐 task** z 读到 0.3145，差 0.0239；而本轮名义增益只有 +0.0023。一个同样合规的归一化选择就能让读数移动 10 倍于增益的量，所以这个“通过”不构成可靠结论。
- 逐 task z 也不是跨 task 的单调变换（每个 task 用不同 mu/sd），所以 EEG 单支的 pooled sepAUC 从 0.8795 变成 0.8731；阈值与 sepAUC 都随归一化约定微动，这正是不能把 +0.0023 当作真增益的原因。
- 图像分支的优势主要来自对称批次均值对齐（E237：对齐后 Test AUC 0.9487，未对齐 0.7600），而 S1/S2 与注册状态混叠（E232）。因此在**训练侧** tau 上多接受 S2，有一部分是 session 偏移而不是身份可分性。

## 10. 判定

**判定：B 列名义达标（`wsum_50_50`），但机制未被证实，不建议当作确定增益部署。**

- B 列：S2=0.3145 > 0.3122，S1=1.0000 ≥ 0.95，按预设规则算"通过"；超过同规则 EEG 基线（0.3089）+0.0056。其 tau 来自**训练侧** LOSO=0.90 分位，合规。
- 但 A 列同 tau 的 LOSO 只有 0.7040（EEG 为 0.8979），说明它**没有买到余量**；同期 train 侧 LOSO AUC 从 0.9088 降到 0.8896，排序其实是变差的。
- 收益来源是分布形状而非排序，且幅度（+0.0023）小于归一化约定带来的读数漂移（同一配方全局 z 读 0.2906 vs 逐 task z 读 0.3145）。因此这是名义通过，不构成"先买余量再花"机制的验证。
- min / 软 and 规则全部失败：B 列 S2 分别为 0.2995、0.2825、0.3084，均低于 0.3122。

**部署参数（训练侧标定，合规）**：

- 组合公式：`0.5*z_eeg + 0.5*z_img_px_all`
- 逐 task z：`z = (x - mu_t) / sd_t`，mu/sd 取自各分量 fit 行参考分数；EEG 的 mu/sd 已写入 `models/e239_gate_headroom.pt`
- tau(B) = -0.434228（组合分数自身 LOSO=0.90 的训练侧分位）
- 在该点：LOSO=0.8996、S1=1.0000、S2=0.3145、sepAUC=0.9553、簇纯度=0.8038
- A 列同 tau 的 LOSO 拒识=0.7040（已知接受率 0.8513）

## 11. 合规性与局限

- B 列 tau 是**训练侧标定**（Train 域 LOSO unknown 分数的 90% 分位），这是唯一可部署的读法。C 列 tau 来自 Test S1 分位，是评估选点，不能当作合规结论。
- Test 自 E65 起被反复查看，所有 S2 数字都带**反复检视偏倚**；本轮候选与组合规则在运行前已写入 `config.json`，A/B 列没有在 Test 上选点。
- Test 没有身份标签，官方 **C / RA / ASafeR 为 N/A**；本任务是门控（拒识）任务，没有闭集分类器输出，**F1 亦为 N/A**。S1 拒识与 S2 接受率是唯一读数。
- E232：S1 = 5 名未注册被试、S2 = 20 名注册用户，session 与注册状态混叠；对齐只把 session 当批次键。均值对齐是批次/转导统计量，需与竞赛规则确认。
- 组合分数是标量，身份仍来自 EEG 分支，簇纯度只检验接受决策是否保持身份一致。
- 图像视图是 E237 的缓存分数（E149 像素视图），本轮**没有重建任何特征**，EEG 分支是 E233 的冻结分数。

- 运行：`.venv\Scripts\python.exe research/E239_gate_headroom/run_e239.py`（CUDA），耗时 2s；逐候选分数在 `cache/`，z 统计量与 tau 在 `models/e239_gate_headroom.pt`。
