# E179 放宽 #9/#10 到 0.75 后的全门禁搜索

## 0. 口径说明

用户要求：把十项门禁的**最后两项**放宽为 **0.75**。

| # | 原目标 | 放宽后 |
|---|---|---|
| 9 | Test S2 拒识率 ≤ 2% | **Test S2 接受率 ≥ 0.75**（等价于拒识率 ≤ 25%） |
| 10 | Test S1 拒识率 ≥ 95% | **Test S1 拒识率 ≥ 0.75** |

其余 8 项维持原阈值：Train 准确率 1.00、C ≥0.95、macro-F1 ≥0.92、块外 ≥0.90、
pseudo-unknown AUROC ≥0.98、U@95% ≥0.95、RA ≥0.95、ASafeR ≥0.98。

搜索空间：`E174_recompute_all_w/all_records.json` 的全部 **21,437** 条工作点记录，
排除 1,398 条来自 LOSO 污染或违规实验的记录后剩 **20,039** 条。

## 1. 结论

**没有任何一条记录同时满足放宽后的 #9 与 #10。**

| 统计 | 值 |
|---|---:|
| 有效记录数 | 20,039 |
| 同时满足 S1 ≥ 0.75 且 S2 ≥ 0.75 的记录 | **0** |
| `S1 拒识 + S2 接受` 的历史最大值 | **1.4479** |
| 满足两项所需的最小和 | **1.50** |
| 缺口 | **0.0521** |

历史最大值出现在 E149 图像路线的 `S1 0.6327 / S2 0.8152`（LOSO 仅 0.2044），
即"高 S2"是靠牺牲 S1 换来的，无法同时站上 0.75。

## 2. 为什么差这一点点也过不去

两项要同时达到 0.75，相当于在 Test ROC 上要求：

```
S1 拒识 = 0.75  ⇒  TNR = 0.75
S2 接受 = 0.75  ⇒  TPR = 0.75
```

按等方差 binormal 模型反解，需要

```
d' = 2 × Φ⁻¹(0.75) = 2 × 0.6745 = 1.349
AUC = Φ(d'/√2) = Φ(0.954) ≈ 0.830
```

**即诊断 AUC 需达到 ≈ 0.83。** 当前历史最高是 **0.8055**（E171 三路融合），
对应的最大和只有约 1.45。

这不是阈值问题：`S1 + S2` 的双指标上限完全由诊断 AUC 决定，
在同一条 ROC 上移动阈值只会让两者此消彼长。

关键点：**#2–#6 全部由 E58 一个方案达成，但 E58 是外部 BCIC IV-2a 上的训练侧代理**，

离放宽后的 #9/#10 仍差 0.50 / 0.19。
而 #9/#10 的达标者（E149/E155）在开放集与对抗项上又完全不合格。

**没有任何单一方案同时占据两侧。**

## 5. 判定

1. 放宽 #9/#10 到 0.75 后，**仍然没有方案能全部达标**。
2. 直接原因：0/20,039 条记录能同时拿到 S1 ≥0.75 与 S2 ≥0.75；缺 0.052 的和，约合诊断 AUC 0.83 vs 现有 0.8055。
3. 更深原因：#5（AUROC 0.9094 vs 0.98）、#6（U@95 0.4882 vs 0.95）、#7（RA 0.4417 vs 0.95）、#8（ASafeR 0.6965 vs 0.98）四项差距更大，且现有 Test 面向的方案完全不含对抗防御。
4. 历史上唯一多项达标的是 E58，但它是**外部数据训练侧代理**，Test 侧两项仍然大幅失败。
5. Test 官方 AUC / F1 / C / RA / ASafeR / U / Score = **N/A**（无真实标签）。

## 6. 若要真正可行，需要同时满足（给后续路线用）

```
单一方案必须同时具备：
  闭集：C ≥0.95、macro-F1 ≥0.92、块外 ≥0.90、in-sample ≈1.00
  开放集：pseudo-unknown AUROC ≥0.98、U@95 ≥0.95
  对抗：RA ≥0.95、ASafeR ≥0.98
  Test：S1 拒识 ≥0.75、S2 接受 ≥0.75（对应诊断 AUC ≈0.83）
```

当前最接近的是 E58（外部代理）在训练侧的 6 项，加上 E171 的 AUC 0.8055；
两者之间的差距不是调参能弥合的，需要**既能对抗鲁棒、又能跨会话拒识**的统一骨干。
