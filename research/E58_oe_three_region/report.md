> 编号说明：本实验在 E53–E55（单模型端到端路线）之后，把 E54 的 OE 训练 EEGNet 接入 E49 的三段式决策。

## 方法

| 组件 | 配置 |
|---|---|
| 身份（受扰动区） | E54 `EEGNetEmbedding`：8 时间卷积(k=65) → depthwise 空间卷积(D=2) → 16 separable(k=15)，64 维 L2 embedding，可训练原型 + 余弦 |
| 训练 | ARPL 双侧开空间损失 + 配对 Outlier Exposure（λu=0.1, m=0.2, T=0.05）+ 混合目标/非目标 PGD 对抗训练，clean/adv 各 0.5 |
| 被试角色 | E54 互斥 4/8/4/4 划分：outer_unknown 4 / enrolled 8 / oe_only 4 / calibration 4 |
| 身份（clean 区） | 冻结 E36 logSPD WCCN |
| 拒识 | logSPD `distance_ratio` |
| 决策 | `dr ≥ tau_high` → logSPD；`tau_low ≤ dr < tau_high` → OE-EEGNet；`dr < tau_low` → 0 |
| 阈值 | 该 run clean known 的 q0.02 / q0.05，不使用 pseudo-unknown 或 Test |

## 为什么有效

1. **OE 让身份模型在扰动下更稳**：E54 单模型 RA 0.7824 已高于 E49 的 CNN（0.7313），接入三段式后 RA 进一步到 0.9371。
2. **logSPD 承担 clean 与拒识**：C 与 U 不受 OE 影响（0.9714 / 0.9875），避免了 E54 单模型 U 只有 0.4180 的问题。
3. 两者互补：OE-EEGNet 负责"被扰动后仍能认出"，logSPD 负责"是不是注册者"。

## 剩余差距与下一步

- 唯一未达标的是 SNR20 的 RA（0.908–0.932）与 ASafeR（0.959–0.977），差距 0.02–0.04。
- 可行方向：E55 的在线 PGD7（每批次重新生成对抗样本）在 E54 基础上已实现但未跑 inner；把它接入 E58 有望进一步压缩 SNR20 差距。
- 注意：E56 已证明 Test 的 `distance_ratio` 分布与 Train 几乎不重叠，**96.74 是 Train 内层代理，不能外推为官方 Test 得分**。

## 证据边界

Train session1 内层嵌套、伪未知被试（calibration 4 人）、连续文件块代理；攻击为对 OE-EEGNet 的白盒 PGD20（E44 已证迁移不弱于白盒）；阈值只用 clean known。无外层选择、未读取 Test、无跨会话结论。
