1. **S1 样本数正好 3,033 = label 0 总数**，且 S2 的 19,218 条全部非 0。
   因此第 1、2 次提交的 S1 拒识与 S2 接受是"100% / 100%"，但这是**按 Session 字段直接置 0 的规则产物**，不是 EEG 开放集拒识能力。

## 对当前 W 指标的含义

若把该 CSV 直接代入 W：

```
W = 0.25 × LOSO + 0.25 × 1.0 + 0.5 × 1.0 = 0.75 + 0.25 × LOSO
```

即使 LOSO = 0，W 也有 **0.75**；若 LOSO = 0.7936，W 达 **0.9484**。

**这说明在允许使用 Session 元数据的口径下，W>0.80 是平凡的**，任何"Session1 全部判 0"的提交都能通过。当前项目坚持的"不使用 Test 侧信息、不做 Session 规则"约束，才是 W 只有 0.72 的原因。

## 结论

- 第 1 次提交：S1 拒识 **1.0000**、S2 接受 **1.0000**，但完全来自 Session 规则，不能作为 EEG 拒识能力证据。
- 官方 69.17 反映的是 S2 上的身份分类质量，不是开放集拒识质量。
- 第 3 次是唯一"session-blind"的提交（S1 0.5796 / S2 0.1742），官方只有 26.10，说明不做 Session 规则时纯 EEG 方案确实困难。
