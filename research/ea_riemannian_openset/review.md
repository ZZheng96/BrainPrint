# 本轮评审与后续方案

日期：2026-11-07

## 1. 本轮结论

- Train 只有 Session1，每名被试的身份和会话完全混在一起。同会话内的验证指标已经饱和（AUROC 约 0.995，U 约 0.99），方法之间的差异在 ±0.002 以内，分不出优劣。
- Riemannian recenter 与 target_zscore 基本持平，唯一的收益是最差折 detection-F1 提高 0.003–0.012。EA、LDA、余弦原型已否决。
- 测试代理诊断中置信度 AUROC 为 0.46，方向反转。这说明当前特征记住的主要是会话指纹，例如电极阻抗和佩戴位置，而不是脑纹本身。
- 跨会话稳定、对抗稳定、正确拒识三个问题都没有解决。LOSO 不再作为优化目标。
- 原稿第 4 节的目标没有对齐官方记分公式，已按 `Score = 100·C^0.40·A^0.35·U^0.25` 重写，见第 4 节。

## 2. 总体思路

目标是学到跨会话不变的脑纹本质特征，再以此做身份识别和区分。

1. **特征去会话化。** 用相对频谱、alpha 峰频率、1/f 斜率、相干和相位同步等对增益不敏感的特征，替代依赖绝对幅值的协方差。每条 trial 先做迹归一化，再映射到切空间。
2. **去掉非身份方向。** 用 Train 内首末段静息的差异、run 之间的差异、task 之间的差异估计会话和状态方向，再用 NAP/WCCN 投影掉。
3. **更难的代理验证。** 用跨 task（SSVEP/Imagery 与静息互测）和跨 run（首段静息训练，末段静息测试）筛选特征，取代已饱和的同会话验证。
4. **测试端转导。** 不读 Session，在测试批次上聚类，按簇与 20 个注册模板做匹配（Hungarian 匹配加拒识代价）。匹配不上的簇整体判为 0。
5. **对抗处理。**
   - 先在原始信号上做测试集内的近重复配对。能配上对的对抗样本继承干净样本的标签。
   - 配不上对时，做输入净化（低通、降采样）并检查一致性，预测不一致就输出 0。
   - 同时在 Train 上用替代模型生成 PGD 迁移攻击，估计 RA 和 ASafeR。

**执行顺序：** 测试端诊断（聚类结构、近重复配对）→ 特征去会话化与 NAP → 簇级匹配拒识 → 对抗评估与防御。

## 3. 无标签验证统计量

记 `pred` 为全部 22,251 条测试样本的预测。这些量只用预测结果和 EEG 特征，不读 Session。它们作为事先写定的验收门槛，每个候选方案只核对一次，不据此反复调参。

| 统计量 | 计算方式 |
|---|---|
| 总拒识率 | `mean(pred == 0)` |
| 归一化熵 H | 被接受样本中 20 个身份的占比 p_k，H = −Σ p_k·log p_k / log 20 |
| 最大/最小计数比 | max(n_k) / min(n_k)，并记录计数为 0 的身份数 |
| 窗口一致率 | 同一 trial 的两个 2 秒窗口分别预测，标签相同的比例 |
| 近邻标签一致率 | 测试特征空间中，每个样本的 10 个近邻里与它预测相同的比例 |
| 拒识聚集度 | 被拒样本的 10 个近邻中同样被拒的比例 |
| 近重复对一致率 | 原始信号相关系数大于 0.98 的样本对中，预测相同的比例 |

拒识率的预期值来自赛题结构：Train 中每人每会话约 565 条，5 名未注册者约 2,825 条，约占测试集的 13%。

## 4. 量化目标

### 4.1 主目标：官方记分公式

所有候选方案统一用官方公式比较，不再用自造的“几何平均”或单一维度门槛：

```
Score = 100 × C^0.40 × (0.7·RA + 0.3·ASafeR)^0.35 × U^0.25
```

其中 A = 0.7·RA + 0.3·ASafeR。任一维度为 0 时总分为 0，因此不能靠“全部拒识”或“全部接受”取巧。

### 4.2 分项目标

| 维度 | 指标 | 目标 | 当前 |
|---|---|---|---|
| 正常识别（C） | 注册者正确身份率 | ≥ 0.90 | 内部 0.946（同会话，不可外推） |
| 对抗识别（RA） | 对抗样本恢复原身份率 | ≥ 0.60 | 未评估 |
| 对抗安全（ASafeR） | 正确识别或拒识率 | ≥ 0.90 | 未评估 |
| 对抗综合（A） | 0.7·RA + 0.3·ASafeR | ≥ 0.70 | 未评估 |
| 未知拒识（U） | 未注册者判 0 率 | ≥ 0.85 | 内部 0.992（同会话，不可外推） |

### 4.3 官方得分对照

按官方公式计算，用于判断方案取舍：

| 场景 | C | A | U | 官方得分 |
|---|---:|---:|---:|---:|
| 当前正式提交，对抗全被拒识（A=0.3） | 1.00 | 0.30 | 1.00 | 65.61 |
| 当前正式提交，A=0.5 | 1.00 | 0.50 | 1.00 | 78.46 |
| 当前正式提交，A=0.7 | 1.00 | 0.70 | 1.00 | 88.26 |
| 纯 EEG 内部最优，A=0.3 | 0.946 | 0.30 | 0.992 | 64.04 |
| 纯 EEG 内部最优，A=0.7 | 0.946 | 0.70 | 0.992 | 86.15 |
| 纯 EEG 保守估计，A=0.3 | 0.85 | 0.30 | 0.95 | 60.70 |
| 纯 EEG 保守估计，A=0.7 | 0.85 | 0.70 | 0.95 | 81.66 |

结论：**A 的弹性最大。** A 从 0.3 提到 0.7 约涨 22 分；C 从 1.0 降到 0.85 只掉约 5 分。因此对抗维度是当前性价比最高的方向，纯 EEG 替换本身不构成收益，必须同时解决对抗。

### 4.5 拒识率口径修正

原稿把“总拒识率 12–25%”作为 U 的目标，口径有误。U 的分母是未注册者样本，不是全部测试样本。按测试集结构：

- session1 共 3,033 条，session2 共 19,218 条；
- 若 session1 即 5 名未注册者，则 U 的分母是 3,033 条，对应全测试集拒识率约 13.6%；
- 若 session1 中混有注册者（幅值诊断显示 session1 有约 10% 样本 raw_std_mean > 40，session2 仅 1.3%），则 U 的分母更小，且 `session1 → 0` 会同时损失 C 和 U。

因此 U 的目标应表述为“未注册者样本中判 0 的比例 ≥ 0.85”，而不是“全测试集拒识率 12–25%”。全测试集拒识率只作为无标签诊断量，不作为目标。

### 4.6 优先级

1. **先测 A。** 用 Train 做 PGD 迁移攻击，估计当前正式提交的 RA 和 ASafeR。若 A 接近 0.3，则 65 分是天花板，必须换方案。
2. **再决定是否换纯 EEG。** 只有当纯 EEG 的 C、U 损失小于 A 的收益时才替换。
3. **最后才调 C 和 U。** 同会话内部指标已饱和，继续调参没有信息量。


**核心问题不在计算流程，而在两个防御假设本身不成立。**

## 1. 非对称配对：方向判据被攻击利用

当前规则默认“置信度更高的一端更可能是干净样本”。但 PGD 可以让对抗样本以很高置信度输出错误身份，于是出现：

- 干净样本 → 对抗样本：纠正部分对抗样本，RA 从 0 提高到 0.1788；
- 对抗样本 → 干净样本：把原本正确的干净预测改错，C 从 0.9228 降至 0.8437。

所以综合分虽然提高 **12.27 分**，但正常识别损失不可接受。

此外，配对质量也不够可靠：

- 主攻击下，配对双方的直接预测一致率平均只有约 **2%**；
- `gap>0.005` 没有过滤掉任何已通过相似度门槛的配对，说明这个约束目前基本无效；
- 图均值更加严重，C 降至 **0.5131**，证明直接平均冲突身份不可行。

## 2. 多视图：多个视图会共同犯错

40 Hz 低通和 150 Hz 降采样仍然共享主要身份频带，扰动也能迁移到这些视图。因此，“两个视图一致”不等于“预测可靠”，它们可能一致地输出错误身份。

定向 SNR20 下尤其明显：

- direct：ASafeR = **0.0051**
- multiview：ASafeR = **0.0053**

几乎没有安全性提升。组合方法也没有解决干净锚点识别问题。

## 3. 原始模型在强攻击下已丢失身份信息

主攻击下 direct 的 **RA=0**。此时后处理只能从未受攻击的配对样本恢复一部分信息，无法稳定重建身份。

SNR30 较弱攻击下，非对称配对能达到 RA=0.3838、ASafeR=0.8648，但仍未达到门槛，且 C=0.8721。这说明攻击越强，依赖置信度判断传播方向越不可靠。

## 建议的改进顺序

### 第一优先级：先做诊断和攻击校准，不新增候选

- 在训练折内审计 `clean→adv`、`adv→clean`、`clean→clean` 三种传播的收益与损失。
- 使用测试集无标签近邻的波形差异，估计实际扰动的 SNR 和频带分布。
- 判断当前 SNR20 白盒攻击是否过强或与赛题扰动不一致。

### 第二优先级：若要保留配对，必须重做“方向判断”

不再直接采用最大置信度，而是在训练折内生成对抗样本，学习干净锚点可靠性，例如结合：

- 多视图身份是否一致；
- 各视图置信度变化；
- 时间窗口一致性；
- 近邻类别一致性。

同时保护正常高置信样本，禁止被配对另一端轻易覆盖。仅仅继续调整相似度或 gap 阈值，成功可能性较低。

### 第三优先级：提高模型本身的鲁棒性

如果配对方向学习仍失败，应停止后处理路线，转向：

- 训练折内的原始波形对抗训练；
- 多视图一致性训练，而不是仅在推理阶段投票；
- 内层伪未知折重新校准拒识阈值，保护 U。

新防御还必须接受针对完整防御流程的自适应攻击，避免只攻击原始视图而高估鲁棒性。
