# BrainPrint 研发目标与量化验收指标

日期：2026-11-12  
状态：用户确认的研发目标，不是当前实验结果或官方 Test 性能估计。

## 1. 目标与证据边界

依据[赛题说明](../赛题说明.md)，模型需要同时优化正常识别 C、对抗鲁棒准确率 RA、对抗安全率 ASafeR 和未知身份拒识率 U：

```text
Score = 100 × C^0.40 × (0.7 × RA + 0.3 × ASafeR)^0.35 × U^0.25
```

Test Session1 全部为未注册者、Session2 全部为注册者正常及对抗样本，属于与官方设计和样本数量高度吻合的**强推断**，不是公开真值。S1/S2 指标只能用于模型冻结后的结构审计，不得参与逐样本身份或拒识决策，也不得作为 pseudo-label 调整阈值、选择模型。

Train 拟合准确率 100% 仅用于检查模型容量和训练流程，不代表跨会话泛化能力。模型选择必须以 Train 内严格折外、时间块及留被试 pseudo-unknown 验证为依据。

## 2. 量化验收目标

| 层面 | 具体指标 | 目标 |
|---|---|---:|
| 拟合能力检查 | Train 准确率 | **100%**，但不作为泛化证据 |
| 折外闭集识别 | 注册者准确率 C | **≥ 0.95** |
| 折外闭集识别 | 身份 macro-F1 | **≥ 0.92** |
| 跨时间代理 | 连续时间块折外准确率 | **≥ 0.90** |
| 开放集区分 | pseudo-unknown AUROC | **≥ 0.98** |
| 开放集工作点 | 已知身份接受率固定为 95% 时，未知拒识率 U | **≥ 0.95** |
| 对抗识别 | 训练折外攻击套件 RA | **≥ 0.95** |
| 对抗安全 | 训练折外攻击套件 ASafeR | **≥ 0.98** |
| Test 冻结后审计 | Session2 拒识率 | **≤ 2%** |
| Test 冻结后审计 | Session1 拒识率 | **≥ 95%**，以 S1 全部为未知者的强推断为条件 |

上述数值是研发验收目标，不是对当前模型已经达到这些指标的声明。连续时间块结果只是跨会话代理，不得报告为真实跨天性能；训练折外攻击结果不得报告为官方 Test 对抗性能。

## 3. 代理总分

若训练侧验证恰好达到 `C=0.95、RA=0.95、ASafeR=0.98、U=0.95`：

- 对抗综合项：`A = 0.7 × 0.95 + 0.3 × 0.98 = 0.959`。
- 训练侧代理总分：约 **95.3/100**。

该数值只用于统一比较训练侧候选，不是官方 Test 得分预测。

## 4. 当前 E31 与目标的差距

当前数值来自 [E20–E35 DINO 路线总结](E20-E35_DINO路线总结.md)。

| 指标 | E31 当前值 | 目标 | 需要改善 |
|---|---:|---:|---:|
| Train 折外闭集准确率 | 0.9294 | ≥0.95 | **+2.06 个百分点** |
| Train 身份 macro-F1 | 0.8961 | ≥0.92 | **+2.39 个百分点** |
| Train unknown AUROC | 0.9095 | ≥0.98 | **+0.0705** |
| Test S2 拒识率（无标签审计） | 8.3% | ≤2% | **至少下降 6.3 个百分点** |
| Test S1 拒识率（强推断口径） | 50.9% | ≥95% | **至少上升 44.1 个百分点** |

Test AUC、Test F1 均为 **N/A**，原因是没有公开真实标签。S2 拒识率不是 C 或 RA，S1 拒识率也只有在上述强推断成立时才等价于 U。

## 5. 可达上限分析（2026-11-13 更新）

E36C 之后的四组实验（E36C 六攻击、E37 对抗训练、E40 双门控拒识、E41 监督检测器、E43 噪声鲁棒特征）给出同一结论：**SNR20 原始波形 PGD 下 RA≈0.02–0.09 是当前数据与特征族的硬边界**。

- E37：特征空间对抗训练（残差 MLP + ARPL）在 PGD20/SNR20 下准确率 0.03，FGSM30 0.39；且证明 logit 尺度不是有效自由度。
- E43：把 logSPD 换成每频带归一化相关矩阵后，攻击下准确率降到 0；相关结构比含特征值的 logSPD 更易被推。
- E40/E41：拒识只能提高 ASafeR，无法提高 RA。

由此可算官方 Score 的结构性上限：

| 情形 | A = 0.7·RA + 0.3·ASafeR | Score（C=0.95, U=0.99） |
|---|---:|---:|
| 只靠拒识，RA→0、ASafeR→1 | 0.300 | **≈64.8** |
| 当前最优训练侧（E40：C 0.95, RA 0.037, ASafeR 0.708, U 0.990） | 0.238 | 59.1 |
| E36C 外层参考（C 0.940, RA 0.061, ASafeR 0.682, U 1.0） | 0.247 | 59.8 |

含义：在不突破 RA 的前提下，训练侧代理总分的上限约 65；任何只调阈值、检测器或拒识策略的方案都无法显著超过它。要突破必须让模型在扰动下仍能识别，这需要与 E36 完全不同的建模路线（如原始波形大容量网络 + 强对抗训练），且不保证在小样本（20 人、11k 试次）上成立。

## 6. 后续实验判据

1. **模型是否保留**：只依据 Train 嵌套折外的 C、macro-F1、RA、ASafeR、U、unknown AUROC 和代理总分；所有候选采用相同协议。
2. **阈值选择**：在已知身份接受率不低于 95% 的约束下，最大化训练侧代理总分，不再默认固定使用 q01。
3. **未知标定**：通过留被试 pseudo-unknown 和内层校准完成；外层未知被试不得参与训练、阈值拟合或模型选择。
4. **Test 审计**：模型及阈值冻结后检查 `S2 拒识≤2%、S1 拒识≥95%`。若未达到，应回到 Train 内研究表征与决策方法，不得直接根据 Test S1/S2 结果调阈值。
5. **防止单一指标投机**：若 S1 拒识提高，但折外 C、RA、macro-F1 或 ASafeR 低于门槛，方案仍判定不合格。
6. **实验报告**：每次使用 Markdown 记录 AUC 和 F1；无真实标签时明确写 N/A 及原因，同时报告可获得的 C、RA、ASafeR、U 和 macro-F1，并注明验证口径。
