# 跨会话表征与扰动已知拒识改进计划

## Context
E202 Test S2 接受率仅 0.2176，S1 拒识率 0.7778。目标仍为 S1/S2 均至少 0.70、LOSO >0.90，以及其余八项指标达标。不能通过全接受或降低阈值牺牲未知拒识。当前 CE+SupCon 并未显式训练跨会话不变性，gate 的训练注册人数与部署人数不同；冻结 E162 的训练身份来源也需核验。因此不能先认定全部差距都由真实会话漂移引起。

## 推荐实施
1. **先排除实现和协议问题**：在相同 Train 原始 trial 上比较 E65 Train/Test 两条提取路径，核对数值、行序和配置；追溯 E162 缓存训练身份。若 E162 包含 LOSO 留出身份，则撤回“全流水线严格 LOSO”表述，新实验不复用全局 E162。核查 gate 拟合/校准/评估是否独立。
2. **新建独立实验目录，保留 E202**：目录编号执行时确认。使用项目 `.venv` 和 CUDA；复用 E200 的 `logspd_subwindow()`、`subwin6()` 数学流程，但所有可学习统计重新按折拟合，不直接加载历史全量 bundle。
3. **固定四组 Train-only 消融**：A0=subwin6 距离基线；A1=subwin6+训练身份 embedding（CE+SupCon）+独立 gate；A2=增加原始 EEG 双视图一致性训练；A3=在 A2 基础上让 gate 同时学习干净及扰动已知 query。通过这些消融区分表征改善和 gate 改善。
4. **有效扰动而非形式增强**：在 Train 内检查带限噪声、轻微通道混合、局部时段污染等是否真正改变 correlation-logSPD，又不破坏身份；不依赖会被标准化抵消的纯通道增益。不读取 Test 分布选择增强强度。
5. **注册 episode 与校准**：support/query 按原始连续块分离；所有增强视图跟随原始样本归组。gate 采用匹配距离、margin、类内半径和子窗一致性等特征。校准集与评估集独立，按真实注册人数校准，禁止16人阈值直接部署20人。只有20个Train身份时，没有额外真实未知身份验证20人完整注册库，明确保留此外推限制。
6. **候选选择和最终评估**：仅使用内层 Train 分组验证选择候选，固定预算和规则；外层留2/5/10及20折LOSO用于评估，不用于反复选参。每折所有学习组件排除外层未知身份。冻结后才做 Test 审计；已反复查看的 Test 不再声称独立盲测，不据其结果反选阈值。

## 关键文件
- `research/E200_final_freeze/predict.py`：复用子窗口特征函数。
- `research/E65_correlation_spd/run_e65.py` 与 `research/E202_dual_model_cross_session/extract_test_e65.py`：特征一致性核验。
- `research/E162_raw_eeg_contrastive_v2/run_e162.py`：训练身份及缓存溯源。
- `research/E202_dual_model_cross_session/model_a.py`、`model_b.py`、`compute_metrics.py`：参考实现；新模型和修正指标放在新实验目录，不覆盖历史结果。

## 验证与交付
- 小规模 Train 检验特征一致性、扰动有效性、分折隔离和注册后逐 trial 推理；通过后运行固定消融。
- 11项指标分别报告：拟合准确率、C、身份macro-F1、真正留块准确率、AUROC、U@95、RA、ASafeR、S1拒识、S2接受、LOSO拒识。最终含拒识预测与拒识前闭集性能分列。
- U@95在独立校准集标定并报告评估集实际已知接受率；RA/ASafeR的特征攻击代理不能替代原始EEG攻击，未完成时明确标注未验证。
- 保存权重、注册模板、阈值、配置和折划分，产出包含AUC/F1及全部限制的Markdown报告。不得拼接不同模型最优指标或承诺一定达标。
