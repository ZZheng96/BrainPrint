# E252：决赛方案综合总结与 11 项指标决策报告

## 1. 最终结论

**决赛推荐继续使用 `final/team_hymn`，配置为 `subwin6_pca96_k1 @ a=0.90`，不采用 E249、E250 或 E251 替换正式提交包。**

选择理由不是某个 Train 指标最高，而是综合考虑：

1. `final/team_hymn` 是唯一完成决赛接口、模型权重、注册流程、未知输出、新用户 21–23 号标签和提交包自测的冻结候选；
2. 冻结后一次性 Test 工程审计中，S1 拒识率为 **0.713485**，S2 接受率为 **0.706889**，均达到当前 0.70 审计门槛；
3. E249/E250/E251 虽改善了部分 Train 代理或严格 LOSO 指标，但 Test S2 仅 **0.429–0.442**，没有形成可替代的跨会话证据；
4. 不能把不同实验、不同模型、不同攻击协议的数字拼接成一个虚假的“完整 11 项成绩”。

因此当前决策是：

```text
正式提交：final/team_hymn
研究参考：E249 C2、E250 C2、E251 lambda=0
正式包：不修改、不替换
```

Test 没有身份真值，因此官方 Test AUC、F1、C、RA、ASafeR、U、Score 均为 **N/A**。S1/S2 只能作为冻结后的工程审计读数。

## 2. 数据与决赛边界

- 输入形状：`(N, 18, 1200)`；通道顺序固定；四类任务为 EC、EO、Imagery、SSVEP。
- Train：20 个身份、session1、11,304 条样本；用于训练、统计量、PCA、原型和阈值。
- 决赛新增场景包括原有用户跨时段/跨设备、新用户注册后识别、未注册用户检测。
- Test 不得用于监督更新、无监督适配、重新拟合 PCA/标准化/阈值、模型选择或任何统计调参。
- `session` 只能在冻结预测写出后用于离线分组审计，不得参与模型判决。
- 输出必须为 `(N, 24)`；第 0 列代表 unknown score，第 1–20 列是原有身份，第 21–23 列是注册后的新身份。

## 3. 几轮实验的经验

### 3.1 E248：身份排序和开放集拒识是两个问题

E248 证明 LDA-cos 显著提升闭集身份排序：在 E247 Late 评估中，LDA-cos 闭集准确率约 **0.982**，欧氏距离约 **0.892**，AUC 约 **0.971**。但未知拒识没有同步显著提升，主要变化是已知分数上移，而不是未知分数下移。

理论上，闭集识别只要求真实身份相对其他身份得分更高：

```text
s(x, y*) > s(x, y), y != y*
```

开放集拒识还要求最高分低于阈值：

```text
max_y s(x, y) < tau
```

所以身份排序变好，并不等价于未知样本更容易拒绝。LDA 可能同时放大真实身份方向和某些未知身份的偶然相似方向。

### 3.2 E249：Train 时间/task 漂移不等于真实跨会话漂移

E249 的 WCCN+drift 候选 C2 在 Train 代理上最好：AUC **0.9779**、拒识 F1 **0.5627**、已知接受 **0.9288**、未知拒识 **0.9232**。但 Test 审计中 S2 接受率仅 **0.429**，S1 拒识率仅 **0.554**。

这说明 Train 可观测的时间漂移和跨 task 漂移不能代表真实 session/device 漂移。用符号表示：

```text
x = identity + time_drift + task_drift + session_drift + noise
```

Train 可以估计前两项，但 Test 主要缺少的是 `session_drift`。如果两类漂移方向不一致，压制 Train 代理漂移不会改善 S2。

### 3.3 E250：分数校准不能创造新的跨会话信息

E250 将身份排序与拒识分数拆开，并加入 margin、cohort 和 hubness 特征。Train 严格 LOSO 中 AUC 为 **0.971098**，F1 为 **0.540760**，已知接受为 **0.923663**。但 Test S2 接受率为 **0.442190**，S1 拒识率为 **0.548961**。

分数后处理只能重新组合现有 Train 信息。如果 S2 的真实分布已经偏离 Train known calibration，校准函数不能恢复缺失的 session-invariant 表征。

### 3.4 E251：hubness 是症状，不是主要原因

E251 使用：

```text
reject_score = top1_cosine - lambda * standardized_predicted_prototype_hubness
```

在严格内层选择下最终为 `lambda=0.00`。当 lambda 增大时，未知拒识略有增加，但已知接受率和 F1 同时下降；Test S2 仍为 **0.441045**。

因此少数原型吸附现象确实存在，但这些原型也可能吸附真实的 S2 样本。简单惩罚 hubness 会同时损伤正确 S2，不能解决根本问题。

E251 修复攻击 NaN 和目标 D 方向后，SNR30 最差 RA 为 **0.035045**，ASafeR 为 **0.041565**。这说明当前 LDA-cos 表征对真实梯度攻击非常脆弱，也提示当前判别方向可能不是稳定的跨会话身份方向。

## 4. 候选对比

### 4.1 正式冻结候选：`final/team_hymn`

核心流程：

```text
18×1200 EEG
→ 6 个 200 点子窗
→ 5 个频带
→ 相关矩阵
→ logSPD
→ 855 维特征
→ 任务级标准化
→ PCA-96

→ 欧氏最近原型

```

冻结配置：`subwin6_pca96_k1 @ a=0.90`。

冻结后 Test 工程审计：

| 项目 | 数值 | 证据性质 |
|---|---:|---|
| S1 拒识率 | 0.713485 | 冻结后工程审计，无身份真值 |
| S2 接受率 | 0.706889 | 冻结后工程审计，无身份真值 |
| Test 官方 AUC/F1 | N/A | 无身份真值 |

### 4.2 E249 C2：Train 代理最强，但不能替换

E249 C2 的 Train 指标较好，但 Test S2 仅 **0.429**，并且攻击 RA/ASafeR 分别为 **0.3325/0.3570**。它适合保留为研究基线，不适合作为当前决赛提交。

### 4.3 E250 C2：小幅校准收益，未改善 S2

E250 C2 的 Train AUC **0.971098**，但 Test S2 **0.442190**。该实验也没有完成同口径攻击重测，不能作为完整 11 项候选。

### 4.4 E251 lambda=0：严格指标完整，但研究失败

E251 补齐了完整 11 项报告，5/11 通过，但 S2 **0.441045**，攻击鲁棒性也明显不足。hubness 方案最终退回基线，不能替换正式冻结包。

## 6. 为什么不选择 Train AUC 最高的 E249

如果只优化严格 LOSO Train AUC，E249 C2 看起来优于冻结方案。但决赛不是单纯的 Train unknown benchmark，而是包含：

- 已注册用户跨时段/跨设备识别；
- 新用户注册后识别；
- 未注册用户检测；
- 对抗扰动下的稳定性；
- 固定提交接口和离线运行约束。

E249 C2 的真实 Test S2 审计比冻结方案低约 0.278，且攻击鲁棒性明显不足。因此它只能是研究候选，不能作为决赛方案。

## 8. 后续研究边界

如果继续研究，方向应从“分数后处理”转向“session-invariant representation”或允许的真实跨会话注册信息。必须满足：

1. 创建新实验目录；
2. 先写明 Train-only 协议和选择规则；
3. 不读取 Test 进行候选、阈值或权重选择；
4. 完成同一工作点的完整 11 项指标；
5. 保存模型和 Markdown 报告；
6. 只有在完整门禁和冻结包回归检查都更好时，才考虑替换 `final/`。

当前不建议继续微调全局阈值、hubness 惩罚或同一 Train 时间/task 漂移代理，因为这些方向已经显示出有限收益，且没有改善真实 S2。
