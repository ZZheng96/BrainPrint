# BrainPrint：现状、不足、研发路线与改进方案

日期：2026-11-14（E72–E86 复盘后更新）  
范围：官方 Train/Test、10 项研发门禁、图像化与纯 EEG 两条路线、外部多 Session 路线。
核心目标：在合规约束下，同时满足项目 Test Session1 拒识率 ≥95%、Session2 拒识率 ≤2%。

> **当前结论**：项目已经具备很强的同 Session 识别、训练侧开放集和部分对抗鲁棒能力，但尚不存在通过项目 Test 两项门禁的候选。下一阶段不能继续围绕旧阈值、同一外部分数或单一骨干做局部修补，必须解决：**外部跨 Session 表征如何迁移到项目 18 通道输入，以及如何降低项目 Test Session2 注册者的过度拒识**。

## 0. 结论先行

### 0.1 唯一最终验收标准

| 指标 | 目标 | 当前状态 |
|---|---:|---|
| Test Session1 拒识率 | ≥95% | 未达到；现有代表候选约 47.64%–59.28% |
| Test Session2 拒识率 | ≤2% | 未达到；现有代表候选约 60.62%–85.07% |

Test 没有公开真实身份标签，因此 Test 上的真实 AUC、F1、C、RA、ASafeR、U 和 Official Score 必须记为 `N/A`。S1/S2 只能在候选冻结后，从预测 CSV 按强推断的 Test Session 分组做工程审计，不能当作真实监督标签。

外部 BCIC IV-2a 结果只能作为跨 Session 能力代理：外部数据为 22 通道、9 名被试，与项目 Test 的 18 通道、20 名注册者及 5 名未注册者不兼容。外部 `known acceptance`、`unknown false acceptance`、`unknown rejection` 不得命名为项目 Test 的 S1/S2。

### 0.2 根因判断

历史结果已把问题从“分类器不够强”收窄为三层缺口：

1. **训练目标错位**：Train 只有 20 名注册者的 Session1，训练侧高闭集准确率不等于跨 Session 身份验证能力。
2. **未知构造不匹配**：留出被试 pseudo-unknown 与项目 Test 的未注册者分布可能不同；外部已知/未知分布仍有明显重叠。
3. **迁移与工作点错位**：外部跨 Session 模型尚未解决 22→18 通道迁移，而且项目 Test 的主瓶颈是 S2 过度拒识，不是继续提高外部 known acceptance。

因此，后续主线应是：

> **项目可用的跨 Session 身份嵌入 + 多层 hard unknown 构造 + 通道掩码/投影迁移 + 身份模板匹配 + 独立未知门控。**

## 1. 数据、规则与证据边界

### 1.1 已确认的数据事实

- Train：20 名注册者的 Session1，共 11,304 条；没有带标签的跨 Session 训练数据。
- Test：22,251 条；官方未公开真实身份标签。
- 官方预处理：300 Hz、18 通道、1–40 Hz、1200 点；通道顺序为 `P3 C3 F3 Fz F4 C4 P4 Cz Fp1 Fp2 T3 T5 O1 O2 F7 F8 T6 T4`。
- 官方评分：`Score = 100 × C^0.40 × (0.7 × RA + 0.3 × ASafeR)^0.35 × U^0.25`。

### 1.2 Test 结构推断等级

| 结论 | 证据等级 | 用途 |
|---|---|---|
| Train 只有 20 名注册者 Session1 | 已确认 | 训练与验证协议 |
| Test S1 大概率为 5 名未注册者 | 强推断 | 候选冻结后的审计分组 |
| Test S2 大概率为注册者及受扰动样本 | 强推断 | 候选冻结后的审计分组 |
| 正常/对抗严格一一配对 | 不可确认 | 不得据此建规则或配对 |

### 1.3 不可突破的合规边界

1. 身份与拒识只能依据单条 EEG 样本的归纳式输出；禁止使用 Session 编号、文件顺序、样本数量、正常/对抗分组或近重复配对替代 EEG 证据。
2. 未知拒识必须通过留被试、留任务或独立外部数据构造 pseudo-unknown，并在独立数据上标定阈值。
3. Test 不参与训练、阈值选择、模型选择或后处理；只能在候选冻结后生成 `Sample,Label` CSV 并审计。
4. 允许使用外部公开 EEG、自监督预训练和新骨干，但必须保留独立验证。
5. 每个实验报告必须写明 AUC 和 F1；无真实标签时写 `N/A`，并同时报告 C、RA、ASafeR、U、macro-F1 及其证据来源。

### 2.1 早期路线：E00–E19

- E00 对数协方差/Ridge 在 Train 内达到约 99% 以上识别与未知 AUROC；历史官方最高分 69.17，但使用 Session 规则，不能作为合规 EEG 开放集能力证明。
- E05/E06 的 ASNorm、Riemannian 和轻量分类器改善有限，未解决跨 Session 拒识。
- E07–E09 表明原始 EEG 对抗训练可提高 ASafeR/RA，但会牺牲 clean C、U 或未知检测。
- E11 第三次合规候选官方分仅 26.10，主要失败模式是过度拒识。
- E14–E19 的高 AUROC/F1 都是 Train 内部或伪未知证据；E19 Test 拒识约 79.2%，说明“高内部指标→Test 可部署”这一假设不成立。

### 2.2 图像化路线：E20–E35

- E20/E21 证明多频带协方差图能保留较强的 Train clean 识别；普通冻结 DINO 探针不是跨 Session 解决方案。
- E22–E25 排除了全局幅度、频带缩放、简单参考变换和范数门控等解释。
- E31“任务条件化 + WCCN”是图像化路线的 Test 诊断代表最佳：Test AUROC(S2 vs S1)=0.7327，S2 接受率约 91.7%，S1 拒识约 50.9%。E32 的诊断 AUROC 约 0.7403，但仍未达到门禁。
- E33/E34 表明复杂 ArcFace 头和更高图像分辨率没有带来稳定收益；E35 表明任务间差异存在但不足以解决问题。

### 2.3 纯 EEG与三段式路线：E36–E61

- E36–E44 证明固定 logSPD 特征族在 SNR20 对抗下 RA 长期偏低；仅靠该表征无法支撑鲁棒识别。
- E45–E47 形成有效分工：原始波形 CNN 负责身份/对抗鲁棒，logSPD/WCCN 负责未知拒识；CNN 单独做未知拒识会失败。
- E49 三段式提升了训练侧综合 Score 至 91.03；E58 的 `OE-EEGNet + logSPD 拒识 + 三段式` 是当前训练侧代理最佳：

| 指标 | E58 |
|---|---:|
| Train 准确率 | 0.9974 |
| C | 0.9714 |
| 身份 macro-F1 | 0.9849 |
| unknown AUROC | 0.9984 |
| U@95 | 0.9875 |
| RA | 0.9371 |
| ASafeR | 0.9758 |
| 代理 Score | **96.74** |

E58 的上述指标不能外推为项目 Test 性能。其冻结候选在 E64/E85 的项目 Test 审计为：S1 拒识 58.0284%，S2 拒识 70.2987%。

- E65 逐通道相关矩阵/logSPD 是纯 EEG clean 表征侧强候选：C=0.9888、身份 F1=0.9888、unknown AUROC=0.9951、U@95=0.9891、RA=0.9336、ASafeR=0.9769；但项目 Test S1/S2 仍为 47.64%/60.62%。
- E56/E60 说明 Test 的分数分布不是简单位置偏移或阈值问题；E61 发现单个 20–40 Hz 能量比例最多只有约 0.7233 的诊断能力，仍不足以满足双门禁。

### 2.4 E62–E70：Test 根因闭合

- E62 多窗口图像的 Test 诊断 AUROC 下降到约 0.40–0.47，低于 E31，说明细化窗口并没有增强跨会话稳定性。
- E67 使用 Test 标签进行事后诊断可得到 AUROC 0.9971，但 Train 留被试训练迁移到 Test 只有 0.4911；该结果不能用于模型选择。
- E68 表明同批次内仍存在高可分性，30 个留出组合的判别方向平均近似正交。由此可判断：Test 的可分性主要来自这 5 名未注册者与 20 名注册者的特定人群组合，并非可迁移的“注册状态”方向。
- E69/E70 显示 DINOv2 clean 强但 RA 弱，DINOv3 RA 较强但 clean C/U 下降；图像化骨干存在明显互斥。

**关键观察**：E93、E95、E97、E98 构成一条清晰的 trade-off 曲线——S2 接受率从 2.4% 提升到 96.9% 时，S1 拒识率从 99.9% 单调下降到 10.1%。没有任何单点同时满足 S1≥95% 与 S2 接受≥98%。这说明当前 18 通道表征下，未注册者与注册者的分数分布高度重叠，问题不在阈值位置，而在表征本身。

**E99 的定量确认**：在 Train/session1 上用留身份 pseudo-unknown 做代理，对 raw、SPD、min 融合三个分支各扫描 401 个阈值，满足 `known acceptance ≥ 0.98 且 unknown rejection ≥ 0.95` 的工作点数量均为 **0**。把 unknown rejection 压到 0.95 时，known acceptance 只剩 0.078（raw）、0.261（SPD）、0.134（融合）。三个分支 AUC 仅 0.63–0.64，而同时满足两项门禁需要约 0.99。这排除了“继续调阈值/换融合方式”的整条路线。

## 3. 当前最佳方案：按能力分别定义

不同实验的最佳指标不能拼接成一个不存在的“全能模型”。当前应按能力使用以下基线：

| 能力 | 代表方案 | 当前证据 | 适用结论 |
|---|---|---|---|
| 训练侧综合代理 | E58 三段式 | Score 96.74；C 0.9714；身份 F1 0.9849；AUROC 0.9984；RA 0.9371；ASafeR 0.9758 | 作为项目 Train 基线，不代表 Test 通过 |
| 纯 EEG clean 表征 | E65 | C/F1 0.9888；AUROC 0.9951；U@95 0.9891 | 保留相关矩阵/logSPD 的身份模板经验，不单独作为 Test 方案 |
| 图像化 Test 诊断 | E31/E32 | Test 诊断 AUROC 约 0.733–0.740 | 作为辅助表征研究，不使用诊断标签调参 |
| 外部综合检测 | E76 | AUC 0.9764；EER 0.0692 | 证明 Mahalanobis/跨 Session 表征有价值，但通道不兼容 |
| 外部最低 FAR | E78 | unknown FAR 0.0729；known acceptance 0.9036 | 证明工作点存在明显 trade-off，不能替代项目 S2 |
| 外部最高身份指标 | E80 | identity F1 0.9814；unknown FAR 0.2569 | 证明提高已知识别不等于提高开放集能力 |

| 项目 Test S2 最佳 | E97 | S2 接受率 96.8987% | 接近 98%，但 S1 拒识率仅 10.1220% |

## 4. 已排除或不再作为主攻方向

以下结论针对已经测试的特征、数据构造和决策机制，不等于数学上证明所有未来方法都不可行：

- 依赖 Session 编号、文件顺序、样本数量、分组结构或近重复配对的规则。
- 继续扫描旧阈值、单调校准、秩映射或简单后处理。
- 只提升 Train 代理分而不生成项目 Test 候选的模型堆叠。
- 普通冻结 DINO 探针、单纯提高图像分辨率和多窗口图像继续扩展。
- 固定 logSPD 单独承担 SNR20 对抗鲁棒；CNN 单独承担未知拒识。
- 仅使用“留出被试二分类”构造未知并假设其能迁移到 Test。
- 在外部 22 通道数据上继续堆叠相同的 open-set head、逐身份阈值、EVT 或简单融合，而不解决通道迁移和未知构造。
- 把外部 `known acceptance` 当作项目 S2 接受率，把外部 `unknown false acceptance` 当作项目 S1/S2。
- 使用 Test 的强推断结构或事后标签进行训练、阈值、模型选择或候选排名。

## 5. 改进方案与优先级

### P0：重构未知样本构造

**问题**：现有 pseudo-unknown 主要是留出被试，可能没有覆盖真实未注册者与注册模板相近的 hard unknown。

**方案**：构造分层 unknown 集合：

1. 留被试 unknown：保留当前基线；
2. 同一被试跨任务/跨时段的 hard unknown；
3. 外部数据中的身份不匹配样本；
4. 与注册模板相近但身份不同的 hard negative；
5. 远离注册者、相近身份、跨 Session 难例三档联合训练/标定。

**验收**：必须使用留被试、留任务和独立外部验证；联合报告 known acceptance、unknown false acceptance、unknown-F1、EER 和 operating point，而不是只追求 AUROC。不得使用项目 Test 推断标签。

### P1：跨通道迁移

**问题**：E73–E84 的 22 通道外部模型无法直接生成项目 18 通道候选，这是外部成果无法验证项目 Test 的直接原因。

**方案**：

- 按通道名称和空间位置建立 22→18 映射；
- 使用通道掩码、随机缺失增强和可学习投影层；
- 在外部数据上模拟 18 通道，做完整留被试 outer test；
- 再用项目 Train 做轻量适配，保持 Test 隔离；
- 保留原始 EEG 与协方差/频谱分支，比较单分支和受控融合。

**验收**：报告完整 22 通道与模拟 18 通道的性能差异、项目 Train 内层指标、模型是否能接受官方 18 通道格式；只有冻结后才能审计项目 Test。

### P2：直接降低项目 Test S2 过度拒识

**问题**：现有候选 S2 拒识约 60%–85%，目标为 ≤2%；继续提高外部 known acceptance 不能替代该目标。

**方案**：

- 在项目 Train 内模拟跨任务、跨时间块、幅度/噪声/频谱变化的注册者正样本；
- 建立身份内变化模型和多模板注册库，而非单一 Session1 中心；
- 将“身份匹配失败”与“未知拒识”分成候选生成器和独立 unknown gate；
- 先用较宽松的身份候选恢复注册者接受率，再用独立 hard-unknown gate 控制误接受；
- 对 clean、扰动和攻击样本分别报告，禁止用大量拒识换取 ASafeR。

**停止条件**：S2 接受率提高但 unknown false acceptance 明显恶化，只能算工作点移动，不能算有效突破。

### P3：非线性身份度量学习

**问题**：Mahalanobis、pair head、EVT 和融合已经证明仅改变分数或阈值不能消除 known/unknown 重叠。

**方案**：在 P0/P1 基础上尝试：

- ArcFace/CosFace 角度间隔；
- 原型对比学习与 hard-negative mining；
- sample-to-template 与 sample-to-sample 联合损失；
- clean、扰动、跨 Session 样本统一身份嵌入；
- 通道掩码与未知 hard case 联合训练；
- 图像分支只在独立验证同时改善 C、RA、ASafeR、U 时保留。

**前置条件**：先证明 unknown 构造有效、跨通道输入兼容，并在外部留被试和项目 Train 内层验证中取得联合改善，再生成 Test 候选。

## 6. 推荐系统架构

```text
18 通道原始 EEG
    ├─ 原始波形鲁棒编码器 ─┐
    ├─ logSPD/相关矩阵编码器 ├─ 跨 Session 身份嵌入
    └─ 可选协方差图像编码器 ┘          │
                                      ├─ 与 20 个身份的多模板匹配
                                      ├─ clean/robust 分数受控融合
                                      ├─ 独立 hard-unknown gate
                                      └─ 最大匹配不足时输出 0
```

设计原则：

- 身份嵌入和未知拒识分工，但共享跨 Session 目标；
- 模板来自官方 Train，模板数量、聚合方式和阈值必须在独立内层验证确定；
- 外部预训练权重必须经过 18 通道模拟与项目 Train 适配；
- 图像分支不是默认必选，只有在联合验证改善时才保留；
- 不采用依赖 Test Session 的门控或规则。

## 7. 统一合规实验闭环

### 7.1 训练与验证

- 训练、阈值标定和模型选择只使用官方 Train 的嵌套划分及外部公开数据。
- 至少保留留被试、留任务或时间块验证；未知阈值与模型选择使用独立标定集。
- 保存模型、配置、阈值、数据划分和逐样本预测。
- 统一口径：`unknown-F1` 使用 `pos_label=0`；C 含拒识；外部字段使用 known/unknown 命名。

### 7.2 外部验证

必须报告数据集、通道数、被试划分、AUC、identity macro-F1、unknown-F1、known acceptance、unknown false acceptance、unknown rejection、EER 和 operating point 可行性。所有指标标注为外部代理，不能写成项目 Test 改善。

### 7.3 项目 Test 审计

候选冻结后才允许：

1. 生成 `Sample,Label` 预测 CSV；
2. 重新读取 CSV，按强推断的 Test S1/S2 分组统计拒识率；
3. 记录 S1、S2 是否改善；
4. 将 Test AUC/F1/C/RA/ASafeR/U/Official Score 写为 `N/A`；
5. 不根据本次审计回调模型、阈值或后处理。

### 7.4 通过条件

- S1 拒识率 ≥95%；
- S2 拒识率 ≤2%；
- 两项必须同时满足；任一失败即为未通过。

## 9. 最终判断

截至 E98：

1. E00 的 69.17 是历史官方最高分，但不合规，不能作为能力上限。
2. E58 是训练侧综合代理最佳，Score=96.74；E65 是纯 EEG clean 表征侧强候选；E31/E32 是图像化 Test 诊断代表最佳；E76 是外部检测最佳；不存在同时取得这些指标的单一方案。
3. 外部多 Session 监督和身份验证显著提高了检测 AUC，但 E83 证明 known/unknown 重叠仍未消除。
4. 项目 Test 当前没有合格候选。E93 满足 S1（99.93%）但 S2 仅 2.40%；E97 达到 S2 96.90% 但 S1 仅 10.12%。两者之间是连续 trade-off，不存在中间阈值同时达标。
5. E67/E68 排除了“从这批 Test 人群差异学习通用未知方向”的路线；这不等于所有新表征和跨通道方法都不可行。
6. E94–E98 进一步证明：在现有 18 通道 raw EEG / correlation-logSPD 表征上，单纯更换门控结构、窗口聚合或融合方式都无法突破分布重叠。继续在同一表征上扫描阈值或融合权重不会产生新信息。
7. E99 给出定量边界：三个现有分支在 Train-only 代理下的 AUC 仅 0.63–0.64，满足两项门禁的可行工作点数为 0。要同时达到 S1≥95% 与 S2 接受≥98%，代理 AUC 需要提升到约 0.99，即需要约 0.35 的 AUC 增量——这不是调参能补的差距。
8. 下一阶段的唯一主线是：**构建 18 通道原生的跨 Session 身份表征（而非从 22 通道迁移），使未注册者与注册者在嵌入空间中真正分离，再配合独立未知门控，直接降低 Test S2 过度拒识，同时保留 S1 未知拒识能力。** 任何新表征必须先通过 E99 式的 Train-only 联合可行性审计（可行工作点数 > 0），才值得冻结并做项目 Test 审计。
