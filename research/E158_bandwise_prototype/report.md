# E158 分频带独立建模 + Train-only 融合

问题：E143 干净基准（E65 correlation-logSPD 855 维 → task 标准化 → **联合** PCA-96 → k=12 原型）给出 LOSO 0.7936 / Test S1 拒识 0.7979 / Test S2 接受 0.5960 / W = 0.6958，诊断 AUC 0.7578。E157 证明逐样本归一化只能挪工作点、不能改排序。
本次验证另一个轴：**不把 5 个频带拼在一起做同一个 PCA，而是每个频带单独标准化 + PCA + 原型，再用只由 Train 决定的权重融合**。若某些频带的身份结构跨会话更稳定，融合应把诊断 AUC 推高。

严格合规：per-task 标准化 / PCA / 原型 / z 校准 / 权重与频带选择全部只由 Train 拟合；LOSO 每折排除被评分身份且原型只用 `frac<=0.6`；评估块 `0.6<frac<=0.8`；五块 Train OOF 定阈值；Test 只评分；session 仅用于诊断。**Test 官方 AUC/F1 = N/A（无真实标签）**。

设备 `cuda`；频带划分沿用 E36 `bands_hz`（band-major 拼接，band b 占列 `[171b,171(b+1))`）：b1_1-8、b2_8-13、b3_13-20、b4_20-30、b5_30-40；PCA 维度 [16, 32, 48, 64]；k [1, 3, 6, 12]；接受率网格 0.80–0.96。

## 4. 结论

1. **单频带最强**：诊断 AUC 最高的是 `b4_20-30` （dim=16, k=1）AUC = 0.7433；按 W 最优的单频带是 `b4_20-30`（dim=16, k=1, 接受率 0.88）W = 0.6484。
2. **融合是否抬高诊断 AUC 超过 0.7578**：融合中诊断 AUC 最高的是 `loso_weighted`（dim=16, k=3, 接受率 0.90）0.7574，不高于 E143 的 0.7578（Δ -0.0004）。
3. **全局最佳 W**：`E143_joint_PCA96`（baseline, dim=96, k=12, 接受率 0.90）W = 0.6958，LOSO 0.7936 / S1 0.7979 / S2 0.5960，诊断 AUC 0.7578。E143 对照 W = 0.6958。
4. **是否达到 0.80**：未达到，距目标差 0.1042。

## 5. 关键判断

- **频带身份信息量的排序**（诊断 AUC）：`b4_20-30` 0.7433 > `b5_30-40` 0.7276 > `b3_13-20` 0.7084 > `b2_8-13` 0.6950 > `b1_1-8` 0.6451。20–40 Hz（beta/gamma）承载最多可跨会话迁移的身份结构，delta 带（1–8 Hz）几乎不携带身份信息。
- **分频带建模没有超过联合 PCA，但已非常接近**：最佳融合 `loso_weighted`（dim=16, k=3）诊断 AUC 0.7574，比联合 PCA-96 的 0.7578 低 0.0004。855 维上的联合 PCA 本就已经隐式完成频带融合，显式分频带没有暴露新的跨会话稳定结构。
- **融合改变的是分数分布形状，不是排序**：`mean_z`（dim=16, k=3，接受率 0.90）把 S2 接受从 0.5960 抬到 0.6513，同时把 S1 拒识从 0.7979 压到 0.7277，W 反而低 0.0194；这正是 0.25/0.25/0.5 权重下 S1 与 S2 的零和取舍，与 E150/E157 的结论一致。
- **LOSO 与 S1 的落差**：单频带 LOSO 拒识普遍明显低于自己的 S1 拒识（如 `b4_20-30` 0.6693 vs 0.7949），说明单频带对会话外推更脆弱；秩融合把 LOSO 提到 0.7251，但仍低于联合 PCA 的 0.7936。分频带没有带来更强的会话鲁棒性。
- **Train-only 选择器本身工作正常但受限于信号**：贪心前向在 LOSO 准则下把 5 个频带逐步全部选入（因此与 `mean_z` 完全一致，W 0.6764）；单纯形 LOSO 加权（W 最优行）剔除 `b3_13-20`，诊断 AUC 0.7539。两个选择器都只用 Train，未接触 Test，可排除“用 Test 调权重”的可能。
