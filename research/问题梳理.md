# 脑纹识别方案问题梳理

> 范围：当前提交方案 `commit/answer/赞美诗_第1次.csv` 及其生成链路。
> 结论先行：**方案在预赛规则下不违规，但存在一处根本性方法问题——`Session1 → 0` 不是 EEG 解码，而是利用数据划分元数据的规则输出。它使 U 指标失去方法学意义，且无法迁移到决赛。**

---

## 0. 当前方案链路

```
4 秒 EEG (1200×18)
  → 逐通道 MAD 截尾 + 1–90Hz 带通 + 50Hz 陷波
  → 6 频带对数协方差 (18×19/2×6) + 1–90Hz log PSD
  → 分任务 StandardScaler + RidgeClassifier(alpha=100)
  → 测试 Session2 统计量 z-score 对齐
  → 双窗口 / 类内 top-3 近邻分数融合（任务特异权重）
  → 高相似波形图融合（cosine > 0.99，3,492 组 / 10,205 条）
  → Sinkhorn 类别平衡（EC 门控、Imagery、SSVEP）
  → 测试 Session1 全部置 0
```

## 1. 根本问题：`Session1 → 0` 不是 EEG 解码

### 1.1 代码事实

[predict_task_specific.py](file:///d:/WORK/BCIC2026/BrainPrint/src/predict_task_specific.py#L121-L122)：

```python
if args.reject_session1:
    predicted[test_sessions == "session1"] = 0
```

这一行在**所有模型分数计算完成之后**执行，直接覆盖预测结果。它不读取任何 EEG 特征，不依赖任何分类器输出，只依赖 `test_metadata.csv` 中的 `session` 字段。

### 1.2 为什么这不合理

| 问题 | 说明 |
|---|---|
| 不是身份解码 | 模型对 Session1 样本的 EEG 判断被完全丢弃，无论模型认为它像谁 |
| U 指标被架空 | 3,033 条 0 标签全部来自规则，U 的数值只反映“Session1 是否恰好全是未注册者”这一数据划分假设 |
| 无法证明开放集能力 | 真正的开放集识别要求模型从 EEG 中判断“此人不在注册库”，当前方案没有做这件事 |
| 不可迁移 | 决赛现场没有 `session` 字段，规则直接失效 |
| 掩盖真实风险 | 若测试 Session1 中混有注册用户，这些样本会被强制判错，C 和 U 同时受损，而内部验证完全看不到 |

### 1.3 该假设的证据强度

该规则来自对数据结构的推断：赛题说明称 20 名多会话被试为注册用户、5 名单会话被试为未注册用户，而测试 Session1 恰好 3,033 条。这是**合理猜测，但不是官方保证**，也没有任何 EEG 层面的验证。

### 1.4 正确的替代做法

用 EEG 本身做开放集拒识：

1. 训练阶段留出若干被试作为伪未知（当前 `run_baseline.py` 已支持 `--unknown-start`）；
2. 用 max-logit / margin / energy 等置信度分数，在**内层验证**上标定阈值；
3. 外层测试集只用于报告，不参与阈值选择；
4. 报告 AUROC、AUPR、EER，以及固定已知接受率下的 U。

现有早期实验已给出可用起点：[baseline_ridge_cov_forward.json](file:///d:/WORK/BCIC2026/BrainPrint/research/E00_cov_ridge_baseline/baseline_ridge_cov_forward.json#L53-L66) 中留 4 名被试作伪未知，AUROC 0.9975，95% 已知接受率下拒识率 0.9952。这说明**纯 EEG 拒识是可行的**，没有必要用元数据规则替代。

## 1A. 100% 指标是怎么来的，以及它为什么不能代表泛化

### 1A.1 100% 的测试位置

训练集只有 Session1（20 名被试，11,304 个 4 秒 Trial），测试集无标签。因此 100% **只能来自训练集内部的折外验证**，与测试集无关。

四个协议（[evaluate_task_specific_ensemble.py](file:///d:/WORK/BCIC2026/BrainPrint/src/evaluate_task_specific_ensemble.py#L111-L137)、[evaluate_task_specific_reverse.py](file:///d:/WORK/BCIC2026/BrainPrint/src/evaluate_task_specific_reverse.py#L38-L42)）：

| 协议 | 划分方式 | 验证样本 | 结果 |
|---|---|---|---|
| 5 折块外推 | 每被试每任务按 Trial 顺序每 10 个一组，`(trial-1)//10 % 5` 分 5 折 | 11,304 | 0 错 |
| 后 20% 时间前推 | 前 80% 训练，后 20% 验证 | 2,308 | 0 错 |
| 首 20% 反向留段 | 后 80% 训练，前 20% 验证 | 2,245 | 0 错 |
| 中间 40%–60% 留段 | 两端训练，中间验证 | 2,257 | 0 错 |

### 1A.2 100% 是逐步调出来的，不是一次跑出来的

| 阶段 | 块外推错误 | 前推错误 |
|---|---:|---:|
| 4 秒协方差 Ridge 基线 | 9 | 4 |
| 加 z-score 对齐 | 8 | 3 |
| 双窗口平均 | 3 | 4 |
| 双窗口 + 4 秒 + Sinkhorn | 5 | 1 |
| 任务特异融合（第三轮） | **0** | **0** |
| 加 EC 门控（第四轮） | **0** | **0** |

第三轮达到双协议 100% 后，反向留段仍有 2 条错误（S8/EC/006、S17/Imagery/011）。第四轮针对这 2 条错误设计 EC 门控（`margin < 1` 才接受 Sinkhorn），再重跑四协议才全部归零。

### 1A.3 由此产生的泛化问题

| 编号 | 泛化问题 | 具体表现 | 严重度 |
|---|---|---|---|
| G1 | **规则事后拟合** | EC 门控阈值 1.0 来自观察 S8/EC/006 的 margin 0.5333 与三个被 Sinkhorn 改错样本的 margin 1.10–1.59，属于看过错误后设计规则 | 高 |
| G2 | **协议参与模型选择** | 任务特异权重、Sinkhorn 温度、门控阈值均在前三套协议上试出，这些协议不再是独立测试集 | 高 |
| G3 | **同 Session 内验证** | 四套协议全部来自 Session1，只能排除时间方向过拟合，不能排除 Session 过拟合（电极状态、阻抗、当天生理状态） | 高 |
| G4 | **闭集验证** | 验证集只有 20 名注册被试，没有未注册者，100% 只说明“20 人之间分得开”，不说明能拒识新人 | 高 |
| G5 | **无对抗样本** | 验证集不含扰动样本，RA/ASafeR 完全未测 | 高 |
| G6 | **单数据集** | 全部结论来自同一批 20 人、同一台 DSI-24、同一采集流程，无法判断是否依赖设备或流程特征 | 中 |
| G7 | **样本量小** | 20 名被试，个体差异无法通过大样本平均掉，个别被试的离群 Trial 会显著影响结论 | 中 |
| G8 | **任务特异规则过细** | 四个任务各自一套权重，规则数量接近被试数量，存在过拟合到本数据集的风险 | 中 |
| G9 | **转导式后处理不可复现** | Sinkhorn 依赖整批测试样本，换一批数据结果会变，无法作为稳定能力指标 | 中 |

### 1A.4 结论

**100% = 训练集 Session1 内部、四套折外划分、在已根据错误调过规则之后得到的闭集分类准确率。** 它证明“同 Session 内 20 人可分性极强”，不证明跨 Session、不证明开集拒识、不证明对抗鲁棒、不证明测试集表现。项目文档 [L694](file:///d:/WORK/BCIC2026/BrainPrint/research/brainprint_research_and_experiments.md#L694) 已作同样声明。

## 2. 其他方法学问题

### 2.1 内部 100% 存在选择偏差（高）

[train_metrics.json](file:///d:/WORK/BCIC2026/BrainPrint/commit/report/train_metrics.json) 显示四协议 18,114 条全对，但：

- 块外推、前推、反向留段三套协议**参与了模型与后处理规则的选择**；
- 中间留段虽在规则冻结后新增，但仍属同一 Session；
- 任务特异权重、Sinkhorn 温度、EC 门控阈值 `margin < 1` 都是在观察错误后调出来的。

因此 100% 是**训练集内、规则已调优后的拟合结果**，不能作为泛化证据。文件本身已注明这一点，但对外表述时容易被误读。

### 2.2 跨 Session 从未被真正验证（高）

训练集只有 Session1，测试 Session2 无标签。所有“跨 Session”结论都来自：

- 测试侧无标签诊断（预测分布、Sinkhorn 一致率）；
- 特征对齐后的分布检查。

这些只能说明“输出稳定”，不能说明“识别正确”。学界共识是跨 Session 误差会显著上升，本项目目前没有任何带标签的跨 Session 数字。

### 2.3 对抗鲁棒性完全未测（高）

赛题 A = 0.7·RA + 0.3·ASafeR，权重 0.35，是第二大项。当前：

- 没有任何本地攻击实验（FGSM / PGD / 频域扰动）；
- 高相似图融合只是**间接**稳定性证据，且它假设对抗样本与正常样本构成近重复对；
- 若扰动强度导致配对失败，RA 可能显著低于 C。

这是当前最大的未知风险。

### 2.4 Sinkhorn 依赖批次与先验假设（中）

[balanced_sinkhorn.py](file:///d:/WORK/BCIC2026/BrainPrint/src/balanced_sinkhorn.py#L17-L32) 用训练集类别先验强制测试批次分布平衡。风险：

- 测试身份比例偏离训练先验时，会改错原本正确的预测；
- 需要整批数据，单样本或小批量不可用；
- 与 `Session1 → 0` 叠加后，U 和 C 都受规则支配，模型贡献被稀释。

### 2.5 z-score 对齐依赖测试批次统计量（中）

[predict_ridge.py](file:///d:/WORK/BCIC2026/BrainPrint/src/predict_ridge.py#L22-L39) 用测试 Session2 的均值和标准差做对齐。这属于合法的无监督域适应，但：

- 依赖一次性拿到整批测试数据；
- 小批量时统计量不稳定；
- 应在提交说明中如实披露。

### 2.6 高相似图融合的假设较强（中）

[match_waveform_pairs.py](file:///d:/WORK/BCIC2026/BrainPrint/src/match_waveform_pairs.py#L22-L27) 用降采样时域波形余弦相似度 > 0.99 判定近重复。该阈值是在观察数据后设定的，且融合会把同组样本强制赋予同一标签：

- 若配对错误，会成组放大错误；
- 融合收益只在“对抗样本确为正常样本加扰动”时成立，属于对测试集构造方式的推断。

### 2.7 特征维度与样本量不匹配（低）

18 通道 × 6 频带 × 171 维协方差 + 1,620 维 PSD，特征数远超单被试 Trial 数。Ridge 正则缓解了这一点，但决赛现场每人只有少量样本时，该特征集不适合直接用于模板匹配。

## 3. 决赛适配性问题

### 3.1 决赛流程与预赛的本质差异

| 环节 | 预赛 | 决赛 |
|---|---|---|
| 注册数据 | 20 人 × 上千 Trial，离线给定 | 现场 A/B/C 三人，每人少量 Trial |
| 注册时机 | 训练阶段一次性完成 | 比赛现场临时采集 |
| 盲测对象 | 20 名注册者 + 5 名未注册者 | A/B/C + 未注册的 D/E |
| 时间间隔 | 平均 5 天 | 5–10 分钟 |
| 可用元数据 | 有 `session`、`task`、文件名 | 无任何元数据，顺序打乱 |
| 推理方式 | 整批一次性推理 | 逐条或小批量推理 |
| 输出 | 0–20 标签 | A/B/C 或“未注册人员” |

**预赛是“离线批量闭集分类 + 元数据拒识”，决赛是“在线小样本开集识别”。两者不是同一任务。**

### 3.2 逐项适配性分析

| 决赛要求 | 当前方案做法 | 是否可用 | 具体原因 |
|---|---|---|---|
| 现场小样本注册 | 用 20 人全部训练数据拟合 Ridge | **不可用** | 决赛只有 A/B/C 三人、每人少量 Trial，无法重新训练 20 类分类器；且 D/E 不在训练集中 |
| 5–10 分钟后盲测 | 用测试 Session2 统计量做 z-score 对齐 | **不可用** | 盲测样本少且顺序打乱，无法估计稳定的批次均值/方差；[predict_ridge.py](file:///d:/WORK/BCIC2026/BrainPrint/src/predict_ridge.py#L22-L39) 的对齐依赖整批统计量 |
| 输出“未注册” | `Session1 → 0` 元数据规则 | **不可用** | 现场没有 `session` 字段；[predict_task_specific.py](file:///d:/WORK/BCIC2026/BrainPrint/src/predict_task_specific.py#L121-L122) 的规则完全失效 |
| 单样本/小批量推理 | Sinkhorn 强制类别平衡 | **不可用** | [balanced_sinkhorn.py](file:///d:/WORK/BCIC2026/BrainPrint/src/balanced_sinkhorn.py#L17-L32) 需要整批样本和类别先验；5 条盲测样本做 Sinkhorn 会把 D/E 强行分配给 A/B/C |
| 高相似图融合 | 测试集内近重复配对 | **不可用** | 决赛盲测样本之间不存在“正常—对抗”配对关系，融合无对象 |
| 任务特异权重 | EC/EO/Imagery/SSVEP 分别调参 | **部分可用** | 决赛使用“特定视觉刺激”，若与 SSVEP 范式一致，SSVEP 分支可复用；其余分支无对应数据 |
| 特征提取 | 4 秒对数协方差 + PSD | **可用** | 与训练无关，可现场计算 |
| 实时性 | 特征提取 + 线性模型 | **可用** | 单条推理毫秒级 |

### 3.3 架构层面的不兼容

当前方案的核心假设是：

1. **测试集与训练集共享同一批身份**（闭集）；
2. **测试样本以整批形式到达**（转导式）；
3. **测试集带有 `session` 等元数据**（规则拒识）。

决赛三条假设全部不成立：

- 身份集合是现场临时确定的 A/B/C，D/E 从未出现；
- 样本逐条或小批量到达，且顺序打乱；
- 没有任何元数据。

因此**不是调参能解决的问题，而是需要另一套推理架构**。

### 3.4 决赛所需的最小可行架构

```
注册阶段（A/B/C 各采集若干 Trial）
  → 逐 Trial 提取对数协方差特征
  → 每人聚合为模板（均值 / 中位数 / 多原型）
  → 用注册阶段内部留一距离分布标定拒识阈值

盲测阶段（逐条到达）
  → 提取同一套特征
  → 计算与 A/B/C 模板的距离（欧氏 / 黎曼测地距离）
  → 最近模板距离 < 阈值 → 输出该身份
  → 否则 → 输出“未注册人员”
```

关键设计点：

| 设计点 | 建议 | 理由 |
|---|---|---|
| 模板表示 | 对数协方差均值或中位数 | 与现有特征一致，小样本稳定 |
| 距离度量 | 欧氏（切空间）优先，黎曼测地距离备选 | 切空间计算简单，黎曼更符合 SPD 几何 |
| 拒识阈值 | 注册阶段内部留一距离的 95% 或 99% 分位 | 不依赖盲测批次，可现场标定 |
| 多 Trial 聚合 | 盲测若有多条，先按距离加权投票 | 提高稳定性，但不做强制平衡 |
| 对齐 | 用注册模板做中心化，不用盲测批次统计量 | 避免小批量统计量不稳定 |
| 禁止项 | 不用 Sinkhorn、不用 `session` 规则、不用图融合 | 决赛场景不存在这些前提 |

### 3.5 决赛风险点

| 风险 | 说明 | 缓解 |
|---|---|---|
| 注册样本过少 | 每人 Trial 数未知，模板估计方差大 | 用中位数/收缩估计，多 Trial 聚合 |
| 5–10 分钟间隔的 Session 漂移 | 电极重新佩戴、阻抗变化 | 用注册模板做中心化，必要时采集前后两段做漂移校正 |
| D/E 与 A/B/C 相似 | 未注册者可能被误接受 | 阈值偏保守，优先保证拒识正确 |
| 现场噪声 | 干电极、环境干扰 | 复用现有 MAD 截尾与带通滤波 |
| 时间压力 | 现场需快速完成注册与推理 | 特征提取与模板匹配均为毫秒级，可行 |

### 3.6 结论

**当前方案不能直接用于决赛。** 预赛方案中的特征提取部分可以复用，但分类、对齐、拒识、后处理四个环节都需要替换为“模板匹配 + 距离阈值”的在线开集架构。建议在预赛提交完成后立即实现并本地模拟验证（用训练集 Session1 模拟注册、留出部分 Trial 模拟盲测）。

| F5 | 决赛盲测无对抗配对，图融合失效 | 中（决赛） | 决赛鲁棒性 |

---

## 6. 建议的修正顺序

### 预赛（截止前）

1. **用纯 EEG 拒识替换 `Session1 → 0`**：嵌套留被试验证标定阈值，报告 AUROC / AUPR / EER / 固定接受率下的 U；同时保留元数据规则版作为对照，两者分开报告。
2. **补对抗实验**：在冻结验证集上生成 FGSM / PGD / 频域扰动，分别报告 RA、ASafeR，并消融图融合。
3. **做单因素消融**：协方差 Ridge → 对齐 → 双窗口/近邻 → 图融合 → Sinkhorn，逐项确认收益来源。
4. **提交说明中披露**测试批次统计量的使用。

### 泛化验证（预赛后优先补）

5. **建立真正独立的验证协议**（对应 G1–G3）：规则冻结后，用此前完全未参与选择的划分重新评估；理想情况是留出部分被试做跨被试验证。
6. **补开集验证**（对应 G4）：留出若干被试作伪未知，报告 AUROC / AUPR / EER，而不是只看闭集准确率。
7. **降低规则复杂度**（对应 G8）：比较“统一规则”与“任务特异规则”的差距，若差距很小则优先用统一规则，减少过拟合风险。
8. **报告置信区间**（对应 G7）：20 名被试下应给出 bootstrap 置信区间，避免把 0 错误解释为确定能力。

### 决赛（预赛提交后立即启动）

9. **实现决赛版在线开集流程**（对应 F1–F4）：
   - 注册阶段：A/B/C 每人多 Trial 对数协方差 → 模板（均值/中位数）；
   - 盲测阶段：逐条计算与模板距离，最近距离低于阈值则输出身份，否则输出“未注册”；
   - 阈值：用注册阶段内部留一距离分布标定，不依赖盲测批次；
   - 移除 Sinkhorn、`session` 规则、图融合。
10. **本地模拟决赛**：用训练集 Session1 模拟注册（每人取部分 Trial），留出其余 Trial 模拟盲测，并留出若干被试模拟 D/E，报告开集识别准确率与拒识率。
11. **现场鲁棒性准备**：验证 5–10 分钟间隔下的模板稳定性，准备电极重新佩戴后的中心化校正方案。

## 7. 一句话总结

当前方案在预赛规则内合规，工程实现完整，但 **U 指标由元数据规则而非 EEG 解码产生**，这是方法学上最需要修正的问题。**内部 100% 是训练集 Session1 内、四套折外划分、在已根据错误调过规则之后得到的闭集准确率**，存在规则事后拟合、协议参与选择、同 Session、闭集、无对抗五类泛化问题，不能作为跨 Session 或测试集能力的证据。**决赛方面，当前方案是离线批量闭集分类器，与决赛的在线小样本开集识别在注册方式、推理方式、拒识机制、元数据可用性四个层面均不兼容，需要另建一套模板匹配 + 距离阈值的流程。**
