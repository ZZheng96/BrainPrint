# E201 双模型跨会话与拒识方案

## Context

当前可信基线是 E170/E200 的 E65 correlation-logSPD、logbp 和 E162 embedding 融合，但严格 LOSO 拒识仍低于用户要求的 `>0.90`，且 Test S1 拒识与 Test S2 接受存在明显 trade-off。历史结果表明继续扫描固定特征、距离和阈值不能消除 known/unknown 分布重叠；Train 只有 session1，必须把“跨会话身份表征”和“未知身份拒识”拆成两个训练模型，并通过注册流程协同推理。

本阶段目标不是通过 Test 调参制造达标，而是建立可复现、Train-only、严格 LOSO 无污染的双模型实验，先验证留 2/5/10 的注册机制，再冻结候选进行一次 Test S1/S2 审计。若指标仍未达标，报告真实上限和失败原因。

## 推荐实现

第一步固定复现 E200/E199 baseline；若 baseline 不能复现，停止双模型训练并先修协议。

### 2. 模型 A：跨会话身份 embedding

模型 A 专注于“是谁”，不直接学习 unknown 类：

- 主分支：E65 correlation-logSPD，经当前外层训练折拟合的 task 标准化和 PCA-96，再投影到 128 维。
- 互补分支：冻结 E162 embedding，投影到 64 维。
- 训练分支：沿用 E162/E191 的 raw EEG encoder，首轮只训练融合投影；若 A0 无收益，再解冻 encoder。
- 融合输出：归一化的 256 维注册 embedding，并保留 identity CE 辅助头。

训练目标采用：

`L_A = 1.0 SupCon + 0.5 identity CE + 0.5 双扰动一致性 + 0.05 VICReg`。

正样本优先使用真实同身份跨 session（若数据存在），否则使用同 trial 两种扰动、同身份不同 trial；负样本使用不同身份 hard negative。人工扰动只服务于模型 A，不作为模型 B 的 unknown 标签来源。

注册时只用注册身份的 fit rows 建立 prototype；模型 A 推理输出候选身份、top1 相似度、top1-top2 margin 和 embedding 质量特征。

### 3. 模型 B：独立未知拒识

模型 B 在冻结模型 A 后训练，只判断“是否属于当前注册库”：

输入至少包括：模型 A top1 匹配分数、top1-top2 margin、候选 prototype 距离、E65/E162 匹配分数、embedding 质量统计和 task one-hot。

首轮使用可校准的 LogisticRegression/B0；只有 B0 不足时才使用小型 MLP/B1。训练数据必须由模型 A 的 OOF embedding 生成：

- known：注册身份中未参与 prototype 的 calibration rows；
- unknown：外层留出身份，按 identity 划分 unknown-train、unknown-calibration、unknown-eval；
- hard negative：高置信误认和 E65/E162 分支冲突的已知样本，但标签仍为 known。

禁止让同一 unknown identity 同时出现在 B 训练和最终评估；禁止用 Test 身份、session、统计量或标签训练/校准。

### 4. 协同推理与注册

推理按级联执行：

1. 模型 A 对注册身份 prototype 匹配，得到 `c_hat`、`s_A` 和 margin；
2. 模型 B 对匹配特征输出 `p_known`；
3. 只有 `p_known >= tau_B`、`s_A >= tau_A` 且 margin 达到预设条件时输出 `c_hat`，否则输出 `0`。

阈值只使用 Train OOF/calibration 拟合，主工作点预先固定为 known acceptance 0.90，并同步报告 0.85/0.90/0.95 曲线。不得把模型 B 概率与身份 logits 直接相加，避免两个任务再次耦合。

### 5. 留出实验矩阵

对 K=`2,5,10` 分别执行多组 identity-level 留出集合，不固定只留 16–20：

- 注册人数：`20-K`；
- 每折重新建立注册 prototype；
- 留出身份绝不进入该折统计量、PCA、模型 B 训练、prototype 或阈值；
- 报告注册身份识别率、端到端正确率、留出身份拒识率、unknown AUROC、unknown F1、AUC、macro-F1、均值/标准差/最差身份。

训练侧沿用 `frac<=0.6` fit、`0.6<frac<=0.8` evaluation；优先采用 5-block OOF，避免用同一批样本训练并校准拒识器。

### 6. 严格验收与 Test 审计

候选选择只看 Train OOF、留出实验和严格 LOSO，不看 Test 结果。完整冻结后才进行一次 Test 审计，记录 Test S1 拒识率和 Test S2 接受率，并明确这些是无真实标签的工程审计读数。

重新计算 11 项指标并记录 AUC/F1：

1. Train 拟合准确率；2. C；3. 身份 macro-F1；4. 连续时间块准确率；5. pseudo-unknown AUROC；6. U@95；7. RA；8. ASafeR；9. Test S1 拒识；10. Test S2 接受；11. 严格 LOSO 拒识。

验收硬约束为：`LOSO > 0.90`、`S1 >= 0.70`、`S2 >= 0.70`，其余 8 项保持原门禁。若双模型无法同时满足，必须保留失败结果，不得通过 Test CDF、Test 选阈值、LOSO prototype contamination 或元数据规则作弊。

## 文件与产物

实验目录至少包含：

- `config.json`、`run_e202.py`、`model_a.py`、`model_b.py`、`protocol.py`；
- `cache/`：fold plan、OOF embedding、OOF 拒识特征和 Train-only 统计量；
- `checkpoints/`：模型 A/B 各折权重及最终权重；
- `bundle/`：模型权重、特征配置、注册模板、阈值、训练身份列表、源码指纹；
- `results.json` 和 `report.md`，报告明确 AUC、F1、C、RA、ASafeR、U、S1、S2、LOSO 及数据口径。

模型不得只保存最终权重；必须保存可复现实验配置和冻结 bundle，避免重复训练。

## Verification

1. 用 `.venv\Scripts\python.exe`、CUDA 运行协议审计和 baseline smoke，确认 Train 行顺序、E65/E162/raw 对齐、无重复 trial。
2. 运行 A0+B0 的留 2/5/10 多折实验，检查严格 LOSO 防污染断言、OOF 覆盖率和每身份统计。
3. 对比 E200、E65+E162 固定融合、A0、A0+B0，确认模型 B 是否在不显著损失 known acceptance 的情况下提高 unknown rejection。
4. 只有出现满足硬约束且无泄漏的冻结候选后，才运行一次 Test 审计；否则报告最接近候选和不可解决的分布缺口。
5. 检查所有实验报告含 AUC/F1，权重和 bundle 可加载，重复运行不覆盖历史结果。
