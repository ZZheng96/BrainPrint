# 查看器方案指标汇总（s1–s4）

数据来源与计算方法见 `vis/schemes.py`。测试集没有真值，所以测试相关指标只给标签分布和代理分。

- OOF：训练集 blocked OOF。指标有 acc、macro-F1，以及 margin AUC（用 top1−top2 区分 OOF 正确与错分样本的 ROC AUC）。
- Score_proxy：属于代理估计，基于两个假设：session1 约等于未注册被试，session2 约等于已注册被试；并以参考方案 s1 的标签作伪真值。其中 U 为 session1 的拒识率，C 和 RA 为 session2 上与 s1 非 0 标签的一致率，Score=100·C^0.4·(0.7RA+0.3ASafeR)^0.35·U^0.25。
