# E184 跨分支一致性门控：能否突破 S1+S2 = 1.4479？

日期：2026-11-15。分支 A（E180 对抗训练 EEGNet，20 类闭集）与分支 B（E65 correlation-logSPD / PCA-96 / k=12 原型）**全部只读复用、未重训**。本实验不引入任何新模型，只提出一个新的门控信息维度：**两个分支对同一 trial 的身份判断是否一致**。

## 4. 明确回答

**`S1+S2` 能否超过 1.4479 的历史上限？** 不能。本实验最好的犯规上界 1.4058，Train 标定下最好的候选 1.4038，选定门控 1.2740；对照 E181 1.3756、E183 1.0906、历史最高 E149 1.4479。

**能否达到 1.50（#9/#10 同时 0.75）？** 不能。缺口 +0.0942（以本实验最好的 1.4058 计）。换算成 AUC：本实验最好的诊断 AUC 是 0.7642，要扛住阈值迁移损失需要约 0.83。

**一致性是否带来任何增益？** 有，但极小且不可靠。`g_dist` 单独 Test 诊断 AUC 0.7563，加入 agree 后最高 0.7642（+0.0079）；Train 标定 S1+S2 从 1.3728 抬到 1.4038（+0.0309）。但**预设选择规则（Train LOSO AUC 最大）选中的是 g_dist + 4*agree**，它在 Test 上反而只有 1.2740：LOSO 上 agree 几乎完美（AUC 0.897），λ 越大 AUC 越高，于是规则把 λ 推到 4；Test 上 agree 只有 AUC 0.609，λ=4 变成过权重的噪声。这是「Train LOSO 无跨会话偏移」造成的系统性高估，不是调参能修的。

## 5. 机制解读：假设成立，但信息量不够

1. **方向确实对**：S1 agree 0.2186 显著低于 S2 0.4365（差 +0.2179，p = 6.26e-114）。未注册身份确实让两个分支更难给出同一个答案。四个一致性读数全部同向：agree 0.6090、soft_agree 0.6718、margin_agree 0.6713、rank_agree 0.6521，没有出现 E181 那种方向反转。
2. **量级不够**：最好的单信号 AUC 仅 0.6718，`g_dist` 是 0.7563。20 个注册身份的随机一致率约 0.05，S1 一侧 0.2186 是随机基线的约 4 倍——两个分支不是各自乱指，而是被同一份会话特征共同推向同一个错误身份；S2 一侧也只有 0.4365，并未饱和。两者叠在一起，一致率的可分性就被压到 0.61。
3. **它不是 g_dist 的重复，但增量太小**：agree 与 z(g_dist) 的线性相关很弱（S1 +0.0009 / S2 +0.2728），因此这确实是一个新维度；但它的分辨力本身只有 AUC 0.6718，与 0.7563 的 g_dist 线性合成后只把 AUC 抬到 0.7642（+0.0079）。弱信号配强信号，合成分辨力由强信号主导。
4. **Train LOSO 严重高估**：LOSO 上 agree 的 AUC 是 0.8974（known 一致率约 0.97、伪未知 0.02–0.50），soft_agree 达 0.9784。原因是 LOSO 全程同会话，而 Test 跨会话；且 LOSO 的伪未知是「被掩蔽身份的 19 类强制选择」——分支 A 与分支 B 同时被逼到 19 个候选里，而 Test 的两个分支都在 20 个已注册身份里选，两者的一致性行为并不相同。
5. **结论**：跨分支一致性是**真实但很弱的新维度**——它不与 g_dist 冗余（相关系数 ≈0），但自身 AUC 只有 0.61–0.67，合成后 S1+S2 最高 1.4058，无法突破 1.4479，也到不了 1.50。「两个分支是否一致」这个想法本身是对的，瓶颈在于两个分支在未注册身份上**共享同一个错误**，一致性因此不够干净。
