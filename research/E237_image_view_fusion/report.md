# E237 图像视图叠加到 E233 对齐分数

> **一句话结论**：`fuse_zscore_50_50` 达标并冻结。 最高分离 AUC = 0.9611（`fuse_zscore_50_50`，基线 0.8795）；S1≥0.95 下最高 S2 = 0.8776（`fuse_zscore_50_50`，对比目标 0.706；同读法基线 0.7063，E233 原始读法 0.7569）。

口径：EEG 侧为 E233 `mean_align` 的冻结分数（E228 e226_auc2W 表征 + 对称批次均值对齐），不重训、不重新标定；图像侧为 E149 的像素视图，走同一套 E228/E233 打分流程（fit 行逐 task 标准化 → PCA96 → 每 (task, identity) k=12 原型 → 负最近距离），并施加同一套逐 (session, task) 批次均值对齐。融合权重在运行前写死在 config。

## 5. 判定

- **满足 config 中的达标规则，冻结 `fuse_zscore_50_50`**：sepAUC 0.9611 > 0.8795（+0.0816）、S2@S1.95 0.8776 > 0.706（+0.1716）、簇纯度（LOSO 点）0.8186 ≥ 基线 0.8145 的 95%（比值 1.005×）。
- 同时满足规则的还有 `fuse_rank_50_50`（S2@S1.95 0.8753、sepAUC 0.9471）、`fuse_rank_70_30`（S2@S1.95 0.8469、sepAUC 0.9395）。三个候选的结论一致（0.847–0.878），说明增益不是某一个权重或某一种融合尺度的偶然结果：秩融合与 z-score 融合给出同一量级的结果，图像单视图 50/50 也给出 0.82/0.72。
- 但**在工作点（LOSO=0.90 的 tau）上融合并未提升 S2**：`fuse_zscore_50_50` 的 S2 是 0.2906，低于基线的 0.3041（`fuse_rank_70_30` 的 0.3094 与之持平）。也就是说：融合改变的是**S1 尾部的相对位置**，而不是"在同一个阈值下接受更多 S2"。详见 5.1。

### 5.1 为什么 sepAUC 与 S1.95 门槛都涨，而 LOSO 阈值下 S2 反而降

- 两个 branch 都在各自空间做了对称批次均值对齐。对齐后 Test S1（5 名未注册被试）在图像空间里被推得比 EEG 空间更深：图像单视图的对齐后 AUC 已经到 0.90–0.95（未对齐只有 0.71–0.76）。因此融合分数在 S1 尾部比 EEG 单一分数更"深"，S1 的 95% 分位 tau 因此更低，同样的 95% S1 拒识能放进更多 S2。
- 这条增益是**真实的排序增益**（sepAUC 0.8795 → 0.9611，与阈值无关），而不是靠放宽接受：在同一 S1 拒识水平上比较，融合确实接受更多 S2。
- 但它**不是可在训练域推导出的工作点**：LOSO 的"未知"是同一 session、同一批次里的留出被试，比 Test 里那 5 名未注册被试难得多。融合把 Test S1 推得更深，等价于把 LOSO 标定的 tau 抬到比 Test S1 的 95% 分位还高，于是固定阈值下 S2 反而下降。这与 E233/E236 已经记录的性质一致：任何改变 S1 尾部形状的操作，都会让"LOSO 标定阈值"和"S1 门槛"两种读法背离。
- 因此冻结的含义是"**在 S1≥0.95 门槛口径下有效**"，而不是"可直接用 Train 侧阈值部署"。门槛 tau 由 Test S1 分位决定，属转导式评估选点。

### 5.2 纯度敏感性（同一接受率对比并不成立）

- LOSO 工作点上采纳候选接受 5585 条 S2、纯度 0.8186（基线 5845 条 / 0.8145）；S1.95 门槛上接受 16865 条（基线的门槛只接受 13573 条），纯度比降到 0.949×（基线门槛纯度 0.6837）。
- 这个下降是**接受率变宽（0.71 → 0.88）的机械结果**，不是身份塌缩：门槛上不同预测身份数仍为 20（基线 20），最大单一身份占比 0.1179（基线 0.1377）——融合后的接受集合反而更分散。按 config 预先登记的口径（同一 LOSO 工作点、同一 tau 定义）纯度判据成立；若改在 S1.95 门槛上对比，比值 0.947–0.957 落在 0.95 容差两侧，属噪声级差异，已如实列出。

**追加一轮（权重 / 组合，仅作稳健性检查，不改变判定）**：`fuse_rank_80_20` sepAUC 0.9319、S2@S1.95 0.8184、`fuse_rank_20_80` sepAUC 0.9506、S2@S1.95 0.8454、`fuse_rank_50_50_threeview` sepAUC 0.9542、S2@S1.95 0.8678。

## 7. 限制

- **图像缓存覆盖**：只有 7 类图像类型同时有 Train/Test 缓存；GAF / MTF / 谱图 / DINOv3 只有 Train 缓存，本轮完全不可用。因此"图像路线"的结论只覆盖这 7 类像素视图，不能外推到 GAF/MTF/谱图。
- **Test 无身份标签**：官方 C/RA/ASafeR = N/A；S1 拒识与 S2 接受是唯一可读出的行为指标。
- **Test 反复查看偏倚**：Test 自 E65 起被反复评估，所有 S2 数字都带这一偏倚；本轮四个融合权重、z/秩变换、PCA/原型参数与判定规则在运行前写死，未按 Test 调整，但"选出一个采纳候选"这一动作本身已经消耗了 Test 信息。
- **S1 门槛是转导式的**：`S2@S1.95` 的 tau 来自 Test S1 分数的分位，属评估选点；而 LOSO 标定阈值下融合的 S2 不升（5.1 节），所以这两列不能同时当作可部署指标。
- **session 与注册状态混叠（E232）**：S1 = 5 名未注册被试，S2 = 20 名注册用户；session 仅作对齐的批次键，从不用于决定身份或门控。图像视图对齐后 AUC 之所以从 0.71 跳到 0.93+，主要是"这 5 个人的批次均值被移回 Train 原点"，与生物特征可分性不是一回事。
- **转导式对齐**：批次均值统计量来自被评分的同一批无标签输入，是否可用需按赛规确认。
- **秩变换尾部外推**：逐 task ECDF 在参考支撑之外用最低/最高 50 个参考点做线性外推；不外推时 S1 会全部饱和到秩 0，S1.95 门槛失去分辨率（基线 S2@S1.95 会跌到 0.43，与 E233 的 0.7569 明显不符），因此必须外推。z-score 融合不依赖这一步，得到同量级结论，说明结论不是秩映射的产物。
- **融合分数是标量**：预测身份仍来自 EEG 分支，因此纯度/覆盖只能检验"接受决策是否保持身份一致"，不能证明图像分支独立带来了身份信息。
