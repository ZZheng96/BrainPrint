# E20–E35：EEG 图像化 + DINO 路线总结

日期：2026-11-12
范围：E20（图像化 + 冻结 DINOv2）至 E35（逐任务拆解）。本文汇总目标、全部尝试、遇到的困难与当前结论。

---

## 一、目标与硬约束

### 1.1 评分目标

官方公式：

```
Score = 100 × C^0.40 × (0.7·RA + 0.3·ASafeR)^0.35 × U^0.25
```

| 指标 | 定义 | 分母 |
|---|---|---|
| C | 正常样本正确识别率 | 注册者正常样本 |
| RA | 对抗样本正确识别原身份率 | 对抗样本 |
| ASafeR | 对抗样本「判对或拒识」率 | 对抗样本 |
| U | 未注册样本拒识率 | 未注册样本 |

### 1.2 项目硬约束（2026-11-12 用户确认）

1. 身份与拒识决策必须**仅凭 EEG**，禁止用 Session 编号、文件顺序、样本数量、正常/对抗分组、近重复配对。
2. 未知拒识阈值必须来自**内层伪未知**（Train 留被试），外层一次性评估。
3. 本对话限定在 **DINO 图像路线**内。
4. 用户当前诉求：**降低 S2（注册者）拒识率，同时提高 S1（未注册）拒识率**，且不得有数据泄露。

### 1.3 Test 结构口径（项目记忆第 41–42 行，强推断）

| 分组 | 样本数 | 含义 |
|---|---:|---|
| Test Session1 | 3,033 | 5 名未注册者的唯一 Session（U 的分母） |
| Test Session2 | 19,218 | 20 名注册者的正常 + 对抗样本（C / RA 的分母） |

## 二、路线定义

```
4 秒 18 通道 EEG
  → 多频带 log 协方差（6 频带 × 171 维）
  → 编码为图像（224×224×3）
  → 冻结 DINOv2 ViT-B/14（768 维 CLS）
  → 线性探针（身份分支）+ 距离型新颖度（拒识分支）
```

所有环节逐样本、归纳式；Test 只做无标签审计。

## 三、全部尝试（E20–E35）

### 3.1 图像表示与骨干（E20）

| 表示 | C | 身份 F1 | U | unknown AUROC |
|---|---:|---:|---:|---:|
| 纯协方差（对照） | 0.9573 | 0.9196 | 0.9752 | 0.9929 |
| covariance5 图像 | 0.9294 | 0.8961 | 0.4323 | 0.9095 |
| covariance5 融合 | 0.9628 | 0.9225 | 0.9685 | 0.9901 |
| topomap5 图像 | 0.8690 | 0.8422 | 0.2327 | 0.7969 |

- **DINOv3 ViT-B/16 对比（E20J）**：图像单独 AUROC 0.8694（劣于 DINOv2 的 0.9095），融合后 0.9917 vs 0.9901，**骨干不是瓶颈**。
- E20H：两阶段判据在 Test 上 Session2 拒识 **34.77%**；E20I 定位到 Test 分数只有训练的一半（max 中位 7.35 vs 14.32）。

### 3.2 尺度不变表示（E21）

7 种逐样本归一化表示，最优 `cov_detrend_zband`：

| 表示 | 闭集错误 | 闭集准确率 | C | U | AUROC |
|---|---:|---:|---:|---:|---:|
| cov_raw | 27 | 0.9971 | 0.9573 | 0.9752 | 0.9929 |
| **cov_detrend_zband** | **11** | **0.9988** | 0.9635 | 0.9760 | **0.9940** |
| corr_fisher | 87 | 0.9905 | 0.9582 | 0.7375 | 0.9610 |

但 Test S2 两阶段接受率仅 **0.10–0.28**，且 max 比恒为 0.48–0.54、margin 比 0.19–0.24。

### 3.3 偏移性质与可恢复性（E22–E23）

- **E22**：相关矩阵对通道增益 `D C D` 与频带缩放**严格不变**（保持率 1.000），但 Test 分数比仍 0.54、AUROC 0.29 → 排除「幅度/阻抗/频带功率」类解释。域随机化对 Test 零改善。
- **E23**：CAR / Cz / 拉普拉斯只把闭集错误 27→18、AUROC(S2 vs S1) 0.317→0.43，分数比仍 0.50–0.55。均值协方差差值非低秩（主特征值占 17%–34%）。
- **E23 附带发现**：Test S2 双峰（低范数 7,985 条 / 高范数 11,233 条）。

### 3.4 扰动检测与 RA 导向（E24–E25）

- **E24**：SNR 30 dB 白噪声可把范数从 59.7 压到 31.7（≈ 低范数组 34.1），据此做过范数门控——**该解释后被 E25A 推翻，候选已撤回**。
- **E25A**：同会话 SNR30 扰动下，干净模型 RA 代理 **0.9896**，对抗增广后 **0.9972**（ASafeR 1.0000）；但对 Test 低范数组接受率只从 0.041 到 0.055。
  → **结论：低范数组不是对抗样本，跨会话识别才是唯一瓶颈。**

### 3.5 拒识判据（E26–E32）

| 实验 | 判据 | Test AUROC(S2 vs S1) | 代表性工作点（S2 接受 / S1 拒识） |
|---|---|---:|---|
| E26 | 原始协方差距离 | 0.7576 | 0.845 / 0.467 |
| E27 | 五信号融合 | 0.467（变差） | — |
| E28 | DINO cov5 距离 | 0.7065 | 0.952 / 0.435 |
| E29 | 修正内层标定 | 0.7065（内层 0.6369） | 0.955 / 0.430 |
| E30 | + 类内白化 WCCN | 0.7243（+PCA 0.7253） | 0.938 / 0.486 |
| **E31** | **+ 任务条件化** | **0.7327** | **0.917 / 0.509** |
| E32 | + 距离比率 | **0.7403** | 0.894 / 0.506 |

### 3.6 表征改造（E33–E34，均负结果）

| 尝试 | 闭集准确率 | C | Test AUROC | 结论 |

## 四、遇到的困难

### 4.1 跨会话分数塌缩（核心困难）

| 指标 | Train 内层 | Test S2 | 比值 |
|---|---:|---:|---:|
| 分类分数 max 中位数 | 14.32 | 7.35 | 0.51 |
| margin 中位数 | 10.35 | 2.20 | 0.21 |
| DINO 距离中位数 | 18.66 | 20.75 | 1.11 |

已排除的解释：全局幅度缩放（E21）、频带功率与通道增益（E22）、参考电极与空间混合（E23）、
公共模式伪迹（E23，非低秩）、扰动强度（E25）。

**剩余解释：跨会话的身份证据本身很弱，分布重叠严重。**

### 4.2 未注册与注册者不可分

AUROC(S2 vs S1) 最高只有 0.74，且早期判据（margin / energy）方向相反（0.30–0.44）。
注册者距离中位数 16–17，未注册者 34–46，**中心分得开但尾部重叠严重**。

### 4.3 判据与表征两端的边际收益都已接近零

- 判据：E29→E32 提升 +0.034 AUROC，工作点不变。
- 表征：E33（学习式投影）掉 0.09–0.11；E34（高分辨率）掉 0.01。
- 内层标定已经可信（逐任务内层与 Test 差 0.006–0.020），不存在「标定失败」这一借口。

### 4.4 数据量限制

20 类 × 约 500 条样本，训练 768→512→256 的非线性头直接过拟合（E33）。

## 五、当前最优配置与指标

### 5.1 配置

```
covariance5 图像（5 频带 18×18 log 协方差，74×74 平铺到 224×224）
→ 冻结 DINOv2 ViT-B/14 CLS（768 维）
→ 任务特异线性探针（逻辑回归）
→ 任务内 WCCN 白化后的最近类中心欧氏距离
→ 阈值取训练内层伪未知已知距离的 1% 分位
```

### 5.2 指标

| 指标 | 数值 | 口径 |
|---|---:|---|
| Train 闭集准确率 | 0.9294 | E20D 严格嵌套，AUC/F1 同协议 |
| Train 身份 macro-F1 | 0.8961 | 同上 |
| Train unknown AUROC | 0.9095 | 同上 |
| Test S2 接受率 | 0.917 | 无标签审计 |
| Test S1 拒识率 | 0.509 | 无标签审计（强推断口径） |
| Test AUROC(S2 vs S1) | 0.7327 | 无标签审计 |
| Test AUC / F1 | **N/A** | 无真实标签 |
