# E186 频谱特质标记（跨会话身份判别）

从原始 18×1200 @300 Hz 提取文献公认的**跨会话稳定**频谱特质标记：逐个 trial 做 Welch（600 点 Hann、50% 重叠、补零到 2048 → 0.146 Hz 分辨率），然后每通道提取 IAF、alpha 峰突出度、峰宽 FWHM、4–30 Hz 谱质心、2–40 Hz 非周期 1/f 斜率与截距（IRLS 稳健回归，排除7–13 与 15–25 Hz）、95% 谱边缘，共 **126 维**。特征不做逐 trial 标准化（否则会抹掉特质），只在 task 内用 Train 统计量做 z 标准化。

评估协议逐字沿用 E143：Train-only 标准化 / PCA / 原型 / 阈值；5 块 Train OOF；LOSO 每折排除被评分身份、原型只用 `pm & fit_rows`（frac≤0.6）、评估块 0.6<frac≤0.8；Test 只评分，Session 只用于诊断 AUC。

## 1. 判定（核心）

- **特质标记单独的 Test 诊断 AUC 是否 > 0.70？** 最高 **0.7557**（aperiodic PCA-32 k=12）→ 是；高于 0.65 下限，跨会话仍有判别力。
- **与 E65 融合后 S1+S2 能否突破 1.4479？** 最高 **1.3952**（block_norm concat 96+16 -> PCA-96 k=12 @a=0.90）→ 未突破。能否达到 1.50：不能。
- E65 对照：诊断 AUC 0.7578、S1 0.7979、S2 0.5960、S1+S2 1.3938（历史 0.7578 / 0.7979 / 0.5960 / 1.394）。

## 5. 机制解读

1. **特质标记里只有「非周期 1/f 斜率+截距」跨会话稳定**：36 维的 aperiodic 单族诊断 AUC 0.7557，与 855 维的 E65 correlation-logSPD （0.7578）几乎持平；谱质心 0.7320、95% 谱边缘 0.6823 次之。而文献里最常说的 IAF 只有 0.5447、峰突出度 0.5369、峰宽 0.5391，即 4 秒单 trial 的alpha 峰形状在本数据上几乎是噪声（未见可靠的个体 alpha 峰）。
2. **特质全拼接反而低于单一 1/f 族**（0.7535 < 0.7557）：IAF/峰形状这些低信噪比维度在 PCA 里占掉了方差，把已经很强的 1/f 方向冲淡了。
3. **S1/S2 的分工完全互补**：aperiodic 单族的 LOSO 拒识极低（@a=0.90 仅 0.1932），说明它的分数在 Train 上分不开「伪未知 vs 已知」，所以阈值被压得很松、S2 接受高（0.7751）而 S1 拒识低（0.6202）；E65 正好相反（LOSO 0.7936、S1 0.7979、S2 0.5960）。两者的 S1+S2 之和几乎相同（1.395 vs 1.394），说明它们只是同一条跨会话 ROC 上的不同工作点，不是互补信息。
4. **融合买到的是 AUC 不是工作点**：E65+trait 融合把诊断 AUC 抬到 0.7746（比 E65 +0.0167），但 S1+S2 只有 1.3952（E65 1.3938）。AUC 的增益集中在「排序」上，而 S1 拒识与 S2 接受在同一阈值下此消彼长，融合没有改变这个斜率——与 E167/E169 的结论一致。
