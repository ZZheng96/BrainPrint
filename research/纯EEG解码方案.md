# 纯 EEG 身份识别、跨会话鲁棒与开放集拒识方案

日期：2026-11-12
适用范围：脑纹识别预赛后续实验，并兼顾决赛的现场小样本注册与逐样本盲测。

## 0. 目标与硬性约束

### 0.1 要解决的三个问题

1. **身份区分**：对 20 名注册用户输出正确标签 1–20，优化正常识别准确率 C。
2. **鲁棒识别**：跨时间、跨 Session 以及对抗扰动后仍恢复原身份，优化 RA；不能把受扰动样本错误认证为其他注册身份，优化 ASafeR。
3. **开放集拒识**：仅根据 EEG 判断样本不属于注册库，输出 0，优化 U。

官方综合指标固定为：

\[
A=0.7RA+0.3ASafeR
\]

\[
Score=100\times C^{0.40}\times A^{0.35}\times U^{0.25}
\]

因此，全部拒识、只追求闭集准确率或只追求输出稳定性都不是可行目标。

### 0.2 后续候选的禁止项

身份和拒识决策不得使用：

- `Session1 → 0` 或任何 Session 编号规则；
- 文件名、文件顺序、样本编号、样本数量或身份配额；
- 正常/对抗样本的分组、排列、配对或近重复关系；
- 测试集标签 0 的数量先验；
- Sinkhorn 等依赖整批身份分布的强制分配；
- 人工修改个别预测标签。

允许把文件顺序仅用于**写出提交 CSV**，不允许它影响任何一条预测。模型必须满足：单独输入一个 `18×1200` EEG Trial，即可独立、确定地输出 0–20。

第一次正式提交的 Session 拒识链路只保留为历史对照，不再进入后续合规候选。其问题记录见[问题梳理](file:///d:/WORK/BCIC2026/BrainPrint/research/问题梳理.md)。

## 1. 证据边界

当前 Train 只有 20 名注册被试的 Session1，官方 Test 无标签。由此得到三个不能回避的限制：

- 可以用连续时间块、前推/反向/中间留段检验同 Session 内时间泛化，但**不能直接证明跨天 Session 泛化**；
- 可以留出注册被试模拟未知身份，但这只是 pseudo-unknown 验证，不等同于官方 5 名新被试；
- 可以自行生成 FGSM、PGD、稀疏和时频攻击，但不能保证覆盖官方扰动类型。

因此，后续报告必须区分“本地有标签验证”“官方 Test 无标签诊断”和“官方得分”，不得把其中任何一个冒充另一个。要真正证明跨 Session 能力，仍需带标签的第二 Session、决赛现场注册/盲测数据或官方分项反馈。

## 2. 总体技术路线

采用“**稳健表征 + 度量学习 + 开集校准 + 对抗训练**”的渐进路线：

```text
单个 EEG Trial（18×1200）
  → 轻量稳健预处理与数据质量特征
  → 多频带 SPD 协方差/切空间表征
  → 可选轻量时序身份嵌入（只有通过验证门禁才加入）
  → 身份原型相似度与开集分数
  → 内层验证拟合的已知/未知校准器
  → p_known 低于阈值：输出 0
  → 否则：输出相似度最高的注册身份 1–20
```

主线先建立可解释、低方差的 SPD 协方差模型；深度嵌入是增强项，不以随机 Trial 高分替换稳健基线。最终只保留在严格外层验证中改善综合得分的组件。

## 3. 数据与预处理

### 3.1 固定数据事实

- 训练集：11,304 条，20 名注册被试，每条 4 秒、300 Hz、18 通道。
- 官方已执行 50 Hz 陷波、1–40 Hz 四阶 Butterworth 零相位带通、坏通道球面插值、异常片段剔除和逐通道去均值。
- 任务包括 EC、EO、Imagery、SSVEP；任务只用于分层采样和分任务报告，主模型推理不读取任务或 Session 字段。
- 幅值单位未确认，不使用绝对微伏阈值。

赛题依据见[赛题说明](file:///d:/WORK/BCIC2026/BrainPrint/赛题说明.md)和[赛题赛制介绍与邮件](file:///d:/WORK/BCIC2026/BrainPrint/赛题赛制介绍与邮件.md)。

### 3.2 每个 Trial 独立处理

1. 检查 NaN、Inf、常数通道和异常幅值，记录质量指标；不因单一质量规则直接拒识。
2. 以训练折统计量确定稳健截尾尺度，或使用当前 Trial 自身的稳健尺度做截尾；不得使用官方 Test 批次均值、方差或身份伪标签。
3. 保留官方 1–40 Hz 有效频带。旧方案中的 45–90 Hz 特征不得直接沿用为有效生理证据。
4. 同时提取完整 4 秒和两个 2 秒窗口，窗口分数在模型内部融合；不依赖其他 Trial。
5. 所有 scaler、白化矩阵、SPD 参考均值和特征选择器都只在相应训练折拟合。

### 3.3 模拟 Session 漂移的训练增强

增强只应用于训练折，验证折只保留干净样本或独立生成的攻击样本：

- 每通道小幅增益和全局增益变化；
- 带限噪声与低频基线漂移；
- 小范围时间平移、裁剪和时间伸缩；
- 少量通道 dropout 或通道噪声放大，模拟接触状态变化；
- 保持空间拓扑的轻量空间混合，不随机打乱通道位置；
- 不同任务、不同时间块的混合训练，避免模型记住 Trial 顺序。

增强参数在内层验证选择，不能用官方 Test 分布调参。

## 4. 表征与身份模型

### 4.1 必做基线：多频带 SPD 协方差

建议使用 1–8、8–13、13–20、20–30、30–40 Hz 五个频带，并通过消融决定是否合并或删除频带。

每个窗口计算：

1. 带通后的通道协方差；
2. Ledoit–Wolf 或固定收缩，保证 SPD；
3. 以训练折黎曼均值为参考做切空间映射，或使用 log-Euclidean 矩阵对数；
4. 上三角向量化，非对角项乘 `sqrt(2)`；
5. 保留 trace 归一化协方差与少量 log 功率特征，检验身份信息和 Session 幅值漂移的权衡。

分类器从强正则 Ridge/线性 Logistic 开始。该基线延续 E00 中“协方差优于单纯 PSD”的有效证据，但移除 Session 拒识、测试批次 z-score、图融合和 Sinkhorn。

### 4.2 身份原型与统一相似度

对每类身份计算归一化原型：

\[
\mu_k=\operatorname{normalize}\left(\frac{1}{N_k}\sum_{i:y_i=k}z_i\right)
\]

身份得分由以下证据组成：

- 向量与身份原型的余弦相似度；
- top-1/top-2 原型间隔；
- 到最近原型的稳健距离；
- 可选的类别条件协方差距离；
- 多窗口预测的一致性。

所有组合权重只由内层 OOF 分数学习或选择，不针对特定被试、特定错误 Trial 手工设权重。

### 4.3 条件增强：轻量身份嵌入

仅当 SPD 基线在外层协议中显示明确瓶颈时，增加轻量 EEGNet/时序卷积嵌入：

- 输出 L2 归一化 embedding；
- 使用 ArcFace 或 supervised contrastive loss 增大类间间隔、压缩类内距离；
- 训练时进行类别/任务均衡采样，避免 Imagery 样本数支配梯度；
- 与 SPD 模型做分数级融合，而非堆叠大量互补规则；
- 深度分支必须接受完全相同的外层留被试、时间隔离和攻击评估。

这一结构也可迁移到决赛：预训练特征提取器后，现场 A/B/C 只需用注册 Trial 建立新原型，无需重新训练三分类网络。

## 5. 纯 EEG 开放集拒识

### 5.1 不把未知身份训练成普通第 21 类

不同未知被试并不构成一个紧凑类别。主方案采用“注册身份得分 + 已知/未知校准”，而不是把 pseudo-unknown 直接拟合成固定的未知类。

### 5.2 校准器输入与输出

校准器只接收由 EEG 模型产生的分数，例如：

- 最大原型相似度；
- top-1/top-2 margin；
- 最近原型距离；
- 多窗口一致性；
- 可选 energy/logsumexp；
- 信号质量统计。

输出 `p_known`。最终规则为：

```text
p_known < τ        → 0（未注册）
p_known ≥ τ        → argmax_k identity_score(k)
```

`τ` 在内层验证上选择，目标为官方综合分，同时约束 C 不能因过度拒识明显下降。校准器和阈值均不得查看外层未知被试或官方 Test。

### 5.3 为什么不能只看 margin

高 margin 的错误接受仍可能存在，低 margin 的真实注册样本也不应全部拒绝。因此 margin 只是校准特征之一；最终必须同时报告已知样本接受率、未知拒识率和身份条件准确率，防止通过大量误拒注册样本换取高 U。

## 6. 对抗鲁棒与误认证防护

### 6.1 本地攻击集合

训练攻击仅由训练折生成，验证攻击仅由验证折生成；二者不共享扰动样本，验证攻击及其标签不参与模型、阈值或攻击强度选择：

- FGSM：单步基线；
- PGD：多步 L2/L∞ 攻击，作为主要压力测试；
- 时间—通道稀疏攻击：模拟局部电极干扰；
- 频域/时频扰动：检验非波形对齐攻击；
- 多档扰动强度，按每通道 RMS 或训练折标准差归一化。

攻击可使用本地验证标签生成以进行评估，但攻击强度、训练配置和阈值只能由内层确定；官方 Test 不参与攻击生成或调参。

### 6.2 防御训练

- 在训练折内混合干净样本和 PGD/FGSM 样本做对抗训练；
- 对 embedding 同时约束扰动前后的同身份一致性和不同身份间隔；
- 比较多窗口平均、SPD 收缩和对抗训练的独立贡献；
- 不采用“遇到攻击就拒识”的策略来提高表观安全性，因为拒识只增加 ASafeR，不增加 RA。

### 6.3 逐层消融

至少比较：

| 版本 | 目的 |
|---|---|
| 干净 SPD 模型 | 正常识别基线 |
| + Session 模拟增强 | 检验时间/设备漂移鲁棒性 |
| + 多窗口融合 | 检验短时扰动抑制 |
| + 对抗训练 | 检验 RA 与 ASafeR |
| + 开集校准 | 检验 U 及其对 C/RA 的影响 |
| + 深度嵌入 | 判断额外容量是否真正必要 |

## 7. 严格验证协议

### 7.1 外层：留被试开放集评估

采用 5 折被试分组，每折：

- 4 名被试全部作为外层未知身份，只用于最终评估；
- 其余 16 名作为注册身份；
- 16 名注册被试按连续时间块划分开发数据和固定已知测试数据；
- 外层模型、校准器和阈值确定后，一次性评估注册者的干净/攻击样本以及 4 名未知者。

每条训练被试都在某一折担任未知身份，避免只留出“容易拒识”的固定四人。

### 7.2 内层：模型和阈值选择

在外层 16 名注册被试的开发数据内继续做留被试折：

- 一部分被试作为内层 pseudo-unknown；
- 其余被试提供训练和时间隔离的已知验证样本；
- 选择特征、模型权重、增强强度、攻击强度、校准器和 `τ`；
- 不读取外层折结果反复调参。

外层运行前冻结配置和随机种子。若根据外层错误再次修改规则，该外层就不再是独立验证，必须明确降级为开发结果。

### 7.3 时间隔离

所有已知身份验证均按被试、Run 内连续 Trial 块划分，禁止相邻窗口或同一原始 Trial 的派生样本跨训练和验证。至少保留：

- 后 20% 时间前推；
- 首 20% 反向留段；
- 中间 40%–60% 留段；
- 连续块 OOF。

这些协议用于检验时间稳定性，但仍不得表述为真实跨 Session 结果。

### 7.4 单样本一致性验收

对同一 Trial 独立推理与放入不同批次推理，标签和分数应一致；随机重排文件、修改 Session 字段或改变其他样本数量，输出不得变化。这是排除元数据和转导依赖的自动测试。

## 8. 指标与报告要求

每个实验报告至少包含：

| 维度 | 必报指标 |
|---|---|
| 正常识别 | C、20 身份 macro-F1、逐身份召回率 |
| 对抗识别 | RA、ASafeR、A、对抗后的身份 macro-F1 |
| 未知拒识 | U、未知 AUROC/AUC、未知 AUPR、未知类 F1、EER |
| 联合输出 | 21 类 macro-F1、固定已知接受率下的 U |
| 综合 | 本地 Score、逐被试 bootstrap 95% 置信区间 |
| 安全分析 | 误接受率、误认证率、拒识导致的 C/RA 损失 |

AUC 默认指“未知身份检测 AUROC”，并明确分数方向；F1 同时给未知类 F1 和身份 macro-F1，避免只报一个含义不清的数值。

若官方 Test 无真值，则 Test AUC、F1、C、RA、ASafeR、U 均写 `N/A（无真实标签）`，不能用候选 CSV 的标签分布或配对一致率代替。

## 9. 模型选择与冻结门禁

候选只有同时通过以下门禁才允许成为正式提交：

1. **合规门禁**：推理只读取单条 EEG；无 Session、文件结构、配对或批次身份先验。
2. **开放集门禁**：外层留被试验证完成，阈值完全由内层产生，报告 AUC、F1 和 U。
3. **鲁棒门禁**：在多种本地攻击上报告 RA、ASafeR，不只报告扰动前后一致率。
4. **泛化门禁**：时间隔离结果稳定，且未通过反复查看外层错误拟合规则。
5. **综合门禁**：相对纯 SPD 基线改善内层 Score，且没有靠显著牺牲 C 或 RA 换取 U/ASafeR。
6. **复现门禁**：固定配置、随机种子、数据划分和模型哈希；同配置重复运行得到一致输出。
7. **格式门禁**：22,251 行、Sample 顺序不变、Label 为 0–20 整数且无缺失。

最终冻结后只运行一次确认评估。此后任何修改都建立新实验编号，不覆盖旧候选。

## 10. 实施顺序

后续实验从 `E12` 起建立独立子文件夹，缓存继续放在 `BrainPrint_cache`，研究报告放在对应实验目录。协方差、SPD 特征分解、网络训练与批量推理优先用 PyTorch/cuPy 的 GPU 流程实现，尽量驻留显存；仅将必要的指标和预测落盘。

### E12A：纯 EEG 可复现基线

- 建立统一输入、无元数据的 SPD/Ridge 推理链；
- 加入单样本/批次不变性测试；
- 重现时间隔离闭集基线，报告 AUC、F1 的适用项和 N/A 原因。

### E12B：嵌套开放集拒识

- 完成 5 折外层留被试和内层阈值标定；
- 比较 max-cosine、距离、energy 与学习式校准；
- 冻结一种全局规则，不设置被试特异补丁。

### E12C：跨时间增强与对抗训练

- 加入 Session 模拟增强和多窗口模型；
- 在内层选择攻击配置，在外层报告 C、RA、ASafeR、U；
- 完成防御消融和扰动强度敏感性分析。

### E12D：条件性嵌入增强

- 仅在 SPD 基线不足时训练轻量 embedding；
- 比较单独使用与分数融合；
- 若外层综合分或最差折没有稳定改善，立即停止该分支。

### E12E：冻结、确认与提交

- 冻结全流程并重跑确认折；
- 保存模型、配置、环境、指标和预测文件；
- 官方提交文件仍按原始 Sample 顺序写出，但预测过程不读取顺序；
- 保留旧正式提交作历史记录，不回滚到 Session 拒识。

## 11. 决赛复用方式

现场注册时，用 A/B/C 的注册 Trial 建立各自 embedding/SPD 原型，并用注册数据内部留一距离与已有 pseudo-unknown 校准先验设置阈值。盲测时逐条输出 A/B/C 或“未注册人员”。

决赛链路同样禁止 Sinkhorn、Session 规则、文件顺序和近重复图融合。若现场注册样本过少，优先使用收缩原型和多 Trial 稳健聚合，而不是临时训练高容量分类器。

## 12. 当前最关键的成功条件

本方案的核心不是再寻找测试集结构，而是建立三个可信能力：

1. 用稳定的空间—频率身份表征区分注册者；
2. 用时间隔离、信号增强和对抗训练提高扰动后的原身份恢复率；
3. 用严格留被试校准识别“不在注册库”的 EEG。

只有这三项在同一套逐样本、纯 EEG 推理链中同时成立，所得 C、A、U 才具有方法学意义，并可迁移到决赛。
