# E39：类数不变的 ECDF 校准与 K=8 → K=20 阈值迁移

日期：2026-11-13。仅使用 Train Session1；Test 未读取、未推理、未参与任何选择。

## 1. 动机

E38 证明 DINO 图像分支在融合中无增益，且 q=0.05 工作点 U 只有 0.6774。
E36E 曾观察到 ECDF 映射后的 distance_ratio 从 K=8 内层迁移到 K=16 外层几乎无损。
本实验检验同一校准能否迁移到**与官方 Test 一致的 K=20 全注册场景**，并检查只用内层 K=8
选出的阈值能否同时满足 U≥0.95 与 C≥0.99。

## 2. 方法

```
五频带 1–40 Hz logSPD(855) → detrend+zband → WCCN 类中心余弦
→ distance_ratio = (1 − second) / (1 − max)
→ 逐折 ECDF：u = count(fit 折已知 distance_ratio ≤ r) / n
→ u < threshold 判为 0（未注册），否则输出最近类中心身份
```

- ECDF 参考分布只来自 fit 折已知样本，逐样本映射，无批次统计。
- 阈值只在 **K=8 内层 pooled 已知 OOF** 上选择：101 个分位（0–0.05），约束已知接受率≥0.95，
  最大化 `100·C^0.40·U^0.25`。
- 外层 K=16 与 K=20 只做迁移确认，不回头调阈值。

## 7. 结论

- **ECDF 校准是类数不变的**：同一个阈值 0.023106 在 K=8、K=16、K=20 三种注册规模下
  给出的 C 差异 ≤0.0001，U 在外层反而更高（0.9937 vs 0.9688）。
- **U 门禁已解决**：E38 的 q=0.05 工作点 U=0.6774，改用内层选出的 ECDF 阈值后外层 U=0.9937，
  同时 C 保持 0.9773、身份 F1 0.9881。
- **K=20 全注册场景的闭集能力极强**：direct C 0.9996、macro-F1 0.9996，说明 20 类身份区分本身
  不是瓶颈，瓶颈只在开放集工作点选择。
- 图像分支（E38）在此配置下无增益，本实验因此只使用纯 EEG 分支。
