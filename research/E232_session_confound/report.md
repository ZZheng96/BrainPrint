# E232 Test session 与注册状态混叠诊断

只用 Train 拟合 per-task 标准化 + PCA96，然后在 Test 两段各自做无监督 k-means（3000 行子样本，固定种子），
比较轮廓系数最优簇数与簇大小分布。若 session1 的最优簇数接近 5、session2 接近 20，则说明 session 划分与
“未注册 5 人 / 注册 20 人”高度混叠，S1/S2 不是纯生物特征指标。

## 判定结论

- **session1**：k=5 取得最佳轮廓系数 0.1959，5 个簇大小为 553–622、簇大小变异系数仅 0.041（几乎完全均衡）。结合赛题“5 名被试仅参加 1 次会话”，判定 Test session1 就是 **5 名未注册被试（真实标签 0）**。
- **session2**：最佳 k=28（silhouette 0.1142）；k=20 时 silhouette 0.1029、簇大小 58–286。结合“20 名注册用户 + 对抗扰动样本保留原标签”，判定 Test session2 是 **20 名注册用户（标签 1–20，含正常与对抗样本）**。

## 对指标解释的影响

1. S1 拒识 = 对 5 名未注册者的拒识率，与官方未知拒识指标同向；当前 0.9637 是真实指标，且已达官方 ≥0.95 门槛。
2. S2 接受 = 对 20 名注册用户（含对抗样本）的接受率，混合了 clean 与对抗两类样本，**不等于官方 C**；0.3043 是两者的混合值。
3. session 字段与“是否注册”一一对应（0 vs 1–20）。因此任何用 session 做门控或分布对齐的方法，都是在绕开生物特征本身，属退化解法，不可采纳。这也解释了为何所有实验中 Test S1 拒识恒高于 LOSO 拒识：两段的“未知”根本不是同一难度。
4. 在 Test 无标签的条件下，“S2 最大化”不可验证：把 session2 全判为已注册即可把 S2 推到 1.0，但无法证明 C 提升。因此不应继续以 S2 作为优化目标。

## 建议

- 冻结 `e226_auc2W` 作为最终方案；S1 拒识 0.9637 可对外报告，S2 0.3043 只能表述为“注册用户接受率的下界”（其中包含非鲁棒模型必然拒识的对抗样本）。
- 官方 C / RA / ASafeR 需要带标签的验证集，当前数据无法计算；如需报告，只能标注 N/A。
