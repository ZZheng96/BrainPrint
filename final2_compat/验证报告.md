## 验证条件

- 两个 ZIP 分别解压至系统临时目录。用项目 `.venv` 的 Python 3.10.22，每次加载使用新的 `-I -B` 隔离进程，工作目录为对应解压目录。核对三个函数的实际实现路径及原型张量设备，排除串包及 CUDA 回退。PyTorch 2.5.1+cu121，NumPy 1.26.4，NVIDIA GeForce RTX 3080 Laptop GPU。
- 只用合成输入：NumPy `default_rng(20261119)` 依次生成标准正态 float32 查询 `(5,18,1200)` 和注册输入 `(9,18,1200)`。查询任务依次为 EC、EO、Imagery、SSVEP、unknown；注册 meta 为 None，21/22/23 号分别注册 4/3/2 条。注册前三个新身份列均为负无穷，注册后所有分数均有限。
- 未访问比赛数据，未训练，未执行 Git 操作。本次不测 AUC/F1；原 README 记载严格身份 LOSO AUROC **0.9871**、5 折 OOF 身份 macro-F1 **0.9988**，二者不是此次合成输入验证所得。
