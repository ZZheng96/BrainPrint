# 纯 EEG 开集识别、对抗鲁棒性与小样本注册模拟

日期：2026-11-06
数据：Train Session1，20 名被试，11,304 个 Trial
硬件：NVIDIA GeForce RTX 3080 Laptop GPU，PyTorch 2.7.1+cu118

## 1. 结论先行

- **纯 EEG 拒识在内部嵌套留被试验证中可行。** `base` 分支的外层折宏平均 AUROC 为 **0.9935**，逐 Trial 汇总 macro-F1 为 **0.9556**、unknown-F1 为 **0.9680**；C=0.9321，U=0.9901。
- **简单分支足够，复杂融合没有开集收益。** `full` 的 C 和 macro-F1 略高于 `base`；`fused` 虽然拒识前闭集 C=0.9990，但 U、macro-F1 和 unknown-F1 均最低。后续应优先保留 `full/base`，不要继续堆叠任务特异规则。
- **当前纯 EEG 测试候选不可提交。** 它拒识 18,194/22,251 条（81.77%），表明训练内阈值迁移到测试特征时失效。没有测试标签，不能据此计算或声称测试 C/U/AUC/F1；正式提交未被修改。
- **特征空间对抗实验显示明显鲁棒性下降。** 在 fused 分支上，PGD、epsilon=0.1 时 RA 从 C=0.9228 降至 0.5120。理想图配对提高 RA，但同时降低 C，官方公式代理分没有提高。
- **三注册身份模拟尚未达到可部署水平。** N=10 时，Ridge 的 C=0.5153、U=0.9097、AUROC=0.8138、macro-F1=0.5292；原型模型 C=0.5340、U=0.9107、AUROC=0.8390、macro-F1=0.5373。主要损失来自阈值拒识，而非拒识前的身份分类。

## 2. 实验协议

### 2.1 嵌套留被试开集评估

- 特征：4 秒及双窗口对数协方差，6 个频带，每窗 1,026 维；不使用 session 拒识、测试批次对齐或类别平衡。
- 外层：5 折留被试，每折 4 人全部 Trial 作为未知，其余 16 人为注册者；注册者每任务后 20% Trial 只用于外层评估。
- 内层：在 16 名注册者中做 2 折伪未知划分；内层模型用前 60% Trial 训练，注册者的 60%–80% Trial 与伪未知被试的前 80% Trial 用于选择置信度分数及阈值。
- 阈值：内层已知置信度的 5% 分位，即目标已知接受率约 95%；外层数据不参与分支、分数或阈值选择。
- 分支：`full`=4 秒 Ridge；`base`=4 秒与双窗口 Ridge 等权；`fused`=固定任务特异 Ridge/近邻融合。
- 不确定性：200 次按被试聚类 bootstrap。C/U/F1 使用逐 Trial 汇总；AUROC/AUPR/EER 使用 5 个外层折的宏平均，避免拼接不同分数或不同尺度的置信度。

指标中，C 为注册者拒识后的正确率，U 为未知者拒识率；AUROC 以“已知”为正类；unknown-F1 以未知拒识为正类；detection-macro-F1 为已知/未知二分类宏平均。

### 2.2 对抗与消融

- 对 fused 分支施加特征空间 L∞ FGSM/PGD；epsilon 为每个训练特征标准差的倍数，取 0.03、0.1；PGD 为 10 步。
- RA 为对抗样本仍预测正确身份的比例；ASafeR 为预测正确或被拒识的比例；A=0.7·RA+0.3·ASafeR。
- 代理分按 `100·C^0.40·A^0.35·U^0.25` 计算，仅对应本地模拟，不是排行榜成绩。
- `graph_pair` 使用已知的正常—对抗对应关系，是理想配对诊断；Sinkhorn 使用注册者批次的真实类别先验。二者都不是可部署的开集规则。

### 2.3 三注册身份模拟

- 每轮选择 3 名注册者，其余 17 人全部作为未知；20 轮轮转覆盖所有被试，并分别评估 4 个任务。
- 每名注册者每任务使用 N 个注册 Trial，另有独立校准 Trial：N=5/10/20 时分别为 2/5/10 条。
- 内层在 3 名注册者中留 1 人作伪未知，只选择置信度分数；阈值由 3 人独立校准 Trial 的已知分数 5% 分位确定。
- 外层使用注册者剩余 Trial 和 17 名未知者全部 Trial；逐 Trial 推理，不使用 session 拒识、批次对齐、图融合或 Sinkhorn。
- 比较标准化空间中的 Ridge 与类均值欧氏原型。C/U/F1 为逐 Trial 汇总，AUROC/AUPR/EER 为 80 个“轮次×任务”折的宏平均。

ASafeR 接近 1 主要因为被拒识也算安全；身份保持能力应重点看 RA。epsilon=0.1 时 RA 已明显下降。

### 4.2 理想图配对与 Sinkhorn

| 攻击 | direct：C / RA / 分 | graph_pair：C / RA / 分 | graph_pair+Sinkhorn：分 |
|---|---|---|---:|
| FGSM 0.03 | 0.9228 / 0.8330 / 91.69 | 0.8837 / 0.8837 / 91.37 | 91.37 |

理想图配对提高了 RA，却因正常与对抗分数平均而降低 C，代理分反而略降。Sinkhorn 单独相对 direct 的代理分变化小于 0.005 分，图配对上再加 Sinkhorn 也没有额外变化。因此，本实验不支持把这些后处理作为稳定收益来源。

## 7. 局限与下一步

1. 所有有标签结果均来自 Train Session1 内部，**不是跨 Session 证据，也不是测试集准确率**。
2. 决赛模拟仍按 task 分别训练和评估，即用 task 做模型路由；只是不使用 session 或批次统计。若现场没有 task 信息，还需统一模型或可靠的任务路由。
3. 三注册身份、N=5/10/20 和任务设置都是本地模拟选择，不应表述为官方决赛规则。
4. 对抗实验发生在标准化特征空间，不是原始 EEG、频域或物理采集攻击；epsilon 不能直接解释为实际信号扰动强度。
5. 图配对与 Sinkhorn 结果是带 oracle 信息的诊断，不代表可部署防御。
6. 20 名被试、单数据集和轮转模拟限制了泛化结论；bootstrap 只反映当前被试重采样的不确定性。

建议顺序：

1. 保留正式提交，不使用当前纯 EEG 候选；先解决跨分布置信度校准，并用独立的有标签验证确认已知接受率。
2. 将 `full` 或 `base` 作为后续开集基线，停止增加没有外层收益的任务特异融合。
3. 小样本注册优先增加独立校准 Trial，报告不同目标已知接受率下的 C/U/F1 权衡，再决定 Ridge 或原型。
4. 若需评估真实对抗能力，补原始 EEG 域攻击与可部署、无 oracle 的防御实验。
