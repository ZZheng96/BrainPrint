# E38：DINO 图像分支 + 纯 EEG WCCN 分支分数级融合

日期：2026-11-13。仅使用 Train Session1；Test 未读取、未推理、未参与任何选择。

## 1. 动机

E20–E35 的 DINO 图像路线在 Test 上 AUROC(S2 vs S1) 最高 0.7327，S1 拒识 50.9%，离目标差距过大。
E36 的纯 EEG 五频带 logSPD + WCCN 原型在 Train 外层 K16 上 AUROC 0.9981、C 0.9998。
本实验保留图像分支，把两个分支在**分数级**融合，检验能否在保住闭集/开放集指标的同时让图像分支贡献信息。

## 2. 方法

```
分支 A（图像）：covariance5 图像 → 冻结 DINOv2 ViT-B/14 CLS(768)
                → 逐任务 StandardScaler + 逻辑回归 → 任务内 WCCN 类中心余弦
分支 B（纯EEG）：五频带 1–40 Hz logSPD(855) → detrend+zband → WCCN 类中心余弦
融合：每个分支置信度先映射到该分支 fit 折已知样本的 ECDF，
      再按 w·A + (1−w)·B 组合；身份标签取权重较大分支的预测
```

- 两个分支都只用 fit 折拟合；ECDF 参考分布也只来自 fit 折已知样本，逐样本映射，无批次统计。
- 阈值取 fit 折已知融合置信度的分位（q ∈ {0.01, 0.02, 0.05, 0.10, 0.20}），不按 U 调阈值。
- 内层：RNG42 五折留被试 × 每折 2 个内层留被试（K=8），用于选型。
- 外层：RNG42 五折留被试（K=16），只应用内层冻结的 w / 判据 / 分位。

## 7. 结论与证据边界

- **图像分支在融合中没有增益**：内层与外层的 AUROC、U 都随图像权重单调下降。这与 E20–E35 的结论一致——DINO 图像表征的跨会话身份证据弱于原始 logSPD 协方差。
- 融合本身没有解决 U 门禁：AUROC 0.9978 说明排序能力足够，但 q=0.05 工作点下 U 只有 0.68；要到 U≈0.95 需要把工作点推到 q≈0.10，此时 C 降到 0.9925。
- 所有 unknown 都是 Train 留被试 pseudo-unknown，连续文件块只是跨会话代理，不是真实跨天证据。
- Test AUC / F1 / C / RA / ASafeR / U：**N/A**（无公开真值，Test 未读取）。
- 本实验未包含对抗攻击，A 项与完整官方 Score 未计算。
