# E26：最终候选装配

日期：2026-11-12
状态：完成。给出 5 个可提交工作点，并说明每个工作点的预期四项指标。

## 0. 方法

- 身份分支：`clean + SNR30 噪声 1:1` 对抗增广的 6 频带 log 协方差 + 逻辑回归（E25A 最优配置）。
- 拒识分支：**距离型新颖度**——样本到最近注册类中心的欧氏距离（标准化空间）。
  这是目前唯一在 Test 上方向正确的信号（AUROC(S2 vs S1) = **0.7576**，margin 只有 0.3781）。
- 阈值：只由 Train 内层伪未知的距离分位决定；类中心只用「既不在内层也不在外层」的样本估计。
- 不使用 Session、文件顺序、样本数量、正常/对抗分组、近重复配对。

## 2. 代理分（不是官方分）

假设 Test 上完整闭集准确率 `C_full = 0.35`（跨会话，见 E22），对抗维度 `A = 0.35`
（RA 受跨会话限制、ASafeR 由拒识决定），`C ≈ C_full × S2接受率`、`U = S1拒识率`：

| 工作点 | 代理 C | 代理 U | 代理分 |
|---|---:|---:|---:|
| reject1% | 0.338 | 0.207 | 30.1 |
| reject2% | 0.326 | 0.309 | 32.7 |
| **reject5%** | **0.296** | **0.467** | **34.6** |
| reject20% | 0.210 | 0.757 | 34.6 |
| reject50% | 0.098 | 0.959 | 26.9 |

若 `C_full = 0.45`，reject5% 与 reject20% 都升到约 38–40。

**结论：最优工作点在 reject5%–reject20%，代理分约 34–35，明显高于 E21 估计的 30.8。**

## 4. 证据边界

- Test 无真值，`C_full` 与 `A` 都是假设值，代理分只能用于工作点之间的相对比较，不是官方分。
- RA 代理 1.0000 是**同会话噪声扰动**下的结果；Test 的对抗样本同样来自跨会话记录，真实 RA 会更低。
- 距离型拒识在 Test 上 AUC 0.758，仍不是强判别（理想 >0.9），因此 U 与 C 的换算存在误差。
