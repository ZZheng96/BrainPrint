## 结论

**新权重下（0.25/0.25/0.5）最好 W = 0.7796，未达 0.80。图像化路线本身有效但融合方式失效。**

### 1. 图像化路线（冻结 DINOv2）单视图

| 视图 | 诊断 AUC | 最好 W |
|---|---:|---:|
| B_E65 logSPD（纯 EEG，路线 B） | 0.7603 | **0.7796** |
| A_E62cov8（多窗口协方差图像） | 0.7480 | 0.7208 |
| A_DINOcovHR | 0.7409 | 0.6247 |
| A_E62corr8 | 0.7239 | 0.7176 |
| A_E62cov4 | 0.7222 | 0.7004 |
| A_DINOcov5 | 0.7222 | 0.6413 |
| N_E21corrf | 0.5659 | 0.7009 |
| A_DINOcorr | 0.4971 | 0.3561 |
| A_DINOtope5 | 0.4538 | 0.5718 |
| N_E21covdz | 0.4721 | 0.7301 |

**没有任何单个图像化视图超过纯 EEG 的 E65**（0.7603）。最好的三个图像视图在 0.72–0.75，属于可用但不占优。

### 2. 图像化 + 互补融合：AUC 提升，但 W 崩塌

| 融合方式 | 视图集 | 诊断 AUC | 最好 W |
|---|---|---:|---:|
| 分数级 z 平均 | routeA_only（7 个 DINOv2） | 0.7645 | 0.4810 |
| 分数级 z 平均 | B + A | 0.7775 | 0.4950 |
| 分数级 z 平均 | B + A + N | **0.7954** | 0.4997 |
| 特征级 PCA 拼接 | routeA_only | 0.7221 | <0.70 |
| 特征级 PCA 拼接 | B + A + N | 0.7478 | <0.72 |
| 单视图 | B_E65 | 0.7603 | **0.7796** |

**这是本轮最重要的发现**：B+A+N 的分数级融合把诊断 AUC 从 0.7603 抬到 **0.7954**（当前所有实验里的最高 AUC），但 W 反而从 0.7796 掉到 0.4997，S1 拒识 1.0、S2 接受 0.0。

原因：`A_DINOcorr` 与 `A_DINOtope5` 这两个视图的 Test 分数相对 Train 参考**整体下移了几个标准差**（AUC 0.497/0.454 意味着几乎无信号，但分布位置偏得极远）。等权 z 平均后，融合分数被这两个视图拖到阈值以下，所有样本都被接受 → S2 接受率反而变成 0。**一个坏视图可以摧毁整个融合。**

特征级 PCA 拼接同样失败（AUC 0.72–0.75），因为拼接后 PCA 被低质量视图的主成分占据。

### 3. 与 E139 的对比说明了一个隐藏细节

E139 在新权重下最好的点是 C_plus_cov k=32、接受率 0.96，**W = 0.7875**，高于 E141 的 0.7796。差别只在阈值构造：E139 用**合并后的 Train OOF 分位数**（单阈值），E141 先把每个任务 z 标准化再取分位数。

**逐任务 z 标准化会损害工作点**——因为各任务的跨会话偏移量不同，逐任务归一会打乱任务间的分数排序。后续应保持"单一合并阈值"。

### 4. 下一步

融合必须有界化（CDF 映射），否则无法利用 0.7954 这个 AUC。E142 正在验证这一点。
