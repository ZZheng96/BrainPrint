# E171 多尺度子窗口融合（subwin_mean N 扫描 / 多尺度拼接 / 幅值融合 / 上界分析）

E168 证明 `subwin_mean`（把 trial 切成 N 个不重叠子窗口，每个子窗口独立跑完整 E65 流程，再对 855 维特征取平均）是与 E65 不同的信息源：N=4 诊断 AUC 0.7822，且随 N 单调上升。本实验把 N 延展到 1/2/3/4/6/8/12，检验 AUC(N) 曲线；做 N=2/3/4/6 的多尺度拼接；把 E65（结构）、logbp（幅值）、subwin_mean（子段尺度归一化）在特征级与分数级融合；最后对最佳配置做 E159/E169 同口径的冻结分数上界分析，检验上界能否越过 0.80。

协议逐字沿用 E143/E168/E169：task-wise Train 标准化（用该 task 全部 Train 行）→ PCA 在 fit_rows(frac≤0.6) 上拟合 → k 原型（k=1/3/6/12）→ 5 块 Train OOF 阈值（接受率 0.80–0.96，参考点 0.90）→ LOSO 每折排除被评分身份、原型只用 fit_rows、评估块 0.6<frac≤0.8 → Test 只评分，session 只用于诊断 AUC。**Test 官方 AUC/F1 = N/A**。

## 结论

- **E65 复现**：PCA-96 k=12 诊断 AUC **0.7578** / W@.90 **0.6958**（公布 0.7578 / 0.6958），逐位复现。N=1 子窗口流程与 E65 诊断 AUC 差 +5.15e-08（AUC 0.7578），特征缓存逐位一致（见 feature_manifest 的 max_abs）。
- **AUC(N) 曲线**：N=1→12 的固定工作点（PCA-96 k=12）诊断为 1:0.7578 → 2:0.7570 → 3:0.7644 → 4:0.7736 → 6:0.7808 → 8:0.7794 → 12:0.7813；每个 N 的最优配置诊断为 1:0.7637 → 2:0.7691 → 3:0.7735 → 4:0.7822 → 6:0.7902 → 8:0.7866 → 12:0.7937。曲线非单调，峰值在 N=12（下降出现在 N=8（Δ-0.0037））。
- **最佳诊断 AUC：0.8055**（score 0.1*E65(64) + 0.4*logbp(16) + 0.5*subwin(64,N=12) k=12 [B]），相对 E167 的 0.7999 +0.0056；目标 0.835 **未达到**。
- **最佳 W**：0.6998（subwin_mean N=4 PCA-48 k=12，接受率网格内选点）；固定工作点 W@.90 最高 0.6964（E65 PCA-128 k=12）。
- **上界分析**（最佳 AUC 配置 score 0.1*E65(64) + 0.4*logbp(16) + 0.5*subwin(64,N=12) k=12 [B]）：单阈值 oracle W 0.6704；E159 同口径（LOSO 固定 @.90 = 0.6905，Test 工作点任选）**0.7489**，距 0.80 +0.0511；最松口径（LOSO 取网格最高 0.9083）0.8033，距 0.80 -0.0033。对照 E65+logbp（E159 口径 0.7704 / 最松 0.8225）、E65（0.7355 / 0.7781）。

## 判定

- **诊断 AUC 能否 > 0.7999**：是，最好 0.8055。
- **能否达到 0.835**：否。
- **同口径 W 上界能否 > 0.80**：E159 口径 否（0.7489）；最松口径 是（0.8033）。
- **AUC(N) 拐点**：最优配置曲线在 N=8（Δ-0.0037） 处下降，峰值在 N=12；固定工作点（PCA-96 k=12）曲线在 N=2（Δ-0.0008）、N=8（Δ-0.0014） 处下降。N=8 是两条曲线共同的明显拐点（N=2 那一次 -0.0008 属噪声量级），说明子窗口越细越快进入「短窗相关矩阵噪声」主导的区间；N=12 随后恢复并略高于 N=6 的水平。

## 机制解读

- **AUC(N) 与 LOSO(N) 反向**：固定 PCA-96 k=12 时，LOSO@.90 随 N 为 1:0.7936 → 2:0.8487 → 3:0.8427 → 4:0.8456 → 6:0.8274 → 8:0.7803 → 12:0.6631，而诊断 AUC 从 N=1 的 0.7578 升到 N=12 的 0.7813。子窗口越细，跨会话/跨身份的排序力越强，但「未注册 vs 已注册」的可拒识性越弱——这是 W 始终无法跟着 AUC 走的直接原因。
- **最佳 AUC 配置是「排序换校准」**：score 0.1*E65(64) + 0.4*logbp(16) + 0.5*subwin(64,N=12) k=12 [B] 诊断 AUC 0.8055，但 LOSO@.90 只有 0.6905（E65 0.7936）、W@.90 0.6691（E65 0.6958），S2 接受 0.5727。增益主要来自 logbp（幅值）+ subwin（子段尺度归一化）互补，代价是 OOF 分位阈值被推向更宽松的工作点。
- **多尺度拼接没有额外信息**：N=2/3/4/6 四块拼接最好只有 0.7822，低于单尺度 N=12 的 0.7937；特征级三路最高 0.7988、两路最高 0.7823，都没超过 E65+logbp 的 0.7999。只有**分数级**融合越过了 0.7999。
- **E169 的 ΔAUC→Δ上界 斜率不能跨信息源迁移**：最佳 AUC 配置（0.8055）的 E159 口径上界只有 0.7489，反而低于 AUC 更低的 E65+logbp（0.7704）；上界由「LOSO 拒识 × Test 工作点」共同决定，三路融合牺牲了 LOSO 一侧的需求。只有最松口径（LOSO 取 a=0.80 处的最高值）才到 0.8033 > 0.80，而该口径把 LOSO 的工作点与 Test 的工作点分别取在各自最优处，实际不可同时达到。
