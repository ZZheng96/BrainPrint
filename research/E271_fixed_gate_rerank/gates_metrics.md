# E271：固定 final 拒识，替换接受样本的身份排名

仅用 Train 的 20 名已注册者、4 种已知任务、11,304 条干净样本。列中 C 与 F1 均计入拒识损失；最后一列为关闭拒识的诊断，不是系统准确率。

|测量|n|接受数（两者相同）|同折 final C / macro-F1|E271 C / macro-F1|E271 关闭拒识准确率|
|---|---:|---:|---:|---:|---:|
|#1 冻结权重回放 Train|11304|10435|0.894728 / 0.922086|0.923036 / 0.953132|0.999646|
|#2–3 严格五块 OOF（拼接预测）|11304|10116|0.881104 / 0.918046|0.893931 / 0.933091|0.998319|
|#4 前向：前 60% 拟合，后 40% 留出|4609|3675|0.756563 / 0.813066|0.794749 / 0.861637|0.995878|

**解释。** 五折均有净提升；合计纠正 152 条、改错 7 条。OOF 身份 macro-F1 达到 0.92，C 未达到 0.95。前向净纠正 176 条，仍有 934 条被共同拒识，因此含拒识准确率未达到 0.90；若按历史闭集口径则达到。冻结回放无论开关拒识均未达 100%，且只是拟合诊断。

**同折协议。** 每个被试×任务按 trial/max(trial) 分五块，块号 min(floor(5×比例),4)。五折依次留一块，前向单独按比例 ≤0.6 / >0.6 切分。两个方法逐样本共享 final 最近欧氏距离及阈值（相等拒识）；接受后 final 用 PCA96 单原型最近邻，E271 用 final2 的 PCA256、类内白化、每身份×任务四个时间段原型的最大余弦排名，不使用 final2 的拒识阈值。按实际 final2 包推理：保存的原型已在白化空间中求均值，打分时仍按包逻辑对原型再乘白化矩阵，并非对称单次白化变体。

冻结回放直接读两个提交包现有权重；折外测量不使用这些权重。每个外折只在可见行拟合任务标准化、PCA、白化及原型；阈值取该训练集再按被试×任务顺序等分五块、逐内折重拟合 final 后得到的最近距离的 90% 分位数。故“同折 final”是同一数据上的重拟合基线，不等同历史冻结包。指标 C=正确身份数/全体已知行；macro-F1 为身份 1–20 的 F1 等权平均，拒识只计真实身份的 FN，不把 0 当第 21 个真实类。OOF 指标在全体一次性折外预测上计算，不是逐折平均。

**限制。** 未知检测 AUC：N/A（本次没有未知负例）。无法据此估计未知拒识率、真实跨会话/设备、新用户、对抗表现或官方 Test 成绩。前向仅是组内 trial 顺序代理，不是时间戳或独立会话。

**复现。** 项目根目录运行 `.\.venv\Scripts\python -B research/E271_fixed_gate_rerank/gates.py`，实测 GPU 为 NVIDIA GeForce RTX 3080 Laptop GPU。`gates.json` 含各折阈值、接受数、两种排名及闭集诊断；`gates_fits.pt` 含五套 OOF 和一套前向拟合、行索引与内折分块。输入为未标准化的逐样本 Train 特征，final 使用 E171 缓存，排名使用 E262 clean 缓存；未读 Test。
