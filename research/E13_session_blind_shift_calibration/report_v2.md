# 无 Session 依赖方案重新评估报告

日期：2026-11-08  
目的：在提交截止后，对方案进行可解释复盘；不生成新的提交文件，不把任何方案宣称为已验证的 Test 最优方案。

## 1. 结论

本次应把问题明确拆成两个互相制约的维度：

1. **已注册人员维度**：正常样本身份区分 + 对抗扰动后的身份恢复/安全拒识。
2. **未注册人员维度**：拒识未知身份，避免把未注册者误认证为 1–20。

第一次提交不能作为合法的 Session-blind 方案，因为它利用了 Session 结构：Session1 全部输出 0，而 Session2 基本不拒识。它不能作为无 Session 方案的基准，但它暴露出一个重要事实：**在已注册人员上，模型的身份区分能力可能是有效的；主要问题不是单纯“模型完全不能识别”，而是跨会话置信度和拒识规则失配。**

第三次 full_none_global 与 raw-PGD 候选的失败说明：不能只看训练内身份分类或本地攻击代理分数，必须同时检查 Test 输出是否符合已知的数据分布假设。尤其是：Test Session2 共 19,218 条，按赛题说明属于已注册人员；对这部分大量输出 0，会直接损失正常识别和对抗正确恢复，不能解释为良好的未知拒识。

当前最可靠的结论是：

- `base`/`full` 类模型在严格留被试内部验证中具有较强的已知身份区分和未知排序能力；
- raw-PGD 增强明显改善本地构造攻击下的 RA/ASafeR，但牺牲部分 clean C 和未知拒识能力，且不能直接外推到官方 Test；
- 本轮 conditional calibration 没有实质改善，只是对 base 的小幅调整；
- 目前没有一个已经被 Test 真值验证、同时证明“已注册识别 + 抗干扰 + 未注册拒识”三方面都可靠的 Session-blind 方案。

## 2. Test 分布及其对方案的硬约束

Test 总数为 **22,251**：

| 离线审计分组 | 数量 | 占比 | 解释 |
|---|---:|---:|---|
| Session1 | 3,033 | 13.63% | 不能在新方案推理中使用；仅用于事后诊断 |
| Session2 | 19,218 | 86.37% | 赛题说明明确为已注册用户；大规模输出 0 是严重误拒识风险 |

Test 任务分布：

| 任务 | 数量 |
|---|---:|
| Imagery | 11,207 |
| SSVEP | 6,760 |
| EO | 2,312 |
| EC | 1,972 |

因此，无 Session 方案在 Test 上至少应满足以下**分布一致性检查**：

- 不应出现接近全量的拒识；
- 拒识数量不应显著超过 Session1 的 3,033 条，除非有独立证据说明大量已注册样本质量异常；
- 不能把“Session2 接受率高”当成未知拒识能力，也不能把“Session2 拒识率高”当成安全；
- 不能按 Session 设置阈值，也不能读取 Session 字段；Session 只能在实验结束后做审计；
- Test AUC、F1、C、U、RA、ASafeR 均不能由无标签 Test 直接计算。

这些检查不是用 Session 参与预测，而是检查预测结果是否违反已知的 Test 构成假设。

## 3. 两维度评估框架

### 3.1 已注册人员：身份区分与抗干扰

应同时报告：

- Clean C：正常已注册样本身份正确率；
- 已知接受率：已注册样本没有被拒识的比例；
- clean macro-F1：包含拒识标签后的多分类表现；
- RA：对抗样本仍恢复原身份的比例；
- ASafeR：对抗样本预测正确或安全拒识的比例；
- A = 0.7 × RA + 0.3 × ASafeR；
- 误认证率 = 1 − ASafeR。

其中 clean C 与已知接受率必须一起看：只提高接受率、却把样本改成错误注册身份，不是改进；只输出 0 虽然可能提高 ASafeR，却会降低 RA 和 C。

### 3.2 未注册人员：拒识与误接受

应同时报告：

- U：未注册样本输出 0 的比例；
- 未知误接受率 = 1 − U；
- unknown AUC：已知/未知置信度排序能力；
- unknown F1：已知/未知二分类的拒识效果；
- 已知接受率与未知拒识率的联合曲线，而不是只报一个固定阈值点。

训练内部的未知结果来自留被试伪未知，属于方法学证据；它不是 Test 的真实 U。

## 4. 现有方案的两维度结果

### 4.1 Session-blind direct/base/conditional：严格嵌套五折 clean + unknown

协议：5 折留被试；每折的模型、分数和条件阈值只由外层训练折内部数据拟合；不读取 Test Session、Test 标签或 Test 批次统计。

| 方法 | 已知 C | 已知接受率 | clean macro-F1 | 未知 U | unknown AUC | unknown F1 | clean/unknown代理分 |
|---|---:|---:|---:|---:|---:|---:|---:|
| direct | 0.9980 | 0.9999 | 0.7115 | 0.2032 | 0.9890 | 0.3193 | 64.09 |
| base | 0.9988 | 1.0000 | 0.7223 | 0.2216 | 0.9892 | 0.3354 | 64.82 |
| conditional | 0.9987 | 0.9999 | 0.7227 | 0.2220 | 0.9892 | 0.3359 | 64.80 |

这组结果说明：

- `base` 比 `direct` 的已知身份结果略好；
- `conditional` 只带来极小的未知指标改善，代理分反而略低于 `base`；
- 该实验没有对抗样本，因此不能报告 RA、ASafeR、A；
- 不能据此宣称方案能超过第一次官方分数 69.17。

### 4.2 严格五折 raw-PGD Ridge：已注册身份抗干扰 vs 未知拒识权衡

- 该方案更像“已注册人员抗干扰增强分支”，不能单独代表完整开放集方案。

Test 没有标签，因此下面不是 C/U/AUC/F1，而是检查是否符合赛题已知分布假设。

| 候选 | 总拒识 | 拒识率 | Session1拒识率 | Session2拒识率 | 结论 |
|---|---:|---:|---:|---:|---|
| 第1次 | 3,033 | 13.63% | 100.00% | 0.00% | 利用了 Session 结构，不能作为 Session-blind 合法方案 |
| 第2次 | 3,033 | 13.63% | 100.00% | 0.00% | 同样保留 Session 依赖，不作为合法方案 |

## 6. 对后续方案的正确验收方式

以后不再用单一“代理总分”选方案，而使用二维报告：

### A. 已注册人员表

必须至少包含：

- clean C；
- 已知接受率；
- clean macro-F1；
- raw EEG 攻击下 RA、ASafeR、A；
- 不同扰动强度下的曲线或分层结果；
- 误认证率 `1-ASafeR`。

### B. 未注册人员表

必须至少包含：

- U；
- 未知误接受率 `1-U`；
- unknown AUC；
- unknown F1；
- 已知接受率—未知拒识率曲线；
- 阈值变化对两者的影响。

### C. Test 分布一致性审计

无 Session 推理后只做离线审计：

- 总拒识率；
- 不同任务拒识率；
- 按 Session1/Session2 的拒识率，仅用于验证是否违反已知构成假设；
- 输出标签计数；
- 与“Session2 主要为已注册用户”的预期是否一致。

如果候选在 Test 上出现 70%–80% 的拒识，尤其集中在 Session2，则即使训练内部 U/AUC 很高，也应判为失败候选，因为它把已注册人员误当未知人员。

## 7. 最终判断

- 第一次/第二次：已注册人员上的表现可能较好，但由于依赖 Session，不属于合法的 Session-blind 方案；不能全盘否定其身份模型价值，但不能继续作为目标方案。
- 第三次 full_none_global：clean/未知内部指标不能抵消 Test 上对 Session2 的大规模拒识，判定失败。
- raw-PGD：在本地攻击鲁棒性上有价值，但未解决跨会话分布偏移，且 Test 候选仍大量拒识 Session2，判定为“抗干扰分支证据”，不是完整方案。
- conditional calibration：严格五折结果只比 base 有微小变化，未证明能修复 Test 分布问题，暂不作为候选。

下一阶段若继续研究，目标应是：**在不读取 Session 的前提下，使用训练期可验证的跨域校准或特征学习，同时保持已注册身份恢复、抗干扰和未知拒识三者的平衡；每个候选必须同时展示两方面指标和 Test 分布一致性审计。**
