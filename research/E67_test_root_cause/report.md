# E67 Test 不可分根因诊断：信息存在但不可迁移

日期：2026-11-13。Test 只做无标签结构分析 + 离线 session 审计，未参与任何决策。

## 0. 结论先行

**Test 的 S1/S2 在协方差特征上 AUROC 0.9971（完全可分），但这个可分性来自 Test 特有的采集条件差异，不是可迁移的「注册者 vs 未注册者」规律。**

| 证据 | 数值 | 含义 |
|---|---:|---|
| 用 Test 标签训练 L2 二分类器 | **AUROC 0.9971** | 信息确实存在 |
| 用 Train 留被试训练，迁移到 Test | **AUROC 0.4911** | 不可迁移 |
| S1/S2 均值差白化后 top20 能量占比 | 0.305 | 差异非低秩，分散在大量维度 |
| S2 范数双峰 silhouette | 0.5674 | S2 内部混了两类样本 |
| S1/S2 任务分布差异 | ≤2.7 个百分点 | 不是任务污染 |

## 1. 诊断 1：逐层追踪 S1/S2 可分性

对每一层特征，用 Test 标签做 5 折交叉验证二分类（仅诊断，不可用于决策）：

| 层 | 维度 | Test AUROC(S2 vs S1) | Train AUROC(已知 vs 伪未知) |
|---|---:|---:|---:|
| L0 原始统计（范数/峰度/平坦度/高频占比） | 4 | 0.7384 | 0.6850 |
| L1 频带功率（5 频带 × 18 通道） | 90 | 0.9646 | 0.9727 |
| **L2 频带 log 协方差（5 频带 × 171）** | **855** | **0.9971** | **0.9993** |
| L3 DINOv2 图像特征（covariance5） | 768 | 0.9734 | 0.9857 |

**关键发现：**

1. **L2 的 Test AUROC 是 0.9971，远高于此前所有判据的 0.7327。** 说明 S1/S2 在 Test 上完全可分。
2. **信息随层级单调增加**：L0 0.7384 → L1 0.9646 → L2 0.9971。协方差结构承载了几乎全部分辨信息。
3. **L3（DINOv2）反而低于 L2**（0.9734 vs 0.9971），说明图像化 + 冻结骨干有信息损失，但损失不大。
4. **Train 与 Test 的 AUROC 几乎相同**（L2：0.9993 vs 0.9971），说明"可分性"本身在两侧都存在。

## 2. 诊断 2：为什么此前判据只有 0.7327

此前所有判据（E26–E32）都是「20 类身份分类器的 top1−top2 margin」或其变体。这个分数衡量的是**"像不像某个注册者"**，而不是**"是不是注册者"**。

跨会话后 margin 整体塌缩（E20I）：

| 分布 | margin 中位 |
|---|---:|
| Train 内层已知 | 10.35 |
| Test S2 | 2.20 |
| Test S1 | 2.41 |

S1 与 S2 一起塌缩，所以 margin 分不开。而 L2 直接做 S1 vs S2 二分类，AUROC 0.9971——说明协方差里存在一个**跨会话稳定的"注册者 vs 未注册者"方向**，它不等于"身份分类置信度"。

## 3. 诊断 3：合规迁移验证（决定性）

在 Train 上用「留出 4 名被试 = 未注册者，其余 16 名 = 注册者」训练二分类器，直接应用到 Test：

| 层 | 5 折 Test AUROC 均值 | 逐折数值 |
|---|---:|---|
| L1 频带功率 | 0.3869 | 0.2835 / 0.2977 / 0.2557 / 0.7312 / 0.3665 |
| L2 log 协方差 | 0.4911 | 0.5449 / 0.5127 / 0.2609 / 0.7484 / 0.3889 |

**迁移后掉到 0.49，接近随机，且逐折波动极大（0.26–0.75）。**

对比：用 Test 标签训练是 0.9971，用 Train 留被试训练迁移是 0.4911。**差距 0.51，说明 Test 的可分性依赖 Test 特有的分布信息。**

## 4. 诊断 4：Test 内部结构

### 4.1 S2 双峰确认

对 S2 的 L2 特征范数做 2-means：

| 项目 | 数值 |
|---|---:|
| 两簇中心 | 23.40 / 28.13 |
| 两簇计数 | 7,106 / 12,112 |
| silhouette | **0.5674** |

**S2 内部明确双峰**，与 E23 的发现一致（当时是 7,985 / 11,233）。说明 S2 混了两类采集条件不同的样本。

### 4.2 任务分布均衡

| 任务 | S1 占比 | S2 占比 | 差 |
|---|---:|---:|---:|
| EC | 9.63% | 8.74% | 0.89 |
| EO | 9.59% | 10.52% | 0.93 |
| Imagery | 48.10% | 50.72% | 2.62 |
| SSVEP | 32.67% | 30.02% | 2.65 |

**任务分布差异 ≤2.7 个百分点，不是任务污染。**

### 4.3 差异方向非低秩

S1/S2 均值差用 S2 协方差白化后的能量集中度：

| 主成分数 | 累计能量 |
|---|---:|
| top1 | 0.031 |
| top5 | 0.131 |
| top10 | 0.207 |
| top20 | 0.305 |

**top20 只占 30.5%**，说明差异分散在大量维度，不是单一可学的方向。

### 4.4 Test 无法按被试聚类

用 L2 特征 PCA(50) 后 KMeans：

| k | silhouette | 各簇 S2 占比 std |
|---:|---:|---:|
| 5 | 0.1731 | 0.3748 |
| 10 | 0.1583 | 0.3037 |
| 20 | 0.1562 | 0.2881 |
| 25 | 0.1629 | 0.2734 |

**silhouette 全部 ≤0.17，说明 Test 样本不按被试成簇。** 身份信息在 Test 上不是以"被试簇"的形式存在。

## 5. 根因结论

**Test 的 S1/S2 可分性（0.9971）来自 Test 特有的采集条件差异，不是可迁移的「注册者 vs 未注册者」规律。**

证据链：

1. 用 Test 标签训练 → 0.9971（信息存在）
2. 用 Train 留被试训练 → 迁移到 Test 只有 0.4911（不可迁移）
3. 差异方向非低秩（top20 仅 30.5%），不是单一可学方向
4. S2 内部双峰（7,106 / 12,112），说明 S2 混了两类采集条件
5. Test 不按被试成簇（silhouette ≤0.17），身份信息不以簇形式存在

**最可能的解释**：S1 与 S2 的差异主要来自**采集条件**（设备、阻抗、参考电极、环境噪声、被试状态），而不是"注册/未注册"这一身份属性。这类差异在 Test 内部高度可分（同一批采集），但 Train 里没有对应的采集条件变化，所以学不到、也迁移不了。

这与 E22/E23 的结论一致：相关矩阵对通道增益严格不变，但 Test 分数比仍 0.54——说明差异不在增益，而在更复杂的采集条件组合。

## 7. 后续可探索方向

尽管根因是采集条件差异，仍有两条可能提升 Test 指标的路径：

| 方向 | 思路 | 预期 |
|---|---|---|
| **A. 采集条件不变性** | 在 Train 上模拟采集条件变化（阻抗、参考、噪声），训练对这些变化不变的表示 | 若 Test 差异主要是采集条件，可能提升迁移性 |
| **B. 无监督域适应** | 用 Test 的无标签数据做逐样本归一化（不用批次统计），对齐分布 | 需严格逐样本，不能用批次统计 |

方向 A 是 E22 的延伸（E22 在特征层试过域随机化无效，但未试过"采集条件模拟"这一特定形式）。方向 B 受项目约束限制（不能用批次统计），只能做逐样本变换。
