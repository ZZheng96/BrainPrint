# team_hymn（赞美诗）决赛提交

## 方法简述

训练免参数的几何模板匹配，不含神经网络：

1. 每条 18×1200 样本切成 6 个 200 点子窗。
2. 每个子窗用 FFT 掩码分成 5 个频带（1–8 / 8–13 / 13–20 / 20–30 / 30–40 Hz）。每个频带做通道标准化，计算 18×18 相关矩阵，按 0.05 收缩，取矩阵对数（logSPD），取上三角，非对角乘 √2。每个频带内对角去均值，再整体 z-score，得到 5×171 = 855 维向量。
3. 6 个子窗向量取平均。
4. 按任务（EC / EO / Imagery / SSVEP）做 z-score，然后投影到 PCA-96。

之后用两个头分别负责「排序」和「拒识」：

- **身份排序**：对 PCA 投影做一次类内白化（Train 上的类内协方差向单位阵收缩 0.5，得到 96×96 矩阵 W），再用余弦相似度找最近原型。白化放大类间可分、抑制类内方差，因此比直接欧氏距离更稳。
- **未注册拒识**：在未白化的 PCA-96 空间计算到最近原型的欧氏距离，距离 > τ = 19.170644 时判为未注册（输出 -1）。τ 取 Train 5 块 out-of-fold 最近原型距离的 90% 分位，没有用任何测试数据或测试标签。

两件事分开做是刻意的：余弦排序在跨会话样本上的 top-1 明显更好，但余弦本身分不清未注册用户；欧氏距离幅度对未知用户更敏感。

## 输入 / 输出

- `load_model(model_dir, device)`：只读取 `model_dir/weights.pt`（可用 `weights_only=True` 加载）。请求 `cuda:0` 但 CUDA 不可用时自动退回 CPU。
- `predict_batch(artifact, x, meta)`：x 为 float32 (N, 18, 1200)，N 取 1–128。返回 numpy float32 (N, 24)。
  - 第 c 列（c=1..23）= 白化余弦相似度（越大越像）；未注册的新用户列为 -inf。
  - 第 0 列正好在「欧氏最近距离 > τ」时取得最大值，此时 argmax 为 0，主办方映射为 -1。
  - 输出不含 NaN，每行至少一个有限值。
  - 不修改 x，不读盘，不训练。
- `enroll(artifact, x, meta, labels)`：labels 取 21–23。返回更新后的 artifact，只写第 21–23 列原型，不改标准化统计量、PCA、W、τ 和 1–20 号原型。
- `meta`：如果每条 dict 含 `task` 字段（EC/EO/Imagery/SSVEP 或 Task1–4），就用对应任务的标准化。缺失或无法识别时，取四种任务空间下的最大相似度。不从文件名、路径或数据顺序推断任何信息。

## 训练数据来源和预处理

只用主办方 Train（20 人，session1，11,304 条）。任务标准化的均值/标准差、PCA 均值与基、类内白化矩阵 W、20 个身份原型均只用每个 subject×task 内前 60% 的试次（frac ≤ 0.6）拟合；τ 取 Train 内 5 块 out-of-fold 最近原型距离的 90% 分位。原始信号除 FFT 带通外不做其他预处理，通道顺序保持不变。

## 新用户注册方法

每名新用户的 20 条注册样本先提取 855 维特征，投影到 PCA-96，在每种任务的标准化空间里取均值作为原型（同时写入未白化原型，白化在推理时统一施加）。为了增加样本数，所有任务的样本合并使用。注册不改变预训练权重、W、τ 和原有 20 个原型。

## 已知限制和失败情况

- **跨时段**：初赛 Test 已注册用户（19,218 条）的 top-1 为 0.588（在接受的样本上），端到端 0.410；会话间漂移仍是主要误差来源。
- **跨设备**：只用单一设备训练，没有做设备适配。不同设备的频响差异会让部分受试者的距离整体偏移，进而被判为未注册。
- **个体差异大**：Test 上有的受试者准确率超过 0.8，也有的接近 0，错误集中到少数原型上。
- **拒识与接受的权衡**：τ 固定后两者此消彼长；初赛 Test 未注册拒识 0.723。
- **新用户**：只有 20 条注册样本，原型噪声较大。
- 依赖 `meta['task']`。缺失时退化为四种任务的最大相似度，拒识率会略降。
