# E248：最新实验的指标补测与评估

## 结论

补测后，E245–E247 的结论要分开看：

- **同会话/时间块内的身份表征，LDA 白化余弦确实明显更强**：E247 后期闭集准确率 0.982 vs 欧氏 0.892，AUC 配对差 +0.175，区间不含 0。
- **未知拒识没有显著提升**：E247 后期拒识差 +0.039，95% 区间 [−0.049, 0.123] 跨 0；提升主要来自已知分数上移，而不是未知分数下移。
- **E245“中心化把 TPR@1% 提高 0.07”是口径错误**：那个指标实为“已知误拒 1% 时的未知拒识”。真实 TPR@FAR1 只从 0.9205 升到 0.9328（+0.012）。
- **仍没有合规的 S2 改善证据**。E246 的 Test 审计仍显示两端不能同时达标；E245 的 S2=0.567 用了 Test 会话中心化，违反项目规则，不能当作合规成绩。

因此“保严格 LOSO≈0.90、同时把 S2 提到 0.60”本轮仍未解决，但问题已收窄为：**表征已够好，缺口在拒识阈值与跨会话漂移，而不在分类器排序能力。**

## 1. 缺失指标与口径更正

| 实验 | 原有指标 | 缺失/问题 | 本次补测 |
|---|---|---|---|
| E245 | AUC、旧 TPR_FAR1/5、inner 阈值下 known/unknown/F1 | `TPR_FAR1/5` 实际是 known false-rejection 1%/5% 时的未知拒识，命名错误；无误拒率统计 | 真实 TPR@FAR1/5/10、实际 FAR、对应 unknown-F1（重跑，保真校验通过） |
| E246 | AUC、known/new 接受、unknown 拒识、F1、closed_acc（单工作点） | 缺 TPR@FAR；缺 20 次重复的标准差/最小值 | TPR@FAR1/5/10（含 known/new 拆分）、mean/std/min（重跑，RNG 逐字复现） |
| E247 | AUC、F1、known/unknown、TPR@FAR1/5/10、逐折 | 缺闭集准确率（忽略拒识），缺区间估计 | `closed_set_acc`、subject 级 bootstrap CI、LDA−欧氏配对 CI（读缓存，无重跑） |

口径定义：FAR = 未知身份被接受；known false rejection = 已知被拒；`TPR@FAR` 用评估侧未知分数取分位得到工作点，只作为**排序诊断**，不是可部署阈值，也不用于选模型。

## 2. E245：中心化的增益被旧口径放大

shrink=0.01、max、20 折均值：

| 配置 | TPR@FAR1（实际 FAR 1.70%） | TPR@FAR5（5.56%） | TPR@FAR10（10.52%） | 旧口径 FRR1 / FRR5 | AUC |
|---|---:|---:|---:|---:|---:|
| 中心化 | **0.9328** | 0.9639 | 0.9770 | 0.7990 / 0.9617 | 0.9917 |
| 不中心化 | **0.9205** | 0.9568 | 0.9704 | 0.7328 / 0.9481 | 0.9889 |

- 中心化对真实 TPR@FAR1 只提升 **+0.012**，对 AUC +0.003；旧口径的 +0.067 主要来自已知分数整体上移，而非拒识能力变化。
- 每折仅约 124 条 unknown，1% 分位落在并列值上，实际 FAR 为 1.70%；5% 档同理为 5.56%。这是离散样本的固有限制，不能宣称精确卡在 1%。
- 旧口径数值与 `E245/summary.csv` 一致（max|Δ|≈1e-16），说明重跑复现无误，差异只来自口径。

## 3. E246：真实 TPR@FAR 与重复波动

honest、不中心化、20 次重复均值（括号为标准差）：

| 方法 | TPR@FAR1 | TPR@FAR5 | TPR@FAR10 | AUC | 闭集准确率 |
|---|---:|---:|---:|---:|---:|
| LDA-cos 0.01（已注册） | **0.774** (0.074) | **0.863** (0.042) | 0.901 (0.028) | 0.961 | 0.970 |
| └ 已注册者拆分 | 0.811 | 0.889 | 0.920 | | |
| └ 新用户拆分 | 0.603 | 0.745 | 0.812 | | |
| 欧氏（已注册） | 0.317 (0.075) | 0.474 (0.069) | 0.549 (0.069) | 0.777 | 0.863 |
| └ 已注册者拆分 | 0.320 | 0.471 | 0.543 | | |
| └ 新用户拆分 | 0.304 | 0.487 | 0.576 | | |

- 在同等未知误接受率下，LDA 的已注册接受率优势约 0.4，且远超重复波动；这不是单工作点假象。
- **新用户是明显短板**：FAR1 时仅 0.603，比已注册者低约 0.21。20 条注册样本的均值原型对 LDA 白化空间更敏感，需要单独关注。
- 原报告“跨会话区分能力已归零”表述过强：Test S1/S2 接受率同为 0.515 只能说明**在该单一阈值下不可分**，不能推出 AUC=0.5 或整个 ROC 失效；应改为“该工作点下无法区分”。

## 4. E247：闭集能力与拒识能力分开看

FAR10 工作点，subject 级 10000 次 bootstrap：

| 候选 | 时间块 | 闭集准确率 [95% CI] | 已知接受 | 未知拒识 [95% CI] | AUC [95% CI] |
|---|---|---|---:|---|---|
| 严格欧氏 | Middle | 0.9307 [0.9287, 0.9330] | 0.670 | 0.879 [0.832, 0.922] | 0.840 [0.809, 0.871] |
| 严格欧氏 | Late | 0.8918 [0.8885, 0.8967] | 0.587 | 0.879 [0.817, 0.931] | 0.796 [0.753, 0.838] |
| 严格 LDA-cos | Middle | 0.9917 [0.9912, 0.9922] | 0.956 | 0.914 [0.874, 0.947] | 0.984 [0.979, 0.988] |
| 严格 LDA-cos | Late | 0.9822 [0.9810, 0.9837] | 0.919 | 0.918 [0.848, 0.961] | 0.971 [0.957, 0.979] |

LDA−欧氏配对差（Late）：

| 指标 | 差值 | 95% 区间 | 判读 |
|---|---:|---|---|
| 闭集准确率 | +0.090 | [0.087, 0.093] | 明确提升 |
| known 接受率 | +0.332 | [0.326, 0.339] | 明确提升 |

- 这纠正了 E246 的解释：LDA 的优势不只是早期窗口过拟合，在更晚的时间块仍成立。
- 但它**没有**改善未知拒识；改善的是身份可分性与已知接受。两者被平均指标混在一起时容易误判。
- 闭集准确率仍非 1.0：Subject07 一类身份本身就是薄弱点（该折未知拒识仅 0.361），说明尾部身份需要单独机制。

## 5. 综合评估：还差什么

已解决：
1. 同会话与相邻/较远时间块内的身份表征与排序（LDA 稳定优于欧氏）。
2. 阈值标定的 Train-only 流程（内层留一、加权 FAR、并列保守）。

未解决：
1. **真实跨会话已知接受率**。Train 只有一个 session，E247 只能覆盖会话内时间漂移。
2. **未知拒识的尾部身份**。均值接近 0.90，但最差身份 0.361，且 LDA 相对欧氏未显著改善拒识。
3. **合规的 S2 证据**。E245 的 Test 数字依赖 Test 侧中心化；E246 的 Test 数字只是描述性审计，二者都不能用于选模。

在现有数据条件下，继续调全局阈值或换评分函数的边际收益很低；更有信息量的是“按身份尾部”和“只用 Train 时间块估计漂移方向”的约束方法，且必须预先固定协议。
