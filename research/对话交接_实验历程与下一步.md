## 2. 第一次提交的生成链路

主要流程：

## 3. Test 分布分析

数据量：

| 数据 | 数量 |
|---|---:|
| Train Session1 | 11,304 |
| Test Session1 | 3,033 |
| Test Session2 | 19,218 |
| Test 总计 | 22,251 |

Test 任务比例与 Train 基本接近：

| 任务 | Train | Test |
|---|---:|---:|
| EC | 9.48% | 8.86% |
| EO | 9.47% | 10.39% |
| Imagery | 48.69% | 50.37% |
| SSVEP | 32.36% | 30.38% |

信号幅度分布明显偏移：

| 数据 | raw_std 均值 | 中位数 | 95% 分位 |
|---|---:|---:|---:|
| Train | 12.20 | 10.66 | 23.35 |
| Test 总体 | 15.37 | 12.91 | 30.76 |
| Test Session2 | 14.17 | 12.51 | 27.61 |
| Test Session1 | 22.94 | 15.18 | 81.78 |

结论：Test 任务采样比例没有严重变化，主要变化是跨 Session、幅度、采集状态和长尾信号条件。Test 不是 Train 的简单同分布复制。

但“Session1 全部是未注册者、Session2 全部是注册者”只有结构性证据，不是官方标签证明。当前规则可能抓住了赛题数据组织，但方法学上不可迁移到没有 Session 字段的现场。

## 4. 既有内部基线结论

### 4.1 同 Session 闭集验证过于乐观

此前任务特异模型在 Train Session1 内部多个折外协议达到接近/甚至 100% 的闭集准确率，但这些结果不能代表 Test：

- 没有跨 Session；
- 没有真实未知者标签；
- 没有对抗样本；
- 规则、权重和门控曾根据内部错误调整；
- 不能证明跨 Session 泛化或开放集拒识。

### 4.2 纯 EEG 开集拒识

研究目录：[research/open_set_improvement](file:///d:/WORK/BCIC2026/BrainPrint/research/open_set_improvement/report.md)

嵌套留被试结果：

- full：C=0.9361，U=0.9866，unknown AUROC=0.9921，unknown-F1=0.9678；

## 7. 官方分数情景换算（修订版）

第一次提交提供了唯一真实锚点：官方 `69.17`。本地 direct 的 untargeted SNR20 公式分为 `46.9996`，但它不是第一次正式提交在官方 Test 上的完整复算，因此不能用单个比例系数拟合出真实官方校准。

上一版将 `A` 乘以 `3.00792`，使 robust 候选全部落入约 94–95 分的饱和区，已删除其作为排序依据的意义。现在改用“部分迁移”情景模型：

```text
S_base = 69.17
R_i = S_local_i / S_local_direct
S_scenario(i, lambda) = S_base * R_i^lambda
lambda ∈ {0.15, 0.25, 0.35}
```

`lambda=0.25` 是中性情景，表示本地人工攻击分数相对增益只有四分之一迁移到官方 Test；`0.15–0.35` 只是敏感性范围，不是统计置信区间，也不是官方预测。

| 实验 | 攻击 | 本地公式分 | λ=0.15 | λ=0.25 | λ=0.35 |
|---|---|---:|---:|---:|---:|
| direct | untargeted SNR20 | 47.00 | 69.17 | 69.17 | 69.17 |
| raw robust 首轮 1:1 | untargeted SNR20 | 79.47 | 74.84 | 78.88 | 83.13 |
| raw robust 混合 targeted 1:1 | untargeted SNR20 | 79.64 | 74.86 | 78.97 | 83.24 |
| raw robust 混合 targeted 1:1 | targeted SNR20 | 80.82 | 75.03 | 79.21 | 83.62 |
| raw robust 2:1 | untargeted SNR20 | 73.06 | 73.90 | 77.24 | 80.72 |
| raw robust 2:1 | targeted SNR20 | 73.61 | 73.98 | 77.38 | 80.93 |

因此，当前 raw robust 1:1 候选的中性情景值约 `79` 分，范围约 `75–83`；2:1 候选约 `77` 分，范围约 `74–81`。这些数值只用于比较“本地增益可能有多少迁移”，不能替代 Test 官方成绩；正式决策仍以第一次提交 `69.17` 和 Test-like 跨 Session 验证为准。

## 8. 当前最重要的下一步方向

### 优先级 1：先模拟 Test 的跨 Session/幅度漂移

不要继续优先增加 PGD。Test raw_std 已显著高于 Train，应该在 Train 内构造可控的跨 Session 风格验证：

1. 训练部分使用较早/正常幅度 Trial；
2. 验证部分使用后段 Trial 或高幅度 Trial；
3. 对验证数据做 amplitude scaling、通道增益扰动、低频/高频噪声扰动；
4. 评估 C、U、unknown AUC/F1 和代理官方分；
5. 使用嵌套内层选择参数，不用 outer 结果调参。

建议新目录：`research/cross_session_shift/`，对应代码：`src/cross_session_shift/`，测试：`test/test_cross_session_shift.py`。

### 优先级 2：建立 Test-like proxy，而不是 PGD-only proxy

重点比较：

- Train 内部正常验证；
- 高幅度子集验证；
- 后 20% Trial 前推；
- 幅度拉伸后验证；
- 组合扰动验证。

保留第一次提交的生成链路作为 baseline，同时对比：

- 不使用 Session→0 的纯 EEG 拒识；
- 使用 Session-like 校准但不依赖 Test session 元数据；
- 低风险的特征标准化/幅度不变特征。

### 优先级 3：hard-example / 风险加权，而不是全局降权

如果继续 raw robust：

- 保持 targeted 比例约 2/8，不再增加；
- 只提高 hard untargeted 样本权重；
- 选取攻击后 margin 大幅下降或身份改变的样本；
- 容易样本降低权重，避免 unknown AUC/F1 损失；
- 重新跑固定五折三攻击。

不要：

- 继续统一增加 PGD 样本数量；
- 继续简单全局 clean:adv 降权；
- 使用 outer 测试结果选样本/权重；
- 只追求 ASafeR，不看 RA、unknown AUC/F1 和 C/U。

### 优先级 4：提交策略

- 第一次提交仍是保护版本；
- 新候选必须先在 Test-like proxy 上明确优于 baseline；
- 不通过冻结门槛的候选不直接提交；
- 若必须尝试下一次官方提交，优先选择小改动、可解释、低风险版本，而不是未通过验收的 raw robust 版本。
