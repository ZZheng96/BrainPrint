# E229 原始信号鲁棒编码器：LOSO 0.90 约束下最大化 Test S2

> **结论**：**未达成改进**：原始信号重训在现有单会话训练数据下无增益。最好的原始信号候选 `raw_ce_contrast` 的 Test S2 0.2885（基线 0.3043，-0.0158），分离 AUC 0.4254（基线 0.7918）。

本轮验证的是唯一尚未证伪的实质路线：在每个 strict outer LOSO fold 内，**只用 enrolled 身份的 fit 行从头训练**一个轻量原始波形编码器，held 身份完全不参与训练、早停、原型与标定。在 LOSO 未知拒识 = 0.90 的硬约束下比较 Test S2，并与 E228 冻结基线（0.3043 / 0.9637 / 0.7918）逐项对照。

## 1. 口径与不变项

- strict 20 折 subject-LOSO；每折训练集 = 非 held 身份且 trial fraction ≤ 0.6 的行；评估窗口 (0.6, 0.8]，held 身份只出现在窗口里。20 折全部跑完，未减少折数。
- 输入 = 原始 (18, 1200) @300Hz；forward 内做逐 trial 逐通道去均值 + 全 trial RMS 归一化（可微、无跨样本统计）。
- 编码器 3 个 1D 卷积块 18→32→64→64（k=9, s=2, GroupNorm+ELU）→ 全局平均池化 → Linear→64 维 L2 归一化 embedding，参数量 66260（<200k）。
- 训练目标 = CE（仅 enrolled 身份）+ 0.5 × 监督对比（同 subject 不同 trial 为正对，温度 0.1），15 epoch 固定、无早停（held 身份不可用于早停）。
- 打分 = 同 task 内到 (task, identity) 原型的最近欧氏距离（embedding 已 L2 归一化），高分 = known，`score < tau` 判未知。
- 标定 = `tau(A) = fit 行 inner-OOF known 分数的 (1−A) 分位`；在 Train 侧二分 A，使 pooled micro LOSO 未知拒识命中 0.90，取仍然 ≥0.90 的最松 A；与 E228 同一规则。
- 官方 Test AUC/F1 = **N/A**（Test 无身份标签）。

### 1.1 inner-OOF 的实现与一处偏差

tau 需要编码器**没见过**的 known 分数。每折额外训练一个 OOF 编码器：只用 fit 行中 block ∈ {0,1}（fraction < 0.4）训练，去打分 fit 行中 block = 2（0.4 < fraction ≤ 0.6）的 known 分数。deploy/LOSO 编码器则用全部 fit 行训练。

E228 把 inner 的 3 个 block 全部平均（每折 3 次表征重拟合）；这里只取最新的一块，原因是 20 折 × 3 个训练制度 × 2 个编码器的预算。该偏差的后果是每折 tau 的分位数由约 2200 条 OOF 分数估计（E228 约 6700 条），A* 的随机性略大；但 0.90 的硬约束仍由 20 折 真实 held 分数二分保证，不受此影响。**这是一处需要记录的口径偏差。**

## 5. 判定

- 没有任何原始信号候选同时满足"LOSO ∈ [0.90,0.91] 且 S2 > 0.3043 且 sepAUC > 0.7918"。
- **结论：原始信号重训在现有单会话训练数据下无增益。** 证据见第 2~4 节：（a）三个训练制度的 S2 都低于基线；（b）窗口 known 准确率明显低于 fit 上的原型训练准确率，说明编码器学到的身份特征在只更换 trial 的窗口里已经衰减；（c）漂移增强与对抗训练各自对 S2 的贡献见第 3 节，方向与幅度即机制验证；（d）训练曲线显示 15 epoch 内 loss 正常下降，未出现欠拟合，因此不是训练不充分。
- 另一条独立证据：raw 候选的 Test S1 拒识只有 0.5618（基线 0.9637），sepAUC 0.4254（基线 0.7918，且低于 0.5）—— 该编码器的分数在 S1/S2 之间几乎不可分，方向甚至与基线相反。LOSO 被钉死在 0.90 时，任何阈值的合法移动都无法把 S2 抬到基线之上。
- 按"只允许一轮追加"的规则，本轮不再追加第二轮（增强强度/k 已在第 3/3.1 节覆盖）。

## 7. 限制与偏倚

- 官方 Test AUC/F1 = **N/A**：Test 没有身份标签，只能报告会话分层行为指标（S1 拒识 / S2 接受 / 分离 AUC），它们不等同官方未知检测指标。
- Test 自 E65 起被反复查看；本轮候选定义、增强与对抗参数在运行前写死，标定只用 Train 行，但最终"在合格候选里挑 S2 最高"这一步读到了 Test，属于评估偏倚，0.3043 与任何新数字都不应当作无偏泛化估计。
- 训练数据只有 session1：S1→S2 的真实漂移无法用于训练，只能靠合成增强近似，这是本路线最根本的上限。
- inner-OOF 只用了最新一个 inner block（见 1.1），不是 E228 的三块平均。
- 运行：`.venv\Scripts\python.exe research/E229_raw_robust_encoder/run_e229.py`（CUDA）；折级训练合计 24.1 min，Test 重建约 1–2 min；本次缓存复用运行 0.1 min。
