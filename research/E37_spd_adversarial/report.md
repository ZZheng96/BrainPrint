# E37 残差 SPD + ARPL 对抗鲁棒（未完成，负结果归档）

## 结论（先说清楚）

**E37 不构成任何通过门禁的证据，外层与 Test 均为 N/A。** 按 config 预注册的规则，三变体未产出可评估的完整内层；SMOKE 阶段的诊断显示：在 SNR20dB 原始波形 PGD 攻击下，本方案的对抗训练无法在预算内把 RA 拉起来，因此停止扩展，转而做 E40。

## 做了什么

- 冻结 E36 五频带 logSPD → detrend+zband（855 维）与 fit 折 WCCN 白化。
- 残差头 855→256→855（GELU，末层零初始化），零残差时与 E36 WCCN 余弦模型严格等价。
- 可训练原型（初值为同一 fit 折的 WCCN 原型）+ 可训练半径，ARPL 互反点分类损失 + 开空间 MarginRanking 损失。
- 三变体：`clean_arpl` / `untargeted_at_arpl` / `mixed_targeted_untargeted_at_arpl`。
- 对抗训练改为**原始波形空间** PGD（半径与评估一致：`signal_norm/10^(SNR/20)`），端到端穿过 logSPD/zband/白化/残差。

## 消融与失败模式（SMOKE，非证据）

| 现象 | 诊断 | 处理 |
| --- | --- | --- |
| 训练后 C=0.0000，argmax 全错 | 互反点 logits 与余弦评分 argmax 不一致（squared 项在去均值前主导） | 交叉熵改用余弦 logits（`classification_logits`），开空间损失仍用互反点距离 |
| 原型漂移，零残差等价性被破坏 | 可训练原型无约束 | 加入原型锚定项（权重 1.0） |
| 单侧开空间损失让半径塌缩、嵌入被推离所有原型 | 只约束真实类距离 | 补上“最近其他类距离”的对侧 MarginRanking |

修复后单折 SMOKE：clean 准确率 0.99–1.00，代理 C 0.95 左右；但**攻击后**：

| 攻击 | 未防御（E36C 同类） | E37 单折 SMOKE |
| --- | --- | --- |
| FGSM SNR30 | acc≈0.30 | 0.39 |
| PGD SNR20 非目标 | acc≈0.09 | 0.03 |
| PGD SNR20 目标 | acc≈0.10（目标命中 0.90） | 0.18（目标命中 0.82） |

即：对抗训练只对单步 FGSM 有边际改善，对 20 步 PGD/SNR20 无实质提升。

## 一个重要负结论（方法论）

为压过 PGD，我逐次放大分类 logits 尺度（d×1 到 d×1e29 共 20 余档）试图增强梯度。结果**攻击成功率和最终指标在 4 位小数上完全不变**：L2 归一化 PGD 每一步都会对梯度做方向归一化与半径投影，logit 的整体缩放会同时缩放梯度并被归一化抵消，因此**logit 温度/尺度不是对抗训练的有效自由度**。这条探索已终止，相关临时方法已从 `run_e37.py` 清除。

## 判定

- 内层六攻击未跑满，外层未运行，Test 未读取。
- 按项目约束，负结果保留归档；鲁棒性主线不再沿“特征空间对抗训练 + ARPL”推进。
- 后续改为 E40：不重训身份模型，用**双门控攻击感知拒识**直接提升 ASafeR（官方 Score 中权重 0.35 的 A 项），见 `research/E40_attack_rejection/report.md`。
