## 1. 表征训练（严格 Train-only）

- 输入：原始 18×1200 @300Hz，per-trial 去通道均值 + 全局 RMS 归一化（固定规则、无 batch 统计）。
- Encoder：4 层 stride-2 Conv1d [32, 64, 96, 128]（kernel [7, 7, 5, 5]）+ BN + ELU + 全局 mean/max 池化 + Linear→128，参数量 144,064（预算 <1M），输出 L2 归一化。
- 目标：Supervised Contrastive（temperature 0.1）。每个 batch 固定单任务、20 个身份 × 2 个不同时间块的 trial × 2 个增强视图；batch 内负样本即同任务异身份 hard negative。
- 增强：时间平移 ±50、每通道增益 0.8–1.2、通道 dropout 0.1、2–3 段 ×100 点时间遮挡、加性高斯噪声 SNR 20–30dB（增强后重新归一化）。
- 划分：每 (subject,task) 内 frac≤0.6 拟合（6695 条），0.6<frac≤0.8 仅用于早停（2301 条），>0.8 不参与训练。
- 早停指标：验证块上分任务的留半最近质心身份准确率；最佳 epoch 33，验证准确率 0.9360（{'EC': 0.872, 'EO': 0.877, 'Imagery': 0.945, 'SSVEP': 0.959}），训练耗时 63s。
- 权重：`model_contrastive.pt`；encoder 配置：`encoder_config.json`；embedding 缓存：`train_emb.npy` / `test_emb.npy`。

## 2. 评估协议（完全照搬 E143）

task-wise Train 标准化 → PCA(32/64/96，仅 fit_rows 拟合) → k=1/3/6/12 原型（每 task×identity，kmeans 种子与 E143 一致）→ 最近原型负距离作为分数 → 五块 Train OOF 分位数阈值 → LOSO 每折排除被评分身份且原型只用 fit_rows、评估块 0.6<frac≤0.8 → Test 只评分。Test 诊断 AUC = roc_auc(S1 为负类, S2 为正类)。

不同任务的原型几何不同，跨任务分数水平不可直接比较；因此任务内 AUC 比 pooled AUC 更能反映“注册身份的跨 session trial 是否更靠近原型”。E161 在四个任务上全部低于 0.5，说明反转不是某一个任务造成的，而是全局的 session 主导。

**方向反转（诊断 AUC 0.4301 < 0.5）**：S2（注册身份、session2）的分数中位比 S1（未注册身份、session1）还低 0.217 sd。也就是说，原型来自 session1，同 session 的陌生 trial 反而比跨 session 的本 trial 更靠近原型——**session 偏移在距离上压倒了身份信号**。训练是收敛的（早停验证准确率 0.9360、Train OOF AUC 0.9814），失败点不是不收敛，而是 embedding 的跨会话身份可分性不但没提升，排序还比 E65 特征更差。Train OOF 与 Test 诊断 AUC 相差 +0.5513，说明端到端 CNN 学到的主要是同会话共享成分（与 E154/E156 同一模式，且这次在原始信号上更极端）。另外 embedding 有效秩极低：前 7 个主成分已解释 99.99% 方差，PCA-32/64/96 结果因此几乎相同，说明对比学习把 128 维压成了约 7 维、丢掉了可能的身份细节（可作为下一步用更弱的池化/更小温度/更多维投影的改进点）。
