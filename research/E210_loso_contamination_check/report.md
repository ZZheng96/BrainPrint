# E210 历史“LOSO 与 S2 双高”复核报告

## 问题
E137 / E139 / E141 的结果文件中确实存在同一工作点同时满足 LOSO ≥0.92 与 S2 ≥0.75 的记录（如 E139 `A_E65 / PCA96 / k=32 / 接受率0.96`：LOSO 0.9798，S2 0.7913；`k=32 / 接受率0.98`：LOSO 0.9336，S2 0.8878）。本实验判断这些数值是否可复现。

## 根因
三个脚本的 LOSO 段完全同构（E139 第 131–147 行、E141 第 105–117 行、E137 第 174–187 行）：

```python
pm = np.isin(subjects, enrolled)          # 19 个身份的全部行
ki = pm & (f > .6) & (f <= .8)            # 用于取阈值的 known 行
p2, k2 = build_prototypes(trp, subjects, tasks, pm, enrolled, k)   # 原型也来自 pm
s = neg_d1(trp, p2, k2, tasks)
rejs = np.mean(u < np.quantile(kn, 1 - a))  # kn = s[ki] 是在原型内的样本
```

`ki` 这些行既参与了原型构建，又被当作 known 分布来取 `1-a` 分位数。known 分数因此是**样本内**的，分布被压得过窄，阈值偏小，留出身份更容易被判为未知 → LOSO 被系统性高估。

## 复核
用 E139 的最优配置（E65 logSPD 855 → 任务标准化 → PCA96，Test 侧阈值与部署原型完全不变），只改 LOSO 的 known 侧：

## 结论
1. 历史“双高”不是真实可达的工作点，而是 LOSO 口径污染造成的虚高，幅度 0.18–0.54。
2. 干净口径下 E139 的最好权衡是 `k=12, a=0.90`：S1 0.7910 / S2 0.5926 / LOSO 0.6885，或 `k=1, a=0.96`：S1 0.3159 / S2 0.9011 / LOSO 0.1917。
3. 这与本轮 E209（subwin6）得到的权衡曲线一致：**S2 高时 LOSO 低，LOSO 高时 S2 低**，S1 随之摆动。
4. E175 用干净口径重建 159 个历史候选，其中满足 LOSO≥0.88 且 S2≥0.70 的候选数为 **0**，最高干净综合分 W=0.6394。

AUC/F1：本实验沿用 E139 的诊断 AUC（E65/PCA96 约 0.756–0.760）；Test 无真实标签，F1 记 N/A。
