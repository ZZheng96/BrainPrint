## 决策规则（三段）

```
dr = logSPD WCCN distance_ratio
dr >= tau_high  -> logSPD 身份      （clean 区域，logSPD direct=1.0）
tau_low <= dr < tau_high -> CNN 身份（受扰动区域，CNN 更鲁棒）
dr < tau_low    -> 输出 0           （未知身份）
```

`tau_low` = 该 run clean known dr 的 q0.02，`tau_high` = q0.05；**只用 clean known**，
不使用 pseudo-unknown 或 Test 分位。

## 设计要点

- CNN 的 clean 直接准确率上限约 0.965（E48 三组容量配置均未突破），单靠 CNN 时 C≤0.92。
- logSPD 在 clean 上 direct=1.0，但被扰动后几乎失效（RA 0.06）。
- 按 `distance_ratio` 分段正好把两者的适用域分开，因此 C 与 RA 同时提升。

## 证据边界

Train session1 内层嵌套、伪未知被试、连续文件块代理；攻击为对 CNN 的白盒 PGD20
（E44 已证迁移不弱于白盒）；阈值只用 clean known。无外层选择、未读取 Test、
无跨会话结论。clean 直接准确率仍受 CNN 限制（0.96 量级），但本例由 logSPD 承担 clean 身份。
