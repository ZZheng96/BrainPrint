# E166 多频带时频图 + Train 内监督对比学习

填补 E149（冻结图像骨干）和 E161（原始波形端到端对比）之间的空隙：从原始 18×1200 EEG 用**完全确定、无统计量**的规则生成多频带时频图，再在 **Train session1** 上训练一个小 CNN 做身份监督对比学习，最后走**逐字沿用**的 E143 开放集协议。Test 只被评分，session 只用于诊断 AUC。

## 结论与当前 AUC / F1

- **Test 诊断 AUC = 0.7358**（E143/E65 基准 0.7578，差 -0.0220）
- **W = 0.6534**（基准 0.6958，差 -0.0424），工作点 PCA-32 / k=6 / 接受率 0.90
- Train OOF AUC = 0.8204，Train OOF 宏 F1 = 0.7662（身份准确率 0.7703）
- LOSO 拒识 = 0.4759，Test S1 拒识 = 0.5912，Test S2 接受 = 0.7733
- 有效秩：task 标准化后 Train 拟合块 embedding 解释 95% 方差需 **8 维**（99% 需 11 维，共 256 维）
- Test 官方 AUC/F1 = **N/A**（Test 无公开标签）

## 判定

**核心问题的答案：不能。** Test 诊断 AUC = 0.7358，低于 E143 基准 0.7578（差 -0.0220）。

**“时频图 + Train 内对比学习”路线失败。**

| 指标 | E166 时频图 | E65 对照（同协议） | E143 基准 |
|---|---:|---:|---:|
| Test 诊断 AUC | 0.7358 | 0.7578 | 0.7578 |
| W | 0.6534 | 0.6958 | 0.6958 |
| Train OOF AUC | 0.8204 | 0.9302 | – |
| Train OOF 宏 F1 | 0.7662 | 0.9895 | – |
| LOSO 拒识 | 0.4759 | 0.7936 | 0.7936 |
| Test S1 拒识 | 0.5912 | 0.7979 | 0.7979 |
| Test S2 接受 | 0.7733 | 0.5960 | 0.5960 |

证据：

1. **学到的身份信息量本就不足**：同一协议下 E166 的 Train OOF 宏 F1 只有 0.7662、OOF AUC 0.8204，远低于 E65 correlation-logSPD 的 0.9895 / 0.9302。时频图在 fit 块上就已经丢掉了大部分身份判别信息。
2. **表征严重降维坍缩**：256 维输出解释 95% 方差只需 **8 维**、99% 只需 11 维，第 1 主成分独占 38%。训练中 embedding 范数稳定在 ~0.86，所以不是 E161 那种范数坍缩，而是所有 trial 被压进一个极低维子空间——**去掉 L2 归一化并没有阻止坍缩**。
3. **分数分布被 session 偏移主导**：S1 中位分数 -1.77 vs S2 -0.43，跨 session 偏移（约 1.35 个标准化单位）远大于身份间距，于是 LOSO 拒识 0.4759 与 S1 拒识 0.5912 同时崩掉，S2 接受 0.7733 只是阈值被压低后的虚高。
4. 逐任务诊断 AUC 0.710–0.780，没有任何任务接近 0.93（E159 已证明 W>0.80 所需）。

W 也未超过基准 0.6958（0.6534 vs 0.6958）。

## 时频图表征

- STFT n_fft=128、hop=32、Hann 窗、center=False → 65 个频点 × 34 帧
- 6 个频带（1-4/4-8/8-13/13-20/20-30/30-40 Hz）→ 合并成 3 个图像通道（1-8 / 8-20 / 20-40 Hz），每通道是 18 通道 × 时间帧的 log 功率矩阵，双线性 resize 到 64×64
- 逐图标准化（减均值除标准差），逐样本操作，Train/Test 同一规则，无任何数据集统计量
- 缓存：`train_tfmap.npy` (11304×3×64×64, float16) / `test_tfmap.npy` (22251×3×64×64, float16)

## 训练（严格 Train-only）

- 编码器：3 层 conv(32/64/128, 3×3, maxpool2) + BN + ELU + 全局 mean/max 池化 → 256 维线性投影，参数 159,264（预算 1,000,000）
- 输出**不做 L2 归一化**（E161 教训：会导致表征坍缩）；训练日志里记录了 embedding 范数
- 损失：supervised contrastive，温度 0.1；正样本 = 同 subject 同 task 的不同 trial/视图，负样本 = batch 内其他 subject
- 增强：时间轴随机遮挡 2 段×8 列、频率轴遮挡 4 行、高斯噪声 σ=0.05；禁止水平翻转（EEG 时间不可逆）
- 划分：frac≤0.6 为 fit，0.6<frac≤0.8 仅用于早停；epoch 上限 40、patience 5；最佳 epoch = 39，验证准确率 = 0.8046（未触发早停，跑满 epoch 上限）
- 模型：`model_tfmap_ssl.pt`；训练用时 35s
