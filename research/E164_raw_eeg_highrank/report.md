# E164 原始 EEG 高秩编码器（去 BN + 弱化池化）

日期：2026-11-15；设备：NVIDIA GeForce RTX 3080 Laptop GPU；只用 Train session1 训练，Test 只被评分，Session 仅在评分后用于诊断 AUC。

## 结论

**有效秩假说被否定**：最优变体 `C_multiscale4_gn512` 的诊断 AUC 0.5044 仍低于 E65 的 0.7578（-0.2534）。**原始 EEG 端到端在当前数据下不如手工 E65 特征**；去 BN + 弱池化只把 512 维变体的 99% 有效秩从 E162 的 10/256 抬到 26–47/512（95% 有效秩 8–10 对 E162 的 8），诊断 AUC 反而从 0.6756 掉到 0.3548–0.5044，说明低秩不是跨会话泛化的主瓶颈。最优 W 0.6540（E65 0.6958）。

## 1. 相对 E162 的预注册改动

- BatchNorm removed everywhere (batch statistics are a cross-domain instability); replaced by GroupNorm(8 groups, affine, per-sample statistics) in every conv block
- pooling strength reduced in three ways: variant A = learnable-query attention pooling (4 queries x 128 ch = 512), variant B = global mean||max pooling with no final linear compression (256 ch -> 512), variant C = multi-scale time pooling (4 segments x 128 ch = 512)
- variant D = E162 encoder structure kept (mean||max -> Linear) but BN -> GroupNorm, used only to isolate the BN-removal effect from the pooling change
- lambda_VICReg fixed at 0.0 (E162 showed it is harmful) and temperature fixed at 0.1; no further sweep
- eval PCA grid extended to 32/64/128/256 (E162 used 32/64/96) because the embeddings are now 512-d

保持不变的项（E162 已证明有效，未再调参）：

- no L2 normalisation of the output embedding
- dual disjoint perturbation families (A = channel gain + electrode drift, B = band amplitude reweighting + additive noise) of the same trial must map to the same embedding (MSE invariance weight 1.0)
- identical training protocol: SupCon over within-task identity labels, cosine LR with warmup, early stopping on the 0.6<frac<=0.8 Train block, fit rows = frac<=0.6, >0.8 never used
- identical open-set evaluation protocol (task standardisation -> PCA on fit rows -> k prototypes -> 5-block Train OOF threshold -> LOSO excluding the scored identity -> Test scoring only)

## 3. 训练协议（严格 Train-only，沿用 E162）

- 输入：原始 18×1200 @300Hz，per-trial 去通道均值 + 全局 RMS 归一化（固定规则、无 batch 统计）。
- 损失：SupCon（温度 0.10）+ 1.0·MSE(视图A, 视图B)；λ_VICReg 固定 0，无 L2 归一化。
- 跨会话模拟正样本：同一 trial 的两组互斥强扰动——视图 A 通道增益 U(0.5,1.5) + 电极慢漂移；视图 B 6 个频带 ±6dB 幅值重加权 + 加性噪声 SNR 10–20dB；共享 ±50 点时间平移。
- 划分：每 (subject,task) 内 frac≤0.6 拟合（6695 条），0.6<frac≤0.8 仅用于早停（2301 条），>0.8 不参与训练。
- 早停：验证块留半最近质心身份准确率（余弦）；最优 epoch 35、准确率 0.8738，训练耗时 64s。

## 4. 评估协议（与 E143/E162 完全一致）

task-wise Train 标准化 → PCA(32/64/128/256，仅 fit_rows 拟合) → k=1/3/6/12 原型（每 task×identity，kmeans 种子与 E143 一致）→ 最近原型负距离为分数 → 五块 Train OOF 分位数阈值 → LOSO 每折排除被评分身份、原型只用 fit_rows、评估块 0.6<frac≤0.8 → Test 只评分。Test 诊断 AUC = roc_auc(S1 为负类, S2 为正类)。

## 9. 判定与证据边界

- 判定：**未通过（低于手工 E65 特征）**。核心问题“有效秩提高后诊断 AUC 能否超过 0.7578”的答案：**不能**（最优 0.5044，E65 0.7578）。
- 预注册变体 4 个（A/B/C/D），每个只有单一配置（温度 0.1、λ_VICReg=0），总配置数 4 ≤ 6。
- E159 结论：E143 分数上即使把阈值扫满，最优 W 也只有 0.6971（乐观上界 0.7352），要 W>0.80 需诊断 AUC≈0.93。
- 所有阈值、PCA、原型全部来自 Train session1；Test 仅评分。接受率网格的工作点选择沿用 E143（使用 Test 的 S1/S2 分布），该 W 属乐观读数，同时给出固定接受率 0.90 的对照。
- Train 内 unknown 是留身份伪未知（不是官方 5 名新被试）；跨 Session 只有 Test 侧诊断 AUC 可反映。
- 有效秩只说明表征的线性维度，不等于跨会话可迁移性；本实验只检验“低秩是否为瓶颈”这一单因素。
- 副产品：变体 D 与 E162 的唯一差别是 BN→GroupNorm/8，诊断 AUC 从 E162 的 0.6756 降到 0.4081，说明 BatchNorm 在这条管线上对跨会话排序是有帮助的（与预注册假设相反），“去 BN”本身即是本次下降的部分原因。
- **项目 Test 官方 AUC/F1 = N/A（无真实标签）**。
