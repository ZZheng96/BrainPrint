# 纯 EEG 脑纹识别：下一步改进与试验方案

日期：2026-11-07
一句话概括：**脑纹的闭集身份分类已经很强，真正卡住的是跨会话、扰动和未知人员条件下的开集校准。**

1. **阈值迁移失效是首要问题**  
   训练集内确定的拒识阈值不适合测试分布：无对齐候选拒识 81.77%，目标域对齐后反而拒识 94.26%，会导致大量注册用户无法被正确识别。

2. **内部高分不代表测试高分**  
   当前最佳内部结果 AUROC=0.9960、macro-F1=0.9653、U=0.9951，但全部来自 Train Session1 的“伪未知”验证，没有真实测试标签，不能据此判断能否达到 62 分。

3. **真实未注册人员识别尚未解决**  
   内部留出被试能被拒识，不等于真实跨 Session 的 5 名未注册者也能被拒识。目前缺少目标分布下的有效校准证据。

4. **目标域对齐只解决了部分问题**  
   z-score 改善了内部指标，却没有修复测试阈值，说明测试偏移不只是简单的特征均值和方差变化；该方法还依赖整批数据和 task 信息。

5. **对抗鲁棒性仍不足**  
   特征空间较强扰动下，RA 曾从约 0.9228 降至约 0.5120。部分有效防御使用了理想配对等 oracle 信息，尚不能直接部署。

6. **旧元数据规则不可继续依赖**  
   `Session1 → 0` 不是基于 EEG 的识别，无法证明真实未知拒识能力，也不能迁移到没有 Session 字段的决赛场景。

**当前最需要的不是继续提高闭集分类准确率，而是获得独立、接近目标分布的有标签校准数据，或设计不依赖固定源域分数阈值的逐 Trial 开集识别方法。** 现有正式提交应保持不动。

## 1. 约束与目标

本方案只使用 EEG 信号及由 EEG 计算的特征完成身份识别、未知拒识和对抗防御。**Session 信息只能用于冻结预测后的分层验证，不能作为先验进入模型。**

明确禁止：

- `session1 → 0` 或其他 Session 硬规则；
- 按 Session 分别训练、对齐、校准阈值或选择模型；
- 根据 Session 生成身份/未知伪标签；
- 只在某个 Session 内建立配对、聚类、图融合或类别均衡；
- 根据测试 Session 分层结果回头调整预测。

允许：按 task 使用已有生理范式路由，以及在不使用身份标签和 Session 的前提下，对完整目标批次做无监督 EEG 特征适配。若要支持逐 Trial 在线部署，批量适配必须另行通过单样本实验验证，不能直接假定可迁移。

因此，现有使用 `session1 → 0`、Session2 对齐或 Session2 图融合的候选只保留为历史诊断，**不属于本方案的合规模型或基线**；已有正式文件暂不修改。

## 2. 当前基础与真正瓶颈

当前纯 EEG 基线为分频带对数协方差 + Ridge：

| 配置 | C | U | AUROC（外折宏平均） | macro-F1 | unknown-F1 | detection-macro-F1 |
|---|---:|---:|---:|---:|---:|---:|
| base_none | 0.9321 | 0.9901 | 0.9935 | 0.9556 | 0.9680 | 0.9634 |
| base_target_zscore | 0.9424 | **0.9951** | **0.9960** | 0.9653 | **0.9746** | **0.9710** |
| full_target_zscore | **0.9461** | 0.9920 | 0.9958 | **0.9659** | 0.9745 | 0.9709 |

这些数值全部来自 Train Session1 的嵌套留被试伪未知验证，不是真实跨 Session 或测试成绩。当前事实是：

1. 拒识前闭集身份分类已接近满分，说明现有特征含有较强身份信号。
2. 纯 EEG 测试候选出现 81.77% 或 94.26% 的过度拒识，说明**决策分数的跨分布校准失败**。
3. row-zscore 虽提高内部 C，却使 base 的 U 降至 0.2812，已否决。
4. 真实测试无标签，不能计算或声称测试 AUC/F1、C/RA/U，也不能保证晋级分数。

下一步必须同时解决两个问题：

- **表征**：同一个人的脑纹在不同时间、任务和扰动下保持稳定，不同个体之间保持可分。
- **决策**：用 EEG 自身的类内紧凑性和类间/未知间隔完成身份接受与未知拒识，而不是利用数据划分信息。

## 3. 总体技术路线

对每条 Trial 输出两部分：

1. **注册身份候选**：在身份嵌入空间中寻找最相似的注册者原型。
2. **开集置信度**：由最近身份相似度、前两名间隔、能量或类条件距离构成；低于由独立校准确定的接受条件时输出 0。

身份分类与未知拒识共享同一 EEG 表征，但分别验证。高闭集准确率不能替代开集验证，高 AUROC 也不能替代阈值下的 C/U/F1。

## 4. 实验 E0：合规审计与纯 EEG 基线冻结

### 内容

- 对数据加载、特征提取、对齐、训练、校准、后处理和预测逐环节检查，确保没有任何 Session 分支。
- 冻结 `full/base × none/target_zscore` 四个已有纯 EEG 配置及嵌套结果。
- 新实现增加回归测试：打乱或修改 Session 字段后，所有预测、阈值和中间特征必须完全不变。
- 测试预测只允许由 Sample 与 EEG/task 特征决定；Sample 仅用于恢复提交顺序，不能编码身份或 Session。

### 通过条件

Session 不变性测试通过，且复现当前 AUROC/F1 基线。未通过前不生成新候选。

## 5. 实验 E1：无监督 EEG 几何对齐

### 假设

当前逐维 log-cov z-score 只能校正边际均值和方差，不能消除协方差结构的整体位移、旋转和缩放。

### 单因素比较

1. 无对齐。
2. 当前 target z-score。
3. **Euclidean Alignment（EA）**：用完整无标签目标批次的协方差参考均值进行白化，再提取身份特征。
4. **Riemannian recentering / Procrustes Analysis（RPA）**：在 SPD 空间比较参考均值对齐及进一步旋转/缩放。

对齐只能按 task 在全部目标 Trial 上估计，不得按 Session 分组。源域和目标域使用相同的特征提取与分类器，先关闭图融合、伪标签和其他后处理。

### 评估

- 内层选择对齐方法与超参数，外层时间/块留段和留被试只评估。
- 报告 C、U、AUROC、macro-F1、unknown-F1、detection-macro-F1 和分 task 结果。
- 保留条件：多个外层协议稳定改善，而不是只改善测试置信度分布或类别均衡。

## 6. 实验 E2：学习身份判别与类内紧凑的脑纹空间

### 先做轻量模型

在 E1 的最佳特征上比较：

1. 当前 Ridge。
2. 收缩 LDA / Mahalanobis 类原型。
3. 低维监督投影 + 类原型：训练时拉近同一被试的不同时间块和不同 task，推开不同被试。

这里使用 Train 的真实被试标签，不使用测试伪身份。硬 KMeans 已被前推实验否定，不恢复。

### 轻量模型仍存在明确瓶颈时

再比较一个小型 EEG 编码器：

- 输入多频带时频/协方差表征；
- 使用 supervised contrastive loss 或 ArcFace 风格身份损失；
- 同一被试的不同时间块、task 和增广样本作为正例，不同被试作为负例；
- 用原型相似度而非仅用 softmax 分数完成开集识别。

深度模型必须接受与 Ridge 完全相同的外层留被试和时间留段协议，不能用随机 Trial 划分高分替换现有基线。

### 观察重点

- 类内距离与类间距离的分离程度；
- 留被试未知的 embedding 是否仍远离所有注册原型；
- 各 task 是否出现身份不可分或类原型塌缩；
- 表征改进是否同时提高 C、AUROC 和 unknown-F1，而非只提高闭集准确率。

## 7. 实验 E3：不使用 Session 的开集阈值校准

源 OOF 固定阈值已经失效，优先比较以下 EEG-only 校准方式：

### E3a：源域嵌套校准基线

保留现有内层已知置信度 5% 分位阈值，作为必须击败的基线，不继续手工调整分位数。

### E3b：目标分数混合模型校准

- 对完整无标签目标批次的 EEG 置信度按 task 拟合两组件混合模型。
- 高置信组件作为候选已知分布，低置信组件作为候选未知分布；由后验概率确定接受/拒识。
- 不使用 Session、测试身份或预设各 Session 的未知比例。
- 组件数、协方差约束和接受后验阈值只能在内层伪目标实验选择。
- 若目标分数没有可分离结构或拟合退化，应判定方法不适用，而不是强制输出看似合理的拒识率。

### E3c：原型空间的相对证据

比较最近原型距离、最近/次近原型距离比、margin 和 energy，选择只在内层完成。重点检验跨目标批次后，未知 Trial 是否仍表现出较弱且不一致的身份证据。

### 评估

AUROC 只衡量排序，最终必须同时报告固定工作点的 C、U、macro-F1、unknown-F1、EER 和已知接受率。只有阈值下的外层指标改善才算校准有效。

## 8. 实验 E4：保持身份的对抗鲁棒训练

### 训练内构造正常—对抗配对

- 从 Train EEG 或特征生成 FGSM/PGD 扰动，保留原被试标签。
- 损失同时要求正常与扰动样本映射到同一身份原型，而不是简单把所有低置信样本拒识。
- 比较无对抗训练、轻微 EEG 增广、对抗训练及“对抗训练 + 原型一致性”。

### 评估

分别报告：

- 正常样本 C；
- 对抗样本 RA、ASafeR、A=0.7RA+0.3ASafeR；
- 留出未知者 U、AUROC、unknown-F1；
- 本地代理分仅用于内部模拟，不称为官方成绩。

特征空间攻击用于初筛；若有效，再补原始 EEG 域攻击。若 RA 提升但 C 或 U 明显下降，不保留该配置。

## 9. 实验 E5：可选的 EEG 波形一致性约束

只有在训练内正常—对抗实验证明有效后才考虑测试侧无监督一致性。

- 配对图必须在全部适用目标 Trial 中仅依据 EEG 波形/特征相似度建立，不得先按 Session 筛选。
- 比较不融合、温和分数收缩和组件内原型一致性；不强制所有 Trial 配对。
- 高相似边标签一致率只是稳定性指标，不是准确率。
- 若一致性提高但 C/RA/代理分没有提高，删除该后处理。

## 10. 验证协议与 Session 的合法用途

### 模型开发期间

- 外层 5 折留被试：留出被试全部作为未知，其余作为注册者。
- 内层伪未知：只用于选择表征、置信度、校准和阈值。
- 时间前推、反向留段、中间留段和块外推：检验个体内稳定性，所有相邻/配对样本必须同折。
- 对抗实验：正常与对应扰动样本必须保持正确的身份评价，不能把拒识全部当作 RA。

### 最终冻结后

Session 只能用于一次性分层报告，例如“某冻结模型在不同 Session 上的真实指标”；前提是存在相应真值。测试无标签时，只能描述预测数量，不能把 Session 分层拒识率称为 U。

如果根据 Session 分层结果修改了模型，该信息就已参与模型选择，不能再声称“只用于验证”。

## 11. 执行顺序与停止条件

1. **E0**：合规审计和 Session 不变性测试。
2. **E1**：EA/Riemannian 对齐，确认跨分布偏移能否在 EEG 特征层缓解。
3. **E2**：轻量身份原型/监督投影；只有明确瓶颈才进入深度嵌入。
4. **E3**：目标混合校准与原型相对证据，解决固定源阈值失效。
5. **E4**：保持身份的对抗训练。
6. **E5**：仅在前述实验支持时增加 EEG 一致性约束。

每一阶段只做单因素消融。若两个连续外层协议均无收益、unknown-F1 明显下降或出现类别塌缩，则停止该路线，不继续堆叠复杂度。

## 12. 新候选准入标准

1. Session 不变性测试通过，代码中不存在 Session 参与的预测路径。
2. 嵌套外层 AUROC、macro-F1、unknown-F1、C/U 均有完整报告；不能仅展示最优折。
3. 对抗实验报告 C/RA/ASafeR/U，不能只报告 ASafeR。
4. 相对冻结基线，在多个协议上改善本地代理目标，且没有不可接受的 C、RA 或 unknown-F1 损失。
5. 测试侧只使用 EEG/task；输出 22,251 行、Sample 顺序正确、标签为 0–20 且无缺失。
6. 独立保存候选和 MD/JSON 结果，不覆盖已有正式答案；无官方真值时不声称测试性能或晋级分数。
