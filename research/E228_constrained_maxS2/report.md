# E228 约束标定：LOSO 拒识钉在 0.90 下的 Test S2 最大化

> **结论速览**：本轮把目标从"三指标同时达标（已由 E227 证伪）"改为单一硬约束 —— **LOSO 未知身份拒识 = 0.90（允许 0.90~0.91）**，在该约束下最大化 Test S2 接受。十个候选共用同一套 Train 侧标定：二分 `A` 使 pooled LOSO 拒识命中 0.90，取仍然 ≥0.90 的最松 `A`；随后一次性读 Test。

冻结候选为 `e226_auc2W`（E227 的 auc2W 块权重表征，重新做约束标定）：LOSO 拒识 **0.9000**（micro）/ 0.9012（macro），Test S1 拒识 **0.9637**、Test S2 接受 **0.3043**，分离 AUC 0.7918，A*=0.8050。

**S2 增益分解（这是本轮最需要看清的一点）**：

1. E227 报告的工作点（plain，A=0.75，LOSO 0.9235，S2 0.2458）本身**超额**满足了本轮约束（0.9235 > 0.90），相当于把门控开得过严。
2. 同一表征只把阈值合法放松到约束边界（plain，A*=0.7717，LOSO 0.9000）→ S2 0.2845，增益 **+0.0387**。
3. 再叠加 auc2W 块权重 → S2 0.3043，再增益 **+0.0198**。
4. 三个新打分候选（identity_scaled / two_proto_agg / dual_gate）**全部低于**同一约束下的 plain：最高的是 `two_proto_agg`，S2 0.2721，比 plain 的 0.2845 低 0.0124。即：本轮的 S2 提升来自"把过严的阈值放松到约束允许的边界 + 块权重"，而不是新的打分规则。

合计相对 E227 报告点：S2 0.2458 → 0.3043（**+0.0585**），代价是 S1 拒识 0.9763 → 0.9637（-0.0126）。

**偏倚声明**：标定与所有候选定义在本次运行前写死（config.json），标定只用 Train 行；但"在满足约束的候选里挑 Test S2 最高者"这一步读到了 Test，属于评估偏倚，该数字不能当作无偏泛化估计。Test 自 E65 起已被反复查看。

## 1. 口径与不变项

- strict 20 折 subject-LOSO：每折只用 enrolled outer_train 的 trial fraction ≤ 0.6 拟合；评估窗口 (0.6, 0.8]；held identity 不参与标准化、PCA、原型、尺度、OOD 统计与阈值。
- 内层 5 块 OOF：`block = min(floor(fraction × 5), 4)`，与 E221/E226/E227 完全一致。
- 表征固定，特征数组全部读取前作冻结缓存（corr_logspd = E65；bandpower/spectral/pac/energy = E225；hjorth/spec_entropy/power_ratio/graph = E226），未重新设计特征。
- 打分方向：高分 = known；`score < tau` 判未知；unknown 为正类。
- 阈值规则：`tau(A) = fit 行 inner-OOF known 分数的 (1−A) 分位`。`A` 越大 tau 越低、判定越松。

### 1.1 约束标定（Train 侧，二分）

对每个候选，pooled micro 拒识 `f(A)` 关于 `A` 单调不增。二分区间 `A∈[1e-4, 1-1e-9]`，每步保留 `f(A) ≥ 0.90` 的一侧，因此收敛到 **仍然满足约束的最松 A**（即 Test 侧最有利的合法点），而不是随便一个满足约束的 A。迭代 90 次，最终 A 精度远小于 1e-9；由于 `f` 是阶梯函数，落入平台时会向右（更松）移动，正好取边界。

### 6.3 推理流程（可直接照此实现）

1. 读入一条 trial 的原始 18 通道 1200 点信号，按冻结特征定义计算 `corr_logspd`、`bandpower_gainfree`、`spectral_shape`、`spectral_slope`、`pac`、`trial_energy`、`hjorth`、`spec_entropy`、`power_ratio`、`graph_metrics`，按该顺序拼成向量 `x`。
2. 按 `task`（EC/EO/Imagery/SSVEP）取对应的均值向量与标准差向量做 z-score。
3. 若部署模型带块权重，按块乘 `sqrt(w_b)`（见 6.1 表）；
4. 减去 fit 行均值 `pm`，乘 PCA 投影矩阵 `W`（1569×96），得到 96 维 `z`。
5. 在同一 task 的 20 组（每组 12 个）原型上算欧氏距离，取最小者 → `score = −d_min`、最近身份。
6. `score ≥ tau（-24.138）` 则接受并输出该身份；否则判为 unknown（拒识）。
7. 参考实现：`predict_from_model(model, X_test, task_labels)`（本文件内），重载校验即用它复算 Test 分数。

## 7. 结论与限制

- 在 LOSO 拒识 ∈ [0.90, 0.91] 的候选里，`e226_auc2W` 的 Test S2 接受最高（0.3043），其 S1 拒识 0.9637、分离 AUC 0.7918；相对 E227 报告点（S2 0.2458）+0.0585。
- 任务 2 的三个新打分候选**没有一个成立**：`identity_scaled` 需要 A*=0.271（LOSO 已知接受只有 0.4543，ICBR 0.5183）才能把 LOSO 拒识维持在 0.90 —— 按身份尺度归一实际上抹掉了未知/已知的距离差异；`dual_gate_50`/`dual_gate_30` 更差（A*=0.137/0.334，已知接受 0.1493/0.2351），说明"同场次但不同人"的 Train 未知并不比已知更偏离全局协方差 —— OOD 分量在 Train 域内几乎不携带未知信息，叠加后只是压缩了可分性；`two_proto_agg` 的分离度基本持平（sepAUC 0.7907 vs plain 0.7996），但已知接受更低（0.6799 vs 0.7492），S2 反而下降。
- `corr_plus_powerratio`（967 维）LOSO 已知接受最高（0.8168），但 Test 分离 AUC 0.7844 低于 all_blocks_v2 的 0.7996，S2 0.2823 —— "两块互补抗漂移"体现在 LOSO 侧，没有转化到 Test S2 侧。
- 距已放弃的三指标目标（LOSO>0.90、S1≥0.70、S2>0.70）仍有 gap = 0.3957，其中 S1 已满足（0.9637 ≥ 0.70），差额全部来自 S2（0.3957）。
- 官方 Test AUC/F1 因 Test 无身份标签，**N/A**；S1/S2 是会话分层行为指标，不等同官方未知/正常分类指标。
- 无真实 session2 训练数据：S1→S2 的漂移只能用行为指标间接观察，不能做真实跨会话自适应。
- 最终候选比较用到 Test，属评估偏倚；标定与候选定义本身是 Train-only 的。此外"放松阈值到约束边界"本身会系统性地把 S2 抬高，因为 S1/S2 的分数分布差异（E227 指出 Test 分数整体下移）意味着任何降低 tau 的操作都直接增加 S2 接受。
