# E56 跨会话分数标定探针（偏移不是单调平移，无法用秩映射修复）

> 编号说明：本目录原建为 `E53_cross_session_calibration`，与已有的 `E53_raw_eeg_open_robust` 冲突，已改名为 E56。

## 目的

E52 把 E49 系统固化到 Test 后发现 72.5% 的样本落入拒识区（Train 校准块仅 2%）。
本探针量化偏移形态，判断能否用「逐样本、不使用 Session/批次统计」的变换修复。

## 结果

| 统计量 | Train 校准块（N=2,308） | Test（N=22,251） |
|---|---:|---:|
| distance_ratio q01 | 1.0620 | 1.0004 |
| distance_ratio q05 | 1.1066 | 1.0021 |
| distance_ratio 中位 | 1.2397 | 1.0333 |
| distance_ratio q95 | 1.7690 | 3.6528 |
| max_cosine q01 | 0.5026 | 0.3437 |
| max_cosine 中位 | 0.6354 | 0.5491 |
| max_cosine q95 | 0.7318 | 0.8093 |

- Train 阈值 `tau_low=1.0796`、`tau_high=1.1071`；Test 原始拒识率 **0.7250**，落入 logSPD 区 0.2156。
- **诊断对照**：把 Test 的 dr 做秩映射到 Train 分布后，拒识率仍为 **0.7231**（若偏移只是单调平移，应≈0.02）。

## 结论

1. Test 的 `distance_ratio` 分布与 Train **几乎不重叠**（中位 1.033 vs 1.240），且**形状不同**（Test q95 3.65 远高于 Train 1.77，长尾更重）。
2. 秩映射无法修复，说明这不是尺度/平移问题，而是**分布结构本身不同**——与 E21–E35 的跨会话结论一致。
3. 因此任何「逐样本单调变换」都不可能把 Test 拒识率拉回合理区间；要修复必须改变特征或模型对跨会话的敏感性，而不是后处理分数。
4. 该结论也解释了为什么 E52 的 91.03 不能外推为 Test 预期。

## 证据边界

只读取 Test 波形与元数据中的 path/Sample，未使用 Session、标签或文件顺序做任何决策；本探针仅作诊断，不产生提交。
