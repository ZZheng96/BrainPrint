# E20：EEG 图像化 + DINOv2 冻结特征 + 轻量头 脑纹识别

日期：2026-11-12
状态：方案已确认，环境已就绪，待实现

## 1. 目标

用一条**与既往协方差+Ridge 完全独立**的链路做纯 EEG 脑纹识别：

```
18×1200 EEG Trial
  → 图像化（4 种表示，逐一对比）
  → 冻结 DINOv2 ViT-B/14 提特征
  → 轻量头（线性/MLP + ArcFace）
  → 身份 embedding → 原型匹配 + 开集拒识
```

不依赖 Session 元数据、不依赖批次统计、不依赖近重复配对。

## 2. 调研结论（可行性依据）

### 支持证据

| 证据 | 内容 | 对本方案的意义 |
|---|---|---|
| ICML 2026《Standing on the Shoulders of Giants》 | 冻结 **DINOv3 线性探针在 EEG 下游任务上普遍优于专用 EEG 基础模型 CBraMod**（除 CHB-MIT 外全部数据集） | 视觉基础模型特征可迁移到 EEG，是本方案最直接的支撑 |
| arXiv 2401.05409 | 六种时间序列图像表示对比，**MTF、相关矩阵、频谱图**在 EEG 伪迹检测中一致最优 | 图像表示选型有依据 |
| arXiv 2501.17866 | 345 人 / 6007 会话大规模评测，**深度学习方法显著优于手工特征**；跨会话 EER 随时间上升（1 天后 6.7% 起） | 深度路线有效，但跨会话漂移是主要敌人 |
| TF-MEET (2025) | 把 EEG 转成 spatial image + band image，用 Transformer 编码做跨会话解码 | 图像化 + Transformer 已有跨会话先例 |
| NeuroShield (2026) | 双阶段 Transformer 学身份 embedding，跨设备跨数据集迁移 | 身份 embedding + 原型匹配是主流开集做法 |

### 风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| 预训练域不匹配 | DINOv2 训练于自然图像，EEG 图像分布差异大 | 冻结骨干 + 线性探针（文献已验证可行）；必要时加 LoRA |
| 小数据微调过拟合 | 11,304 样本微调 86M 参数 ViT 极易过拟合 | **冻结骨干**，只训练轻量头 |
| 图像化有损 | 18×1200 压成 224×224 必然丢信息 | 多视图图像（时频/相关/拓扑/波形）互补 |
| 跨会话漂移 | 图像化不自动解决 session shift | 训练期增强 + 原型匹配 + 内层阈值标定 |
| SAM 不适合 | 分割模型，无分类语义目标 | **已确认不做 SAM** |

## 3. 四种图像表示

所有表示统一输出 **224×224×3**，逐图做 ImageNet 归一化（DINOv2 标准）。

### V1 多频带时频图（STFT）

- 18 通道 × 5 频带（1–8 / 8–13 / 13–30 / 30–45 / 45–90 Hz）
- 每通道每频带做 STFT → 时频能量图
- 排布：行 = 通道（18），列 = 频带（5），每格为时频图
- 3 通道映射：R = 低频段能量，G = 中频段，B = 高频段
- 优点：信息保留最完整，文献支持最强

### V2 通道相关矩阵图

- 18×18 通道间相关（Pearson / PLV / 协方差）
- 5 个频带各一张 18×18，堆叠为 3 通道（取 3 个代表频带或加权）
- 双线性上采样到 224×224
- 优点：直接编码空间关系，与既往协方差基线同源但表征方式完全不同

### V3 头皮拓扑图序列

- 按 10-20 电极坐标把 18 通道插值成 2D 地形图（grid 64×64）
- 5 个频带 → 5 张地形图，取 3 个代表频带堆叠为 RGB
- 上采样到 224×224
- 优点：空间可解释性最好

### V4 原始波形图（GAF / MTF）

- 18 通道波形分别做 Gramian Angular Field 或 Markov Transition Field
- 18 张 1200×1200 太大，改为：每通道降采样到 224 点后做 GAF → 18 张 224×224
- 3 通道：取 3 个通道组（额/中央/枕）的 GAF 平均
- 优点：无需频域变换，直接编码波形动态

## 4. 模型结构

```
图像 (B,3,224,224)
  → DINOv2 ViT-B/14（冻结，img_size=224）
  → CLS token (B,768) + patch tokens (B,256,768)
  → 轻量头：
       Linear(768→512) → GELU → Dropout(0.3) → Linear(512→256)
       L2 normalize
  → ArcFace(256, n_classes=20, margin=0.3, scale=30)
```

- 骨干完全冻结，只训练轻量头（约 0.5M 参数）
- 可选：patch token 注意力池化替代 CLS（消融项）

## 5. 训练与评估协议

### 5.1 数据划分（与既往实验一致，便于对比）

- 外层 5 折留被试：每折 4 人作未知，16 人作注册
- 注册者每 (subject, task) 后 20% Trial 作外层已知测试
- 内层 2 折伪未知：只用于阈值选择
- 训练只用外层训练折的 Trial

### 5.2 训练配置

| 项 | 值 |
|---|---|
| 优化器 | AdamW，lr=1e-3，weight_decay=1e-4 |
| 调度 | CosineAnnealing，warmup 5% |
| batch size | 64 |
| epochs | 30（早停 patience=8，监控内层验证） |
| 损失 | ArcFace + label smoothing 0.1 |
| 增强 | 时间平移、通道 dropout、小幅幅值缩放、频带掩蔽 |

### 5.3 开集拒识

- 身份分数：与 20 个身份原型的余弦相似度
- 置信度：top-1 相似度 / top1-top2 margin
- 阈值：内层伪未知上选 5% 分位（与既往口径一致）
- 输出：置信度 < 阈值 → 0（未注册）

### 5.4 必报指标

| 维度 | 指标 |
|---|---|
| 正常识别 | C、身份 macro-F1 |
| 未知拒识 | U、unknown AUROC、unknown F1 |
| 联合 | 21 类 macro-F1 |
| 综合 | 官方公式分（本地代理） |

## 6. 实验阶段

### E20A：图像表示可行性（先做，快速）

- 4 种表示各生成 200 张样本图，人工检查 + 统计
- 用冻结 DINOv2 提特征，做**线性探针**（5 折留被试）
- 目标：确认哪种表示的身份可分性最强
- 产出：4 种表示的 C / macro-F1 / unknown AUROC 对比表

### E20B：轻量头训练

- 在 E20A 最优表示上训练 ArcFace 轻量头
- 与线性探针对比，确认轻量头是否带来增益
- 产出：完整 C / U / AUROC / F1

### E20C：多视图融合（条件性）

- 仅当 E20A 显示两种表示互补时，做特征级拼接
- 否则跳过

### E20D：与既往基线对比

- 与 E02 base（AUROC 0.9935 / macro-F1 0.9556）对比
- 明确说明：既往基线是同 Session 内部验证，本实验也是，口径一致

## 7. 停止条件

- 若 E20A 中 4 种表示的线性探针 C 均 < 0.80，说明图像化 + DINOv2 路线在本数据上不可行，停止并记录原因
- 若 E20B 的 unknown AUROC < 0.90，不进入 E20C
- 任何阶段不根据外层结果反复调参
