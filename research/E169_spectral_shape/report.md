# E169 尺度无关的频谱形状特征（E65 + spectral shape）

目标：E167 把 E65 correlation-logSPD 与原始 log band power 拼接后诊断 AUC 达 0.7999，但 W 卡在 0.6997——原始 logbp 的 Train LOSO 区分度弱（@.90 仅 0.4103 vs E65 0.8412），融合后 OOF 分位阈值被推向更宽松的工作点，LOSO 拒识从 0.8412 掉到 0.6730。本实验只保留 logbp 中**尺度无关**的谱型信息（去掉会话级整体幅值偏移），检验能否在保住 LOSO 拒识的同时继续抬 AUC。

协议：逐字沿用 E143/E167——Train-only 标准化 / PCA / 原型 / 阈值；5 块 Train OOF（接受率网格 0.80–0.96）；LOSO 每折排除被评分身份、原型只用 fit_rows(frac≤0.6)、评估块 0.6<frac≤0.8；Test 只评分、session 只用于诊断 AUC。**Test 官方 AUC / F1 = N/A**（无标签）。

缓存布局说明：E146 的 log band power 是 channel-major（列号 = 通道×5 + 频带），代码显式 reshape 到 (n, 18, 5) 再转置为 (n, 5 频带, 18 通道)，未假设 band-major。

## 结论

- 诊断 AUC 最高 **0.7919**（E167 0.7999，Δ-0.0080；E143 0.7578，Δ+0.0341），来自 block_norm concat 96+32 -> PCA-128 k=12。
- W 最高 **0.7010**（E167 0.6997，Δ+0.0013；E163 0.7164，Δ-0.0154；E143 0.6958，Δ+0.0052），取自 raw concat 96+32 -> PCA-96 k=12（接受率网格内选点）；固定工作点 W@.90 最高 0.7008。
- 最佳 AUC 配置的 E159 式上界：扫满阈值后 oracle W = 0.6946；E159 口径乐观上界（LOSO 固定在 @.90 的 0.7367，Test 工作点任选）= **0.7419**；最松口径（LOSO 取网格最高 0.9410）= 0.7930，即距 0.80 仍差 0.0070–0.0581（最松口径把 a=0.80 处的 LOSO 与任意的 Test 工作点拼在一起，实际不可同时达到，E159 口径的上界才是可比结论）。

## 判定

- **核心问题 1（AUC 能否超过 0.7999）**：否，最好 0.7919。
- **核心问题 2（能否同时保住 LOSO 拒识 ≥0.79、使 W 超过 0.6997 / 0.7164）**：最佳 AUC 配置的 LOSO@.90 = 0.7367（未保住 0.79）；全部配置里 LOSO@.90 最高 0.8192；W 最好 0.7010，超过 0.6997、未超过 0.7164。
- **核心问题 3（最佳 AUC 配置的 W 上界）**：E159 口径 0.7419，最松口径 0.7930；距 0.80 分别差 0.0581 / 0.0070。

## 机制解读

- **尺度无关化没有换来 LOSO 区分度**：shape_all 单独最佳（shape_all PCA-96 k=12）诊断 AUC 0.7694、Train OOF AUC 0.7881、LOSO@.90 0.2946；原始 logbp 最佳（logbp PCA-48 k=12）反而是 AUC 0.7818 / OOF AUC 0.8510 / LOSO@.90 0.3791。profile 最佳（profile PCA-16 k=12）AUC 0.7512 / LOSO@.90 0.2653。说明会话级幅值偏移同时也承载了「未注册 vs 已注册」的一部分真实排序信号，把它去掉会同时损失排序力与 LOSO 拒识，而不只是去掉漂移。
- **融合后 W 只是与 E167 持平（不是提升）**：形状融合最佳 W 配置（raw concat 96+32 -> PCA-96 k=12）LOSO@.90 0.7919 / S1 0.8160 / S2 0.5977，W 0.7010；相对 E167 的 0.6997 只差 +0.0013，属噪声量级。而最佳 AUC 配置的 LOSO@.90 0.7367 还低于 E167 对应配置的 0.7467，说明尺度无关化并没有买到更稳的 LOSO 拒识。
- **同口径上界排序（E159 口径）**：E65+logbp 0.7704 > 形状融合 0.7419 > E65 0.7355。排序力最高的分数上界也最高，但三者都 < 0.80；按 E167→E65 的经验斜率（ΔAUC +0.042 带来 Δ上界 +0.035），要让上界越过 0.80 还需要诊断 AUC 再抬约 0.035（≈0.835），单纯换阈值/归一化不够。
