# 原始 EEG 对抗防御五折实验报告

日期：2026-11-07

## 结论

本轮冻结的三个候选均未通过验收，不替换正式提交。非对称配对和组合方法在主攻击下将官方代理分从 47.00 提高到约 59.3，但正常识别率 C 降至 0.85 左右，RA、ASafeR 也低于门槛；多视图没有带来有效收益。

## 协议与有效性检查

- 仅使用 Train Session1；外层 5 折留被试，每折 4 个伪未知、16 个注册被试。
- 注册被试每个 subject/task 的最后 20% Trial 作为已知外层测试；内层 2 折选择各视图阈值，外层不调参。
- 主攻击：原始 EEG、非定向 L2 PGD、SNR20、10 步；辅助攻击：非定向 SNR30 和定向 SNR20。
- 定向攻击目标为注册类别顺序中的下一类别。
- 攻击后通过现有 SciPy 特征链路重新提取特征，不使用 surrogate 分数代替最终评价。
- 不使用测试集真实标签或 clean/adversarial oracle 对应关系。
- 5 折共评估 9,232 条已知样本和 11,304 条伪未知样本。
- 修复了 float32 协方差特征分解反向传播的 NaN；修复后原失败批次输出全部有限，SNR 约束成立。
- 64 条干净样本上，GPU/正式特征相关系数为 0.9634（完整 Trial）和 0.9533（双窗口），模型预测标签一致率为 100%。

## 验收判定

主基线为 direct。三个候选均 `passed=false`，没有任何候选达到提交条件。

- asymmetric_pair：综合分 +12.27、A +0.1504、RA +0.1788，五折均提高综合分；但 C、RA、ASafeR 不达标，两个辅助攻击的 ASafeR 也不达标。
- multiview：综合分 -0.21，RA 没有改善，AUROC 下降超过门槛，仅 1/5 折综合分不下降。
- combined：综合分 +12.30，但 C、RA、ASafeR、AUROC 及辅助攻击安全性不达标。

## 问题定位

1. **置信度不是可靠的干净样本方向判据。** 非对称传播提高了 RA，却把部分高置信度的对抗错误预测传播回干净样本，造成 C 大幅下降。组合方法仅将 anchor 限定为多视图非零预测，仍不能阻止该污染。
2. **近邻间隔约束没有实际筛选作用。** 所有折、所有攻击中，`similarity>0.99` 的配对数量与再要求 `gap>0.005` 后完全相同，说明当前 gap 阈值没有进一步排除不可靠配对。
3. **图均值会混合冲突身份。** graph_mean 在主攻击下 C 仅 0.5131，AUROC 降至 0.8581，不能作为基线改进或候选。
4. **多视图缺乏独立抗性。** 40 Hz 低通和 150 Hz 降采样仍保留主要身份频带及攻击可迁移成分；多个视图会一致输出错误身份。定向 SNR20 下 direct/multiview 的 ASafeR 分别仅 0.0051/0.0053。
5. **内部攻击强度需要与可见测试扰动校准。** 当前 SNR20 是强白盒内部攻击，不等于已证明赛题攻击强度。后续应仅使用无标签波形近邻差异估计 SNR 和频带分布，不能用测试标签或 oracle 配对。

## 后续改进顺序

1. 先做方向错误审计与攻击校准：训练折内统计 clean→adv、adv→clean、clean→clean 的传播效果；测试侧只统计无标签配对的扰动强度和频谱。该步骤不增加候选。
2. 若继续配对方向，新建独立子实验，学习“干净锚点可靠性”而不是直接采用最大置信度；正常高置信样本必须受到保护，验收门槛保持不变。
3. 若配对仍不能同时满足 C、RA、ASafeR，则停止后处理路线，转向训练折内的原始波形对抗训练或多视图一致性训练；阈值仍由内层伪未知折选择。
4. 新防御还需接受针对完整防御流程的自适应攻击，避免只攻击原始视图而高估多视图鲁棒性。

完整逐折指标与自动验收项见 `results.json`。本轮没有生成候选提交，也没有修改既有正式提交。
