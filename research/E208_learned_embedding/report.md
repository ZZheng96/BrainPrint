# E208 学习表征（子窗口增强）报告

## 目的
按“跨会话需要一个模型”的思路，在冻结的 subwin6 特征上训练身份嵌入网络，用子窗口子集、频带丢弃、噪声作为会话式增强，检验能否同时提升 LOSO 拒识与 Test S2 接受率。

## 方法
- 输入：每 trial 的 6 个子窗口特征（6×855），按折内 PCA 投影到 96 维。
- 视图：随机保留 3–6 个子窗口取均值，30% 概率丢弃一个频带，加 0.05 高斯噪声。
- 模型：96→128→64 的两层 MLP，L2 归一化；损失 = 余弦分类交叉熵 + 0.5×SupCon（温度 0.15）；AdamW，lr 3e-3，15 epoch，batch 256。
- 注册：全量视图的平均嵌入作为身份原型；匹配用余弦距离最近原型。
- 严格 20 折 LOSO：任务统计、PCA、网络、原型、阈值全部剔除留出身份；Test 冻结后审计一次。

## 结果（同一 LOSO≥0.90 工作点）
| 指标 | 数值 |
|---|---:|
| LOSO AUC | 0.9819 |
| Train known 接受率 | 0.9552 |
| LOSO 拒识率 | 0.9000 |
| Test S1 拒识率 | 0.6446 |
| Test S2 接受率 | 0.3302 |
| Test 前沿 max S2 @ S1≥0.70 | 0.2738 |
| Test 前沿 max S1 @ S2≥0.70 | 0.3360 |

## 结论
训练确实把 Train 开放集 AUC 从 0.7920 拉到 **0.9819**，但在 Test 上前沿从 0.718 跌到 **0.274**。也就是说，模型学到的主要是 session1 的身份可分性，而不是可迁移的跨会话身份不变性。

结合 E204（相对距离）、E207（多原型），可以看到一个稳定规律：

| 方案 | LOSO AUC | Test 前沿 S2@S1≥0.70 |
|---|---:|---:|
| 原始距离（k=1） | 0.7920 | 0.7178 |
| k=4 多原型 | 0.8864 | 0.6962 |
| 学习表征（E208） | 0.9819 | 0.2738 |

**Train LOSO 可分性与 Test 跨会话迁移在本数据上呈反向关系**。只要优化目标依赖 session1 内的身份可分性，就会牺牲跨会话接受率。

AUC/F1：LOSO AUC 0.9819；Test 无身份标签，F1 记 N/A。模型权重存于 `cache/model_all20.pt`。
