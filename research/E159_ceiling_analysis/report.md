# E159 单一分数的 W 上界分析

设备：cuda；E143 协议（E65 → task 标准化 → PCA-96 → k=12 原型）。
本实验只做上限证明：不使用任何 Test 统计量建模，只在已冻结分数上把阈值扫满，看单条 ROC 能到多高。

- Test S1-vs-S2 诊断 AUC：**0.7569**
- 扫满全部阈值后的最优 W：**0.6971**（a=0.892，LOSO 0.8230，S1 0.8140，S2 0.5756）
- 乐观上界（LOSO 固定 0.7936，Test 工作点任选）：**0.7352**
- S1 拒识恰为 0.80 时，S2 接受最高只有 (0.5995)

项目 Test AUC/F1 = N/A（无真实标签）。

结论：若乐观上界仍 < 0.80，则该分数无论怎么调阈值都不可能达标，必须提升排序能力（诊断 AUC），而不是继续换阈值或换归一化。
