# E178 补齐五项未测门禁（E170 最高 W 方案）

被审计方案：**E170 三路分数融合，最高 W 点**
`score = 0.5·z(E65 logSPD PCA-64) + 0.1·z(logbp PCA-32) + 0.4·z(E162 PCA-64)`，k=1 均值原型，接受率 a=0.88。

E177 已确认 #2/#3/#4 通过、#9/#10 失败，但把 #1/#5/#6/#7/#8 记为「未测量 / 结构性缺失」。本实验**只补这五项**，不修改任何已有实验目录。

**当前关键指标：Train OOF AUC = 0.9229，身份 macro-F1 = 0.9590**（本实验重算，与 E170/E177 公布值完全一致）。

## 2. 五项新测量

### 2.1 门禁 #1：Train 拟合容量

原型（每 (task, identity) 的 k=1 均值）用**全部 11304 条 Train** 建立，再在同一批样本上做身份预测（20 类闭集，argmax）。

| 指标 | 值 |
|---|---|
| **in-sample 准确率** | **0.9730**（目标 1.00，差 2.70 点） |
| in-sample macro-F1 | 0.9728 |
| 分任务 in-sample 准确率 | EC 0.9739 / EO 0.9654 / Imagery 0.9693 / SSVEP 0.9806 |
| 5 块 OOF 准确率（已有，作对照） | 0.9592 |

说明：该方案是**无参数的 1-近邻均值原型打分**，不存在可拟合的参数容量，因此「Train 准确率 = 1.00」这一门禁在结构上不可达——in-sample 也不能把每条样本拉到自己原型上（E162 分支有效秩仅约 8，三路加权后类间几何由 0.4 权重的 E162 主导，均值原型彼此重叠）。要满足 #1 必须换成可插值的判别模型（如原 E58 的 CNN），代价是 #5/#6 会掉（E36–E61 已证「CNN 出身份、logSPD 出拒识」的分工约束）。

### 2.2 门禁 #5：pseudo-unknown AUROC（LOSO，20 折）

协议：每折留出 1 个身份，原型只用其余 19 个身份的 `frac <= 0.6`（`pm & fit_rows`）；known = 19 个注册者在 `0.6 < frac <= 0.8` 的分数，unknown = 留出身份在同一窗口的分数。

| 指标 | 值 |
|---|---|
| **合并 20 折 AUROC（unknown 为正类）** | **0.9094** |
| 20 折各自 AUROC | **0.9083 ± 0.0594**（min 0.7640，max 0.9997） |
| 样本量 | known 43,719 / unknown 2,301 |

（分数是相似度，因此「unknown 为正类」等价于 E170 的 `loso_auc`（known 为正类），两者数值相同。）

判定：**❌**，距 0.98 差 0.071。折间离散度 0.059 本身也说明该分数在不同留出身份上不稳定（最差折 0.764）。

### 2.3 门禁 #6：U@95%（同批 LOSO 分数）

每折阈值 = 该折 known 分数的分位数（known 接受率固定为给定值），U = 该折 unknown 低于阈值的比例。

| 已知接受率 | **U 均值** | 20 折标准差 | min | max |
|---|---:|---:|---:|---:|
| 90% | 0.6950 | 0.2551 | 0.1849 | 1.0000 |
| **95%** | **0.4882** | 0.2915 | 0.0306 | 1.0000 |
| 98% | 0.2411 | 0.2467 | 0.0000 | 1.0000 |
| （参考）88% | 0.7530 | — | — | — |

判定：**❌**，U@95% 只有 0.4882，距 0.95 差 0.462。20 折里 U@95 从 0.031 到 1.000 全跨度，说明该工作点对不同留出身份无稳定保证。

### 2.4 门禁 #7 / #8：对抗鲁棒（自建 PGD 代理）

**⚠️ 这是自建攻击代理，不是官方攻击套件，只能作为上界/参考证据。**

- 采样域：**Train 评估块 `0.6 < frac <= 0.8`**（1252 条，按任务分层上限 400：EC 222 / EO 230 / Imagery 400 / SSVEP 400）。
  选择 Train 而非 Test 的原因：**Test 没有身份标签，RA/ASafeR 在 Test 上不可计算**（不是偷懒）。Session 字段全程未读取。
- 原型：仅 `fit_rows`（`frac <= 0.6`）的 20 个身份 k=1 均值原型；PCA/标准化/OOF μ、σ 全部 Train-only。
- 端到端可微：原始 18×1200 → E65 相关 logSPD（FFT 分带 + 通道标准化 + 相关矩阵 + 收缩 + logSPD + 上三角 + detrend_zband）→ PCA-64；→ E146 logbp（同 FFT 解析信号 → 功率 → logbp）→ PCA-32；→ E162 编码器（`model_lam0.0_t0.1.pt`）→ PCA-64；三路按 0.5/0.1/0.4 加权。
- PGD：L∞，ε ∈ {0.005, 0.01, 0.02}×每 trial 全局 RMS（≈46.0 / 40.0 / 34.0 dB 下界），8 步，步长 ε/2，随机起点，单次重启。实测扰动上界精确达到 0.00500 / 0.01000 / 0.02000。
- 目标 A（单类冒充）：最大化「最佳错误身份」的融合分数。
- 目标 B（躲避拒识）：最大化 logsumexp（整体接受度）。
- 目标 C（边界冒充）：最大化 `z(目标) − z(真实)`。**这是任务书之外补的一档**：目标 A 主要产生共模分数抬升（argmax 几乎不变，见下），单用它会让 RA 偏乐观；补 C 才能给出真正的冒充下界。
- 判决：融合分数最大者接受，否则判 0；阈值取 Train 5 块 OOF 在 a=0.88 的分位数（−0.9812）。

| 条件 | RA（被认成真实身份） | 95% CI | ASafeR（真身份 或 0） | 95% CI | 闭集准确率 | 接受率 | 误认率 | 拒识率 |

| ε=0.005 B | 0.7819 | [0.7591, 0.8048] | 0.9337 | [0.9199, 0.9475] | 0.8786 | 0.8482 | 0.0663 | 0.1518 |
| ε=0.005 C | 0.6733 | [0.6473, 0.6993] | 0.9105 | [0.8947, 0.9264] | 0.8235 | 0.7628 | 0.0895 | 0.2372 |

判定：**#7 ❌（最差 RA 0.4417 < 0.95）、#8 ❌（最差 ASafeR 0.6965 < 0.98；clean 基线 0.9489 本身已不达标）**。

**机制读数**：
- 攻击的核心效果是**把样本推成别的注册身份**：误认率从 clean 的 5.11% 涨到 6.6%–30.4%，闭集准确率从 0.8858 掉到最低 0.5711；同时目标 A/B 把接受率从 0.787 抬到 0.82–0.94（目标 C 维持在 0.74–0.76），也就是「更容易进门、进错门」。
- 目标 A（单类）在 ε=0.005 几乎无效（RA 0.7340 vs clean 0.7356），因为该分数族对小幅扰动的响应主要是共模抬升；到 ε=0.02 才明确产生冒充（误认 27.9%）。**这说明只用目标 A 会低估攻击**，因此补了目标 C。
- 该方案的「安全」没有任何鲁棒表征支撑：ASafeR 的 clean 值就只有 0.9489，与它无关地，Test #9/#10 早已失败；攻击只是把同一个弱点放大。

**残余风险**：ε=0.005 目标 B 的一次运行出现 129,600 个非有限梯度分量（约占总梯度元素 0.06%，来自 18×18 相关矩阵 `eigh` 反向的简并特征值），已用 `nan_to_num` 置零；其余 8 次运行为 0。这只会让该格攻击略弱，不会让 RA/ASafeR 偏高。

另外，clean 闭集准确率 0.8858 低于门禁 #2 的 0.9592，原因是**协议不同而更严**（同一 2301 条窗口块上）：

| 原型协议 | 窗口块闭集准确率 |
|---|---:|
| 5 块 OOF（4/5 数据，含时间相邻的 0.8–1.0 块）→ 门禁 #2 用的就是这个 | 0.9435 |
| 仅注册块 `frac<=0.6`（攻击所用的诚实部署协议） | 0.9057 |
| 全部 Train（in-sample，乐观上界） | 0.9644 |

## 3. 结论

1. E177 缺的五项全部补上，没有一项达标：#1 0.9730（差 2.7 点，且在均值原型结构上不可达）、#5 0.9094（差 0.071）、#6 0.4882（差 0.462）、#7 0.4417（差 0.508）、#8 最差 0.6965 / clean 0.9489（差 0.284 / 0.031）。
2. **十项门禁最终通过 3 项**（#2/#3/#4），且这三项只有 Train 侧代理证据；#9/#10 仍由 E177 的冻结 Test 审计判定失败。
3. 该方案的核心矛盾没有变化：身份可分性（OOF AUC 0.9229 / macro-F1 0.9590 / 身份准确率 0.9592）与跨会话拒绝（Test S1 拒识 0.6775 / S2 拒识 0.2790）不能同时满足；攻击侧进一步显示它没有任何鲁棒表征——全白盒 PGD 在 ε=2%（≈34 dB）下把 RA 打到 0.4417、ASafeR 打到 0.6965，误认率 30.4%。
4. #1 与 #2/#5/#6 在本表征族上互斥（均值原型无法插值拟合，能拟合的 CNN 又丢类条件结构），这与 E36–E61 的分工结论一致。
