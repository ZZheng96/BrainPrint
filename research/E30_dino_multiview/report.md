# E30：DINO 多视图距离融合

日期：2026-11-12
状态：完成。结论：**cov5 的类内白化距离（WCCN）是最佳单信号，AUROC 0.7243；加 PCA 残差到 0.7253。topomap5 融合反而变差。**

## 0. 方法

- 特征：DINOv2 的 covariance5（768 维）与 topomap5（768 维），完全冻结骨干。
- 信号：逐样本、归纳式。
  - `dist`：到最近注册类中心的欧氏距离
  - `dist_wccn`：先用训练集类内散布矩阵白化，再算距离（WCCN）
  - `pca`：训练集 PCA(64) 子空间外的重构残差
- 融合：把每个信号的取值转成「相对训练内层已知分布的分位」，再等权平均。
  参考分布只用训练集估计，逐样本施加，不使用 Test 统计。
- 选择：只用 Train 内层伪未知的 AUROC，Test 只做审计。

## 1. 单信号

| 视图 | 信号 | 内层 AUROC | Test AUROC(S2 vs S1) |
|---|---|---:|---:|
| cov5 | dist | 0.6369 | 0.7063 |
| cov5 | **dist_wccn** | **0.7136** | **0.7243** |
| cov5 | pca | 0.6735 | 0.7276 |
| topo5 | dist | 0.6191 | 0.5892 |
| topo5 | dist_wccn | 0.6802 | 0.5980 |

**内层排名与 Test 排名一致**（cov5 wccn 最优），说明 E29 的标定修复后，内层选择是可信的。

## 2. 融合结果

| 组合 | Test AUROC | q01 S2 接受 / S1 拒识 | q05 S2 接受 / S1 拒识 |
|---|---:|---|---|
| cov5_dist | 0.7063 | 0.952 / 0.435 | 0.883 / 0.530 |
| **cov5_wccn** | 0.7243 | 0.942 / **0.480** | 0.872 / **0.540** |
| **cov5_wccn+pca** | **0.7253** | 0.938 / **0.486** | 0.871 / 0.543 |
| cov5_dist+wccn | 0.7142 | 0.943 / 0.471 | 0.874 / 0.539 |
| cov5_dist+wccn+pca | 0.7179 | 0.942 / 0.477 | 0.875 / 0.539 |
| cov5+topo5_dist | 0.6618 | 0.964 / 0.140 | 0.888 / 0.346 |
| cov5_dist+pca+topo5_dist | 0.6830 | 0.965 / 0.185 | 0.881 / 0.442 |

**发现：**

1. `cov5_wccn` 把 AUROC 从 0.7063 提到 0.7243，q01 时 S1 拒识从 0.435 提到 0.480（S2 接受只降 1 个点）。
2. 再加 PCA 残差几乎没有提升（0.7243 → 0.7253，S1 拒识 0.480 → 0.486）。
3. **topomap5 融合显著变差**（0.6618–0.6830），因为 topomap5 的 Test AUROC 只有 0.589，拖累了整体。
4. 视图间没有互补性：cov5 已经包含了 topomap5 的信息。

## 3. 与 E29 对比

| 方案 | Test AUROC | q01 S2 接受 / S1 拒识 |
|---|---:|---|
| E29 cov5_dist | 0.7063 | 0.952 / 0.435 |
| **E30 cov5_wccn+pca** | **0.7253** | 0.938 / 0.486 |

S1 拒识提升约 5 个百分点，代价是 S2 接受降 1.4 个百分点——**这是本轮唯一一次「同时改善」**。

## 5. 结论与局限

- 距离型判据 + WCCN 是 DINO 路线上目前最好的开集方案，AUROC 0.7253。
- 但 0.72 的 AUROC 决定了 S1 拒识与 S2 接受仍然强耦合：
  想让 S1 拒识过 0.5，S2 接受必然掉到 0.94 以下。
- 内层与 Test 的 AUROC 差距已缩到 0.01（0.7136 vs 0.7243），标定问题基本解决；
  剩余瓶颈是表征本身的判别力。
