# E165：Test-Time Augmentation 能否抬高诊断 AUC

日期：2026-11-15。目标：在不改动 E143 协议的前提下，用原始信号层的确定性扰动产生多视图、重新走 E65 编码后聚合，检验 Test S1-vs-S2 诊断 AUC 是否 > 0.7578。

## 结论

**TTA 在此表征上无效。**

- 基线（E143 B_only / k=12 / 接受率 0.90）：诊断 AUC **0.7578**，W **0.6958**。
- 本次 `identity` 单视图对照：诊断 AUC **0.7578**，W **0.6958**（LOSO 0.7936 / S1 0.7979 / S2 0.5960，@a=0.90）。控制通过：**True**（W 误差 3.70e-05，AUC 误差 2.08e-05）。
- 最佳聚合 `score_max`：诊断 AUC **0.7578**，相对基线 **+0.000000**。
- 四种聚合方式的诊断 AUC 与 `identity` 的最大差异仅 **4.1e-07**，W 全部相同（0.6958）：这是浮点噪声，不是 TTA 增益。

## 增强视图是否真的改变了表征

TTA 只有在视图让 E65 特征真正变化时才有信息量。全部 11304 条 Train 特征与 `identity` 的差异：

| 视图 | max abs Δ | mean abs Δ | 逐行 max abs Δ ≤ 1e-3 的行数 / 11304 |
|---|---:|---:|---:|
| shift | 5.091e-04 | 5.471e-06 | 11304 |
| channel_gain | 5.099e-04 | 2.965e-06 | 11304 |
| band_emphasis | 5.225e-04 | 3.145e-06 | 11304 |

- `identity` Train 特征 vs E65 官方缓存 max|Δ| = 0.000e+00；Test 特征 vs E121 缓存 max|Δ| = 0.000e+00，说明重建管线与基线逐位一致。
- **三个增强视图在 E65 表征上全部恒等（差异仅 FFT/float32 舍入，量级 1e-4/1e-6，远小于任何有效扰动）**：
  - `channel_gain`：E65 在每个 trial、每个频带内先把每个通道减去自身均值并除以其自身样本标准差，再算相关矩阵；逐通道常数增益 $g_i$ 在 $\mathrm{corr}(i,j)=\frac{\sum_t x_ix_j}{\sigma_i\sigma_j}$ 中完全约掉。
  - `band_emphasis`：增益恰好施加在 E65 自身使用的理想矩形频带（1–8 Hz、30–40 Hz）上，同样被该频带的逐通道标准化约掉；E36 的 detrend 只减去对角 log 方差的均值（对 18 个通道是同一个常数），也不引入幅值信息。
  - `shift`：循环平移 $\tau$ 对相关矩阵是精确不变的——$\sum_t x_i(t+\tau)x_j(t+\tau)=\sum_t x_i(t)x_j(t)$，且 E65 的频带滤波是 DFT 域矩形掩码，与循环平移可交换。
- 结论：**TTA 的 4 个预注册视图对 correlation-logSPD 特征构成一个数学上不可观测的变换群**，因此所有聚合方式在结构上必然给出与 `identity` 相同的分数（实际差异仅为浮点噪声，见上表 AUC Δ 量级 1e-7）。不是聚合方式选得不好，而是该表征对此类扰动完全不敏感。

## 设置

- 视图在**原始信号层**生成，随后**重新走 E65 `gpu_correlation_logspd`**（855 维 correlation-logSPD），不在特征空间加噪；全部确定性，Train/Test 同一规则，无任何 Test 侧统计。
- `shift`：循环移位 **+100** 点（预注册为 ±100 点；四视图方案下固定取 +100 这一确定性方向，能量不变）；`channel_gain`：偶/奇通道索引分别 ×0.9/×1.1；`band_emphasis`：1–8 Hz ×1.1、30–40 Hz ×0.9。
- E143 协议逐字沿用：task-wise Train 标准化（Train 全部该 task 行统计）、PCA-96（fit_rows = 每 (subject,task) frac≤0.6 合并）、k=12 k-means 原型（seed=int(class)*17，E143 `kmeans_t`）、5 块 Train OOF 阈值、LOSO 每折排除被评分身份且原型只用 fit_rows(frac≤0.6)。
- 与 E143 一致，主评分与 Test 的原型用**全部 Train 行**，OOF 阈值块的原型用“除该块外全部行”，LOSO 用 `enrolled & fit_rows`。这是 E143 已发表的实现，为精确复现 0.6958/0.7578 不做改动。
- 分数聚合：每视图先用**自身 Train OOF 参考分布**做 z 标准化，再逐元素 mean/max/min；`feature_mean` 则先平均 855 维特征再整条管线。
- Test 只被评分；session 仅用于事后诊断 AUC / S1 拒识 / S2 接受。

## 判定

- 诊断 AUC 基线 0.7578 → 最佳 0.7578（score_max，Δ +0.0000）。
- 是否 > 0.7578：**False**。
- 含义：任何保持「逐频带逐通道尺度」与「循环平移」不变性的视图，在 correlation-logSPD 上都不会带来 TTA 收益；要真正检验 TTA，视图必须改变 trial 内的跨通道结构（如非循环时间裁剪/重采样、子窗口切片），或改用保留幅值信息的表征。

**项目 Test 官方 AUC / F1 = N/A（无真实标签）。** 上表 Test 诊断 AUC 只是 S1 与 S2 的分数可分性，S1 拒识 / S2 接受是基于 Train 阈值的预测工程审计，不是官方真值指标。
