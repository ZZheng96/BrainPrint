# E231 两端极端配置的特征归因：四象限细分与消融

> **结论速览**：把 (A) LOSO 高 / S2 低的配置与 (B) LOSO 低 / S2 高的配置放在同一张表上，对 1569 维逐维计算「场内区分度 in_session」与「跨 run 身份一致性 cross_run」，再按四象限切出固定子集跑完整 strict LOSO（PCA96，tau 二分到 LOSO 拒识 = 0.90）。

- 四象限核心结论：Q1（本质候选）只占 598 维（38.1%），Q2 11.9%、Q3 11.9%、Q4 38.2%；块内 Q1 占比最高的是 `spectral_shape`（90.0%），最低的是 `pac`（0.0%，全部落在 Q4）；`corr_logspd` 的 Q1 占比只有 29.8%。
- cross_run 代理是否有效：cross_run 与 Test 单维 AUC 不构成显著正相关（ρ=-0.030, p=0.24），**代理失效**；按预注册规则回退到合成漂移代理，四象限中的 Q1/Q3 解释需降级为描述性。
- 是否有子集超过 E228 基线 S2 = 0.3043：没有。最好的子集是 `Q1Q3_transfer`（S2 0.2869），仍未超过 0.3043。

## 1. 口径与不变项

- strict 20 折 subject-LOSO；每折只用 enrolled outer_train 的 trial fraction ≤ 0.6 拟合；评估窗口 (0.6, 0.8]；held identity 不参与标准化、PCA、原型、阈值，也不参与它自己那一折的选维。
- 内层 5 块 OOF：`block = min(floor(fraction × 5), 4)`，与 E221/E226/E227/E228 一致。
- 表征：task-wise 标准化 → PCA96 → 每 (task, identity) k=12 原型；`score = -min` 欧氏距离，高分 = known。
- 阈值：`tau(A) = fit 行 inner-OOF known 分数的 (1−A) 分位`，A 在 Train 侧二分到 pooled micro LOSO 未知拒识 = 0.90（E228 规则，保留仍 ≥ 0.90 的最松 A）。
- 官方 Test AUC/F1：**N/A**（Test 无身份标签）。本文的 AUC 是 LOSO 阈值无关 AUC，F1 是拒识 F1（unknown 为正类）。

## 2. Train 内部的 run 切分核实

- 规则：per (subject, task) split at the trial-index median: run1 = trial <= median, run2 = trial > median。
- 80 个 (subject, task) 单元：每单元 trial 数 min/max/mean = 36/300/141.3；run1 大小 mean 70.8，run2 mean 70.5，最大绝对差 1，任一侧 < 10 条的单元 0 个。
- 各 task 的 trial 序号范围：`EC` 1–60（中位 30）；`EO` 1–60（中位 31）；`Imagery` 1–300（中位 150）；`SSVEP` 1–200（中位 102）。
- **限制**：Train 只有 session1，run1/run2 只是同一会话内按序号前后切分，是跨会话的近似，不是真实 session2。所有 cross_run 数字都受此约束。

## 6. 判定

`Q1_essence` 在 LOSO 拒识 0.9000 下 Test S2 = 0.2502，未超过 E228 基线 0.3043（-0.0541）。按预先写死的判定：**本质特征在当前数据下不足以突破**；本报告给出四象限证据后停止，不换配方重跑。

## 8. 限制

- Test 单维 AUC 只用于诊断，且 Test 自 E65 起被反复查看，存在反复查看偏倚；本文据此做的“代理是否有效”判断本身也受该偏倚影响。
- run1/run2 是同一 session1 内按 trial 序号前后切分的近似，不是真实 session2；cross_run 度量的是“同会话内前后半段的身份一致性”，对真实跨会话漂移只能外推。
- 官方 Test AUC/F1 = **N/A**（Test 无身份标签）；S1/S2 是会话分层行为指标，不等同官方未知/正常分类指标。
