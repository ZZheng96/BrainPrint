# E168 子窗口 correlation-logSPD（子段结构 / 非平稳性）

E65 对整个 trial 只算一个相关矩阵，因此对通道增益、频带增益、循环时间平移精确不变，trial 内的子段结构被完全丢弃（E165）。本实验把 trial 切成 N 个**不重叠**子窗口（N=2/3/4，窗长 1200/N），每个子窗口独立执行 E65 的完整流程（5 频带 FFT 滤波 → 去均值 → 通道标准化 → 相关矩阵 → 收缩 → logSPD → 上三角 171 维 → detrend_zband），再把子窗口结果作为**特征向量**（不是 E149/E62 的图像）接入 E143 协议。

评估逐字沿用 E143：task-wise Train 标准化 → PCA（64/96/128/256）→ k=1/3/6/12 原型 → 5 块 Train OOF 阈值（接受率 0.80–0.96）→ LOSO 每折排除被评分身份、原型只用 fit_rows、评估块 0.6<frac≤0.8 → Test 只评分、session 只诊断。

## 结论

- 基线 E143（E65 PCA-96 k=12, 接受率 0.90）：诊断 AUC **0.7578** / W **0.6958**（公布 0.7578 / 0.6958，Δ -0.0000 / +0.0000），逐位复现。
- **诊断 AUC：0.7822**（subwin_mean_n4 PCA-64 k=12，Δ +0.0244 vs 基线，Δ +0.0213 vs 0.7609） → 关键问题 1 **达到**。子段结构确实带来了 E65 结构上没有的信息，且增益不是靠阈值。
- **W（E143 工作点，接受率固定 0.90）：0.7156**（subwin_concat_plus_std_n4 PCA-128 k=12），对比 E65 自身最好 0.6964（E65 PCA-128 k=12）、基线 0.6958；距 0.7164 还差 +0.0008 → 关键问题 2 **未达到**。
- 若按 E143「在 0.80–0.96 网格里取最大 W」的口径，可报 0.7617（subwin_concat_n4 PCA-256 k=3，@a=0.80）；但该点是用 **Test 标签选出来的工作点**，且该配置 Train OOF AUC 只有 0.7350（同变体其它配置最高 0.9448），属于分数分布形状/阈值效应，不能当作方案提升（见「口径说明」）。
- 为什么 AUC 涨了 W 没涨：AUC 最高的 subwin_mean_n4 PCA-64 k=12 在固定接受率 0.90 时 S2 接受只有 0.4410（E65 基线 0.5960），排序增益被 Train OOF 参考与 Test 分数分布之间的平移吃掉；要把 AUC 转成 W，瓶颈在校准而不是表征。

### 子窗口标准差（subwin_std）

- 单独使用几乎无信号：最优诊断 AUC 0.6384（subwin_std_n4 PCA-64 k=3），最优 W@0.90 0.5592（subwin_std_n4 PCA-64 k=3）；AUC 甚至低于 0.5，说明 S2 的子窗口离散度反而更大（方向相反），翻转后也只有 0.52–0.64。
- 与 E65 的相关性最低（PCA-96 k=12 时 Test r = +0.6230（N=4）/+0.4748（N=2）），确实是 E65 没有的信息；但与 E65 等权融合后最好诊断 AUC 只有 0.7783（0.50*E65 + 0.50*subwin_mean_n4 PCA-64 k=12）、最好 W@0.90 只有 0.7111（0.50*E65 + 0.50*subwin_concat_n4 PCA-128 k=12），两者都没有超过子窗口 mean/拼接单路的最好值，说明 trial 内非平稳性在这个表征下不构成可用的身份/会话判别信息。

### 口径说明（重要）

- **诊断 AUC** 与阈值无关，是唯一干净的可比量：它只依赖 S1/S2 的分数排序。
- **W@0.90** 固定 E143 的接受率 0.90（阈值 = Train OOF 分数的 10% 分位），跨配置可比。
- **best W** 是在接受率 0.80–0.96 网格上挑最大值，等于用 Test 的 S1/S2 结果挑工作点；E143 自己也是这么报的（0.6958 恰好同时是最优与 a=0.90），但当某配置的 Train OOF 分数分布在 Test 上发生压缩/平移时，best W 会被阈值位置放大。本实验里 concat 变体在 PCA-256 时正是这种情况（OOF AUC 掉到 0.73，best W 却跳到 0.76），因此结论以 W@0.90 为准。
- Test 官方 AUC/F1 = N/A（无真实标签）。
