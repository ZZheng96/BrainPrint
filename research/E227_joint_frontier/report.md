# E227 联合可达域：LOSO 拒识 × Test S1 拒识 × Test S2 接受

> **结论速览**：在冻结的 `all_blocks_v2` 上，单一阈值 **不存在** 同时满足 `LOSO 拒识>0.90` + `Test S1 拒识≥0.70` + `Test S2 接受>0.70` 的工作点。`LOSO>0.90` 需要 tau≈-20.1（此时 S2 接受只有 0.2458）；`S2>0.70` 需要 tau≈-25.3（此时 LOSO 拒识只有 0.3803）；两者在 tau 轴上相距 5.2 个分数单位。块权重换成单块 LOSO AUC / AUC² 把 LOSO AUC 从 0.8890 抬到 0.9022/0.9096、同 A 下拒识更高，但 Test 分离 AUC 从 0.7996 降到 0.7936/0.7918、S2 上限从 0.7162 降到 0.6900/0.6811：前沿被**旋转**，没有被整体外推。按 task 拆分没有发现"几乎不可拒"的 task（最严端四个 task 的 LOSO 拒识为 0.952–0.978）。

本轮不改表征、不改特征，只把**阈值规则**从固定的 `tau = 10% 分位（A=0.90）` 展开为 `A` 全网格，并在冻结的 `all_blocks_v2` 上补两个只用 Train 侧信息的块权重方案，目的只有一个：**把"是否存在单一阈值同时满足LOSO 拒识>0.90、S1 拒识≥0.70、S2 接受>0.70"这个问题画成一张图**。

## 1. 口径与不变项

- strict 20 折 subject-LOSO：每折只用 enrolled outer_train 的 trial fraction≤0.6 拟合task-wise 标准化 / PCA96 / k12 原型 / 阈值；评估窗口 (0.6, 0.8]；held identity 不参与任何拟合。
- 表征固定为 E226 `all_blocks_v2`（旧 6 块 + 新 4 块，1569 维，PCA96，k12），特征数组直接读取 E226/E225/E65 的冻结缓存，**未重新设计特征**。
- `score` = 同 task 原型的 −最小欧氏距离；高分 = known；`score < tau` 拒识；unknown 为正类计算 rejection F1 与 AUC(-score)。
- 新阈值规则：`tau(A) = fit 行 inner 5-block OOF known 分数的 (1−A) 分位`。`A` 是**训练侧目标已知接受率**，完全不看 Test；`A=0.90` 即 E226 的 10% 分位原规则。

A 网格：0.70, 0.75, 0.80, 0.85, 0.88, 0.90, 0.92, 0.94, 0.96, 0.98, 0.99。

## 6. 存在性结论

**不存在。** 在对 A 网格 × 3 个块权重方案的完整扫描中，没有任何单点同时满足 `LOSO 拒识>0.90`、`Test S1 拒识≥0.70`、`Test S2 接受>0.70`。根本原因是三者被同一个 tau 单调绑定：A 越小（tau 越高）→ LOSO 拒识越高，但 Test S1 拒识与 S2 拒绝同步升高；而 Train 域内 held identity 的分数分布比 Test S1 更靠近 known，要把 LOSO 抬到 0.90，tau 必然越过 Test S1 的 70% 分位，S2 随即被压到 0.70 以下。网格最严点（A=0.70）的 LOSO 拒识已达 0.9800，此时 Test S1 拒识=0.9934、S2 接受=0.1486。最接近的三个点（gap = Σ 未达标差额）：

### 6.1 两个硬约束在 tau 轴上的位置（数据摘要）

`LOSO>0.90` 只在严格端成立（A 小），`S2>0.70` 只在宽松端成立（A 大）。下表给出各自最省（最靠近 0.90 / 0.70 边界）的 A 与对应 tau。

|方案|LOSO>0.90 的最松 A|该 A 的 tau|该 tau 下 S2 接受|S2>0.70 的最严 A|该 A 的 tau|该 tau 下 LOSO 拒识|tau 间距|
|---|---:|---:|---:|---:|---:|---:|---:|
|plain|0.75|-20.088|0.2458|0.94|-25.293|0.3803|5.21|
|aucW|0.75|-21.280|0.2188|0.96|-28.813|0.2860|7.53|
|auc2W|0.80|-24.055|0.2965|0.96|-31.193|0.2968|7.14|

- 正 tau 间距 = 满足 LOSO 目标的阈值本就高于满足 S2 目标的阈值；同一个 tau 不可能同时落在两段里，这是"单阈值不存在"的直接几何证据，三个方案的间距都在 5–7.5 个分数单位。

### 6.2 把 S1 约束钉死时的上界（Test 派生，非法部署，仅作上界）

把 tau 直接钉在 **Test S1 分数的 70% 分位**，S1 约束恰好满足，再看同一 tau 下的 S2 接受与 LOSO 拒识。该 tau 用了 Test 分布，**不能部署**，但它给出"若只优化 S1/S2 这一对"能达到的最好结果。

|方案|tau|S1 拒识|S2 接受|该 tau 下 LOSO 拒识|LOSO 已知接受|LOSO 缺口|
|---|---:|---:|---:|---:|---:|---:|
|plain|-24.964|0.6996|0.7162|0.4090|0.9318|0.4910|
|aucW|-26.907|0.6996|0.6900|0.4268|0.9349|0.4732|
|auc2W|-29.214|0.6996|0.6811|0.4389|0.9360|0.4611|

- 在该 tau 下 S2 接受最高的是 `plain`（0.7162，恰好复现 E226 的 S2 上限），但它的 LOSO 拒识只有 0.4090；LOSO 侧最好的是 `auc2W`（0.4389），此时 S2 接受已掉到 0.6811。三个方案在 S1=0.70 这个截面上，LOSO 拒识都在 0.41–0.44；反过来在 LOSO>0.90 的阈值上，S2 接受只有 0.21–0.30。两个方向各差 0.3–0.5，缺口不可能靠调 tau 弥合。
