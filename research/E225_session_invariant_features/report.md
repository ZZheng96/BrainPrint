# E225 跨会话不变特征：成分账本 + strict LOSO 裁决

Train 只有 session1，无法直接测跨会话；因此用**会话漂移模拟不变性**作为代理判据，并把 **Test S2(known) vs S1(unknown) 分离 AUC** 作为最终裁决指标（基线 0.766024）。

## 1. 口径（与 E221/E224 完全一致，未改动）

- strict 20 折 subject-LOSO：每折只用 enrolled outer_train 的 trial fraction≤0.6 拟合task-wise 标准化 / PCA / k12 原型 / 阈值；评估窗口 (0.6, 0.8]；held identity 不参与任何拟合。
- 高分 = known，`score < tau` 拒识；unknown 为正类计算 rejection F1 与 AUC(-score)。
- `tau` = 折内 5 块 inner OOF known 分数的 10% 分位（global，未做身份校准）。
- `score` = 同 task 原型的 −最小欧氏距离；身份 = 最近原型身份。

- 区分度：按 task 分别算 between-subject / within-subject 的方差比（Fisher 比），再对 4 个 task 取平均，块内取维度均值。
- 稳定性：1−ICC(1)（subject 为组、trial 为观测），块内取维度均值；越小表示同一会话内越稳定。
- 漂移敏感性：10 种漂移条件全部施加在**原始波形**上后重新提特征，逐维取 |Δf| 的均值再除以该维 between-subject 标准差，最后块内取均值。
- 冗余：每块取前 8 个主成分，用一半 fit 行拟合线性映射、另一半计算多维 R²（双向平均）。

## 5. 达标判定

**未达冻结阈值，本轮不再追加新配方。** 最佳候选 `all_blocks` 的 Test 分离 AUC=0.787784（基线 0.766024，提升 +0.021760），LOSO AUC=0.908551；Test S1 拒识=0.824926（≥0.70），S2 接受=0.535331（<0.70）。但 S1 拒识≥0.70 时 S2 上限只有 0.674628（基线 0.680144），说明分离 AUC 的小幅提升没有转化为可用工作点。账本证据：区分度/漂移比最高的是 `bandpower_gainfree`（Fisher=1.2785，漂移=0.3071），最低的是 `pac`（Fisher=0.0390，漂移=1.3351）；`trial_energy` 的 Fisher=0.9748、漂移=0.6507。把增益-free / 谱形 / 谱斜率等块拼进 corr_logSPD 能小幅提高跨会话可分性，而按 F/D 比值裁剪维度反而下降（96 维与 192 维均低于基线），说明瓶颈不是可筛掉的增益类漂移，因此按预设判据在此停止。

## 7. 限制

- 无真实 session2 训练数据：全部"不变性"结论来自合成漂移，不能等同于真实跨会话泛化。
- 漂移模拟只覆盖增益/倾斜/噪声/重参考/重采样/带通边缘 6 类共 10 种条件，真实会话漂移还含电极位移、阻抗变化、被试状态变化等未建模因素。
- 账本用的是块内维度均值与块级 R²，块内异质性会被平均掉；`high_disc_low_drift` 的逐维排序已按折内 fit 行重算，不存在把 held identity 用于排序的泄漏。
- Test 被反复查看；本轮候选与全部参数预先写在 config.json，未按 Test 选型，但偏倚仍在。
- 官方 Test AUC/F1 无身份标签，**N/A**；S1/S2 是会话分层行为指标，不等同官方未知/正常分类指标。
- 运行：`.venv\Scripts\python.exe research/E225_session_invariant_features/run_e225.py`（CUDA）。
