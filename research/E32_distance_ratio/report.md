# E32：距离比率类判据

日期：2026-11-12
状态：完成。结论：**dist + ratio 把 Test AUROC 提到 0.7403（目前最高），但相关工作点没有改善；gap 方向反了。**

## 0. 判据

在 E31 最优空间（任务特异模型 + 任务内 WCCN）里，比较三种「越大越新颖」的量：

| 判据 | 定义 | 直觉 |
|---|---|---|
| dist | d1（最近类中心距离） | 未知样本离所有已知身份都远 |
| ratio | d1/d2 | 未知样本两类距离都大且接近，比率趋近 1 |
| gap | d2 − d1 | 未知样本间隔小（**方向应为负**） |

## 1. 结果

| 组合 | 内层 AUROC | Test AUROC | q01 S2 / S1 | q05 S2 / S1 |
|---|---:|---:|---|---|
| dist | 0.7119 | 0.7273 | 0.917 / 0.509 | 0.840 / 0.558 |
| ratio | 0.9145 | 0.7284 | 0.722 / 0.604 | 0.283 / 0.917 |
| gap | 0.0809 | 0.3710 | 1.000 / 0.000 | 0.998 / 0.004 |
| **dist+ratio** | — | **0.7403** | 0.894 / 0.506 | 0.644 / 0.674 |
| dist+gap | — | 0.6702 | 0.996 / 0.008 | 0.991 / 0.021 |
| ratio+gap | — | 0.6795 | 0.988 / 0.036 | 0.981 / 0.051 |
| dist+ratio+gap | — | 0.7119 | 0.988 / 0.040 | 0.977 / 0.072 |

**发现：**

1. `ratio` 的内层 AUROC 高达 0.9145，但内层与 Test 差距大（0.7284）；它的工作点很陡——
   S2 接受 0.722 时 S1 拒识 0.604，再严一点 S2 就崩。
2. `gap` 方向与假设相反（内层 AUROC 0.0809），加进融合会严重拖累（0.67–0.68）。
3. `dist+ratio` 的 Test AUROC 0.7403 是当前最高，但 q01 的 S2 接受只有 0.894。

## 2. 与之前最优的工作点对比

在 S2 接受 ≈ 0.90 附近比较：

| 方案 | S2 接受 | S1 拒识 |
|---|---:|---:|
| E26 原始协方差 dist | 0.845 | 0.467 |
| E29 DINO cov5 dist | 0.883 | 0.530 |
| E31 task_model_wccn | 0.890 | 0.528 |
| E32 dist+ratio | 0.894 | 0.506 |

**在相同 S2 接受率下，E29/E31 的 S1 拒识最好（0.53）。** E32 的 AUROC 更高，
但增益集中在高拒识区，不在工作区。

## 3. 结论

- AUROC 从 0.7063（E29）→ 0.7327（E31）→ 0.7403（E32），但**工作点几乎不变**。
- 判据层面的改进已到边际收益接近零的位置。
- 下一步只剩表征层面的改造：DINO 特征微调（ArcFace 角间隔损失），
  或更换更强的图像表示。这是唯一还能实质提高 AUROC 的方向。
