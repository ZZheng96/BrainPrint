## 结论

### 1. LOSO AUC 与 Test AUC 负相关，不能用来做模型选择

| 视图 | LOSO AUC | Test AUC |
|---|---:|---:|
| E21_covdz k=3 | **0.9810** | **0.4810** |
| E65_logspd k=3 | 0.9702 | 0.7575 |
| E62_cov8 k=3 | 0.8873 | 0.7470 |
| E62_corr8 k=1 | 0.7352 | 0.7151 |
| DINO_corr k=1 | 0.5865 | 0.4959 |

按 LOSO AUC 贪婪选出的 `E21_covdz_k3 → E65_logspd_k3` 融合，LOSO AUC 0.9825，但 **Test AUC 只有 0.6408**；反过来 Test AUC 最高的 all_equal（0.7895）在 LOSO 上并不突出。

原因是 LOSO 与 Test 检验的是不同的东西：LOSO 全部在同一个会话内（原型用 0.6 前的块，测试用 0.6–0.8 的块），而 Test 是跨会话。**在本项目里，凡是 LOSO 特别高的表征，恰恰是同会话过拟合最强的表征。**

结论：后续所有模型/视图选择都不能以 LOSO 为准则。三项指标中的 LOSO 只能作为必须达标的约束，不能作为优化信号。

### 2. 分数级融合能提高 Test AUC，但破坏阈值校准

等权融合 14 个视图把 Test AUC 从 0.7575 抬到 **0.7895**，但融合后的 z 分数在 Test 上整体落到 Train OOF 参考的 40 分位以下，导致所有接受率下 S2 接受都是 0。

根因是 **Train 的 out-of-fold 参考被高估**：一个 out-of-fold trial 的原型里含有它本被试、本会话约 80% 的兄弟 trial；Test trial 从来没有这个优势。E138 量化出这个偏移约 **-1.3 个标准差**。

### 3. 对当前目标的最好结果

| 方案 | LOSO | Test S1 拒识 | Test S2 接受 | 三项均值 |

| E136 P96_LDA48 @0.95 | 0.9810 | 0.8978 | 0.2700 | 0.7163 |
| E137 greedy（LOSO 选） | 0.9974 | 0.7794 | 0.4615 | 0.7461 |
| **E138 d1 + 全量 Train 原型 k=3 @0.85** | **0.9867** | **0.8665** | **0.4820** | **0.7784** |

真正的增益来自 E138：**原型改用全量 Train（而非 60% 拟合块）**。
