## 4. 结论

1. **s1/s2 的高计数来自元数据，不是 EEG 能力。** #9/#10 满分是“session1 → 0”直接构造的；把这条规则拿掉（s3），同一族特征在 Test 上 S2 接受率只有 0.1742。
2. **#5/#6 的领先不可比。** s1 的 0.9803/0.9567 与 s3 的 0.9921/0.9866 都来自训练集内的 subject holdout；E191 的 0.8835/0.3292 是严格 LOSO。同口径下，协方差族在 strict LOSO 的 AUROC 约 0.907（E65），不是 0.98。
3. **身份头 E191 更好。** 含拒识的 C：s1/s2 0.9228、s3 0.9361、E191 0.9884；macro-F1 同向。
4. **对抗项四次提交全部不合格。** 但决赛说明第八节写明“本次决赛不包含对抗样本”，因此 #7/#8 不应作为决赛选型依据。
5. **当前 AUC / F1**：决赛官方 N/A；E191 训练侧 C 0.9884、macro-F1 0.9882、LOSO AUROC 0.8835；s1 同协议 unknown AUROC 0.9803、unknown F1 0.9473 但不可迁移到 Test。
