# BrainPrint：现状、不足、难点与解决方案

日期：2026-11-14（E72–E86 复盘后更新）  
范围：现有官方 Train/Test、10 项研发门禁、图像化与纯 EEG 两条路线、外部多 Session 路线（E72–E86）。  
目标：明确当前瓶颈，并形成以 Test 跨会话泛化和未知拒识为第一优先级的改进方案。

## 0. 核心判断

当前真正的问题不是分类器不够强，而是**训练目标与 Test 任务错位**：模型已经能够在同 Session 内区分 20 名注册者，却尚未学会“跨 Session 判断一段 EEG 是否属于注册库中的某个具体身份”。

因此，继续调阈值、换普通分类头或堆叠 Test 后处理，很难解决核心问题。后续突破点应是：

> **外部多 Session 监督 + 跨 Session 身份验证式开放集学习 + 两条路线互补。**

**2026-11-14 更新**：上述方向已在 E72–E86 中执行完毕。外部跨 Session 监督与身份验证式匹配确实把外部检测 AUC 提到 0.9764、EER 降到 0.0692，但 known/unknown 分布重叠未消除，项目 Test 的 S1/S2 两项门禁仍未通过。当前真正的缺口已从"缺少跨 Session 表征"转为**"外部表征无法迁移到项目 18 通道 Test，且 Test S2 存在严重过度拒识"**。详见 §2.4、§3.5、§3.6、§5.6。

## 1. 目标与证据边界

### 1.1 评分与门禁

官方评分公式：

```text
Score = 100 × C^0.40 × (0.7 × RA + 0.3 × ASafeR)^0.35 × U^0.25
```

当前仍需以全部 10 项门禁为最终目标，其中第一优先级是：

- Test Session2 拒识率 **≤2%**；
- Test Session1 拒识率 **≥95%**。

其余目标包括 Train 拟合准确率、折外 C、身份 macro-F1、连续时间块准确率、pseudo-unknown AUROC、U@95、RA 和 ASafeR，详见[研发目标与量化验收指标](研发目标与量化验收指标.md)。

### 1.2 不可突破的边界

1. 身份与拒识只能根据单条 EEG 样本决定，禁止使用 Session 编号、文件顺序、样本数量、正常/对抗分组或近重复配对。
2. 未知拒识必须通过 Train 留被试 pseudo-unknown 和独立内层标定完成。
3. Test 不参与训练、调参、阈值选择或模型选择，只在候选冻结后审计。
4. 允许使用外部公开 EEG 数据、自监督预训练和新骨干，但必须保留独立验证。
5. 当前只针对现有 Train/Test，不扩展决赛现场注册和在线推理需求。

## 2. 现状

### 2.1 数据与官方反馈

- Train：20 名注册者的 Session1，共 **11,304** 条；没有带标签的跨 Session 训练数据。
- Test：共 **22,251** 条，无公开真实身份标签。
- Test S1 为 5 名未注册者、S2 为注册者正常及对抗样本属于**强推断**，不是公开真值。
- 历史最高官方分为 **69.17**，但使用了 `Session1 → 0`，不能证明 EEG 开放集能力。
- 合规的第 3 次候选官方分为 **26.10**，主要问题是过度拒识。
- Test 的真实 AUC、F1、C、RA、ASafeR、U 均为 **N/A**，原因是没有公开真实标签。

### 2.6 结果解释注意事项

上述“最佳”数字来自不同实验、模型和配置，**不代表已经存在一个同时取得全部最佳值的候选**。E70 的部分结果还是单折、小样本口径，不能与完整五折结果直接等同。

**指标命名勘误**：E77/E78/E79/E81/E84 曾把外部 `known_acceptance` 命名为 `S1`、`unknown_false_acceptance` 命名为 `S2`，这是错误的。S1 只指项目 Test Session1 拒识率，S2 只指项目 Test Session2 拒识率；外部指标必须写 `known acceptance`、`unknown false acceptance`、`unknown rejection`。数值本身未算错，错在命名与门禁映射。

**口径不一致**：E82 的 `unknown_F1` 使用 `pos_label=1`（known 接受类），E86 统一 schema 使用 `pos_label=0`；E75 的 `C` 为不含拒识的 argmax 准确率。后续统一为 `unknown-F1` 用 `pos_label=0`、`C` 含拒识。

**数值可信性**：E86 为 E73–E84 补齐逐样本 `outer_test_predictions.csv`，从落盘 CSV 重算与各 `results.json` 的最大绝对误差 ≤1.1e-16，逐样本标签、阈值、拒识标记一致。上述问题属于命名与口径，不是计算错误。

详见[E72–E86 外部实验总结与 Test 指标问题](../.trae/documents/E72-E86外部实验总结与Test指标问题.md)。

## 3. 主要不足

### 3.1 跨 Session 身份表征尚未建立

Train 内闭集识别接近满分，但 Test 大量误拒，说明模型仍依赖会话相关的协方差、频谱或采集特征。

已有实验基本排除了以下简单解释或修补方式：

- 全局幅度、频带功率和通道增益缩放；
- CAR、Cz、拉普拉斯等参考变换；
- 普通域随机化；
- 单调分数校准和秩映射；
- 多窗口图像；
- 单纯提高图像分辨率。

因此，不能期待仅靠另一种归一化或后处理解决问题。

### 3.2 未知拒识的训练定义与真实任务不完全一致

E67/E68 主要训练“某批被试为已知、另一批被试为未知”的二分类器。不同留出组合学到的方向接近正交，迁移到 Test 后接近随机。

真实任务并不是判断某种抽象的“注册群体属性”，而是：

> **这条 EEG 是否与注册库中某个具体身份的模板足够匹配？**

因此，后续应优先研究身份验证和度量学习，而不是继续训练通用的“注册/未注册”二分类器。

### 3.3 clean、对抗与开放集能力仍然分裂

- DINOv2：clean 强，RA 弱。
- DINOv3：RA 较强，但 clean C 明显下降。
- 原始波形 CNN：对抗识别较强，单独未知拒识较弱。
- logSPD：Train 内拒识强，Test 跨 Session 失效。

目前缺少能够同时支撑 C、RA、ASafeR 和 U 的统一表征与决策机制。

### 3.4 Train 内部验证与 Test 目标存在断层

Train 的 pseudo-unknown AUROC 可达到 0.998，但对应的 Test 拒识分数几乎失效。这说明当前内部验证虽然流程严格，却没有充分覆盖真实的跨 Session 难度。

### 3.5 外部预训练已尝试，但未解决分布重叠（E72–E86）

§5.3 提出的"外部多 Session 预训练"已实际执行，结论是**必要但不充分**：

- 外部跨 Session 监督确实把 detection AUC 从约 0.76 提到 0.9764、EER 降到 0.0692，说明跨 Session 表征可以学到。
- 但 known 与 unknown 的置信分布仍然重叠：E83 审计的可行 operating point 为 0；E82 用 pseudo-unknown 选阈值后 FAR 0.0938 时 known acceptance 只剩 0.6936。
- 逐身份阈值（E78）、EVT 尾校准（E81）、pair head（E79/E84）、min 融合（E80）都只改变工作点位置，没有改变重叠本身。
- 图像化路线在外部数据上同样失败（E75 AUC 0.4640），与 E62 结论一致。

因此"换外部数据 + 换匹配头"这一层已经探索完毕，下一步必须改变**未知样本的构造方式或表征目标**，而不是继续在同一分数上找阈值。

### 3.6 优化方向与项目 Test 瓶颈错位

项目 Test 的瓶颈是 S2 过度拒识（70–85%，需 ≤2%），即注册者被大量误拒。而 E74–E84 的主攻方向是"提高外部 known acceptance"，且该指标与 unknown FAR 同向上升（E80：0.9644 / 0.2569）。即使外部指标继续提升，直接迁移到项目 Test 也只会加剧 S2 的过度拒识。

后续实验必须以"项目 Test 的 S1/S2 是否改善"为唯一验收口径，外部指标只能作为代理并明确标注。

## 4. 核心难点

### 4.1 官方 Train 缺少跨 Session 监督

只有 Session1，无法直接从官方 Train 学到“同一身份跨天哪些特征不变、哪些特征会变化”。这是 Test 优先攻关最大的结构性限制。

### 4.2 Test 工作点要求苛刻

需要同时满足 S2 拒识率 ≤2% 和 S1 拒识率 ≥95%，要求可迁移的区分能力接近 AUROC 0.99。现有拒识分数的 Test S1/S2 诊断最高约为 0.73–0.74，仍有明显差距。

同时，S2 包含正常和对抗样本，系统既要少拒正常样本，也不能靠大量拒识对抗样本换取 ASafeR。

### 4.3 Test 不能反复用于调参

如果每轮都观察 S1/S2 结果再修改模型，Test 实际上会变成开发集。模型选择必须依赖 Train 和外部数据的独立验证，Test 只用于冻结后审计。

### 4.4 “不可达”结论不能被过度外推

E67/E68 对现有特征、线性探针和留出被试二分类策略提供了很强的负证据，但没有覆盖：

- 外部多 Session 预训练；
- 跨 Session 身份验证；
- 非线性度量学习；
- 新型 EEG 编码器。

准确结论是：**现有方法尚未解决，而不是所有可能方法在数学上均被证明不可达。**

### 4.5 外部预训练已排除其中两项（E72–E86 更新）

上表前两项已在 E73–E84 中实际验证：

- **外部多 Session 预训练**：E73/E74 完成，detection AUC 0.9243/0.9226，EER 0.1331/0.1444，优于旧路线但未达门禁。
- **跨 Session 身份验证**：E79/E84 的 sample–template pair head 完成，known acceptance 可达 0.9557，但 unknown FAR 0.27 左右。

仍未覆盖的是：**未知样本的构造方式**（当前只用留出被试做 pseudo-unknown，与真实"未注册者"分布可能不同）、**非线性度量学习的新目标**、以及**通道数不匹配下的跨数据集迁移**（外部 22 通道 → 项目 18 通道）。

因此 §4.4 的结论需要收窄为：**外部预训练与跨 Session 身份验证这两条路径已尝试且未达标；剩余未验证的是未知构造方式与跨通道迁移。**

## 5. 推荐解决方案

### 5.1 总体架构

```text
原始 EEG ─→ 纯 EEG 编码器 ─┐
                           ├→ 跨 Session 身份嵌入
协方差/频谱图像 → 图像编码器 ┘          │
                                      ├→ 与 20 个注册模板逐一匹配
                                      ├→ clean/robust 身份分数融合
                                      └→ 最大匹配不足时输出 0
```

关键不在于必须采用双分支，而在于让两条路线共同学习**跨 Session、面向身份验证的嵌入空间**。

### 5.2 将开放集识别改为跨 Session 身份验证

训练时构造：

- 同一身份、不同 Session 的样本对作为正样本；
- 不同身份的样本对作为负样本；
- 样本与身份模板之间的 same/different 匹配任务。

推理时：

1. 从官方 Train 为 20 名注册者建立身份模板；
2. Test 样本与 20 个模板分别计算匹配分数；
3. 最大匹配分数不足则输出 0；
4. 否则输出最匹配身份。

该方式学习的是可迁移到新身份集合的匹配规则，而不是记住“哪 20 人属于注册者”。

### 5.3 使用外部多 Session EEG 数据补齐监督

外部数据筛选标准：

- 同一被试具有多个 Session；
- Session 间存在真实时间间隔；
- 具有被试身份标签；
- 通道和任务能够映射到当前数据，或可配合通道掩码/投影训练。

预训练目标可包括：

- supervised contrastive learning；
- 跨 Session 正样本对比学习；
- 样本—身份模板匹配损失；
- 掩码信号重建辅助任务；
- Session 去混淆辅助任务。

外部预训练只是必要条件之一，不是直接保证。E66 已说明，未经身份和跨 Session 定向适配的冻结 EEG 基础模型可能明显退化。

**执行结果（E73–E84）**：上述目标已全部实现并验证。跨 Session SupCon（E74）、样本—模板匹配损失（E79/E84）、外部多 Session 预训练（E73）均已完成。结论是：**外部预训练能显著提升检测能力（AUC 0.76→0.976），但不能消除 known/unknown 分布重叠**。因此本节的方案已被证明为必要但不充分，不能作为唯一主攻方向。

### 5.4 两条路线分别编码，再进行受控融合

- 纯 EEG 分支保留时序细节及 OE-EEGNet 的对抗优势。
- 图像分支使用多频带协方差或频谱图，但允许微调或更换骨干，不再局限于冻结 DINO。
- 融合只在外层跨 Session、伪未知和攻击验证同时改善 C、RA、ASafeR、U 时保留。

不建议仅简单平均 DINOv2/v3 logits；更值得研究共享身份验证目标下的联合训练或匹配分数融合。

**执行结果（E75/E77/E80）**：图像化分支在外部数据上失败（E75 AUC 0.4640）；cosine+Mahalanobis 等权融合（E77 AUC 0.9682）低于单用 Mahalanobis（E76 0.9764）；min 融合（E80）把 id-F1 提到 0.9814 但 unknown FAR 升到 0.2569。**受控融合未带来门禁突破。**

### 5.5 保留三段式思想，替换其核心表征

现有三段式已经证明 clean 与受扰动样本分工有效，可保留：

- clean 区域：高精度身份分支；
- 受扰动区域：对抗训练分支；
- 低匹配区域：未知拒识。

需要替换的是负责跨 Session 和拒识的 logSPD 表征，而不是推翻整个三段式系统。

### 5.6 下一步方向（E72–E86 复盘后新增）

已排除的路径：换外部数据、换匹配头、逐身份阈值、EVT 尾校准、分数融合、图像化骨干。这些只改变工作点位置，不改变分布重叠。

剩余值得验证的方向，按优先级：

1. **改变未知样本的构造方式**：当前 pseudo-unknown 全部来自"留出被试"，与真实未注册者分布可能不同。可尝试用同一被试的其他任务/其他时段构造 hard unknown，或引入真实未注册者数据。
2. **跨通道迁移**：外部 22 通道 → 项目 18 通道的通道掩码/投影训练，使外部预训练权重能真正用于项目 Test 推理。这是当前"外部结果无法用于项目 Test"的直接原因。
3. **直接针对项目 Test S2 过度拒识**：在项目 Train 上做跨任务/跨时段的注册者接受率优化，而不是继续抬高外部 known acceptance。
4. **非线性度量学习新目标**：如 ArcFace/CosFace 类角度间隔、原型对比 + 硬负样本挖掘的组合，需在外部留被试验证后再迁移。

## 6. 推荐推进顺序与验收

| 阶段 | 工作 | 状态 | 保留/推进依据 |
|---|---|---|---|
| 1 | 用现有特征实现样本对/模板匹配基线 | **已完成（E72/E79）** | 身份验证定义可行，但未解决分布重叠 |
| 2 | 筛选外部多 Session 数据并预训练两条编码器 | **已完成（E73/E74/E75）** | 纯 EEG 有效，图像化失败 |
| 3 | 比较纯 EEG、图像化及融合候选 | **已完成（E76–E84）** | E76 综合最强，融合无增益 |
| 4 | 接入对抗训练和三段式决策 | 未在本批执行 | 不以牺牲 C、U 或 ASafeR 为代价提高 RA |
| 5 | 冻结唯一候选后审计 Test | **已完成（E85）** | S1 58–59%、S2 70–85%，均未通过 |
| 6 | 跨通道迁移 + 未知构造方式改造 | **待执行** | 唯一能直接改善项目 Test 的路径 |

所有阶段均应报告 AUC 和 F1；无真实标签时明确写 N/A。不得用 Test 审计结果反向选择阶段 1–4 的模型或阈值。

**验收口径收紧**：阶段 1–5 的外部指标只能作为代理。任何新实验必须明确回答"项目 Test 的 S1/S2 是否变化"，否则不得声称优化了 Test 指标。

## 7. 不再作为主攻方向的内容

- 旧分数和阈值的反复扫描；
- 普通冻结 DINO 探针的边际改造；
- 依赖 Session、文件顺序、批次结构或近重复配对的规则；
- 仅针对 Test 的分数校准和后处理；
- 只提高 Train 代理分而不改善跨 Session 证据的模型堆叠；
- **（E72–E86 新增）** 在外部 22 通道数据上继续堆叠 open-set head、逐身份阈值、EVT 校准或分数融合；
- **（E72–E86 新增）** 把外部 `known_acceptance` / `unknown_false_acceptance` 当作项目 Test 的 S1/S2。

## 8. 最终判断

两条路线已有较强的同 Session 识别与训练侧开放集基础，纯 EEG 路线还接近训练侧对抗门禁；但两者共同缺少可迁移的跨 Session 身份验证能力。

E72–E86 已按原计划验证了"外部多 Session 预训练 + 跨 Session 身份验证"这一核心假设，结果是：**检测能力显著提升，但 known/unknown 分布重叠未消除，项目 Test 两项门禁仍未通过。**

下一阶段不应继续围绕旧阈值或外部代理指标做局部优化，而应集中验证：

> **能否把外部学到的跨 Session 表征真正迁移到项目 18 通道 Test 上，并直接降低 Test S2 的过度拒识（当前 70–85%，目标 ≤2%）。**

这是同时改善 Test 两项门禁的关键方向，也是本批实验暴露出的最大缺口。
