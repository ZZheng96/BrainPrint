# E234 相对分数（margin / ratio / mix）能否抵消跨段偏移并救回 Test S2

> **一句话结论**：**相对分数在此数据上无效（方向正确但量级远不够）**：最优相对候选 `ratio` 的 Test S2 = **0.3496**（E233 合规值 0.3122，+0.0375），落在 0.3122~0.45 的边缘区间，距 0.60 差 0.2504，且 S1 同时被拖低。

全部候选沿用 E228 冻结管线（表征、原型、OOF、阈值规则），只改**打分规则**；每个候选的 tau 都由 Train 侧二分标定到 pooled LOSO 未知拒识 = 0.90（E228 同口径），Test 只读一次。`abs_dist` 用 E228 冻结 tau，用于**逐位复现 E233 的 0.312155 / 1.0 / 0.879522**。

## 6. 判定

- **相对分数在此数据上无效（方向正确但量级远不够）**：最优相对候选 `ratio` 的 Test S2 = 0.3496（E233 合规值 0.3122，+0.0375），落在 0.3122~0.45 的边缘区间，距用户要求 0.60 差 0.2504，同时 S1 跌到 0.7079（< 0.95）。
- **δ 抵消确实成立**（第 3 节）：`margin` 的标准化 S1−S2 gap +0.3858、`ratio` -0.0739，相对 `abs` 的 -1.2711 幅度分别只有 0.30× 和 0.06×。
- **但取消 δ 的同时把可分性一起取消了**：Test 分离 AUC 从 `abs` 的 0.8795 崩到 margin 0.4920 / ratio 0.5484，S1 拒识从 1.0000 掉到 0.6634 / 0.7079；S1≥0.95 门槛下 margin 的 S2 只有 0.0000、ratio 0.0208。
- **LOSO 侧反而是改善的**（这是最容易误判的地方）：`margin` 的已知接受 0.9074、LOSO AUC 0.9584；`ratio` 为 0.9200 / 0.9634；`abs` 为 0.8087 / 0.9096。LOSO 的"未知"是**同一 session 内被留出的已注册身份**，没有跨天平移，所以相对分数在那里是纯增益；它不能迁移到 Test 的 S1。
- **机理**：本数据里 S1 与 S2 的差别本身就是一段大平移（S1 的 (session,task) 批次均值范数 ≈ 20，S2 ≈ 4~7，见主表 cells）。相对分数把这段平移约掉，就等于把"未注册人群离所有原型都很远"这个当前唯一的拒绝依据一起约掉。在 E232 的 session/注册状态混叠下，δ 不是可去的 nuisance，而是 S1/S2 可分性的主要载体。
- **不追加第二轮（λ 与 margin+k=3）的理由**：λ 趋势单调且已饱和——mix λ=0.5 → 1.0 → margin（λ→∞）时 S2 = 0.3371 → 0.3398 → 0.3284，S1 = 0.9159 → 0.8741 → 0.6634；继续加大 λ 只会继续压低 S1，不会把 S2 推向 0.60。margin+k=3 只改 d1 侧的原型聚合，无法恢复被抵消掉的绝对位置信息，故不值得再跑一轮。
- 不冻结新部署参数；E233 的 `abs_dist`（mean_align）仍是合规最优（S2 0.3122 / S1 1.0）。

## 7. 限制与口径

- **官方 C / RA / ASafeR = N/A**：Test 无身份标签。S1 拒识/ S2 接受是赛题行为代理指标，不是官方未知检测/正常分类指标。
- **Test 反复查看偏倚**：Test 自 E65 起被反复读；本轮候选定义、λ、二分规则在运行前写死（config.json），但"在候选间比较 S2"这一动作本身读到了 Test。
- **session 与注册状态混叠**（E232）：S1 = 5 名未注册被试，S2 = 20 名注册用户。S1/S2 不是纯生物特征指标；本轮没有用 session 决定身份或门控。
- **transductive 灰区**：`*_mean_align` 候选使用被评分批次的无标签统计量做均值对齐；不带对齐的 `margin` / `ratio` / `mix` 是**逐条推理**，不需要批次统计，这一点比 E233 更干净。
- 运行：`.venv\Scripts\python.exe research/E234_offset_invariant_score/run_e234.py`（CUDA），耗时 7s；折级 d1/d2 缓存于 `cache/`，指标参数存于 `models/e234_metric_params.pt`。
