# E254：以注册匹配度为核心的严格 LOSO 方案

## 结论

本轮把拒识从「最近邻欧氏距离阈值」改成「注册模板匹配度 + 歧义度」的联合门控，并把身份排序统一到同一套 LDA-cos 几何上。严格嵌套身份 LOSO 的三项核心门禁首次同时达标：

| 指标 | 目标 | E200/final | E253/final2 旧版 | E254（本版） |
|---|---:|---:|---:|---:|
| #5 严格 LOSO pseudo-unknown AUROC | ≥ 0.98 | 0.7920 | 0.7920 | **0.9871** |
| #6 严格 LOSO U@95% | ≥ 0.95 | 0.1758 | 0.1758 | **0.9522** |
| #11 严格 LOSO 未注册拒识 @ a=0.90 | > 0.90 | 0.2947 | 0.2947 | **0.9869** |

AUC 与 F1：严格 LOSO AUC = 0.9871；5 折 OOF 20 类 macro-F1 = 0.9988；拒识 F1（unknown-positive，按 LOSO 汇总）随工作点变化，见 `results/loso_nested.json`。

## 方法

```text
18×1200 → 6×200 子窗 → 5 频带相关 logSPD → 855 维 → 子窗均值
→ 按任务 z-score → PCA-256 → 类内白化（shrink 0.95）
→ 每身份每任务 k=4 个试次顺序原型 → 白化余弦匹配
→ s1, s2 → gate = s1 + 0.5*(s1 - s2) → gate < τ 判未注册
```

关键变化：

1. **注册**：每身份注册 4 个原型而不是 1 个均值，把类内变化（试次顺序块）也纳入注册模板。
2. **匹配**：排序与拒识共用同一白化余弦几何，不再出现「排序用余弦、拒识用欧氏」的双空间割裂。
3. **拒识**：显式使用绝对匹配度 `s1` 和歧义度 `s1-s2`，而不是「先找最近原型、再拿距离比阈值」。这正是「匹配度分数 + 是否足够匹配」的判决方式。
4. **阈值**：`τ = 0.407559`，Train 交叉拟合真实样本 gate 分数的 10% 分位（90% 接受率），不使用 Test。

## 严格嵌套 LOSO 协议

- 外层 20 折，留出身份完全不参与任务标准化、PCA、白化、原型、阈值。
- 外层训练池内再做 19 折身份留出，用于内层选择配置（共 380 个内层折）。
- 原型只用 `frac ≤ 0.4` 拟合、校准用 `0.4 < frac ≤ 0.6`、评估用 `frac > 0.6`，查询不进入自己的原型。
- 候选网格预先固定：dim ∈ {192, 256}、shrink ∈ {0.9, 0.95}、k ∈ {3, 4}、beta ∈ {0, 0.5}。

内层选择结果：17/20 折选 `d256_s0.95_k4_b0.5`，2 折选 `d192_s0.95_k4_b0.5`，1 折选 `d256_s0.9_k4_b0.5`。

外层汇总：

| 指标 | 均值 | 最差单身份 |
|---|---:|---:|
| AUROC | 0.9871 | 0.9588（7 号） |
| U@95% | 0.9522 | 0.7432（7 号） |
| 未注册拒识 @ a=0.90 | 0.9869 | 0.8682（7 号） |

7 号身份是唯一明显偏弱的折，其余 19 折 U@95% 均在 0.89 以上。

| 未注册拒识率 | 0.7108 | 0.7227 | 0.5918 |

Test 分数分布（冻结模型）：

| 分组 | s1 的 10/25/50/75/90 分位 |
|---|---|
| Test 已注册 | 0.153 / 0.180 / 0.223 / 0.290 / 0.403 |
| Test 未注册 | 0.148 / 0.171 / 0.219 / 0.611 / 0.668 |

已注册与未注册的 s1 中位数几乎相同（0.223 vs 0.219），未注册在 75 分位以上反而更高；因此在初赛 Test 上，任何基于该绝对分数的门控都无法同时做到「接受大多数已注册」和「拒绝未注册」。

## 为什么 LOSO 达标与 Test 接受率冲突

这不是阈值没调好，而是两类未知的分布不同：

- Train LOSO 的 pseudo-unknown 与已注册身份同 session、同设备，欧氏距离重叠严重（E253 实测 #11 = 0.295）；白化余弦能把它们分开（#11 = 0.987）。
- 初赛 Test 的已注册样本跨 session 且含对抗扰动，白化把 session 相关方向放大，导致所有已注册分数整体下移；而未注册样本中有一部分反而更贴近原型。排序仍正确（接受样本 top-1 0.931），但绝对分数不再可比。

同一 Test 上，欧氏拒识能接受 0.70 已注册样本，却在严格 LOSO 上只有 0.29 拒识率。两者不可兼得，本轮按用户给定的优先级选择 LOSO。

为压缩这个冲突，额外验证了四种**只依赖单条 query 自身分数结构**的门控（abs / relz / gapz / soft），它们都不使用批次统计量：

| 门控 | LOSO AUROC | U@95% | rej90 | Test 接受率 |
|---|---:|---:|---:|---:|
| abs（采用） | 0.9870 | 0.9518 | 0.9869 | 0.173* |
| relz | 0.9821 | 0.9200 | 0.9718 | 0.282* |
| gapz | 0.9788 | 0.9156 | 0.9779 | 0.205* |
| soft | 0.9865 | 0.9505 | 0.9887 | 0.170* |
| 欧氏（对照） | 0.8720 | 0.3264 | 0.5279 | — |

\* 该列用 Train 汇总 10% 分位作阈值；部署包用 0.407559，得到 0.2242。

还测试了「欧氏分支 + 相对分数保护」的双分支门控：可以恢复部分 Test 接受率，但 LOSO 未注册拒识降到 0（pseudo-unknown 大量通过欧氏分支）。

## 补充实验：特征成分敏感性（严格 LOSO）

固定 E254 判决规则（PCA≤256、shrink 0.95、k=4、gate s1+0.5margin、a=0.90），只替换特征：

| 变体 | 维度 | AUROC | U@95% | rej@90 |
|---|---:|---:|---:|---:|
| 全部 5 频带（采用） | 855 | **0.9870** | **0.9518** | **0.9869** |
| 去掉 30–40 Hz | 684 | 0.9824 | 0.9202 | 0.9760 |
| 去掉 1–8 Hz | 684 | 0.9771 | 0.8757 | 0.9630 |
| 仅 1–20 Hz | 513 | 0.9712 | 0.8473 | 0.9447 |
| 仅 8–30 Hz | 513 | 0.9656 | 0.7849 | 0.9226 |
| 仅 20–40 Hz | 342 | 0.9332 | 0.5596 | 0.7838 |

| 子窗聚合 | AUROC | U@95% | rej@90 |
|---|---:|---:|---:|
| 6 窗均值（采用） | 0.9870 | 0.9518 | 0.9869 |
| 6 窗中位数 | 0.9804 | 0.9080 | 0.9727 |
| 仅前 3 窗 | 0.9637 | 0.7846 | 0.9160 |
| 仅后 3 窗 | 0.9601 | 0.7557 | 0.9010 |

结论：现有配置已经在该消融网格的最优点。**30–40 Hz 有正贡献，不应降权**；1–8 Hz 是单个最重要的频带；时间覆盖比稳健聚合更重要，减到 3 个子窗会明显掉点。逐通道消融需要从原始 EEG 重新提特征，本轮未做。

## 补充实验：Train 内伪会话去漂移（NAP）

把每个受试者每个任务的前 30% 与后 30% 试次当作两个伪会话，估计“块间差异 / 块内方差”最大的方向，并在白化空间去掉前 r 个方向，再重跑严格 LOSO：

| r | AUROC | U@95% | rej@90 | 最差折 |
|---:|---:|---:|---:|---:|
| 0（基线） | 0.9870 | 0.9518 | 0.9869 | 0.8682 |
| 4 | 0.9868 | 0.9528 | 0.9877 | 0.8834 |
| 8 | 0.9863 | 0.9486 | 0.9860 | 0.8801 |
| 16 | 0.9860 | 0.9424 | 0.9840 | 0.8986 |

r=4 的 Test 审计：接受率 0.2305、未注册拒识 0.5915、接受样本 top-1 0.9287（基线 0.2242 / 0.5918 / 0.9306）。

结论：伪会话方向确实存在，但对严格 LOSO 只有 +0.0008 的边际收益，对 Test 的 S1/S2 几乎没有影响。说明 Train 内部时间块之间的漂移远小于真实跨会话漂移，NAP 无法代替真实跨会话校准。因此**不引入 NAP**，final2 保持 r=0 的现有配置。

## 补充实验：在 E237 基础上提高 LOSO（E255）

E237 的 EEG 分支是「E233 mean_align + 欧氏最近原型 k=12」，LOSO AUC 0.9088、固定 LOSO=0.90 的拒识 0.9000。本轮保留 E237 的 20 折窗口（2,301 行）、元数据顺序和图像视图缓存分数，只把 EEG 判决层换成 E254 的 LDA-cos + 匹配度门控。

### LOSO（同一个 E237 折窗口，逐折重拟合）

| 分支 | LOSO AUC | rej@90 | 最差折 |
|---|---:|---:|---:|
| E237 原 EEG 分支（欧氏 k=12） | 0.9088 | 0.9000 | — |
| E254 判决层，仅 EEG | **0.9935** | **0.9962** | 0.9516 |
| 仅 X_mw_cov4 | 0.5808 | 0.1686 | 0.0000 |
| 仅 X_covariance_hr | 0.7052 | 0.2034 | 0.0081 |
| 仅 X_correlation | 0.7198 | 0.2574 | 0.0248 |
| EEG + X_mw_cov4 50/50 | 0.9145 | 0.6428 | 0.2661 |
| EEG + X_covariance_hr 50/50 | 0.9453 | 0.8786 | 0.5484 |
| EEG + X_correlation 50/50 | 0.9521 | 0.8846 | 0.6721 |
| EEG + X_mw_cov4 70/30 | 0.9733 | 0.9750 | 0.8145 |
| EEG + X_covariance_hr 70/30 | 0.9789 | 0.9863 | 0.8468 |
| EEG + X_correlation 70/30 | 0.9841 | 0.9910 | 0.9435 |

结论：判决层移植把 LOSO 从 0.9088 提到 **0.9935**；再把任何图像视图加回来都会降低 LOSO，且只有 X_correlation 在 70/30 时仍 ≥0.98（0.9841）。

### Test（同一 LOSO 标定阈值，raw 视图，未做转导对齐）

| 分支 | Test S1 拒识 | Test S2 接受 |
|---|---:|---:|
| 仅 EEG（τ=0.4291） | 0.5925 | 0.1588 |
| X_mw_cov4 50/50 | 0.8177 | 0.3841 |
| X_covariance_hr 50/50 | 0.9228 | 0.2502 |
| X_correlation 50/50 | 0.6518 | 0.2386 |
| X_mw_cov4 70/30 | 0.8335 | 0.1819 |
| X_covariance_hr 70/30 | 0.7669 | 0.1604 |
| X_correlation 70/30 | 0.5958 | 0.1536 |

关键取舍：能同时抬高 Test S1/S2 的组合（X_mw_cov4 50/50：S1 0.818、S2 0.384）会把 LOSO 打到 0.643；保住 LOSO ≥0.98 的组合（X_correlation 70/30）对 Test 没有增益。这与 E239 的结论一致：固定 LOSO 时，改变的是分数尾部形状，不是可部署的接受余量。

注意：这里的「仅 EEG」S2=0.1588 与提交包的 0.2242 不同，原因是本窗口的 τ（0.4291）与冻结包（0.4076）不同，属于 E237 折窗口口径，不是包内数字。

## 补充实验：抬高 Test 型融合方案的 LOSO（E256）

对 E255 中 Test 表现较好的两个视图，扫描「提高 EEG 权重、min、soft-and、veto」四类规则，所有阈值仍只用 Train 已知行标定。LOSO 三项门禁 = AUC≥0.98、U@95≥0.95、rej@90>0.90。

| 融合 | LOSO AUC | U@95 | rej@90 | Test S1 | Test S2 | LOSO 门禁 |
|---|---:|---:|---:|---:|---:|---|
| 仅 EEG | 0.9935 | 0.9789 | 0.9962 | 0.592 | 0.159 | 通过 |
| X_mw_cov4 50/50 | 0.9145 | — | 0.6428 | 0.818 | 0.384 | 失败 |
| X_mw_cov4 70/30 | 0.9733 | 0.968 | 0.9750 | 0.833 | 0.182 | AUC 失败 |
| **X_mw_cov4 80/20** | **0.9861** | **0.9605** | **0.9903** | **0.701** | **0.155** | **通过** |
| X_mw_cov4 85/15 | 0.9895 | 0.9718 | 0.9937 | 0.616 | 0.145 | 通过 |
| X_covariance_hr 50/50 | 0.9453 | — | 0.8786 | 0.923 | 0.250 | 失败 |
| X_covariance_hr 80/20 | 0.9863 | 0.9637 | 0.9926 | 0.698 | 0.144 | 通过 |
| X_correlation 80/20 | 0.9906 | 0.9776 | 0.9949 | 0.593 | 0.139 | 通过 |
| X_mw_cov4 min | 0.9526 | 0.6408 | 0.9548 | 0.973 | 0.183 | AUC 失败 |
| X_mw_cov4 soft-and | 0.9501 | 0.5694 | 0.9419 | 0.961 | 0.205 | AUC 失败 |
| X_mw_cov4 veto(5%) | 0.9497 | 0.1101 | 0.9836 | 0.961 | 0.035 | AUC 失败 |

结论：

1. **Test 型融合的 LOSO 可以抬到门禁内**，代价是把 EEG 权重提到 80%。50/50 的 Test 优势（S1 0.82、S2 0.38）在 80/20 下只剩 S1 的 0.70，S2 回到基线。
2. 最优折中是 **X_mw_cov4 80/20**：LOSO AUC 0.9861 / U@95 0.9605 / rej@90 0.9903 全部通过，Test S1 从 0.592 提到 0.701，S2 基本不变（0.159→0.155）。
3. min / soft-and / veto 这类「图像一票否决」规则能把 Test S1 推到 0.96–0.98，但 LOSO AUC 掉到 0.95 左右，且 S2 大幅下降，不能采用。
4. 这些图像视图依赖 DINOv2 缓存，提交环境无法运行，因此结果只作为研究结论，final2 仍保持纯 EEG 方案。

注意：本表的 Test 数字用 E237 折窗口的 τ 标定，故「仅 EEG」S2=0.159 与提交包的 0.2242 口径不同，横向比较只在本表内有效。

## 已知限制

1. Test 已注册接受率与未注册拒识均未达标，这是 LOSO 优先的直接代价；决赛无对抗样本，跨时段/跨设备仍需现场验证。
2. #2–#4 为冻结变换口径，偏乐观；严格 LOSO 只覆盖 #5/#6/#11。
3. 新用户注册只验证了接口与原型写入，未在 E254 上重跑「3 新用户 + 3 未注册」的识别率模拟。
4. 最差身份（7 号）的 U@95% 为 0.743，个体差异仍需处理。
