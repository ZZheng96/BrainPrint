# E177 最高 W 方案的十项门禁对照

被审计方案：**E170 三路分数融合**
`score 0.5×E65(64) + 0.1×logbp(32) + 0.4×E162(64), k=1`，接受率 a=0.88
（这是目前可信 W 的最高点）

门禁清单来源：`research/E36-E61_实验总结.md` §1「完整门禁清单（10 项）」。

## 0. 结论

| 结果 | 数量 | 项目 |
|---|---:|---|
| 达标（Train 侧代理） | 3 | #2 C、#3 macro-F1、#4 跨时间代理 |
| 未达标 | 4 | #5 pseudo-unknown AUROC、#6 U@95%、#9 S2 拒识、#10 S1 拒识 |
| 无法测量 / 结构性缺失 | 3 | #1 Train 准确率、#7 RA、#8 ASafeR |

**W 最优不等于门禁最优。** W 给 S2 接受率 0.5 权重，因此最优点偏向"多接受"；而门禁 #9 要求 S2 拒识 ≤2%（即接受 ≥98%）同时 #10 要求 S1 拒识 ≥95%，比 W 更严苛。

## 3. 门禁 #9 与 #10 的内部矛盾

两项要求同时成立意味着：

```
S2 接受 ≥ 0.98  且  S1 拒识 ≥ 0.95
```

实测所有干净分数在 Test 上的 `S1 拒识 + S2 接受` 上限约 **1.39–1.42**。
而 `0.95 + 0.98 = 1.93`，远超该上限。

E172 的 166 个候选里，`S1=0.80 时 S2` 最高只有 **0.6181**；要 S1=0.95 时 S2 仍达 0.98，需要诊断 AUC 约 **0.99**（E99 也曾独立得出同一数字）。

## 4. 结论

1. 最高 W 方案（0.7181）**只有 3 项 Train 侧门禁达标**。
2. 两项 Test 审计门禁 #9/#10 分别超 14 倍和差 27 点。
3. 对抗门禁 #7/#8 对该方案是**结构性缺失**——它没有任何对抗防御成分。
4. 即使把 W 推到 0.80，也不等于通过 10 项门禁；两者是不同的优化目标，且在现有表征上互相冲突。
5. Test 官方 AUC/F1/C/RA/ASafeR/U/Score 一律 **N/A**（无真实标签，Session 仅用于工程审计）。
