### 先做低成本可行性门槛，不直接跑五折

1. 在内层训练折研究对扰动更稳健的波形距离，例如降低 13–45 Hz 扰动频段的影响；

3. 只有方向和身份都可靠时才传播，否则保持拒识 0；

- SNR20 对抗样本配对覆盖率 **≥65%**；

- 在训练折内进行 SNR20–30 原始波形对抗训练；

**建议优先级：先检查配对扩展是否达到 65% 覆盖门槛；同时把对抗训练作为真正可能突破 RA=0.60 的主线，而不是继续微调当前传播规则。**

目前 clean 和 adversarial 样本在 Ridge 拟合中等权。建议改成：

```text

```

   - 或 margin 大幅下降；

4. 只把这些 hard examples 加入 Ridge 训练。

这样比无差别加入 6 条 untargeted 样本更可能提高 RA，同时减少对正常分布的扰动。

### 方案三：加入“未知类保护”目标

当前训练只使用已知身份的 clean/adv 样本，没有显式约束未知类边界。可以在 inner fold 中增加一个轻量保护机制：

- 用 inner unknown 样本监控 unknown F1/AUC；
- 如果某个增强比例导致 unknown AUC 下降超过阈值，则降低 adversarial 样本权重；

- adversarial 样本保持与 clean 样本相同的 identity score；

这相当于从“加入攻击样本”改为“保持 clean 与 adv 的身份预测一致”。

- robust 阈值是否偏高；

四个分量有无数种组合可以得到 `69.17`。

## 5. 当前最佳实验结果能否估算官方分数

当前最佳本地 robust 候选是上一轮 `clean:adv=1:1` 的混合对抗 Ridge，结果见 [raw_eeg_robust/report.md](file:///d:/WORK/BCIC2026/BrainPrint/research/E09_raw_eeg_robust/report.md)。

它的本地结果：

- untargeted SNR20 代理分：约 `79.64`
- untargeted SNR30 代理分：约 `90+`
- targeted SNR20 ASafeR：约 `0.919`
- 但 unknown AUC/F1 和 SNR20 RA 没有全部通过冻结验收。

这个 `79.64` **不能直接解释为官方预计 79.64 分**，原因有三点：

### 第一，本地代理分是在人工攻击上计算的

本地分数主要衡量：

- clean 身份识别；
- 人工 PGD 攻击后的恢复；
- 人工构造的 unknown 样本拒识。

官方 Test 的真实干扰类型、攻击方式和权重未知。Test 可能主要是跨 Session 漂移，而不是 PGD 攻击。

### 第二，正式提交使用了 Session 规则

第一次提交实际上是：

```text
Session1 → 0
Session2 → 任务特异身份分类
```

而 robust Ridge 候选的五折结果是在 Train 内部模拟攻击，不等价于完整 Test 提交结果。当前 robust 实验甚至没有生成可直接提交的 Test CSV。

### 第三，本地 direct 基线与第一次提交不是同一个对象

raw robust 报告里的 direct 代理分约 `47–58`，它是针对攻击样本的本地评估，不是第一次提交的官方成绩 `69.17`。因此不能用：

```text
69.17 + (79.64 - 47)
```

这样的方式推算官方成绩。这会把不同评估协议的分数错误相减。

## 6. 目前可以给出的分数估计

只能做情景估计，不能给出精确预测。

### 情景 A：仅替换模型，不保留 Session1→0

如果 robust 模型能在 Test 上保持本地的攻击恢复增益，但没有破坏跨 Session 身份识别和拒识能力，理论上可能高于第一次提交。

保守估计：

```text
约 70–76 分
```

但这是偏乐观情景，依赖一个尚未验证的假设：Test 中的主要困难与训练时 PGD 攻击相似。

### 情景 B：Test 主要是跨 Session 幅度/状态偏移

从 Test 的 raw_std 统计看，这是更现实的情景。此时对抗增强可能有一定帮助，但不一定等价于真实 Session2 漂移。

较保守估计：

```text
约 66–72 分
```

可能与第一次提交相近，也可能略低。

### 情景 C：对抗增强损害正常开集边界

当前 1:1 robust 候选已经表现出：

- unknown AUC 下降；
- unknown F1 下降；
- SNR20 RA 仍未完全达标；
- 后续 2:1 权重又导致攻击恢复能力明显下降。

如果这些趋势在真实 Test 上成立，官方成绩可能低于第一次提交：

```text
约 60–69 分
```

## 当前最合理的综合区间

结合：

- 第一次提交真实成绩 `69.17`；
- Test 明显存在跨 Session 分布偏移；
- robust 候选只在人工攻击上验证；
- robust 候选未通过冻结验收；
- unknown 指标出现损失；

我认为当前最佳候选的现实预期应放在：

> **约 65–74 分，中心估计约 69–71 分。**

不建议把 `79.64` 当作官方预期分数。它更适合作为“在特定人工攻击协议下的本地代理上限”。

## 7. 这次分析对下一步最有用的指导

下一步优先级应从“加强 PGD 防御”转向：

### 优先方向一：模拟 Test 的跨 Session 分布

Test 的显著特征是：

- amplitude 更高；
- Session2 与 Train 仍有明显统计偏移；
- Session1 的长尾更严重。

因此应在 Train 内构造类似的训练/验证协议：

```text
Train 前段 → 模拟训练
Train 后段或高幅度子集 → 模拟 Test
```

重点测：

- amplitude scaling；
- 通道级增益变化；
- 低频/高频噪声变化；
- session-level feature alignment；
- 在不使用 Session 标签的情况下的拒识。

### 优先方向二：保留第一次提交作为强基线

官方 `69.17` 已经证明第一次提交可用。任何新候选至少应满足：

- 不破坏 Session2 的身份分类；
- 不明显改变任务级类别比例；
- 不依赖正式 Test 的 Session 元数据；
- 在跨时间前推和幅度扰动验证上优于第一次方案；
- 再考虑提交。

### 优先方向三：不要继续简单增加 PGD 样本

目前实验已经说明：

- 对抗增强可以提高人工攻击下的 ASafeR；
- 但可能降低 unknown AUC/F1；
- 统一降权又会降低 RA 和 targeted ASafeR。

因此下一步更适合做**跨 Session 风格增强或 hard-example 增强**，而不是继续扩大对抗样本数量。

## 最终判断

第一次提交给出的最重要信息不是某个具体标签，而是：

> **测试集的任务比例基本稳定，但信号幅度和会话条件明显不同；Session1→0 的结构性假设大概率抓住了测试集组织方式，因此拿到 69.17，但它没有证明模型具备真正的 EEG 开集拒识能力。**

当前最佳 robust 实验有潜力，但按现有证据不能认为它会稳定超过 `69.17`。最合理的官方分数预期是 **65–74 分**，若要有较高把握超过第一次提交，应先针对 **跨 Session 分布偏移** 做验证，而不是继续围绕人工 PGD 指标优化。
