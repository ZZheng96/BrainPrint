# E170 三路融合（E65 + logbp + E162）与 W 上界分析

目标：E167 用 E65+logbp 把开放集诊断 AUC 推到 0.7999，但 W 停在 0.6997。本实验（一）加入 E162 原始 EEG embedding 做三路融合，看 AUC 能否超过 0.7999；（二）对冻结分数做 E159 式阈值扫满分析，回答「给定 AUC，W 最多能到多少」以及「要到 W=0.80 需要多少 AUC」。

协议（不可改动）：Train-only task 标准化 / PCA / 原型 / 阈值；5 块 Train OOF；LOSO 每折排除被评分身份、原型只用 fit_rows(frac≤0.6)、评估块 0.6<frac≤0.8；Test 只评分；Session 只做诊断 AUC。

Test 官方 AUC / F1：**N/A**（Test 无真实标签，Session 仅用于诊断 AUC）。

## 结论

- 三路族（拼接/分数/Train 选权）最高诊断 AUC **0.7943**（E167 0.7999，Δ -0.0056）；同网格两路对照最高 0.8008（block_norm concat 64+48 -> PCA-128 k=6），全场最高 0.8008。
- 三路族内最高 W 0.7181（E163 最好 0.7164 / E167 0.6997 / E143 0.6958），候选：score 0.5*E65(64) + 0.1*logbp(32) + 0.4*E162(64) k=1；全场最高 W 0.7181。
- 固定工作点（接受率 0.90，不用 Test 选点）三路族最高 W 0.7171（score 0.4*E65(64) + 0.1*logbp(48) + 0.5*E162(128) k=1）；上一条 0.7181 出现在接受率 0.88，属 Test 选点的乐观值。
- E143 复现：AUC 0.7578 / W@.90 0.6958（公布 0.7578 / 0.6958）。E167 AUC 复现：0.7999（公布 0.7999），W@.90 0.6721（公布 0.6721）。

## 判定

- **三路融合 AUC 是否 > 0.7999**：否，三路最好 0.7943。
- **三路融合 W 是否 > E163 0.7164**：是，最好 0.7181。

### 上界分析回答

- **a_E143_E65_PCA96_k12**（E65 PCA-96 k=12）：诊断 AUC 0.7578；扫满 2000 阈值（三者同阈值联动）最优 W **0.6972**（a=0.896，LOSO 0.813，S1 0.809，S2 0.583）；S1 拒识 0.80 时 S2 接受最高 0.5929。
- **b_E167_best_auc**（block_norm concat 64+32 -> PCA-96 k=6）：诊断 AUC 0.7999；扫满 2000 阈值（三者同阈值联动）最优 W **0.6745**（a=0.918，LOSO 0.678，S1 0.767，S2 0.627）；S1 拒识 0.80 时 S2 接受最高 0.5847。
- **c_E170_best_auc_3way_score**（score 0.5*E65(64) + 0.5*logbp(48) + 0.0*E162(32) k=12）：诊断 AUC 0.7943；扫满 2000 阈值（三者同阈值联动）最优 W **0.6691**（a=0.873，LOSO 0.796，S1 0.850，S2 0.515）；S1 拒识 0.80 时 S2 接受最高 0.5659。
- **d_E65_PCA64_k12**（E65 PCA-64 k=12）：诊断 AUC 0.7622；扫满 2000 阈值（三者同阈值联动）最优 W **0.6984**（a=0.918，LOSO 0.786，S1 0.790，S2 0.609）；S1 拒识 0.80 时 S2 接受最高 0.5956。

- **乐观上界（Test 工作点任选，LOSO 冻结在各自 .90 工作点）**：a_E143_E65_PCA96_k12: 0.7355；b_E167_best_auc: 0.7704；c_E170_best_auc_3way_score: 0.7459。
- 若把 LOSO 固定为 E143 公布的 0.7936（E159 口径），E65 单路乐观上界 0.7355（E159 公布 0.7352，误差 0.0003，说明扫满阈值的实现与 E159 一致）。
- 注：若把 LOSO 取成扫满阈值时出现的最极端值（accept→0 时 LOSO 拒识=1.0），得到的是无意义的退化上界，不作为可用工作点，故只作记录。

- **要到 W=0.80 需要多少 AUC**：固定 LOSO=0.7936（E143 工作点）、S1 拒识=0.80，则需 S2 接受 0.8032；binormal ROC 反解 **AUC ≈ 0.8846**。若 LOSO 用实测最好的 .90 工作点 0.8412，需 S2=0.7794，对应 AUC ≈ 0.8728。

- 结论：四个冻结分数扫满阈值（三指标联动）的最优 W 在 0.6691–0.6984 之间，最优者是 d_E65_PCA64_k12；其中 AUC 0.7999 的那个分数只有 0.6745（低于 E143 的 0.6972），说明 logbp 带来的 AUC 提升集中在 ROC 尾部，而不是 S1=.80 / S2 工作点上。距 0.80 至少差 0.1016；即便 Test 工作点任选、LOSO 冻结在 .90，乐观上界也只有 0.7704。瓶颈是 S1/S2 的排序（AUC 与工作点形状），不是阈值校准。
