## 结论：图像化路线全量审计 —— 全线劣于纯 EEG

这是图像化路线第一次在**统一、无污染的协议**下被全量测量（E141/E145 只测了 7 个冻结嵌入，且 LOSO 被污染；E62/E20 的旧数字来自不同探针与不同口径，不可横向比较）。

### 1. 可部署的图像类型只有 7 类，另 4 类不可用

| 状态 | 类型 |
|---|---|
| Train + Test 都有（可用） | correlation、covariance5、covariance_hr、topomap5、multiwindow_corr8、multiwindow_cov4、multiwindow_cov8 |
| 只有 Train（**不可用**） | gaf、mtf、spectrogram、topomap（旧版）、correlation_tokens、topomap_tokens、covariance5_**dinov3b16** |

E70 的 GAF / MTF / 频谱图 / DINOv3 全部只有 Train 缓存，**无法用于 Test**，此前的相关工作对最终提交没有贡献。

### 4. 三条硬结论

1. **没有任何图像化表征超过纯 EEG。** 基线 B_only 是 AUC 0.7578 / W **0.6958**；图像化最好的单视图是 X_mw_cov4（AUC 0.7347 / W 0.6080）。AUC 差 0.023，W 差 **0.088**。
2. **DINOv2 编码器没有带来任何增益。** 像素空间与冻结嵌入几乎等价（X_mw_cov4 0.7347 vs D_mw_cov4 0.7206；X_covariance5 0.7166 vs D_covariance5 0.7223）。在这个任务上，冻结的 DINOv2 只是图像像素的一个近可逆变换，**没有引入新的身份信息**。这否定了"通用视觉大模型能提取 EEG 身份线索"的整个前提。
3. **只要融合，W 就崩。** IMG_dino_all 的 AUC 0.7625 但 W 只有 0.3640；IMG_all 0.7701 / 0.3578；B_plus_IMG_dino 0.7765 / 0.4014。机制仍是 E142/E145 发现的：融合后分数偏移更严重，LOSO 与 S1 双降。

### 5. 与历史图像化结论的对照

| 来源 | 口径 | 结果 |
|---|---|---|
| E20D（历史） | Train 内伪未知 | covariance5 图像 C 0.9294 / U 0.4323 / AUROC 0.910 |
| E26–E32（历史） | Test AUROC(S2 vs S1) | 0.7576 → 0.7403，最佳工作点 S2 0.894 / S1 0.506 |
| E62（历史） | Test AUROC(S2 vs S1) | multiwindow 只有 0.40–0.47 |
| E67（历史） | 5 折合规迁移 | L1 频带功率 0.3869、L2 log 协方差 0.4911（均随机） |
| **本实验（统一协议）** | Test AUC + LOSO + S1 + S2 | 图像化最好 W 0.6080，基线 0.6958 |

历史结论与本实验一致：图像化在 Train 内看起来很好（伪未知 AUROC 0.91–0.99），一旦跨会话就掉到 0.70–0.76；E67 的 5 折合规迁移甚至只有 0.39–0.49。

### 6. 结论

**图像化路线（含 DINOv2 冻结骨干、多窗口图像、拓扑图、像素空间）在当前数据上全面劣于纯 EEG correlation-logSPD，且融合会进一步恶化 W。** 该路线可以正式关闭，不再作为主线。
