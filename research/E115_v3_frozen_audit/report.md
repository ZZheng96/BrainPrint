## 结论：S2 接受率没有保持，V3 在 Test 上失败

| 方案 | LOSO 拒识 | Test S1 拒识 | Test S2 接受 |
|---|---:|---:|---:|
| E95（高 S2 基线） | 0.157 | 0.1543 | **0.9414** |
| E102 SPD ratio | 0.831 | **0.8427** | 0.2873 |
| E113b 微调+cosine | 0.843 | — | — |
| **E115 V3（冻结审计）** | **0.886** | 0.5783 | **0.4668** |

**V3 的 LOSO 0.886 完全没有转化为 Test 表现**：

- S1 拒识只有 **0.5783**，比 E102 的 0.8427 低 26 个百分点
- S2 接受只有 **0.4668**，比 E95 的 0.9414 低 47 个百分点
- 两项都远未达标，且 S2 严重退化

## 为什么 LOSO 0.886 会崩到 Test 0.578

1. **LOSO 的留出身份仍在同一 Session（session1）内**。微调时编码器见过该身份的其他 trial（只是不在 fit 块），所以留出身份的嵌入仍落在"熟悉"的区域。Test 的未注册者来自完全不同的采集批次，分布差异大得多。

2. **微调让编码器对 19 个注册身份过拟合**。8 epoch 后 loss 从 0.386 降到 0.232，编码器把注册身份压得很紧，导致 Test 上所有样本（包括注册者）都离原型很远——这正是 S2 接受率崩到 0.47 的原因。

3. **多原型放大了这个问题**。3 个 k-means 中心让每个身份的覆盖范围更窄，Test 的跨 Session 偏移使注册者样本落在所有子模式之外。

## 与 E107 的结论一致

E107 已定量证明 LOSO 代理会高估 Test 0.33–0.40 AUC。V3 是又一个例证：LOSO 0.886 → Test S1 0.578，高估 0.31。

**关键教训**：LOSO 只能验证"模型是否学到了身份判别结构"，不能验证"跨 Session 泛化"。任何在 session1 内部做的微调，都会因为过拟合 session1 而在 Test 上退化。要真正提升 Test S1，必须解决跨 Session 域偏移，而不是在 session1 内部做更强的拟合。
