## 2. 证据等级与阅读规则

后续复用旧结果时采用以下口径：

- **A 级：有标签、未参与调参的独立验证。**当前非常稀缺；同 Session 时间隔离属于有限证据，不等于跨 Session。
- **B 级：有标签但参与过模型/规则选择的开发结果。**可说明方向潜力，不能作为最终泛化证明。
- **C 级：官方 Test 无标签诊断。**预测分布、候选一致率、配对一致率、伪真值共识均不属于准确率。
- **D 级：官方综合分。**是真实提交反馈，但若无分项，无法定位收益或损失来自 C、A 还是 U。

所有 AUC 默认指未知身份 AUROC；F1 必须注明是未知类 F1、注册身份 macro-F1 还是 21 类 macro-F1。原报告没有计算时写 N/A，不事后捏造。

## 3. E00：协方差 Ridge 与任务特异融合

### 3.1 可信的积极发现

1. **空间—频率协方差是有效身份表征。**早期块保留实验中，PSD 正常识别率为 98.63%、未知 AUROC 为 0.9767；对数协方差达到 100.00% 和 0.9992。该证据限于同 Session，但足以支持协方差作为后续基线。
2. **强正则线性模型适合当前小样本高维设置。**Ridge `alpha=100` 的时间前推正常准确率为 99.7296%，优于过大正则；Logistic、RBF-SVM 和硬容量分配均未稳定超过 Ridge。
3. **纯 EEG 开放集拒识有可行起点。**留被试 17–20 作伪未知时，max-logit AUROC 为 **0.99751**，margin AUROC 为 **0.99579**；95% 已知接受率下，二者未知拒识率分别为 **0.99516** 和 **0.99824**。该实验的未知类 F1 为 **N/A（原报告未计算）**。
4. **双 2 秒窗口与完整 4 秒具有互补性。**它们降低了部分同 Session 时间块错误，但不同聚合规则在块外推和前推之间并不一致，不能只看单个协议。
5. **误判不全是明显伪迹。**部分错误具有正常质量指标，且局部近邻支持真实身份而全局 Ridge 判错，说明仅做质量剔除或提高全局模型复杂度不够。

关键原始结果见[E00 前推验证](file:///d:/WORK/BCIC2026/BrainPrint/research/E00_cov_ridge_baseline/baseline_ridge_cov_forward.json)和[E00 总实验记录](file:///d:/WORK/BCIC2026/BrainPrint/research/brainprint_research_and_experiments.md)。

### 3.2 被否定或未被支持的路线

- PCA + KMeans 硬聚类明显低于直接 Ridge；白化后更差。
- 精确类别配额的匈牙利分配不适合真实身份比例未知的测试集。
- PSD + 协方差全特征、全局功率归一化未改善两个主要协议。
- 类条件对角高斯、单独原型距离或全频段 top-k 近邻不足以替换 Ridge。
- 低频近邻对少数错误有互补性，但单独分类很弱，简单全局权重和逐身份校准都未稳定超越基线。
- `alpha=1000` 并未带来更好鲁棒性，说明“正则越大越稳”不成立。

### 3.3 四协议 100% 的正确解释

E00 最终任务特异规则在块外推、时间前推、反向留段和中间留段合计报告 **18,114/18,114 正确**，对应准确率与闭集 macro-F1 均为 1.0；未知 AUC/F1、RA、ASafeR、U 在该闭集验收中为 **N/A**。

但这个 100% 不能作为独立泛化证据，原因包括：

- 前三套协议参与任务权重、Sinkhorn 温度和 EC 门控阈值选择；
- 规则是在观察具体错误后逐步设计的；
- 全部数据来自同一 Session；
- 验证为闭集，没有未知身份和真实对抗样本；
- Sinkhorn、测试批次 z-score 和图融合依赖整批或测试结构。

第三轮任务特异融合曾在双协议达到 100%，随后反向留段立即出现 2 条错误；这是“开发协议满分不等于新协议泛化”的直接反例。

### 3.4 第 1 次官方成绩的经验

第 1 次正式文件与 E00 第四轮 guarded 候选一致。69.17 表明完整提交具有一定有效性，但不能把成绩归功于 EEG 开放集能力：3,033 条标签 0 全部由 Session 规则直接产生。后续必须保留其协方差特征经验，同时放弃元数据拒识。

## 5. 跨实验得到的核心经验

### 5.1 闭集可分性已经很强，开集校准才是瓶颈

E00、E02、E06 多次得到接近 100% 的拒识前闭集准确率，但加入阈值后 C 常降至 0.93–0.97；在官方 Test 上又出现 79%–95% 的异常高拒识。说明“20 人能否分开”和“能否判断是不是这 20 人”是不同问题。

后续必须同时看拒识前 C、拒识后 C、已知接受率、U、未知 AUROC 和 unknown-F1。只看其中一个指标会掩盖大量误拒或误接受。

### 5.2 AUROC 高不代表阈值可部署

AUROC 只衡量排序，不保证不同被试折、不同 Session、不同身份数量下的分数尺度一致。E02/E03 的内部 AUROC 约 0.99，Test 却大量误拒；E11 的第 3 次官方低分进一步说明这一风险不是理论问题。

阈值必须在内层 pseudo-unknown 上标定，并在完全独立的外层被试上报告。校准集、阈值选择集和最终 U 评估集不能混用。

### 5.3 同 Session 时间验证不能替代跨 Session 验证

前推、反向、中间留段和连续块 OOF 能发现时间漂移与规则过拟合，但所有训练 Trial 仍来自 Session1。EA、RPA、z-score、Sinkhorn 或预测一致性都不能补充缺失的真实 Session2 身份标签。

因此，旧实验没有任何一项能够直接证明跨天 C、RA 或 U。后续只能写“Session 模拟增强/同 Session 跨时间验证”，直到获得真实第二 Session 标签或现场数据。

### 5.4 输出一致性不是身份正确率

高相似图融合可让组内标签一致率达到 100%，候选共识也可产生很漂亮的伪真值指标，但这些都可能把同一错误复制到更多样本。E07 还显示图均值会混合身份并降低 C。

只可使用一致性发现风险，不能用其替代 RA、C 或真实标签 F1。正式方案不再依赖近重复配对。

### 5.5 ASafeR 提高可能只是因为拒识增多

对抗样本被拒识会增加 ASafeR，却不增加 RA。E02、E07、E09 都显示：安全率很高时，原身份恢复仍可能很差。全部拒识甚至会使 RA=0。

防御比较必须同时报告 RA、ASafeR 和已知接受率，不能仅凭 ASafeR 或综合代理分宣称鲁棒。

### 5.6 raw-PGD 有收益，但当前仍未过门禁

E09 证明 raw 对抗训练相对 direct 能显著提高攻击下表现，随机 targeted 与 1:1 权重比简单降低对抗权重更好；但 SNR20 RA 最高代表值仍只有 0.4541，并伴随 unknown AUC/F1 下降。

可复用的是 raw 攻击、嵌套评估和针对性增强思路，不能把某个本地场景换算分当作提交依据。后续必须重新验证 adaptive attack、C/U 损失和最差折表现。

### 5.7 复杂后处理经常只增加假设，不增加泛化

以下路线均未形成稳定、可部署收益：硬聚类、硬类别配额、复杂任务融合、ASNorm、EA/RPA、图均值、理想配对、Sinkhorn、逐被试补丁和伪真值共识。

后续采用“简单 full/base 基线 + 单因素消融 + 冻结门禁”。新增组件只有在独立外层综合分和最差折均改善时才保留。

### 5.8 官方总分不能反推分项或构造真值

第 1/2/3 次官方分为 69.17、67.94、26.10。没有分项时，不能确定第 2 次下降具体来自 C、RA、ASafeR 还是 U，也不能用第 1 次标签作为 Test 真值来训练或校准。

本地 Score、Score_proxy、场景换算分和 pseudo-ground-truth F1 必须始终与官方成绩分栏记录。

## 6. 可保留与应停止的清单

### 可保留

- 多频带 log-covariance/SPD 与强正则 Ridge 的 full/base 基线；
- 完整 4 秒与双窗口的简单比较，不预设复杂融合更好；
- 连续时间块和正反向留段，用于同 Session 时间稳定性检查；
- 外层留被试、内层校准的嵌套开放集协议；
- unknown AUROC/AUPR、unknown-F1、身份 macro-F1 与按被试 bootstrap；
- raw-EEG untargeted/targeted 攻击及对抗训练研究；
- 失败候选、配置和哈希归档，避免重复走弯路。

### 应停止

- `Session1 → 0` 及一切由 Session、路径、顺序或样本数量决定身份的规则；
- 用真实 clean–attack 配对、真实类别先验或 Test 伪标签计算“可部署”指标；
- 用高相似图、Sinkhorn 或批次 z-score 包装严格单样本模型；
- 根据同一批外层错误反复调整任务权重和门控阈值后继续称其独立验证；
- 把 Test 拒识率称为 U，把 margin 分类 AUC 称为未知 AUROC，把代理分称为官方分；
- 在 RA、C、U 明显不达标时继续堆叠防御组件或生成新提交。

## 7. 总结判断

1. **当前最高分方案是 E00 第四轮，不是纯 EEG 开集方案。**其 69.17 无法证明真实未知拒识能力。
2. **纯 EEG 内部研究已有可用基础。**协方差 full/base、嵌套留被试和 raw-PGD 都值得保留，但不能直接沿用旧阈值。
3. **当前尚没有证据充分、可替代第 1 次成绩的纯 EEG 提交。**E02 阈值迁移失败，E09 未过对抗门禁，E11 第 3 次官方仅 26.10。
4. 下一阶段应集中解决**跨分布置信度校准、独立开放集验证和 raw 对抗下的原身份恢复**，而不是继续挖掘 Session 或测试排列结构。
