# 无 Session 依赖脑纹识别方案：设计与执行规范

## 1. 目标

构建一个真正不依赖 Session 的脑纹识别系统，同时解决三个必须分开评估的问题：

1. **已注册身份区分**：正常 EEG 上识别正确注册身份；
2. **已注册身份抗干扰**：受到噪声、伪迹、波形扰动后，优先恢复原身份，而不是把已注册人员大量拒识；
3. **未注册身份拒识**：对注册库之外的身份输出 `0`，避免误认证为 1–20。

Test 推理阶段只允许使用 EEG 特征和 `task`，禁止使用 `session`、`trial`、`path`、Test 标签、Test 批次统计和 Test 样本间配对关系。

## 2. Test 分布约束

Test 共 22,251 条：Session1 为 3,033 条，Session2 为 19,218 条；赛题说明明确 Session2 为已注册人员。因此：

- Session2 大量输出 `0` 代表已注册身份误拒识；
- Session1/Session2 只能在候选生成后做离线审计，不能参与推理；
- 不按 Session 设置阈值；
- 不以“拒识越多越安全”为目标；
- 候选应避免 Session2 出现 70%–80% 的拒识；
- 总拒识率、任务拒识率和 Session1/Session2 拒识差异必须报告；
- Test 无标签，审计拒识率不能当作真实 U、C、AUC 或 F1。

## 3. 模型结构

### 3.1 身份结构分支

输入多频带 EEG 特征、log-covariance、相关矩阵、相对频带功率，以及 4 秒完整窗口和两个 2 秒窗口，输出 128 维归一化身份 embedding。

目标是学习跨 Trial、跨任务的身份结构，而不是记忆单个 Session 的幅度或整体分布。

### 3.2 原始 EEG 鲁棒分支

使用小型多尺度 temporal CNN 和空间卷积，采用 LayerNorm/GroupNorm，不使用推理批次统计。训练加入通道增益变化、基线漂移、带限噪声、通道丢失、瞬态伪迹和 raw-EEG PGD。

扰动后的已注册样本仍使用原身份标签，不得统一标为未知。

### 3.3 多原型身份库

每个身份按任务和训练块保存固定数量原型，所有身份原型数量一致。使用归一化余弦相似度和 top-k 原型聚合：

\[
S_y(x)=\operatorname{TopKMean}(\cos(e(x),p_{y,k}))
\]

最终身份为得分最高的注册身份。

### 3.4 独立开集证据头

开集证据由以下信息共同决定：

- top-1 相似度；
- top-1/top-2 间隔；
- 类内原型一致性；
- 完整窗口与子窗口一致性；
- 身份分支与鲁棒分支的一致性；
- 原型距离；
- 单样本信号质量。

质量只能用于有界降权，不能直接把低质量样本判为未知。

\[
\hat y=\begin{cases}
\arg\max_y S_y(x), & g(x)\ge\tau\\
0, & g(x)<\tau
\end{cases}
\]

## 4. 训练目标

\[
L=L_{id}+\lambda_1L_{contrast}+\lambda_2L_{consistency}+\lambda_3L_{adv}+\lambda_4L_{open}
\]

- `L_id`：身份分类损失；
- `L_contrast`：同身份不同 Trial/任务拉近、异身份拉远；
- `L_consistency`：自然增强前后身份保持一致；
- `L_adv`：原始 EEG 扰动后恢复原身份；
- `L_open`：episode 中排除部分训练身份，模拟未注册身份。

## 5. 严格实验协议

### 5.1 外层五折

按 subject 留出身份。外层留出的身份完全作为伪未知，不能进入表征、原型、标准化、开集头或阈值拟合。

### 5.2 内层校准

在外层训练集内进一步划分伪未知身份和已知留出 Trial。模型、开集证据头、融合权重和阈值只能由内层数据确定。阈值必须来自独立 OOF 预测，禁止用训练拟合样本自身分数。

### 5.3 三类评估面板

**已注册身份**：closed-set accuracy、C、known acceptance、known FRR、macro-F1、最差身份 C。

**抗干扰**：RA、ASafeR、A、attack FAR、clean C、robust C；报告非定向/定向和 SNR20/SNR30。

**未注册身份**：U、unknown FAR、unknown AUC、unknown F1、U@95% known acceptance、U@98% known acceptance。

官方公式代理分仅在 C、RA、ASafeR、U 都来自同一严格协议时计算：

\[
A=0.7RA+0.3ASafeR,\quad Score=100C^{0.40}A^{0.35}U^{0.25}
\]

### 5.4 必须报告各组结果

报告每折、每任务、每身份聚类统计，不能只给总体平均。Test 只报告无标签输出审计，不计算 Test AUC/F1/C/U。

## 6. 研发目标

首轮目标不是用手工比例压低拒识，而是同时满足：

- clean C ≥ 0.96；
- known acceptance ≥ 0.95；
- 非定向 SNR20 RA ≥ 0.55、ASafeR ≥ 0.95；
- 定向 SNR20 RA ≥ 0.45、ASafeR ≥ 0.85；
- unknown AUC ≥ 0.98；
- unknown F1 ≥ 0.94；
- U@95% known acceptance ≥ 0.90；
- Test 总拒识率目标 ≤ 25%；
- Test Session1/Session2 拒识率差异目标 ≤ 5 个百分点。

这些是研发验收目标，不是预先保证的结果；若无法同时满足，报告真实权衡并继续改进，不通过人工修改 Test 结果伪造达标。

## 7. 执行顺序

1. 实现单样本、无 Session 的多视角 embedding 和原型匹配；
2. 加入原始 EEG 鲁棒训练与多种自然扰动；
3. 加入 episode 式未知身份训练和独立开集证据头；
4. 运行严格 GPU 五折评估；
5. 按三类面板报告指标；
6. 用全量 Train 固定模型和阈值；
7. 生成无 Session Test 候选；
8. 进行 Session/任务分布离线审计；
9. 将代码、指标、报告和候选文件放在本实验目录，不覆盖历史提交。
