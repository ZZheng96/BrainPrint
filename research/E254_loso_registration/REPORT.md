# E254：以注册匹配度为核心的严格 LOSO 方案

## 结论

本轮把拒识从「最近邻欧氏距离阈值」改成「注册模板匹配度 + 歧义度」的联合门控，并把身份排序统一到同一套 LDA-cos 几何上。严格嵌套身份 LOSO 的三项核心门禁首次同时达标：

| 指标 | 目标 | E200/final | E253/final2 旧版 | E254（本版） |
|---|---:|---:|---:|---:|
| #5 严格 LOSO pseudo-unknown AUROC | ≥ 0.98 | 0.7920 | 0.7920 | **0.9871** |
| #6 严格 LOSO U@95% | ≥ 0.95 | 0.1758 | 0.1758 | **0.9522** |
| #11 严格 LOSO 未注册拒识 @ a=0.90 | > 0.90 | 0.2947 | 0.2947 | **0.9869** |

AUC 与 F1：严格 LOSO AUC = 0.9871；5 折 OOF 20 类 macro-F1 = 0.9988；拒识 F1（unknown-positive，按 LOSO 汇总）随工作点变化，见 `results/loso_nested.json`。

## 方法

```text
18×1200 → 6×200 子窗 → 5 频带相关 logSPD → 855 维 → 子窗均值
→ 按任务 z-score → PCA-256 → 类内白化（shrink 0.95）
→ 每身份每任务 k=4 个试次顺序原型 → 白化余弦匹配
→ s1, s2 → gate = s1 + 0.5*(s1 - s2) → gate < τ 判未注册
```

关键变化：

1. **注册**：每身份注册 4 个原型而不是 1 个均值，把类内变化（试次顺序块）也纳入注册模板。
2. **匹配**：排序与拒识共用同一白化余弦几何，不再出现「排序用余弦、拒识用欧氏」的双空间割裂。
3. **拒识**：显式使用绝对匹配度 `s1` 和歧义度 `s1-s2`，而不是「先找最近原型、再拿距离比阈值」。这正是「匹配度分数 + 是否足够匹配」的判决方式。
4. **阈值**：`τ = 0.407559`，Train 交叉拟合真实样本 gate 分数的 10% 分位（90% 接受率），不使用 Test。

## 严格嵌套 LOSO 协议

- 外层 20 折，留出身份完全不参与任务标准化、PCA、白化、原型、阈值。
- 外层训练池内再做 19 折身份留出，用于内层选择配置（共 380 个内层折）。
- 原型只用 `frac ≤ 0.4` 拟合、校准用 `0.4 < frac ≤ 0.6`、评估用 `frac > 0.6`，查询不进入自己的原型。
- 候选网格预先固定：dim ∈ {192, 256}、shrink ∈ {0.9, 0.95}、k ∈ {3, 4}、beta ∈ {0, 0.5}。

内层选择结果：17/20 折选 `d256_s0.95_k4_b0.5`，2 折选 `d192_s0.95_k4_b0.5`，1 折选 `d256_s0.9_k4_b0.5`。

外层汇总：

| 指标 | 均值 | 最差单身份 |
|---|---:|---:|
| AUROC | 0.9871 | 0.9588（7 号） |
| U@95% | 0.9522 | 0.7432（7 号） |
| 未注册拒识 @ a=0.90 | 0.9869 | 0.8682（7 号） |

7 号身份是唯一明显偏弱的折，其余 19 折 U@95% 均在 0.89 以上。

## Test 一次性审计（模型冻结后）

| 指标 | E200 | E253 旧版 | E254 |
|---|---:|---:|---:|
| 已注册接受率 | 0.7069 | 0.6972 | 0.2242 |
| 已注册 top-1（接受样本内） | 0.5285 | 0.5879 | **0.9306** |
| 已注册端到端准确率 | 0.3745 | 0.4099 | 0.2086 |
| 未注册拒识率 | 0.7108 | 0.7227 | 0.5918 |

Test 分数分布（冻结模型）：

| 分组 | s1 的 10/25/50/75/90 分位 |
|---|---|
| Test 已注册 | 0.153 / 0.180 / 0.223 / 0.290 / 0.403 |
| Test 未注册 | 0.148 / 0.171 / 0.219 / 0.611 / 0.668 |

已注册与未注册的 s1 中位数几乎相同（0.223 vs 0.219），未注册在 75 分位以上反而更高；因此在初赛 Test 上，任何基于该绝对分数的门控都无法同时做到「接受大多数已注册」和「拒绝未注册」。

## 为什么 LOSO 达标与 Test 接受率冲突

这不是阈值没调好，而是两类未知的分布不同：

- Train LOSO 的 pseudo-unknown 与已注册身份同 session、同设备，欧氏距离重叠严重（E253 实测 #11 = 0.295）；白化余弦能把它们分开（#11 = 0.987）。
- 初赛 Test 的已注册样本跨 session 且含对抗扰动，白化把 session 相关方向放大，导致所有已注册分数整体下移；而未注册样本中有一部分反而更贴近原型。排序仍正确（接受样本 top-1 0.931），但绝对分数不再可比。

同一 Test 上，欧氏拒识能接受 0.70 已注册样本，却在严格 LOSO 上只有 0.29 拒识率。两者不可兼得，本轮按用户给定的优先级选择 LOSO。

为压缩这个冲突，额外验证了四种**只依赖单条 query 自身分数结构**的门控（abs / relz / gapz / soft），它们都不使用批次统计量：

| 门控 | LOSO AUROC | U@95% | rej90 | Test 接受率 |
|---|---:|---:|---:|---:|
| abs（采用） | 0.9870 | 0.9518 | 0.9869 | 0.173* |
| relz | 0.9821 | 0.9200 | 0.9718 | 0.282* |
| gapz | 0.9788 | 0.9156 | 0.9779 | 0.205* |
| soft | 0.9865 | 0.9505 | 0.9887 | 0.170* |
| 欧氏（对照） | 0.8720 | 0.3264 | 0.5279 | — |

\* 该列用 Train 汇总 10% 分位作阈值；部署包用 0.407559，得到 0.2242。

还测试了「欧氏分支 + 相对分数保护」的双分支门控：可以恢复部分 Test 接受率，但 LOSO 未注册拒识降到 0（pseudo-unknown 大量通过欧氏分支）。

## 已知限制

1. Test 已注册接受率与未注册拒识均未达标，这是 LOSO 优先的直接代价；决赛无对抗样本，跨时段/跨设备仍需现场验证。
2. #2–#4 为冻结变换口径，偏乐观；严格 LOSO 只覆盖 #5/#6/#11。
3. 新用户注册只验证了接口与原型写入，未在 E254 上重跑「3 新用户 + 3 未注册」的识别率模拟。
4. 最差身份（7 号）的 U@95% 为 0.743，个体差异仍需处理。
